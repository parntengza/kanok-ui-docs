ใน web component ข้อความ label คือเนื้อหาข้างใน element ส่วนใน React + Tailwind คือ prop label import checkbox-group เฉพาะเมื่อใช้กลุ่ม

Checkbox เดี่ยว

  • checked คือสถานะ event change ยิงเมื่อผู้ใช้ติ๊กหรือเอาติ๊กออก
  • ช่องที่ติ๊กไว้จะส่ง value (ค่าเริ่มต้นคือ on) ภายใต้ name ช่องที่ไม่ติ๊กไม่ส่งอะไร
  • required ทำให้ส่งฟอร์มไม่ได้จนกว่าจะติ๊ก เช่น การยอมรับเงื่อนไข

กลุ่มของ checkbox

ui-checkbox-group ใส่ label ให้ checkbox ทั้งชุดและถูกอ่านเป็นกลุ่มเดียว

  • required หมายถึง "อย่างน้อยหนึ่งช่อง" ส่งฟอร์มไม่ได้จนกว่าจะติ๊กสักช่อง
  • orientation="horizontal" เรียง checkbox เป็นแถวแนวนอน
  • disabled และ readonly มีผลกับทุกช่อง โดยไม่ทับค่าที่ตั้งไว้ในแต่ละช่อง
  • แต่ละ checkbox ยังส่ง name และ value ของตัวเอง จึงอ่านด้วย FormData.getAll()

Indeterminate

indeterminate แสดงขีดแทนเครื่องหมายถูก ใช้กับ checkbox แม่ที่ checkbox ลูกถูกติ๊กไว้บางส่วน การคลิกครั้งถัดไปของผู้ใช้จะล้างสถานะนี้ โค้ดของคุณต้องคอยปรับ checkbox แม่ให้ตรงกับลูกเอง

Accessibility

  • แต่ละช่องเป็น checkbox จริงอยู่ใน <label> คลิกได้ทั้งแถว และ screen reader ได้ยินสถานะรวมถึง "mixed"
  • ui-checkbox-group เป็น role="group" ที่ใช้ label เป็นชื่อ ข้อความช่วยเหลือ คำเตือน หรือ error เป็นคำอธิบายของกลุ่ม และทุกช่องจะทวน error ของกลุ่ม จึงได้ยินตั้งแต่ช่องแรก
  • อย่าใช้ checkbox กับการตั้งค่าที่มีผลทันที ให้ใช้ Toggle

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Checkbox
