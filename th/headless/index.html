Headless

@purpurabog/ui/headless คือพฤติกรรมของ component โดยไม่มีหน้าตา เป็นชิ้นส่วน React ที่ให้คีย์บอร์ด โฟกัส ARIA การวาง popup และการส่งค่าไปกับฟอร์มแบบ Carbon แต่ไม่ render class เลยสักตัว markup, label, ข้อความ และ style ทั้งหมดเป็นของคุณ

component แบบ React + Tailwind สร้างอยู่บนชิ้นส่วนเหล่านี้ ทั้งสองแบบจึงทำงานเหมือนกัน

Headless หรือ React + Tailwind

ใช้ เมื่อ
React + Tailwind อยากได้หน้าตาแบบ Carbon แล้วแก้ได้ทีละบรรทัด เริ่มจากช่องที่เสร็จแล้ว มีทั้ง label ข้อความช่วยเหลือ error และขนาด
Headless มี design system ของตัวเอง หรือ layout ที่ component ของ Carbon ใส่ไม่ลง คุณประกอบช่องเองรอบชิ้นส่วนเหล่านี้

ติดตั้ง

npm i @purpurabog/ui react react-dom

import ชิ้นส่วนจาก @purpurabog/ui/headless แต่ละ component เป็น namespace ของชิ้นส่วน (Dropdown.Root, Dropdown.Trigger, …) ไม่ต้องโหลด token เพราะชิ้นส่วนไม่มีสีของตัวเอง

component ตัวแรก

import { useState } from 'react'; import { Dropdown } from '@purpurabog/ui/headless'; const types = [ { value: 'sale', label: 'ซื้อขาย' }, { value: 'lease', label: 'เช่า' }, ]; export default function Example() { const [type, setType] = useState(''); return ( <div className="grid max-w-xs gap-2"> <Dropdown.Root items={types} name="type" onValueChange={setType}> <Dropdown.Label className="text-xs text-ink-muted">ประเภทสัญญา</Dropdown.Label> <Dropdown.Trigger className="group flex h-10 items-center justify-between border-b border-border-strong-1 bg-field-1 px-4 text-left text-sm text-ink hover:bg-field-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-open:outline-2 data-open:-outline-offset-2 data-open:outline-focus"> <Dropdown.Value placeholder="เลือกประเภท" className="data-placeholder:text-ink-placeholder" /> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current group-data-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Dropdown.Trigger> <Dropdown.Popup className="bg-layer-1 text-sm shadow-lg"> {types.map((t) => ( <Dropdown.Option key={t.value} value={t.value} className="flex h-10 cursor-pointer items-center px-4 text-ink-muted hover:bg-layer-hover-1 data-highlighted:bg-layer-hover-1 data-selected:bg-layer-selected-1 data-selected:text-ink" > {t.label} </Dropdown.Option> ))} </Dropdown.Popup> </Dropdown.Root> <p className="text-xs text-ink-muted">ค่า: {type}</p> </div> ); }

Root เก็บสถานะและส่ง name ไปกับฟอร์ม Trigger รับคีย์บอร์ด และมี role กับ aria-* ครบ Popup เปิดใน top layer และพลิกด้านเองเมื่อที่ไม่พอ

popup ทุกตัว ทั้ง headless และแบบอื่น ใช้ตัววางตำแหน่งเดียวกัน (@purpurabog/ui/core): พลิกไปอีกด้านเมื่อที่ไม่พอและอยู่ด้านนั้นตลอดที่เปิด (ไม่กระโดดกลับระหว่างเลื่อน) เลื่อนไปตามแนวของปุ่มเปิดเพื่อให้อยู่ในจอแต่ไม่หลุดจากปุ่ม ซ่อนตัวเมื่อปุ่มเปิดถูกเลื่อนออกไปนอกสายตา วัดจากส่วนของจอที่มองเห็นจริง (คีย์บอร์ดบนจอ การซูม) และวางตรงพิกเซลเต็ม รายการหรือเมนูยังได้ --ui-available-height คือพื้นที่ที่เหลือด้านนั้น เรียก setAnchorPositioning(true) จาก @purpurabog/ui/core เพื่อเปิดใช้ CSS anchor positioning ในเบราว์เซอร์ที่รองรับ ตำแหน่งของ popup จะถูกเขียนเป็น anchor() เบราว์เซอร์จึงพา popup ไปกับปุ่มเปิดเองขณะกล่องรอบ ๆ เลื่อน ค่าเริ่มต้นปิดไว้ เพราะใน body ของ modal ที่เลื่อนได้หรือใน submenu Chromium ยังวาง popup ห่างจากตำแหน่งของตัววางตำแหน่งไปไม่กี่พิกเซล

แต่งด้วย attribute data-*

แต่ละชิ้นส่วนแสดงสถานะเป็น attribute data-* ซึ่งมีเมื่อเป็นจริงและไม่มีเมื่อไม่จริง แต่งด้วย variant data-*: ของ Tailwind หรือ [data-open] ใน CSS ก็ได้:

import { Dropdown } from '@purpurabog/ui/headless'; const fruits = [ { value: 'apple', label: 'แอปเปิล' }, { value: 'mango', label: 'มะม่วง' }, { value: 'durian', label: 'ทุเรียน' }, ]; export default function Example() { return ( <div className="grid max-w-xs gap-2"> <Dropdown.Root items={fruits} name="fruit"> <Dropdown.Label className="text-xs text-ink-muted">ผลไม้</Dropdown.Label> <Dropdown.Trigger className="flex h-10 items-center border-b border-border-strong-1 bg-field-1 px-4 text-left text-sm text-ink hover:bg-field-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-open:outline-2 data-open:-outline-offset-2 data-open:outline-focus data-placeholder:text-ink-placeholder"> <Dropdown.Value placeholder="เลือก" /> </Dropdown.Trigger> <Dropdown.Popup className="bg-layer-1 text-sm shadow-lg"> {fruits.map((f) => ( <Dropdown.Option key={f.value} value={f.value} className="flex h-10 cursor-pointer items-center px-4 text-ink-muted data-highlighted:bg-layer-hover-1 data-selected:font-semibold data-selected:text-ink" > {f.label} </Dropdown.Option> ))} </Dropdown.Popup> </Dropdown.Root> </div> ); }
Attribute ความหมาย
data-open popup เมนู หรือแผงเปิดอยู่ (อยู่บนทั้ง trigger และ popup)
data-highlighted แถวที่คีย์บอร์ดชี้อยู่ในรายการ
data-selected, data-checked, data-mixed เลือกอยู่, ติ๊กอยู่, เลือกบางส่วน (Select all)
data-disabled, data-readonly, data-invalid สถานะของช่อง
data-placeholder ยังไม่ได้เลือกค่า
data-expanded, data-closing ขยายอยู่, กำลังเลื่อนออก (ใช้ทำ animation ตอนปิด)
data-side ด้านที่ popup ไปอยู่จริงหลังพลิก: top, bottom, left, right

หน้าของแต่ละ component มีรายการ attribute ของทุกชิ้นส่วน

ทำตัวสลับธีมเอง

headless ไม่มีตัวสลับธีม แต่ useThemeMode ให้สิ่งเดียวกับที่ <ui-theme-switcher> เก็บไว้ คุณจึงวาดปุ่มแบบไหนก็ได้ hook คืน mode (light, dark หรือ system) และฟังก์ชันที่แสดง จำ และประกาศค่าใหม่ ตัวสลับธีมอื่นในหน้าและในแท็บอื่นจึงเปลี่ยนตาม รายละเอียดว่ามันทำอะไรอยู่ใน ธีม

import { useThemeMode } from '@purpurabog/ui/headless'; export default function ThemeToggle() { const [mode, setMode] = useThemeMode(); return ( <button type="button" onClick={() => setMode(mode === 'dark' ? 'light' : 'dark')} className="h-10 bg-interactive px-4 text-sm text-on-primary hover:bg-blue-hover focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus" > ธีม: {mode} </button> ); }
ตัวเลือก ค่า ค่าเริ่มต้น
value light, dark, system: mode ที่แอปของคุณเป็นเจ้าของ (เช่นจากโปรไฟล์) ไม่มี
defaultValue mode เริ่มต้นเมื่อยังไม่มีค่าที่จำไว้ สิ่งที่ <html data-theme> แสดงอยู่ ถ้าไม่มีคือ light
lightTheme white, g10 white
darkTheme g90, g100 g100
storageKey key อะไรก็ได้; '' คือไม่จำ ui-theme

ถ้าจะบันทึกค่าที่เลือกลงโปรไฟล์ผู้ใช้ ให้ส่ง mode จากโปรไฟล์เป็น value hook จะแสดงและจำค่านั้น

import { useState } from 'react'; import { useThemeMode, type ThemeMode } from '@purpurabog/ui/headless'; interface Profile { theme: ThemeMode; } function ThemeToggle({ profile, saveProfile }: { profile: Profile | null; saveProfile: (profile: Profile) => void }) { // เมื่อใส่ value hook จะแสดงและจำ mode จากโปรไฟล์ const [mode] = useThemeMode({ value: profile?.theme }); return ( <button type="button" onClick={() => saveProfile({ theme: mode === 'dark' ? 'light' : 'dark' })} className="h-10 bg-interactive px-4 text-sm text-on-primary hover:bg-blue-hover focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus" > ธีม: {mode} </button> ); } export default function Example() { // แทนโปรไฟล์บน server ของคุณ: ยังไม่ได้บันทึกอะไร const [profile, setProfile] = useState<Profile | null>(null); return ( <div className="grid justify-items-start gap-2"> <ThemeToggle profile={profile} saveProfile={setProfile} /> <p className="text-xs text-ink-muted">บันทึกในโปรไฟล์: {profile?.theme ?? 'ยังไม่มี'}</p> </div> ); }

บน server hook คืน defaultValue (หรือ light) ใส่ themeScript() ใน <head> เพื่อให้เฟรมแรกเป็นธีมที่จำไว้เลย (ธีม)

Component

หน้าในหมวดนี้ครอบคลุมช่องกรอกของฟอร์ม แพ็กเกจยังมีชิ้นส่วนอื่นที่ยังไม่มีหน้า: Modal, Tabs, Accordion, ContentSwitcher, Menu, Popover, Tooltip, DefinitionTooltip, TreeView, StructuredList, SidePanel, Tearsheet, Notification, Toaster, Loading, Shell, Header, SideNav, DataTable, Pagination, PaginationNav, EditInPlace, Copy, CodeSnippet, TruncatedText, Tag, Card, ProductCard และ ProgressIndicator ระหว่างนี้ props และ attribute data-* ของแต่ละชิ้นส่วนอธิบายไว้ใน type (editor จะแสดงเมื่อชี้)
