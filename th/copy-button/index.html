Copy button หรือ code snippet?

Component ใช้เมื่อ
Copy button ค่าที่คัดลอกแสดงอยู่ที่อื่นใน layout ของคุณเอง เช่น ในช่องกรอก ในเซลล์ตาราง หรือในหัวข้อ
Code snippet คุณแสดงโค้ดหรือคำสั่ง และปุ่มคัดลอกเป็นส่วนหนึ่งของมัน snippet ใช้ปุ่มนี้อยู่ข้างใน

คัดลอกเอง

ก่อนคัดลอก ปุ่มยิง ui-copy พร้อม detail.text เรียก preventDefault() เพื่อใส่ค่าอื่นลงคลิปบอร์ดเอง ข้อความหลังคัดลอกยังแสดงตามปกติ ใน React + Tailwind onCopy ได้รับข้อความ คืนค่า false เพื่อคัดลอกเอง ส่วน showFeedback() ของ element แสดงข้อความหลังคัดลอกได้ทุกเมื่อ เช่น หลังจาก control อื่นคัดลอกค่าไปแล้ว

คีย์บอร์ด

ปุ่ม ทำอะไร
Tab ไปที่ปุ่ม tooltip แสดง label
Enter, Space คัดลอก แล้ว tooltip แสดงข้อความหลังคัดลอก
Esc ซ่อน tooltip ที่เป็น label (ข้อความหลังคัดลอกยังแสดงจนครบเวลา)

Accessibility

  • ข้อความใน tooltip เป็นชื่อของปุ่ม ไอคอนจึงไม่ต้องมี label อื่น ถ้ามีหลายปุ่มให้แต่ละปุ่มมี label ของตัวเอง ("คัดลอกเลขที่สัญญา", "คัดลอกเลขผู้เสียภาษี")
  • หลังคัดลอก live region แบบ polite (role="status") อ่านข้อความหลังคัดลอกหนึ่งครั้ง ผู้ใช้ screen reader จึงได้ยิน "คัดลอกแล้ว" ด้วย
  • แสดงค่าที่คัดลอกไว้ข้างปุ่มเสมอ คลิปบอร์ดมองไม่เห็น ผู้ใช้อยากตรวจว่าคัดลอกอะไรไป
