การย้ายไป 1.0

1.0 เปลี่ยน web component แบบขับเคลื่อนด้วยข้อมูล <ui-data-table> เป็นชุด element ที่ทำตาม Carbon web components (cds-table): <ui-table>, <ui-table-head>, <ui-table-header-row>, <ui-table-header-cell>, <ui-table-body>, <ui-table-row>, <ui-table-cell> และ element ของ toolbar, batch action และ skeleton รอบ ๆ หน้านี้รวมสิ่งที่ต้องเปลี่ยน

อะไรเปลี่ยนและทำไม

  • เขียนเป็น markup แทนข้อมูล <ui-data-table> รับ headers และ rows เป็น property แล้ววาดตารางเอง ส่วน <ui-table> เขียนเป็น element แบบ cds-table ของ Carbon: หัวคอลัมน์ แถว และเซลล์แต่ละตัวเป็น element ที่คุณเขียนหรือ render เอง เซลล์แสดงอะไรก็ได้ที่ใส่ไว้ renderCell จึงไม่มีแล้ว
  • ชื่อตาม Carbon web components attribute, event, slot และ part ตอนนี้ตาม cds-table: is-sortable, is-selectable, use-zebra-styles, ui-table-header-cell-sort, ui-table-row-selected เป็นต้น ความสามารถที่ Carbon ไม่มี (แบ่งหน้า ตั้งค่าคอลัมน์ ตรึงและปรับความกว้างคอลัมน์ CSV แก้ไขในตาราง สถานะกำลังโหลดและว่าง) ยังทำงานเหมือนเดิม และได้ชื่อในแบบเดียวกัน
  • toolbar ก็เป็น element ช่องค้นหา batch action ปุ่ม Columns และปุ่ม Export CSV คือ <ui-table-toolbar-search>, <ui-table-batch-actions>, <ui-table-column-settings> และ <ui-table-csv-export> ใน <ui-table-toolbar> แทนการเปิดสวิตช์บนตาราง
  • entry point ใหม่ import @purpurabog/ui/table แทน @purpurabog/ui/data-table

ไม่เปลี่ยน: DataTable ของ React + Tailwind (tw-data-table ขับเคลื่อนด้วย headers และ rows รวมถึง DataTableSkeleton) และ hook headless useDataTable กับ part ของมัน โค้ดที่ใช้สองอย่างนี้ไม่ต้องแก้

Skeleton

<ui-data-table-skeleton> (UiDataTableSkeleton) เปลี่ยนเป็น <ui-table-skeleton> (UiTableSkeleton) แบบ cds-table-skeleton ของ Carbon: headers เป็นรายการข้อความแทน object { header }, hide-header เป็น show-header="false" และ hide-toolbar เป็น show-toolbar="false" ส่วน row-count, column-count และ zebra เหมือนเดิม และไม่มี size

ข้อความสำหรับ screen reader

<ui-data-table> บอก "เรียงตามคอลัมน์ สัญญา จากน้อยไปมาก" หลังกดเรียง และ "แสดง 3 จาก 12 แถว" เมื่อหยุดพิมพ์ค้นหา ส่วน <ui-table> บอกแค่ "กำลังโหลดข้อมูล" ขณะ loading เพราะตารางของ Carbon ไม่บอกอะไร จำนวนในแถบ batch ยังเป็น status อยู่ DataTable ของ React + Tailwind ยังบอกทั้งสองอย่าง

React

UiDataTable และ UiDataTableSkeleton ไม่มีใน @purpurabog/ui/react แล้ว เลือกอย่างใดอย่างหนึ่ง:

  • wrapper UiTable* (UiTable, UiTableHead, UiTableHeaderRow, UiTableHeaderCell, UiTableBody, UiTableRow, UiTableCell, UiTableExpandedRow, UiTableHeaderTitle, UiTableHeaderDescription, UiTableToolbar, UiTableToolbarContent, UiTableToolbarSearch, UiTableBatchActions, UiTableColumnSettings, UiTableCsvExport, UiTableSkeleton): map ข้อมูลของคุณเข้าไป event เป็น prop onUiTable… เช่น onUiTableRowSelected
  • DataTable ของ React + Tailwind: ยังขับเคลื่อนด้วย headers และ rows ใกล้กับ prop ของ UiDataTable เดิมที่สุด

ตารางเรียงลำดับด้วยการย้ายแถวใน DOM และบันทึกการแก้ไขด้วยการเขียนลงเซลล์ แถวที่ React render เป็นของ React จึงต้องเรียงและบันทึกผ่าน state ของคุณ:

<UiTable onUiTableCellEdit={(e) => { e.preventDefault(); // React เขียนค่าเอง const { row, column, value } = e.detail; setRows((all) => all.map((r) => (r.id === row.dataset.id ? { ...r, [column]: value } : r))); }} > <UiTableHead> <UiTableHeaderRow> {headers.map((h) => ( <UiTableHeaderCell key={h.key} column={h.key} editable={h.editable} sortDirection={sort.column === h.key ? sort.direction : 'none'} onUiTableHeaderCellSort={(e) => { e.preventDefault(); // React จัดลำดับแถวเอง setSort({ column: h.key, direction: e.detail.sortDirection }); }} > {h.header} </UiTableHeaderCell> ))} </UiTableHeaderRow> </UiTableHead> <UiTableBody> {sortRows(rows, sort).map((row) => ( <UiTableRow key={row.id} data-id={row.id}> {headers.map((h) => <UiTableCell key={h.key}>{row[h.key]}</UiTableCell>)} </UiTableRow> ))} </UiTableBody> </UiTable>

Vue, Angular และ framework อื่นที่ render แถวเองก็ทำแบบเดียวกัน ดูทุกความสามารถทั้งแบบ HTML และ React ได้ที่ Data table

Type

type DataTable… ของ web component (DataTableHeader, DataTableRow, DataTableSortDetail …) ไม่มีใน @purpurabog/ui แล้ว type ใหม่คือ UiTable, UiTableRow, UiTableHeaderCell …, TableSortDirection และ detail ของ event (TableSortedDetail, TableRowSelectedDetail, TableCellEditDetail …) ส่วน type ของ React + Tailwind (DataTableSort …) ไม่เปลี่ยน
