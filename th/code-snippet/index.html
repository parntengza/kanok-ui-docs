ข้อความของปุ่มคัดลอก

  • copy-label (copyLabel): tooltip ของปุ่มคัดลอกใน snippet บรรทัดเดียวและหลายบรรทัด (ค่าเริ่มต้น "คัดลอก")
  • label: ชื่อสำหรับ accessibility ของกล่องโค้ด (single และ multi) ส่วนชิป inline จะใช้เป็น tooltip และคำอธิบาย
  • feedback: tooltip หลังคัดลอก (ค่าเริ่มต้น "คัดลอกแล้ว") แสดงนาน feedback-timeout ms (2000)
  • placement (หรือ align แบบ Carbon): ด้านของ tooltip ค่าเริ่มต้น bottom

คีย์บอร์ด

ปุ่ม ทำอะไร
Tab ไปที่กล่องโค้ด แล้วปุ่มคัดลอก แล้ว "แสดงเพิ่มเติม" ถ้าเป็น inline ไปที่ชิป
ลูกศร เลื่อนกล่องโค้ดที่โฟกัสอยู่ เมื่อโค้ดกว้างหรือสูงกว่ากล่อง
Enter, Space ที่ปุ่มคัดลอกหรือชิป inline: คัดลอก ที่ "แสดงเพิ่มเติม": เปิดหรือพับบล็อก

Accessibility

  • กล่องโค้ดแบบ single และ multi เป็น textbox อ่านอย่างเดียว (role="textbox", aria-readonly) ที่รับโฟกัส ผู้ใช้คีย์บอร์ดจึงเลื่อนดูได้ ตั้งชื่อด้วย label (ค่าเริ่มต้น "คัดลอก" ตั้งเป็น "URL ของ webhook" จะดีกว่า)
  • ปุ่มคัดลอกได้ชื่อจาก tooltip (copy-label) ชิป inline ได้ชื่อจากโค้ด และ label จะเป็นคำอธิบาย
  • หลังคัดลอก live region แบบ polite อ่านข้อความหลังคัดลอกหนึ่งครั้ง
  • "แสดงเพิ่มเติม" มี aria-expanded

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Code snippet
