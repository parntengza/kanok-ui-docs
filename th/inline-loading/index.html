Inline loading

Inline loading แสดงความคืบหน้าของการกระทำหนึ่งในที่ เช่น การบันทึกหรือการส่ง: spinner 16px กับข้อความสั้น ๆ ข้าง ๆ สถานะเปลี่ยนจาก active ไปเป็น finished (เครื่องหมายถูก) หรือ error และ screen reader ได้ยินทุกครั้งที่เปลี่ยน

Inline loading หรือ loading?

ใช้ inline loading ข้างตัวควบคุมที่เริ่มงาน เมื่อผลลัพธ์จบที่สำเร็จหรือไม่สำเร็จ ถ้าใช้ทั้งหน้าจอหรือพื้นที่หนึ่งไม่ได้จนกว่าข้อมูลจะมา ให้ใช้ Loading ถ้างานรู้ขนาด ให้ใช้ Progress bar part ของ Headless Loading ครอบคลุมแค่ spinner กับจังหวะเวลา ไม่มีสถานะเหล่านี้

สถานะ

status เป็นค่าใดค่าหนึ่ง:

  • active (ค่าเริ่มต้น): ไอคอนหมุน
  • finished: เครื่องหมายถูกสีเขียว (ขึ้นทันทีแบบ Carbon)
  • error: ไอคอนข้อผิดพลาดสีแดง
  • inactive: มีแค่ข้อความ ใน HTML และ React (UiInlineLoading) spinner จะหยุดแบบ Carbon web components คือหมุนช้าลงแล้วหายไปใน 1.4 วินาที (หายทันทีถ้าผู้ใช้ตั้งลดการเคลื่อนไหว) ส่วน React + Tailwind ทำตาม Carbon React คือไม่มีไอคอนตั้งแต่แรก

ข้อความใน element คือข้อความสถานะ (description ของ Carbon) เปลี่ยนไปพร้อมกับสถานะ

ยังไม่เริ่ม กำลังส่ง… ส่งแล้ว ส่งไม่สำเร็จ

แทนที่ปุ่มส่ง

รูปแบบของ Carbon: เมื่อผู้ใช้กดส่ง ปุ่มส่งหลีกทางให้ inline loading เมื่องานเสร็จ เครื่องหมายถูกแสดง แล้ว ui-success เอาปุ่มกลับมา

ยกเลิก ส่ง

หลังสำเร็จ

ui-success ยิงหลัง status เป็น finished ไปแล้ว success-delay มิลลิวินาที (ค่าเริ่มต้น 1500 เหมือน successDelay ของ Carbon) ใช้ปิด dialog ล้างฟอร์ม หรือเอาปุ่มกลับมา ใน React prop ของ event คือ onUiSuccess ใน React + Tailwind คือ onSuccess

ส่งใบแจ้งหนี้ INV-0412 ยังไม่ได้ส่ง

ui-success: ยังไม่ยิง

Accessibility

  • ทั้ง element เป็น live region แบบ polite screen reader จึงได้ยินชื่อไอคอนกับข้อความทุกครั้งที่สถานะเปลี่ยน
  • เขียนข้อความให้สั้นและชัด: "กำลังส่ง…" "ส่งแล้ว" "ส่งไม่สำเร็จ"
  • inline loading ไม่รับโฟกัส เมื่อมันแทนที่ปุ่มที่มีโฟกัสอยู่ ให้ย้ายโฟกัสไปที่ที่ใช้ต่อได้เมื่อจบ เช่น กลับไปที่ปุ่ม
  • เมื่อผู้ใช้ตั้ง prefers-reduced-motion spinner จะไม่หมุน และเครื่องหมายถูกแสดงทันที

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-inline-loading> · React UiInlineLoading

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
status status InlineLoadingStatus 'active'
success-delay successDelay number 1500 Milliseconds after finished before ui-success fires (Carbon successDelay).
icon-label iconLabel string '' Accessible name of the icon; defaults to the status.

Event

Event React คำอธิบาย
ui-success onUiSuccess success-delay ms after status became finished

Slot

Slot คำอธิบาย
(ค่าเริ่มต้น) The status text (Carbon description)

CSS part

Part คำอธิบาย
base The row
icon The spinner / check / error icon
text The description
