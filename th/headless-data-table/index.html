Headless Data table

DataTable คือพฤติกรรมของ Data table แบบมี style โดยไม่มี class เลย ในแบบ TanStack Table: hook useDataTable(options) เก็บ state ทั้งหมด คือการเรียง การค้นหา หน้า การเลือก แถวที่เปิด คอลัมน์ที่ซ่อน ความกว้างคอลัมน์ และ grid ที่แก้ไขได้ แล้วคืนแถวที่จะแสดง action และ prop getter ให้ คุณเขียน <table> เอง ส่วน parts ใส่กฎคีย์บอร์ด focus และ ARIA ในจุดที่ต้องใช้

ส่วนที่คุณเขียนเอง: ทุกเซลล์ หัวตาราง toolbar ไอคอน ข้อความตอนไม่มีข้อมูล และ style ทั้งหมด สถานะแสดงเป็น attribute data-* ที่ parts

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { DataTable } from '@purpurabog/ui/headless';

ใช้เฉพาะ part ที่ต้องการ ตารางที่อ่านอย่างเดียวใช้แค่ Root, Table, Body, Row และ Cell หรือแม้แต่ <tr> และ <td> ธรรมดาครอบ table.pageRows

ค้นหาและแบ่งหน้า

table.setFilterText(text) กรองแถว (เซลล์ใดที่แสดงอยู่มีข้อความนั้น ไม่สนตัวพิมพ์เล็กใหญ่) และกลับไปหน้า 1 เมื่อมี pageSize (หรือ defaultPageSize) table.pageRows จะเป็นหนึ่งหน้า ควบคุมด้วย Pagination แบบ headless หรือปุ่มของคุณเองผ่าน table.setPagination

filterRows(row, text, headers) ใช้แทนการตรวจเดิม และ manualFiltering คงทุกแถวไว้ขณะคุณกรองบน server filterText / onFilterChange และ page / onPageChange ทำให้ควบคุมทั้งสองอย่างเองได้

แถวที่ขยายได้

เมื่อใส่ expandable ปุ่ม ExpandToggle ของแต่ละแถวจะเปิดแถวนั้น ให้ render ExpandedRow ใต้ทุกแถวที่เปิดอยู่ (table.isExpanded(id)) ExpandAll เปิดทุกแถวที่แสดง หรือปิดทั้งหมดเมื่อเปิดครบแล้ว ปุ่มเหล่านี้มี aria-expanded และ aria-controls ที่ชี้ไปยังแถวที่เปิด

คืนแถวเป็นรายการชั้นเดียว (อย่างที่นี่ใช้ flatMap) การเปิดแถวจะได้ไม่ mount แถวนั้นใหม่

เลือกหนึ่งแถว

เมื่อใส่ radio ตัว SelectRow จะเป็น radio ทุก radio หยุด Tab ที่เดียว (แถวที่เลือก ถ้าไม่มีก็แถวแรกที่ใช้งานได้) ปุ่มลูกศรย้ายไปแถวถัดไปที่ใช้งานได้และเลือก วนกลับเมื่อสุดปลาย SelectAll ไม่ render อะไร แถวที่มี disabled: true เลือกไม่ได้

แสดงและซ่อนคอลัมน์

table.columns คือคอลัมน์ที่แสดง table.headers คือทั้งหมด toggleColumn(key, show) แสดงหรือซ่อนหนึ่งคอลัมน์ isColumnLocked(key) บอกว่าซ่อนไม่ได้ (hideable: false หรือเหลือคอลัมน์เดียว) และ resetColumns() กลับไปตาม hidden ของ header columnsChanged บอกว่าที่เลือกต่างจากค่านั้น

คอลัมน์ที่ซ่อนจะไม่ถูกค้นหาด้วย hiddenColumns / onColumnsChange ทำให้ควบคุมค่านี้เองและบันทึกไว้ได้

แก้ไขเซลล์ในตาราง

คอลัมน์ที่มี editable: 'text' | 'number' | 'select' ทำให้ตารางเป็น grid ตาม APG: Table ได้ role="grid" เซลล์หนึ่งในตัวตารางเป็นที่หยุด Tab และปุ่มลูกศร Home / End และ Ctrl + Home / End ย้ายมัน Enter, F2, ดับเบิลคลิก คลิกที่ element ที่มี data-edit-icon หรือพิมพ์ จะเปิดช่องแก้ไข ให้ render CellInput หรือ CellSelect ขณะเซลล์ถูกแก้ไข (useCellContext().editing) และ CellError สำหรับข้อความจาก validate onCellEdit ส่ง rows ใหม่ให้คุณ

ปรับความกว้างคอลัมน์

resizable (หรือ resizable ของคอลัมน์) ทำให้ ResizeHandle ทำงาน: เป็น range input จริงที่ขอบของหัวคอลัมน์ ลากได้ หรือใช้ลูกศรทีละ 2px, Shift / Page Up / Down ทีละ 16px, Home / End แคบสุด / กว้างสุด การปรับครั้งแรกจะตรึง layout อัตโนมัติเป็นความกว้างคงที่ (table.resize.fixed) แล้ว Filler จะกินพื้นที่ที่เหลือของแถว ผูก table.boxRef กับกล่องที่เลื่อนได้ คอลัมน์จะกว้างได้ไม่เกินกล่องนั้น

Hook

DataTable.useDataTable(options)

เก็บ state ทุกส่วนของ state ควบคุมเองได้ (sortKey, selectedIds …) หรือปล่อยให้ hook เก็บ (default…)

Option Type ค่าเริ่มต้น
headers DataTableColumn[] คอลัมน์: { key, header } และตัวเลือกของคอลัมน์ข้างล่าง (ต้องใส่)
rows R[] แถว: { id, …cells } ใส่ disabled เพื่อไม่ให้เลือก (ต้องใส่)
id string สร้างให้ ส่วนต้นของ id ที่ parts ใส่ให้ element
sortable boolean false ทุกคอลัมน์เรียงได้ ยกเว้น header ที่ตั้ง sortable: false
sortKey, sortDirection string, SortDirection การเรียง (ควบคุมเอง)
defaultSortKey, defaultSortDirection string, SortDirection '', 'none' การเรียงตอนเริ่ม
onSortChange (sort: { key, direction }) => void หลังกดปุ่มเรียง
manualSorting boolean false คง rows ตามลำดับของคุณ (เรียงบน server) หัวตารางยังแสดงการเรียง
sortRow (a, b, context) => number ใช้แทนการเปรียบเทียบเดิม
locale string 'en' ภาษาที่ใช้เรียง (ตารางภาษาไทยใส่ 'th')
selectable boolean false checkbox พร้อมช่องเลือกทั้งหมด
radio boolean false เลือกได้หนึ่งแถว มี radio ทุกแถว
selectedIds, defaultSelectedIds string[] [] แถวที่เลือก
onSelectionChange (ids: string[], rows: R[]) => void หลังการเลือกเปลี่ยน
filterText, defaultFilterText string '' คำค้น
onFilterChange (value: string) => void หลัง setFilterText
filterRows (row, text, headers) => boolean ใช้แทนการตรวจแถวของการค้นหา
manualFiltering boolean false คงทุกแถวไว้ (กรองบน server)
expandable boolean false แถวเปิดปิดได้
expandedIds, defaultExpandedIds string[] [] แถวที่เปิดอยู่
onExpandChange (change: { expandedIds, expanded, id? }) => void หลังแถวหนึ่ง (หรือทุกแถว เมื่อไม่มี id) เปิดหรือปิด
pageSize, defaultPageSize number 0 แถวต่อหน้า (0: หน้าเดียวทุกแถว)
page, defaultPage number 1 หน้า เริ่มที่ 1
onPageChange (change: { page, pageSize }) => void หลัง setPagination หรือเมื่อค้นหาใหม่ขณะอยู่หน้าหลัง ๆ
hiddenColumns, defaultHiddenColumns string[] header ที่มี hidden key ของคอลัมน์ที่ไม่แสดง
onColumnsChange (change: { hiddenColumns, key, hidden }) => void หลังแสดงหรือซ่อนคอลัมน์ (key เป็น '' หลังรีเซ็ต)
resizable boolean false ทุกคอลัมน์มีที่จับปรับความกว้าง
columnWidths, defaultColumnWidths Record<string, number> {} ความกว้างคอลัมน์เป็น px ตาม key
onColumnResize (change: { key, width, widths }) => void หลังปรับความกว้าง (ครั้งเดียวต่อการลากหรือการกดปุ่ม)
staticWidth boolean false ตารางที่ปรับความกว้างแล้วกว้างเท่าผลรวมคอลัมน์ ไม่ใช่เท่ากล่อง
onCellEdit (edit: { rowId, key, value, previous, row, rows }) => void เซลล์ที่แก้ถูกบันทึก: ตั้ง rows เป็น edit.rows

ตัวเลือกของคอลัมน์ในแต่ละ header: sortable, editable ('text' \| 'number' \| 'select'), options ({ value, label }[] for a select), validate(value, row), resizable, width, minWidth, maxWidth, hideable, hidden, pinned ('start' \| 'end').

สิ่งที่คืนมา แยกตามหัวข้อ:
แถว rows, filteredRows (ที่การค้นหาเหลือไว้), sortedRows, pageRows (แถวที่จะ render), rowById
คอลัมน์ headers (ทั้งหมด), columns (ที่แสดง), hiddenColumns, toggleColumn(key, show), resetColumns(), isColumnLocked(key), columnsChanged, pins
การเรียง sortKey, sortDirection, sortDirectionOf(key), isSortable(column), sortBy(key)
การค้นหา filterText, setFilterText(text)
หน้า paged, page, pageSize, pageCount, setPagination({ page, pageSize })
การเลือก selectable, radio, selectedIds, isSelected(id), setSelectedIds(ids), toggleRow(row, checked), toggleAll(), selectAll(), allSelected, someSelected, radioStop, getSelectAllProps(), getSelectRowProps(row)
แถวที่เปิด expandable, expandedIds, isExpanded(id), allExpanded, toggleExpanded(id), toggleAllExpanded(), expandedRowId(id)
ความกว้างและ grid columnWidths, resize (fixed, hasFiller, tableStyle, widthOf(column) …), grid (enabled …), tableRef, boxRef, id

DataTable.useDataTableContext() คืน object เดียวกันนี้ให้ component ใดก็ได้ที่อยู่ใน Root

Parts

DataTable.Root

ไม่ render element ของตัวเอง แค่ส่งตารางจาก hook ให้ลูก

Prop Type ค่าเริ่มต้น
table สิ่งที่ useDataTable คืนมา ต้องใส่

DataTable.Table

สร้าง <table> พร้อม tableRef ของ hook เป็น role="grid" เมื่อมีคอลัมน์ที่ editable รับ prop ทุกตัวของ <table>

DataTable.Body

สร้าง <tbody> เมื่อเป็น grid จะจัดการปุ่ม คลิก ดับเบิลคลิก และ focus ของเซลล์

DataTable.ColumnHeader

สร้าง <th scope="col"> ที่มี aria-sort เมื่อคอลัมน์เรียงได้ data-key และความกว้างที่ปรับแล้ว รับ prop ทุกตัวของ <th>

Prop Type ค่าเริ่มต้น
column string key ของคอลัมน์ (ต้องใส่)
Attribute เมื่อ
data-sortable คอลัมน์เรียงได้
data-resizing กำลังลากที่จับของมัน

DataTable.SortButton

สร้าง <button type="button"> ที่เลื่อนการเรียงของคอลัมน์: ไม่เรียง → น้อยไปมาก → มากไปน้อย → ไม่เรียง คอลัมน์ใหม่เริ่มที่น้อยไปมาก อธิบายขั้นถัดไปด้วย aria-describedby ได้ถ้าต้องการ

Attribute เมื่อ
data-direction มีเสมอ: none, ascending หรือ descending

DataTable.ResizeHandle

สร้าง <input type="range"> (ไม่ render อะไรถ้าคอลัมน์ปรับไม่ได้) ตั้งชื่อให้ด้วย ("ปรับความกว้างคอลัมน์ ชื่อ") รับ prop ทุกตัวของ input ยกเว้น type, value, min, max และ step

Prop Type ค่าเริ่มต้น
valueText (width: number) => string ความกว้างเป็นคำสำหรับเทคโนโลยีช่วยเหลือ ("120 พิกเซล")

DataTable.Row

สร้าง <tr> ที่มี data-row-id ซึ่ง grid และ radio ใช้หาแถว

Prop Type ค่าเริ่มต้น
rowId string id ของแถว (ต้องใส่)
Attribute เมื่อ
data-selected แถวถูกเลือก
data-expanded แถวเปิดอยู่

DataTable.Cell

สร้าง <td> เมื่อเป็น grid เซลล์หนึ่งในตัวตารางเป็นที่หยุด Tab ที่เหลือเป็น tabIndex={-1} เซลล์ที่แก้ไม่ได้เป็น aria-readonly

Prop Type ค่าเริ่มต้น
index number ลำดับของเซลล์ในแถว เริ่มที่ 0 นับทุกเซลล์ (ขยาย เลือก ข้อมูล) (ต้องใส่)
column string key ของคอลัมน์ สำหรับเซลล์ข้อมูล คอลัมน์ที่ editable ทำให้เซลล์แก้ไขได้
Attribute เมื่อ
data-editable เซลล์แก้ไขได้
data-editing เซลล์กำลังถูกแก้ไข
data-key key ของคอลัมน์ ที่เซลล์ที่แก้ได้

DataTable.useCellContext() คืน rowId, column และ editing ของเซลล์ ({ draft, error } ขณะแก้ไข ไม่อย่างนั้นเป็น null)

DataTable.CellValue, DataTable.EditHint

CellValue สร้าง <span> ครอบค่าของเซลล์ที่แก้ได้ คลิกที่มันจะ focus เซลล์ EditHint สร้าง <span> ที่มีข้อความอธิบายเซลล์ที่แก้ได้ทุกเซลล์ ("กด Enter เพื่อแก้ไข") เฉพาะเมื่อเป็น grid ให้ซ่อนจากสายตา

DataTable.CellInput, DataTable.CellSelect, DataTable.CellError

ช่องแก้ไขขณะเซลล์ถูกแก้: CellInput เป็น <input> (ข้อความ หรือตัวเลขพร้อม inputMode="decimal") CellSelect เป็น <select> ของ options ของคอลัมน์ (หรือ <option> ที่คุณใส่เอง) ทั้งสองเป็น aria-invalid และอธิบายด้วยข้อความ error ขณะ validate ไม่รับค่า CellError สร้าง <span role="alert"> พร้อมข้อความ และไม่ render อะไรเมื่อค่าถูกต้อง

DataTable.SelectAll

สร้าง checkbox จริง (Checkbox แบบ headless) ติ๊กเมื่อเลือกครบทุกแถวในขอบเขต เป็นแบบผสมเมื่อเลือกบางแถว กดแล้วจะล้างการเลือกถ้ามีแถวที่เลือก ไม่อย่างนั้นเลือกทุกแถวที่ใช้งานได้ที่แสดงอยู่ (แบบ Carbon) ไม่ render ในตาราง radio

Attribute เมื่อ
data-checked เลือกครบทุกแถวในขอบเขต
data-indeterminate เลือกบางแถว

DataTable.SelectRow

สร้าง checkbox จริงของแถว หรือ radio ในตาราง radio แถวที่ disabled จะมีช่องที่ disabled

Attribute เมื่อ

DataTable.ExpandToggle, DataTable.ExpandAll

แต่ละตัวสร้าง <button type="button"> ที่มี aria-expanded และ aria-controls ชี้ไปที่แถวที่เปิด ExpandToggle เปิดหรือปิดแถวของมัน ExpandAll เปิดทุกแถวที่แสดง หรือปิดทั้งหมดเมื่อเปิดครบ ตั้งชื่อด้วย aria-label

Attribute เมื่อ
data-expanded แถวของมันเปิดอยู่ (ทุกแถว สำหรับ ExpandAll)

DataTable.ExpandedRow

สร้าง <tr> ใต้แถวที่เปิด พร้อม id ที่ปุ่มของมันควบคุม

Prop Type ค่าเริ่มต้น
rowId string id ของแถวที่เปิด (ต้องใส่)

DataTable.Filler

สร้าง <td aria-hidden="true"> ว่าง ที่กินพื้นที่ที่เหลือของแถวเมื่อคอลัมน์ถูกปรับความกว้างแล้ว (เฉพาะตอนนั้น)

คีย์บอร์ดและ accessibility

  • เมื่อไม่มีคอลัมน์ที่แก้ได้ parts เป็นของจริงทั้งหมด ปุ่มเรียง checkbox และปุ่มขยาย อยู่ในลำดับ Tab ทุกตัว radio ของตาราง radio หยุด Tab ที่เดียว ปุ่มลูกศรย้ายและเลือก วนกลับเมื่อสุดปลาย
  • เมื่อมีคอลัมน์ที่แก้ได้ ตารางเป็น grid ตาม WAI-ARIA: เซลล์ในตัวตารางหยุด Tab ที่เดียว ปุ่มลูกศร Home / End และ Ctrl + Home / End ย้ายมัน และ Enter หรือ Space กดตัวควบคุมในเซลล์
  • สิ่งที่คุณต้องใส่เอง: ชื่อตาราง (aria-label หรือ aria-labelledby ไปที่หัวข้อของคุณ) ชื่อของตัวเลือกและปุ่มขยาย (บอกชื่อแถว: "เลือกแถว, NDA") ชื่อสำหรับ screen reader ของคอลัมน์ radio และข้อความ "กด Enter เพื่อแก้ไข"
  • ประกาศสิ่งที่เปลี่ยนเอง: หลังเรียง ("เรียงตามคอลัมน์ สัญญา จากน้อยไปมาก") และเมื่อหยุดพิมพ์ค้นหา ("แสดง 3 จาก 12 แถว") ด้วยสถานะแบบ polite ใส่ aria-busy ที่ตารางขณะโหลดใหม่
