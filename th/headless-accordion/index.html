Headless Accordion

part ของ Accordion ให้พฤติกรรมเดียวกับ Accordion แบบมี style แต่ไม่มี style เลย ได้แก่ รายการหัวข้อที่แต่ละหัวข้อเป็นปุ่มเปิดหรือซ่อนเนื้อหา พร้อม aria-expanded aria-controls และ region ของเนื้อหาที่มีชื่อตามปุ่ม เปิดหลายหัวข้อพร้อมกันได้เหมือน Carbon

ส่วนที่คุณทำเองคือ markup ข้างใน part (ลูกศร ระดับหัวข้อที่ครอบปุ่ม) ข้อความ และ style ทั้งหมด part ต่าง ๆ บอกสถานะผ่าน attribute data-* ให้คุณใช้ใส่ style

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Accordion } from '@purpurabog/ui/headless';

วิธีใช้

import { Accordion } from '@purpurabog/ui/headless'; const clauses = [ { title: 'คู่สัญญา', body: 'บริษัท เมโทร พร็อพเพอร์ตี้ จำกัด (ผู้ให้เช่า) และ บริษัท สยาม รีเทล จำกัด (ผู้เช่า)' }, { title: 'เงื่อนไขการชำระเงิน', body: 'ชำระค่าเช่าภายในวันที่ 5 ของทุกเดือน ชำระล่าช้าคิดดอกเบี้ยร้อยละ 1.5 ต่อเดือน' }, { title: 'การรักษาความลับ', body: 'คู่สัญญาทั้งสองฝ่ายต้องเก็บรักษาเงื่อนไขเป็นความลับเป็นเวลาห้าปีหลังสัญญาเช่าสิ้นสุด' }, ]; export default function Example() { return ( <Accordion.Root className="max-w-xl"> {clauses.map((c, i) => ( <Accordion.Item key={c.title} defaultOpen={i === 0} className="border-t border-hairline last:border-b"> <Accordion.Trigger className="group flex min-h-10 w-full cursor-pointer items-center justify-between gap-4 px-4 text-start text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> {c.title} <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 shrink-0 fill-current transition-transform group-data-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Accordion.Trigger> <Accordion.Panel className="px-4 pt-2 pb-6 text-sm text-ink">{c.body}</Accordion.Panel> </Accordion.Item> ))} </Accordion.Root> ); }

โครงสร้าง

<Accordion.Root> <Accordion.Item> <Accordion.Trigger /> <Accordion.Panel /> </Accordion.Item> </Accordion.Root>

เปิดจากโค้ด

Item แต่ละอันเป็นอิสระต่อกัน: defaultOpen เปิดตั้งแต่ render ครั้งแรก หรือเก็บสถานะเองด้วย open และ onOpenChange หัวข้อแบบ controlled ทำให้ปุ่มคู่หนึ่งเปิดหรือปิดทุกหัวข้อพร้อมกันได้ onOpenChange เกิดเฉพาะเมื่อผู้ใช้คลิกเอง

import { useState } from 'react'; import { Accordion } from '@purpurabog/ui/headless'; const sections = [ { title: '1. คำนิยาม', body: 'คำที่เป็นตัวหนามีความหมายตามที่กำหนดในข้อนี้' }, { title: '2. ระยะเวลา', body: 'สามปี นับจากวันที่ 1 มกราคม 2570' }, { title: '3. ค่าเช่า', body: 'เดือนละ 120,000 บาท ปรับขึ้นร้อยละ 3 ทุกปี' }, ]; const button = 'h-8 border border-interactive px-4 text-sm text-interactive hover:bg-interactive hover:text-on-primary focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus'; export default function Example() { const [open, setOpen] = useState(sections.map(() => false)); const setOne = (index: number, next: boolean) => setOpen((all) => all.map((v, j) => (j === index ? next : v))); return ( <div className="grid max-w-xl gap-4"> <div className="flex flex-wrap gap-4"> <button type="button" className={button} onClick={() => setOpen(sections.map(() => true))}>เปิดทั้งหมด</button> <button type="button" className={button} onClick={() => setOpen(sections.map(() => false))}>ปิดทั้งหมด</button> </div> <Accordion.Root> {sections.map((s, i) => ( <Accordion.Item key={s.title} open={open[i]} onOpenChange={(next) => setOne(i, next)} className="border-t border-hairline last:border-b"> <Accordion.Trigger className="group flex min-h-10 w-full cursor-pointer items-center justify-between gap-4 px-4 text-start text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> {s.title} <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 shrink-0 fill-current transition-transform group-data-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Accordion.Trigger> <Accordion.Panel className="px-4 pt-2 pb-6 text-sm text-ink">{s.body}</Accordion.Panel> </Accordion.Item> ))} </Accordion.Root> <p className="text-xs text-ink-muted">เปิดอยู่: {open.map((v, i) => (v ? sections[i].title : null)).filter(Boolean).join(', ') || 'ไม่มี'}</p> </div> ); }

หัวข้อที่ครอบปุ่ม

หัวข้อของ accordion แบบมี style เป็นปุ่มธรรมดา เมื่อใช้ part คุณเลือก markup เองได้ ใส่ Trigger แต่ละอันไว้ใน <h3> (หรือระดับที่เหมาะกับหน้า) แล้วผู้ใช้ screen reader จะกระโดดไปมาระหว่างหัวข้อได้ ตามที่ pattern accordion ของ WAI-ARIA แนะนำ

import { Accordion } from '@purpurabog/ui/headless'; const offices = [ { name: 'สำนักงานใหญ่', address: '88 ถนนสุขุมวิท แขวงคลองเตย เขตคลองเตย กรุงเทพฯ 10110' }, { name: 'สาขาเชียงใหม่', address: '25 ถนนนิมมานเหมินท์ ตำบลสุเทพ อำเภอเมือง เชียงใหม่ 50200' }, ]; export default function Example() { return ( <Accordion.Root className="max-w-xl"> {offices.map((o) => ( <Accordion.Item key={o.name} className="border-t border-hairline last:border-b"> <h3 className="m-0 text-sm font-normal"> <Accordion.Trigger className="group flex min-h-10 w-full cursor-pointer items-center gap-4 px-4 text-start text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 shrink-0 fill-current transition-transform group-data-open:rotate-90"> <path d="M11 8 6 13l-.7-.7L9.6 8 5.3 3.7 6 3z" /> </svg> {o.name} </Accordion.Trigger> </h3> <Accordion.Panel className="ps-12 pe-4 pt-2 pb-6 text-sm text-ink">{o.address}</Accordion.Panel> </Accordion.Item> ))} </Accordion.Root> ); }

ในตัวอย่างนี้ลูกศรอยู่หน้าข้อความ (align="start" ของแบบมี style) ลำดับขึ้นอยู่กับ markup ของคุณ

ปิดใช้งาน

disabled ที่ Item ทำให้ปุ่มหัวข้อเป็น disabled คลิกไม่ได้และ Tab ข้ามไป disabled ที่ Root ปิดใช้งานทุกหัวข้อ ทั้งสองแบบตั้ง data-disabled ที่หัวข้อและปุ่ม

import { Accordion } from '@purpurabog/ui/headless'; export default function Example() { return ( <Accordion.Root className="max-w-xl"> <Accordion.Item defaultOpen className="border-t border-hairline last:border-b"> <Accordion.Trigger className="flex min-h-10 w-full cursor-pointer items-center px-4 text-start text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus">ฉบับร่าง</Accordion.Trigger> <Accordion.Panel className="px-4 pt-2 pb-6 text-sm text-ink">ฉบับที่ 3 แก้ไขวันนี้</Accordion.Panel> </Accordion.Item> <Accordion.Item disabled className="border-t border-hairline last:border-b"> <Accordion.Trigger className="flex min-h-10 w-full cursor-pointer items-center px-4 text-start text-sm text-ink hover:bg-ghost-hover data-disabled:cursor-not-allowed data-disabled:text-ink-disabled data-disabled:hover:bg-transparent"> คลังเอกสาร (หลังลงนาม) </Accordion.Trigger> <Accordion.Panel className="px-4 pt-2 pb-6 text-sm text-ink">สำเนาที่ลงนามแล้วจะแสดงที่นี่</Accordion.Panel> </Accordion.Item> </Accordion.Root> ); }

ใส่ style

import { Accordion } from '@purpurabog/ui/headless'; const faqs = [ { q: 'ใครลงนามได้บ้าง', a: 'กรรมการที่มีชื่อในหนังสือรับรองบริษัท หรือผู้รับมอบอำนาจ' }, { q: 'ลงนามบนกระดาษได้ไหม', a: 'ได้ พิมพ์สัญญา ลงนามทุกหน้า แล้วอัปโหลดไฟล์สแกน' }, { q: 'อนุมัติใช้เวลานานเท่าไร', a: 'สัญญามาตรฐานใช้เวลาสองวันทำการ' }, ]; export default function Example() { return ( <Accordion.Root className="max-w-xl"> {faqs.map((f) => ( <Accordion.Item key={f.q} className="group/item border-t border-hairline last:border-b data-open:bg-layer-1"> <Accordion.Trigger className="group flex min-h-12 w-full cursor-pointer items-center justify-between gap-4 px-4 text-start text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-open:font-semibold"> {f.q} <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 shrink-0 fill-current transition-transform group-data-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Accordion.Trigger> <Accordion.Panel className="px-4 pb-6 text-sm text-ink-muted">{f.a}</Accordion.Panel> </Accordion.Item> ))} </Accordion.Root> ); } /* className="item" ที่ Item, "trigger" ที่ Trigger, "chevron" ที่ svg */ .item[data-open] { background: #f4f4f4; } .trigger[data-open] { font-weight: 600; } .trigger[data-open] .chevron { transform: rotate(180deg); } .trigger[data-disabled] { color: #c6c6c6; cursor: not-allowed; }

Panel ที่ปิดอยู่มี attribute hidden จึงไม่ต้องใส่ style เพื่อซ่อน

Parts

Accordion.Root

<ul> ให้ reset list เอง (list-style: none ไม่มี padding)

Prop Type Default
disabled boolean false ปิดใช้งานทุกหัวข้อ
Attribute เมื่อ
data-disabled ตั้ง disabled

Accordion.useAccordionContext() คืน { disabled } ให้ component ที่อยู่ใน Root

Accordion.Item

<li>: หนึ่งหัวข้อ มี Trigger และ Panel ของตัวเอง

Prop Type Default
open boolean เปิดอยู่ (controlled)
defaultOpen boolean false เปิดตั้งแต่ render ครั้งแรก (uncontrolled)
onOpenChange (open: boolean) => void หลังผู้ใช้เปิดหรือปิด
disabled boolean false ปิดใช้งานปุ่มของหัวข้อ
Attribute เมื่อ
data-open เปิดอยู่
data-disabled หัวข้อนี้หรือทั้ง Root ปิดใช้งาน

Accordion.useItemContext() คืน { open, disabled, toggle, triggerId, panelId } ให้ component ที่อยู่ในหัวข้อ เช่น ใช้หมุนลูกศรที่อยู่นอกปุ่ม

Accordion.Trigger

<button type="button"> ที่มี aria-expanded และ aria-controls (id ของ panel) คลิก (และ Enter หรือ Space ของปุ่มเอง) เปิดหรือปิดหัวข้อ รับ prop ของปุ่มทุกตัว ยกเว้น type และ disabled ส่วน id หัวข้อเป็นผู้ตั้ง

Attribute เมื่อ
data-open หัวข้อเปิดอยู่
data-disabled หัวข้อปิดใช้งาน

Accordion.Panel

<section> ที่มีชื่อจากปุ่ม (aria-labelledby) จึงเป็น region landmark มี attribute hidden ขณะหัวข้อปิดอยู่ รับ prop ของ section ทุกตัว ยกเว้น hidden

Attribute เมื่อ
data-open หัวข้อเปิดอยู่

คีย์บอร์ดและ accessibility

ปุ่ม ทำอะไร
Tab / Shift+Tab ย้ายไปมาระหว่างปุ่มหัวข้อ (และเข้าไปใน panel ที่เปิดอยู่) ข้ามปุ่มที่ปิดใช้งาน
Enter, Space เปิดหรือปิดหัวข้อที่โฟกัสอยู่

ไม่มีปุ่มลูกศรสำหรับย้ายระหว่างปุ่มหัวข้อ เหมือน Carbon

part ตั้ง aria-expanded และ aria-controls ที่ปุ่มแต่ละอัน และ aria-labelledby กับ hidden ที่ panel แต่ละอัน รายการเป็น <ul> ที่มี <li>

ส่วนที่คุณเพิ่มเอง:

  • ข้อความของปุ่ม
  • element หัวข้อที่ครอบปุ่ม เมื่อหัวข้อเหล่านี้เป็นส่วนหนึ่งของโครงหัวข้อของหน้า
  • ไม่มีอย่างอื่น: ลูกศรเป็นของตกแต่ง จึงใส่ aria-hidden="true"
