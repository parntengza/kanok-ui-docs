ใช้ tag แบบไหน?

Carbon มี tag สี่แบบ ที่นี่รวมเป็น element เดียว เลือกแบบด้วย attribute

Tag Attribute ใช้เมื่อ
อ่านอย่างเดียว ไม่ต้องใส่ สถานะหรือหมวดหมู่ที่ให้อ่านเฉย ๆ ไม่รับ focus
ปิดได้ dismissible ค่าที่ผู้ใช้ลบออกได้ เช่น ตัวกรองที่เลือกไว้ ผู้รับ
เปิดปิดได้ selectable ตัวกรองที่ผู้ใช้กดเปิดปิด สถานะอยู่ใน selected
กดเพื่อเปิด operational tag ที่เปิดอย่างอื่น เช่น รายการที่เหลือของลิสต์ยาว รายละเอียดของหมวดหมู่

ถ้าเป็นสถานะที่มีไอคอนกับคำ (เช่น "เกินกำหนด" ในตาราง) ดู Status indicator ถ้าเป็นตัวเลขบนไอคอน ดู Badge indicator

แบบปิดได้

dismissible เพิ่มปุ่มปิด กดแล้วยิง ui-dismiss (React + Tailwind ใช้ onDismiss) tag จะยังอยู่จนกว่าคุณจะลบเอง คุณจึงอัปเดตตัวกรองก่อนได้ ถ้าลบ tag ที่มี focus อยู่ focus จะหายไป ให้ย้ายไปที่ tag ถัดไปแบบใน demo

ปุ่มปิดมีชื่อว่า "ลบ {text}" ตามภาษาของหน้า ตั้งชื่อเองได้ด้วย dismiss-label โดย {text} จะกลายเป็นข้อความของ tag

คีย์บอร์ด

ปุ่ม ทำอะไร
Tab ไปที่ปุ่มปิดของ tag แบบปิดได้ tag แบบเปิดปิดได้ หรือ tag แบบกดเพื่อเปิด tag แบบอ่านอย่างเดียวไม่ใช่จุดที่ Tab หยุด
Enter, Space กดปุ่มปิด สลับ tag แบบเปิดปิดได้ หรือกด tag แบบกดเพื่อเปิด

Accessibility

  • tag แบบอ่านอย่างเดียวคือข้อความ screen reader อ่านไปพร้อมเนื้อหารอบ ๆ ข้อความจึงต้องเข้าใจได้ในตำแหน่งนั้น สีอย่างเดียวไม่ได้บอกอะไร
  • ปุ่มปิดมีชื่อว่า "ลบ {text}" (แปลตามภาษา) แต่ละปุ่มจึงชื่อไม่ซ้ำกัน เปลี่ยนคำได้ด้วย dismiss-label
  • tag แบบเปิดปิดได้เป็นปุ่มที่มี aria-pressed
  • tag แบบกดเพื่อเปิดเป็นปุ่ม ถ้าข้อความเป็นแค่ตัวเลขอย่าง "+3" ให้ใส่ label
  • el.focus() ย้าย focus ไปที่ control ของ tag เอง คือปุ่มปิด หรือปุ่มของ tag แบบเปิดปิดได้หรือกดเพื่อเปิด

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Tag
