Side panel

Side panel เลื่อนเข้ามาจากขอบจอ ใต้ header ของ UI shell สูง 48px ใช้แสดงรายละเอียดหรือฟอร์มสั้น ๆ โดยที่หน้าเว็บยังมองเห็นอยู่ ตัวนี้คือ SidePanel ของ Carbon for IBM Products ถ้างานต้องใช้ทั้งหน้าจอ ให้ใช้ Tearsheet ถ้าเป็นการตัดสินใจสั้น ๆ ให้ใช้ Modal

panel เป็น position: fixed ตัวอย่างที่ใช้งานได้ด้านล่างจึงอยู่ในกล่องที่กัก panel ไว้ และตั้ง --ui-side-panel-top: 0px เพราะกล่องไม่มี header ด้านบน

× กด Esc และคลิกที่ overlay จะขอปิดก่อน (ดู ขอยืนยันก่อนปิด) และส่ง ui-close เมื่อ panel เลื่อนออกไปแล้ว React + Tailwind เป็นแบบ controlled: onRequestClose(reason) บอกเหตุผล แล้วคุณตั้ง open เป็น false

ขอยืนยันก่อนปิด

× กด Esc และคลิกที่ overlay จะส่ง ui-request-close ซึ่งยกเลิกได้ และมี reason เป็น close-button, escape หรือ overlay เรียก preventDefault() เพื่อให้ panel เปิดค้างไว้ requestClose(reason) ใช้ถามแบบเดียวกันจากปุ่มของคุณเอง ส่วนการตั้ง open เป็น false จะปิดโดยไม่ถาม panel ด้านล่างปิดได้ด้วยปุ่มเสร็จสิ้นเท่านั้น

ui-request-close และ ui-close bubble ขึ้นมา notification ที่อยู่ข้างในจึงส่ง event เหล่านี้ถึง panel ด้วย ต้องเช็กว่า event.target คือ panel ส่วน UiSidePanel ของ React เช็กให้แล้ว onUiRequestClose และ onUiClose ได้รับเฉพาะ event ของ panel เอง

hide-close-button เอาปุ่ม × ออก ถ้าใช้ ต้องมีทางอื่นให้ปิด panel ได้

ปุ่ม ทำอะไร

Accessibility

  • panel เป็น landmark complementary ที่ใช้ heading เป็นชื่อ
  • × มีชื่อว่า "ปิด" และปุ่มย้อนกลับมีชื่อว่า "ย้อนกลับ" ตามภาษาของหน้า พร้อม tooltip เปลี่ยนได้ด้วย close-icon-description และ navigation-back-icon-description
  • panel แบบ slide-over กัก Tab ไว้ข้างใน แต่หน้าเว็บข้างหลังไม่ได้เป็น inert ผู้ใช้ screen reader ยังอ่านไปถึงได้ด้วยปุ่มอ่านของตัวเอง ถ้าต้องกันไม่ให้เข้าถึงหน้าเว็บเลย ให้ใช้ Modal
