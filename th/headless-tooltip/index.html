Headless Tooltip

part ของ Tooltip ให้พฤติกรรมเดียวกับ Tooltip แบบมี style แต่ไม่มี style เลย ได้แก่ popup ใน top layer ข้าง element ที่มันอธิบาย เปิดเมื่อชี้เมาส์หลังหน่วงเวลาสั้น ๆ และเมื่อได้โฟกัสจากคีย์บอร์ด ปิดเมื่อ blur เมื่อสั่งงาน element และเมื่อกด Esc เมาส์เลื่อนไปบน popup ได้ (WCAG 1.4.13) ข้อความเป็นคำอธิบายของ element หรือเป็นชื่อเมื่อมี label

ส่วนที่คุณทำเองคือ element ที่เป็น trigger ข้อความ ลูกศร และ style ทั้งหมด part ต่าง ๆ บอกสถานะผ่าน attribute data-* ให้คุณใช้ใส่ style

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Tooltip } from '@purpurabog/ui/headless';

วิธีใช้

import { Tooltip } from '@purpurabog/ui/headless'; export default function Example() { return ( <Tooltip.Root label="แก้ไขสัญญา"> <Tooltip.Trigger className="inline-block"> <button type="button" className="grid size-10 place-items-center text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current"> <path d="m13.7 4.3-2-2a1 1 0 0 0-1.4 0L2 10.6V14h3.4l8.3-8.3a1 1 0 0 0 0-1.4ZM5 13H3v-2l6-6 2 2Zm7-7-2-2 1-1 2 2Z" /> </svg> </button> </Tooltip.Trigger> <Tooltip.Popup className="w-max max-w-72 rounded-xs bg-inverse-surface-1 px-4 py-0.5 text-sm text-inverse-ink">แก้ไขสัญญา</Tooltip.Popup> </Tooltip.Root> ); }

Trigger คือ <span> ที่ครอบ element ที่รับโฟกัสได้หนึ่งตัวพอดี มันคอยดูการชี้เมาส์ โฟกัส และการสั่งงานข้างใน และให้ชื่อหรือคำอธิบายกับ element นั้น popup จะวางข้าง element ไม่ใช่ข้าง span

โครงสร้าง

<Tooltip.Root> <Tooltip.Trigger> <button type="button" /> </Tooltip.Trigger> <Tooltip.Popup /> </Tooltip.Root>

คำอธิบายหรือชื่อ

ถ้าไม่มี label ข้อความใน popup จะเป็นคำอธิบาย (accessible description) ของ element ผ่าน aria-describedby ต่อท้ายคำอธิบายที่มีอยู่เดิม ใช้กับคำแนะนำบน control ที่มีชื่อที่มองเห็นอยู่แล้ว ถ้ามี label ข้อความจะเป็น aria-label ของ element และ popup จะเป็น aria-hidden ใช้กับปุ่มที่มีแต่ไอคอน แบบใน "วิธีใช้"

import { Tooltip } from '@purpurabog/ui/headless'; export default function Example() { return ( <Tooltip.Root placement="bottom"> <Tooltip.Trigger className="inline-block"> <button type="button" className="h-10 border border-interactive px-4 text-sm text-interactive hover:bg-interactive hover:text-on-primary focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> นโยบายการเก็บเอกสาร </button> </Tooltip.Trigger> <Tooltip.Popup className="w-max max-w-72 rounded-xs bg-inverse-surface-1 p-4 text-sm text-inverse-ink">เก็บสำเนาที่ลงนามแล้วไว้ 10 ปี</Tooltip.Popup> </Tooltip.Root> ); }

ตำแหน่งและลูกศร

placement รับ top (ค่าเริ่มต้น), bottom, left, right แต่ละแบบเติม -start / -end ได้ ถ้าที่ไม่พอ popup จะพลิก และ data-side บอกว่าไปอยู่ฝั่งไหน gap คือระยะห่างจาก element (ค่าเริ่มต้น 8px)

เมื่อมี caret popup จะได้ --_caret-start คือจุดเริ่มของลูกศรที่กว้าง --_caret-w (12px ถ้าไม่ตั้ง) ตามแนวขอบ เพื่อให้ชี้ไปกลาง element ลูกศรคุณวาดเอง แบบด้านล่าง

import { Tooltip } from '@purpurabog/ui/headless'; const caret = [ 'pointer-events-none absolute h-1.5 w-3 bg-inherit', 'group-data-[side=top]:top-full group-data-[side=top]:left-(--_caret-start) group-data-[side=top]:[clip-path:polygon(0_0,100%_0,50%_100%)]', 'group-data-[side=bottom]:bottom-full group-data-[side=bottom]:left-(--_caret-start) group-data-[side=bottom]:[clip-path:polygon(50%_0,100%_100%,0_100%)]', 'group-data-[side=left]:top-(--_caret-start) group-data-[side=left]:left-full group-data-[side=left]:h-3 group-data-[side=left]:w-1.5 group-data-[side=left]:[clip-path:polygon(0_0,100%_50%,0_100%)]', 'group-data-[side=right]:top-(--_caret-start) group-data-[side=right]:right-full group-data-[side=right]:h-3 group-data-[side=right]:w-1.5 group-data-[side=right]:[clip-path:polygon(100%_0,0_50%,100%_100%)]', ].join(' '); const sides = [ { side: 'top', label: 'บน', text: 'เปิดด้านบน' }, { side: 'bottom', label: 'ล่าง', text: 'เปิดด้านล่าง' }, { side: 'left', label: 'ซ้าย', text: 'เปิดด้านซ้าย' }, { side: 'right', label: 'ขวา', text: 'เปิดด้านขวา' }, ] as const; export default function Example() { return ( <div className="flex flex-wrap items-center gap-4"> {sides.map(({ side, label, text }) => ( <Tooltip.Root key={side} placement={side} gap={12} caret> <Tooltip.Trigger className="inline-block"> <button type="button" className="h-8 border border-interactive px-3 text-sm text-interactive hover:bg-interactive hover:text-on-primary focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> {label} </button> </Tooltip.Trigger> <Tooltip.Popup className="group w-max max-w-72 overflow-visible rounded-xs bg-inverse-surface-1 p-4 text-sm text-inverse-ink"> {text} <span aria-hidden="true" className={caret} /> </Tooltip.Popup> </Tooltip.Root> ))} </div> ); }

หน่วงเวลา

popup เปิดหลังเมาส์มาถึง 100ms (delay) และปิดหลังเมาส์ออกจากทั้ง element และ popup 300ms (closeDelay, leaveDelayMs ของ Carbon) โฟกัสจากคีย์บอร์ดเปิดทันที เพิ่ม delay ใน toolbar ที่มีปุ่มถี่ ๆ เพื่อไม่ให้ tooltip กะพริบตอนเมาส์ลากผ่าน

import { Tooltip } from '@purpurabog/ui/headless'; function Tip({ text, delay }: { text: string; delay?: number }) { return ( <Tooltip.Root delay={delay} placement="bottom"> <Tooltip.Trigger className="inline-block"> <button type="button" className="h-8 px-3 text-sm text-link hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> {text} </button> </Tooltip.Trigger> <Tooltip.Popup className="w-max rounded-xs bg-inverse-surface-1 px-4 py-0.5 text-sm text-inverse-ink"> เปิดหลัง {delay ?? 100}ms </Tooltip.Popup> </Tooltip.Root> ); } export default function Example() { return ( <div className="flex flex-wrap items-center gap-4"> <Tip text="หน่วงตามค่าเริ่มต้น" /> <Tip text="ช้า (600ms)" delay={600} /> </div> ); }

เปิดค้างไว้: "คัดลอกแล้ว"

ควบคุมสถานะเองด้วย open และ onOpenChange ระหว่างที่ flag ของคุณยังตั้งอยู่ popup จะค้างไว้ ไม่ว่าการชี้เมาส์ โฟกัส การคลิก หรือ Esc จะรายงานอะไร ใช้กับข้อความยืนยันสั้น ๆ ลองคลิกเลขที่สัญญาด้านล่าง

import { useEffect, useState } from 'react'; import { Tooltip } from '@purpurabog/ui/headless'; export default function Example() { const [hover, setHover] = useState(false); const [copied, setCopied] = useState(false); useEffect(() => { if (!copied) return; const timer = setTimeout(() => setCopied(false), 2000); return () => clearTimeout(timer); }, [copied]); const copy = async () => { await navigator.clipboard?.writeText('CN-2026-0142').catch(() => undefined); setCopied(true); }; return ( <Tooltip.Root open={hover || copied} onOpenChange={setHover}> <Tooltip.Trigger className="inline-block"> <button type="button" onClick={copy} className="h-10 px-4 font-mono text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> CN-2026-0142 </button> </Tooltip.Trigger> <Tooltip.Popup className="w-max rounded-xs bg-inverse-surface-1 px-4 py-0.5 text-sm text-inverse-ink"> {copied ? 'คัดลอกแล้ว' : 'คัดลอกเลขที่สัญญา'} </Tooltip.Popup> </Tooltip.Root> ); }

onOpenChange รายงานเฉพาะเมื่อค่าเปลี่ยน การคลิก tooltip ที่ปิดอยู่จึงไม่รายงานอะไร ส่วน disabled ที่ Root เป็นกรณีกลับกัน popup ไม่แสดงเลย (เช่น ระหว่างที่ข้อความยังโหลดไม่เสร็จ) แต่การชี้เมาส์และโฟกัสยังรายงานอยู่

อธิบายว่าทำไมกดไม่ได้

ปุ่มที่ disabled รับโฟกัสไม่ได้ ผู้ใช้คีย์บอร์ดจึงไม่เห็น tooltip ของมัน ให้ใช้ aria-disabled="true" แทน ไม่สนใจการคลิก และบอกเหตุผลใน tooltip

import { Tooltip } from '@purpurabog/ui/headless'; export default function Example() { return ( <Tooltip.Root placement="right"> <Tooltip.Trigger className="inline-block"> <button type="button" aria-disabled="true" onClick={(e) => e.preventDefault()} className="h-10 cursor-not-allowed bg-button-disabled px-4 text-sm text-on-color-disabled focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus" > ลงนามสัญญา </button> </Tooltip.Trigger> <Tooltip.Popup className="w-max max-w-72 rounded-xs bg-inverse-surface-1 p-4 text-sm text-inverse-ink"> เฉพาะผู้อนุมัติเท่านั้นที่ลงนามได้ ติดต่อคุณอนัญญา ฝ่ายกฎหมาย </Tooltip.Popup> </Tooltip.Root> ); }

ใส่ style

import { Tooltip } from '@purpurabog/ui/headless'; export default function Example() { return ( <Tooltip.Root placement="bottom" gap={12} caret> <Tooltip.Trigger className="group/trigger inline-block"> <button type="button" className="h-10 border-b-2 border-transparent px-4 text-sm text-ink group-data-open/trigger:border-interactive focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> ฉบับที่ 3 </button> </Tooltip.Trigger> <Tooltip.Popup className="group w-max max-w-72 overflow-visible rounded-xs bg-inverse-surface-1 p-4 text-sm text-inverse-ink"> แก้ไขล่าสุด 12 มีนาคม 2569 โดยสมชาย <span aria-hidden="true" className="pointer-events-none absolute bottom-full left-(--_caret-start) h-1.5 w-3 bg-inherit [clip-path:polygon(50%_0,100%_100%,0_100%)] group-data-[side=top]:top-full group-data-[side=top]:bottom-auto group-data-[side=top]:[clip-path:polygon(0_0,100%_0,50%_100%)]" /> </Tooltip.Popup> </Tooltip.Root> ); } /* className="tip" ที่ Trigger, "bubble" ที่ Popup, "caret" ที่ span ข้างใน */ .tip[data-open] button { border-bottom-color: #0f62fe; } .bubble { width: max-content; max-width: 288px; padding: 16px; background: #393939; color: #f4f4f4; } .caret { position: absolute; left: var(--_caret-start); width: 12px; height: 6px; background: inherit; } .bubble[data-side='bottom'] .caret { bottom: 100%; clip-path: polygon(50% 0, 100% 100%, 0 100%); } .bubble[data-side='top'] .caret { top: 100%; clip-path: polygon(0 0, 100% 0, 50% 100%); }

Parts

Tooltip.Root

ไม่ render element ของตัวเอง เก็บสถานะเปิดและตัวจับเวลาการชี้เมาส์ วาง popup และปิดเมื่อกด Esc

Prop Type ค่าเริ่มต้น
open boolean แสดงอยู่ (ควบคุมเอง) การชี้เมาส์และโฟกัสจะแค่รายงานผ่าน onOpenChange
defaultOpen boolean false แสดงตั้งแต่แรก (ไม่ควบคุมเอง)
onOpenChange (open: boolean) => void เมื่อการชี้เมาส์ โฟกัส การสั่งงาน หรือ Esc จะเปลี่ยนค่า (เฉพาะเมื่อเปลี่ยน)
label string ใช้ข้อความเป็นชื่อของ element แทนคำอธิบาย popup จะเป็น aria-hidden
disabled boolean false ไม่แสดงเลย การชี้เมาส์และโฟกัสยังรายงานอยู่
placement Placement 'top' top, bottom, left, right แต่ละแบบเติม -start / -end ได้
gap number 8 ระยะห่างระหว่าง element กับ popup หน่วย px
caret boolean false เขียน --_caret-start ที่ popup
delay number 100 เวลาที่ต้องชี้เมาส์ค้างก่อนเปิด หน่วย ms
closeDelay number 300 เวลาหลังเมาส์ออกก่อนปิด หน่วย ms

Tooltip.useTooltipContext() คืนสถานะของ Root (open, popupId, label …) ให้ component ใดก็ได้ที่อยู่ข้างใน

Tooltip.Trigger

<span> ที่ครอบ element หนึ่งตัวที่ tooltip อธิบาย (child ตัวแรก) คอยดูการชี้เมาส์ โฟกัสจากคีย์บอร์ด (เฉพาะ :focus-visible เพราะการคลิกเมาส์มี tooltip จากการชี้ไปแล้ว) การคลิก และ Enter / Space ข้างใน ใส่ aria-describedby (หรือ aria-label เมื่อมี label) ให้ element นั้น และวาง popup ข้างมัน รับ prop ทุกตัวของ span

Attribute เมื่อ
data-open popup แสดงอยู่

Tooltip.Popup

<span role="tooltip" popover="manual"> ใน top layer มี id ที่ aria-describedby ของ element ชี้มา เนื้อหายัง render อยู่ตอนปิด เมาส์วางบนมันได้ รับ prop ทุกตัวของ span ยกเว้น popover, id และ role

Attribute เมื่อ
data-open แสดงอยู่
data-side top, bottom, left หรือ right คือฝั่งที่ไปอยู่

เมื่อ Root มี caret popup จะได้ CSS variable --_caret-start ด้วย

คีย์บอร์ดและ accessibility

ปุ่ม ผลลัพธ์
Tab โฟกัสมาถึง element แล้ว popup เปิดทันที โฟกัสออกไปแล้วปิด
Esc ปิดเฉพาะ tooltip (dialog ที่ครอบอยู่ยังเปิดอยู่) โฟกัสอยู่ที่เดิม
Enter, Space สั่งงาน element แล้วปิด popup

part ต่าง ๆ ตั้ง role="tooltip" ที่ popup และ aria-describedby หรือ aria-label ที่ element การคลิกก็ปิด popup ด้วย เพื่อไม่ให้บังผลลัพธ์

ส่วนที่คุณเพิ่มเอง

  • element ที่รับโฟกัสได้ไว้ใน Trigger <span> หรือไอคอนเปล่า ๆ ไม่ได้รับโฟกัสจากคีย์บอร์ด
  • ไม่ใส่อะไรที่ต้องกดไว้ใน popup ถ้าต้องการ ให้ใช้ Headless Popover
