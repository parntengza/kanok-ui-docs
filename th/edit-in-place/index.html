Edit in place

Edit in place แสดงค่าเป็นข้อความธรรมดาที่แก้ไขได้ตรงที่มันอยู่ ไม่ต้องเปิดฟอร์ม (EditInPlace ของ Carbon for IBM Products) เมื่อ hover จะมีพื้นสีของช่องกรอกและปุ่ม "แก้ไข" เมื่อคลิกหรือ Tab เข้าไป จะกลายเป็นช่องกรอกที่มีปุ่ม "ยกเลิก" และ "บันทึก" ใช้กับค่าเดียวในหน้าที่ส่วนใหญ่ใช้อ่าน เช่น ชื่อสัญญาหรือเลขอ้างอิง

บันทึกและยกเลิก

ui-save เกิดเมื่อบันทึกการเปลี่ยนแปลง: กดบันทึก กด Enter หรือ focus ออกไปพร้อมการเปลี่ยนแปลงที่ถูกต้อง ui-cancel เกิดเมื่อค่าถูกคืนกลับ: กดยกเลิก กด Escape หรือ focus ออกไปโดยไม่มีการเปลี่ยนแปลงที่ถูกต้อง ทั้งคู่ส่งค่ามาใน detail.value ปุ่มบันทึกและยกเลิกกดได้เมื่อค่าเปลี่ยนแล้วเท่านั้น (ช่องว่างหัวท้ายไม่นับ)

คีย์บอร์ด

ปุ่ม ระหว่างแก้ไข
Tab เข้าไปในช่อง ซึ่งเริ่มการแก้ไข จากนั้นไปที่ยกเลิกและบันทึกเมื่อกดได้แล้ว แล้วออกไป (ออกไปพร้อมการเปลี่ยนแปลงที่ถูกต้องจะบันทึก ไม่เช่นนั้นจะคืนค่า)
Enter บันทึกการเปลี่ยนแปลงที่ถูกต้องและแก้ไขต่อ ถ้าไม่มีอะไรให้บันทึก จะหยุดแก้ไข โดย focus ยังอยู่ในช่อง
Escape คืนค่าและแก้ไขต่อ

Accessibility

  • ช่องเป็น text box ที่มีชื่อจาก label ให้ตั้ง label ที่บอกชื่อค่า ("ชื่อสัญญา") เพราะไม่มีอะไรที่มองเห็นบอกไว้
  • invalid ตั้ง aria-invalid และ invalid-text เป็นคำอธิบายของช่อง จึงถูกอ่านไปด้วย
  • ปุ่มมีชื่อและ tooltip การกดบันทึกหรือยกเลิก focus ยังคงอยู่ในช่อง
  • ออกจากช่องพร้อมการเปลี่ยนแปลงที่ถูกต้องจะบันทึกโดยไม่ต้องคลิก ถ้าอาจทำให้ผู้ใช้แปลกใจ ให้บอกไว้ในคำอธิบายของหน้า หรือใช้ text input ปกติกับปุ่มบันทึกสำหรับค่าที่มีผลตามมา
