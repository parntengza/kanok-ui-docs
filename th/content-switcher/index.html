Content switcher

Content switcher แสดงเนื้อหาเดิมในอีกแบบหนึ่ง: ตัวกรอง (คำขอทั้งหมดหรือเฉพาะของฉัน) หรือมุมมอง (ตารางหรือกริด) เลือกได้ทีละหนึ่งรายการเสมอ และเปลี่ยนทันทีที่เลือก

เปลี่ยนเนื้อหา

switcher บอกแค่ว่าผู้ใช้เลือกอะไร: ui-change เกิดพร้อม detail.index และ detail.name ของรายการที่เลือก การแสดงเนื้อหาที่ตรงกันเป็นหน้าที่ของคุณ วางเนื้อหานั้นไว้ต่อจาก switcher ทันที

    เลือกด้วยตัวเอง (manual)

    ค่าเริ่มต้นคือปุ่มลูกศรเลือกไปพร้อมกับการย้าย (selection-mode="automatic") ถ้าใช้ selection-mode="manual" (selectionMode) ปุ่มลูกศรจะย้ายแค่โฟกัส แล้วกด Enter หรือ Space เพื่อเลือก ใช้เมื่อการเปลี่ยนต้องโหลดข้อมูล

    Accessibility

    • switcher เป็น tablist และแต่ละรายการเป็น tab ที่มี aria-selected ตั้งชื่อกลุ่มด้วย aria-label
    • มีจุดหยุดของ Tab จุดเดียว คือรายการที่เลือก (หรือรายการแรกที่ใช้งานได้) ปุ่ม ← และ → ย้ายและวนรอบ ข้ามรายการที่ปิดใช้งาน (กลับด้านเมื่อเขียนจากขวาไปซ้าย) Home และ End ไปที่ปลายทั้งสองข้าง ในโหมด manual กด Enter หรือ Space เพื่อเลือก
    • รายการไม่ได้ควบคุม panel ใด (aria-controls) ให้วางเนื้อหาที่เปลี่ยนไว้ต่อจาก switcher ทันที ผู้ใช้คีย์บอร์ดและ screen reader จะเจอเนื้อหานั้นเป็นอย่างถัดไป
    • รายการแบบไอคอนอย่างเดียวต้องมี label ซึ่งเป็นทั้งชื่อและ tooltip

    ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Content switcher

    สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

    <ui-content-switcher> · React UiContentSwitcher

    Attribute

    Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
    selected-index selectedIndex number 0
    size size ContentSwitcherSize 'md'
    selection-mode selectionMode ContentSwitcherSelectionMode 'automatic'
    low-contrast lowContrast boolean false
    icon-only iconOnly boolean false Reflected by the switcher itself when every item is icon-only.

    Method

    Method คำอธิบาย
    focus(options) Focus the selected item (the tab stop).

    Event

    Event React คำอธิบาย
    ui-change onUiChange detail: { index, name } after the user selects a different item

    Slot

    Slot คำอธิบาย
    (ค่าเริ่มต้น) <ui-content-switcher-item> elements

    CSS custom property

    Custom property ค่าเริ่มต้น คำอธิบาย
    --ui-content-switcher-border / --ui-content-switcher-selected-fill / --ui-content-switcher-selected-ink - Border, selected fill and selected text of the default kind (default: Carbon's inverse; Kanok: no border, a segment in the page colour with ink text)
    --ui-content-switcher-track / --ui-content-switcher-padding / --ui-content-switcher-radius / --ui-content-switcher-outline - The track around the items (default transparent, 0, 4px, border-inverse: Carbon's outlined group; Kanok: the contained tabs' segmented track)
    --ui-content-switcher-item-radius / --ui-content-switcher-item-size / --ui-content-switcher-item-grow / --ui-content-switcher-divider / --ui-content-switcher-selected-shadow - Its items (on <ui-content-switcher-item>)

    Attribute

    Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย

    icon-only iconOnly boolean false
    tooltip-placement tooltipPlacement TooltipPlacement 'top' Where the icon-only tooltip shows (Carbon align, default top).
