Headless Pagination nav

PaginationNav คือพฤติกรรมของ Pagination nav แบบมี style ในรูป React part ที่ไม่มี style Root เก็บหน้าปัจจุบัน (นับจาก 0 เหมือน Carbon) และจัดแถว: หมายเลขหน้าไหนแสดง และหน้าไหนพับเข้าเมนู "…" ที่ปลายทั้งสองข้าง โดยเลื่อนตามหน้าปัจจุบันแบบเดียวกับ Carbon Prev, Next, Page และ Overflow ใช้ย้ายหน้า ส่วน Status ประกาศการเปลี่ยนหน้า

markup และ style ทั้งหมดเป็นของคุณ ทั้งรายการ ไอคอน เส้นใต้ของหน้าปัจจุบัน "…" ที่วางทับแต่ละเมนู และคำที่ screen reader อ่าน

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { PaginationNav } from '@purpurabog/ui/headless';

วิธีใช้

Root ไม่ได้ render แถวเอง ให้อ่าน items จาก PaginationNav.usePaginationNavContext() ใน component ที่อยู่ข้างใน แล้ว render แต่ละรายการเป็น Page หรือ Overflow

import { PaginationNav } from '@purpurabog/ui/headless'; const pageClass = 'relative h-10 min-w-10 cursor-pointer border-0 bg-transparent px-1 text-sm text-ink hover:bg-layer-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-current:font-semibold data-current:after:absolute data-current:after:bottom-0 data-current:after:start-[calc(50%-8px)] data-current:after:h-1 data-current:after:w-4 data-current:after:bg-border-interactive'; const stepClass = 'grid size-10 cursor-pointer place-items-center border-0 bg-transparent text-ink hover:bg-layer-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:bg-transparent data-disabled:text-ink-disabled'; const overflowClass = 'h-10 w-10 cursor-pointer appearance-none border-0 bg-transparent text-transparent hover:bg-layer-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed [&>option]:bg-layer-1 [&>option]:text-ink'; function Row() { const { items, page, total } = PaginationNav.usePaginationNavContext(); return ( <> <ul className="m-0 flex list-none items-center p-0"> <li> <PaginationNav.Prev aria-label="ก่อนหน้า" className={stepClass}> <svg viewBox="0 0 32 32" aria-hidden="true" className="size-4 fill-current"><path d="M20 24 10 16 20 8z" /></svg> </PaginationNav.Prev> </li> {items.map((item) => item.kind === 'page' ? ( <li key={`page-${item.page}`}> <PaginationNav.Page page={item.page} className={pageClass}> <span className="sr-only">หน้า </span> {item.page + 1} </PaginationNav.Page> </li> ) : ( <li key={`overflow-${item.from}`} className="relative"> <PaginationNav.Overflow from={item.from} count={item.count} aria-label="เลือกหมายเลขหน้า" className={overflowClass} /> <span aria-hidden="true" className="pointer-events-none absolute inset-0 grid place-items-center text-ink">…</span> </li> ), )} <li> <PaginationNav.Next aria-label="ถัดไป" className={stepClass}> <svg viewBox="0 0 32 32" aria-hidden="true" className="size-4 fill-current"><path d="M12 8 22 16 12 24z" /></svg> </PaginationNav.Next> </li> </ul> <PaginationNav.Status className="sr-only">หน้า {page + 1} จาก {total}</PaginationNav.Status> </> ); } export default function Example() { return ( <PaginationNav.Root totalItems={25} aria-label="การแบ่งหน้า"> <Row /> </PaginationNav.Root> ); }

โครงสร้าง

<PaginationNav.Root> <PaginationNav.Prev /> <PaginationNav.Page /> <PaginationNav.Overflow /> <PaginationNav.Next /> <PaginationNav.Status /> </PaginationNav.Root>

items (จาก usePaginationNavContext()) คือแถวตามลำดับ: หน้าแรก overflow ด้านหน้า หน้ารอบ ๆ หน้าปัจจุบัน overflow ด้านหลัง และหน้าสุดท้าย แต่ละรายการคือ { kind: 'page', page, active } หรือ { kind: 'overflow', from, count }

Parts

PaginationNav.Root

render <nav> ตั้งชื่อด้วย aria-label ("การแบ่งหน้า") รับ prop ของ <nav> ได้ทุกตัว

Prop Type ค่าเริ่มต้น
totalItems number — จำนวนหน้า (ชื่อตาม Carbon ต้องใส่)
page number — หน้าปัจจุบัน นับจาก 0 (ควบคุมเอง)
defaultPage number 0 หน้าเริ่มต้น (ไม่ควบคุมเอง)
onChange (page: number) => void — หลังผู้ใช้เลือกหน้า (นับจาก 0)
itemsShown number 10 จำนวนรายการในแถว รวม overflow (อย่างน้อย 4)
loop boolean false Prev ในหน้าแรกไปหน้าสุดท้าย Next ในหน้าสุดท้ายไปหน้าแรก
disableOverflow boolean false เปิด overflow ไม่ได้
size 'sm' | 'md' | 'lg' 'lg' มีผลแค่จำนวนรายการที่พอดีเมื่อหน้าต่างแคบกว่า 320px (ตาม Carbon)

PaginationNav.Prev, PaginationNav.Next

แต่ละตัว render <button type="button"> ที่ย้ายถอยหรือไปข้างหน้าหนึ่งหน้า ตั้งชื่อด้วย aria-label จะปิดใช้งานที่ปลายแถว เว้นแต่ใส่ loop

Attribute เมื่อ
data-disabled ย้ายไม่ได้ (หรือคุณตั้ง disabled)

PaginationNav.Page

render <button type="button"> ที่ไปยังหน้าของมัน หน้าปัจจุบันมี aria-current="page" และมี tabIndex={0} (Safari จึงโฟกัสเมื่อคลิก)

Prop Type ค่าเริ่มต้น
page number — หน้าของมัน นับจาก 0 (ต้องใส่)
Attribute เมื่อ
data-current เป็นหน้าปัจจุบัน
data-page มีเสมอ: หน้าของมัน นับจาก 1

PaginationNav.Overflow

render <select> ของหน้าที่ซ่อนอยู่ โดยมี option แรกที่ว่างและซ่อนไว้ จึงไม่แสดงอะไร ให้วาด "…" ของคุณทับไว้ เลือก option แล้วจะไปหน้านั้น ตั้งชื่อด้วย aria-label

Prop Type ค่าเริ่มต้น
from number — หน้าแรกที่ซ่อน นับจาก 0 (ต้องใส่)
count number — จำนวนหน้าที่อยู่ข้างใน (ต้องใส่)
renderPage (page: number) => ReactNode หมายเลขที่นับจาก 1 ข้อความของ option
Attribute เมื่อ
data-disabled Root มี disableOverflow หรือคุณตั้ง disabled

PaginationNav.Status

render <div aria-live="polite" aria-atomic="true"> ข้อความเป็นของคุณ เช่น "หน้า 5 จาก 25" มักซ่อนจากสายตา

usePaginationNavContext()

คืนสถานะของ Root ที่ครอบอยู่: page (นับจาก 0), total, items, loop, disableOverflow, go(page), step(-1 | 1) และ stepDisabled(-1 | 1)

คีย์บอร์ดและ accessibility

ทุกหน้า Prev, Next และ overflow เป็นปุ่มหรือ select จริง Tab จึงไล่ผ่านได้ และ Enter, Space และปุ่มของ select ใช้ได้ตามปกติ part ตั้ง aria-current="page", disabled ที่ปลายแถว และ live region แบบ polite ให้แล้ว

สิ่งที่คุณต้องใส่เอง:

  • ชื่อของ landmark: aria-label ที่ Root
  • ชื่อของ Prev, Next และ Overflow แต่ละตัว (aria-label) และ "…" ที่วาดทับ overflow โดยใส่ aria-hidden="true" และ pointer-events: none
  • คำนำหน้าหมายเลขสำหรับ screen reader ("หน้า 4") แบบข้อความที่ซ่อนจากสายตาในตัวอย่าง และข้อความของ Status
