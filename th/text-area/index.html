Text area

ช่องกรอกข้อความหลายบรรทัด เช่น หมายเหตุ คำอธิบาย หรือเหตุผล มี label, helper text และบรรทัด error เหมือน text input และเพิ่มตัวนับตัวอักษรหรือนับคำ กับช่องที่ขยายตามข้อความได้

ความสูง

rows กำหนดความสูงเริ่มต้นเป็นจำนวนบรรทัด ค่าเริ่มต้นคือ 4 แบบ Carbon ผู้ใช้ลากมุมช่องให้สูงขึ้นได้ (resize: vertical) ช่องที่ปิดใช้งานจะย่อขยายไม่ได้

ขยายตามข้อความ

auto-grow เริ่มที่ rows แล้วสูงขึ้นทีละบรรทัดตามที่ผู้ใช้พิมพ์ และไม่มีมุมสำหรับลาก max-rows จำกัดความสูงสูงสุด เกินจากนั้นช่องจะเลื่อนดูได้ Carbon ไม่มี auto-grow

นับตัวอักษรหรือนับคำ

max-count แสดงตัวนับไว้เหนือช่อง เป็นขีดจำกัดแบบไม่บังคับเหมือน text input: ถ้าเกิน ตัวนับจะเป็นสีแดง error ขึ้นทันที และฟอร์มส่งไม่ได้ แต่ไม่มีข้อความไหนถูกตัดทิ้ง screen reader จะอ่านเตือนเมื่อใกล้ครบ

counter-mode="word" นับเป็นคำแทน (counterMode ของ Carbon) ภาษาไทยไม่เว้นวรรคระหว่างคำ ช่องจึงใช้ตัวตัดคำของเบราว์เซอร์ตามภาษาของช่อง (lang ที่ช่องหรือที่หน้า): "สวัสดีครับ ผมชื่อสมชาย" นับได้ 5 คำ ส่วนวิธีนับของ Carbon จะตัดคำไทยทุกครั้งที่เจอสระหรือวรรณยุกต์ ตัวเลขไม่นับเป็นคำ

เปลี่ยนข้อความได้ด้วย too-long-text ({max} จะถูกแทนด้วยจำนวนที่กำหนด) และ near-limit-text ถ้าต้องการขีดจำกัดที่พิมพ์เกินไม่ได้เลย ให้ใช้ maxlength รายละเอียดเพิ่มเติมที่ ฟอร์มและการตรวจค่า

เขียนข้อความของตัวนับเอง

ใน element required, minlength และ maxlength ทำงานเหมือน <textarea> ส่วนใน React + Tailwind การตรวจค่าเป็นหน้าที่ของแอป ให้ส่ง invalid และ invalidText มา เรื่องอื่น ๆ ของ error ดูที่ ฟอร์มและการตรวจค่า

label และข้อความช่วยที่มี markup

Skeleton

ระหว่างที่ข้อมูลของฟอร์มกำลังโหลด <ui-text-area-skeleton> จองที่ของช่องไว้ เป็นแถบ label กับแถบช่องสูง 100px หรือเป็นกล่องแบบ fluid เมื่อใส่ fluid screen reader ข้ามแถบนี้ จึงต้องบอกว่า "กำลังโหลด" ที่ฟอร์มแทน (เช่น aria-busy="true")

HTMLReactReact + Tailwind<ui-text-area-skeleton></ui-text-area-skeleton> <ui-text-area-skeleton fluid></ui-text-area-skeleton> import { UiTextAreaSkeleton } from '@purpurabog/ui/react'; <UiTextAreaSkeleton /> <UiTextAreaSkeleton fluid /> import { TextAreaSkeleton } from '@/components/ui/react-tw/text-area'; <TextAreaSkeleton /> <TextAreaSkeleton fluid />

Accessibility

  • label เป็น <label> จริงที่ผูกกับ <textarea> ข้างใน และบรรทัดข้อความใต้ช่องเป็น aria-describedby ของมัน aria-label ที่ตัว element ไปไม่ถึง textarea ให้ใช้ label แทน (คู่กับ hide-label ถ้าไม่อยากให้เห็น)
  • Enter ขึ้นบรรทัดใหม่เหมือน text area ทั่วไป ไม่ส่งฟอร์ม
  • ตัวนับไม่ถูกอ่านทุกครั้งที่พิมพ์ screen reader จะอ่านครั้งเดียวเมื่อใกล้ครบ และเมื่อเกินจำนวนที่กำหนด

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Text area

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)
