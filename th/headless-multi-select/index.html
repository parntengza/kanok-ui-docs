Headless Multi-select

part ของ MultiSelect ให้พฤติกรรมเดียวกับ Multi-select แบบมี style แต่ไม่มี style เลย ได้แก่ ช่องที่เปิด listbox ใน top layer และเปิดค้างไว้ระหว่างที่ผู้ใช้ติ๊กรายการ รายการที่เลือกย้ายขึ้นบนสุด แถว "เลือกทั้งหมด" ที่ใส่หรือไม่ใส่ก็ได้ ช่องพิมพ์สำหรับกรอง คีย์บอร์ด และ hidden input หนึ่งตัวต่อหนึ่งค่าที่เลือก

ส่วนที่คุณทำเองคือ markup ข้อความ label ตัวเลขจำนวน ช่องติ๊กในแต่ละแถว ข้อความช่วยเหลือหรือ error ข้อความ "กำลังโหลด…" และ style ทั้งหมด part ต่าง ๆ บอกสถานะผ่าน attribute data-* ให้คุณใช้ใส่ style

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { MultiSelect, type ListOption } from '@purpurabog/ui/headless';

จำนวน ปุ่มล้างค่า และคำอธิบาย

Value แสดง children ถ้าไม่มีก็แสดง placeholder มันไม่นับจำนวนให้ อ่าน count จาก MultiSelect.useMultiSelectContext() เพื่อแสดงว่าเลือกไปกี่รายการ Clear ล้างทุกค่าที่เลือกและให้โฟกัสอยู่ที่ช่อง ปุ่มนี้ถูกปิดใช้งานเมื่อ Root ปิดใช้งานหรืออ่านอย่างเดียว ตัวอย่างด้านล่างยังไม่แสดงปุ่มในตอนนั้นด้วย เหมือน MultiSelect แบบมี style

รายการที่เลือกไปอยู่ตรงไหน

selectionFeedback กำหนดว่าแถวที่เลือกจะย้ายขึ้นบนสุดของแถวที่ Popup ส่งให้เมื่อไร

selectionFeedback แถวที่เลือก
top-after-reopen (ค่าเริ่มต้น) ย้ายขึ้นบนสุดตอนเปิดรายการครั้งถัดไป
top ย้ายขึ้นบนสุดทันที
fixed อยู่ที่เดิม

ถ้ามีกลุ่มใน items จะไม่มีอะไรย้าย

พิมพ์กรองได้

โหลดรายการตอนเปิดรายการ

onOpenChange ยิงหลังรายการเปิดหรือปิด ระหว่างที่ loading เป็น true ตัว Popup จะไม่ส่งแถวให้ แถว "เลือกทั้งหมด" ถูกซ่อน ปุ่มคีย์บอร์ดเลือกอะไรไม่ได้ และ popup มี aria-busy ให้ render แถว "กำลังโหลด…" และข้อความ role="status" เอง แบบเดียวกับใน Headless Dropdown

อ่านอย่างเดียวและปิดใช้งาน

  • readOnly แสดงค่าที่เลือก แต่เปิดรายการไม่ได้และปุ่มคีย์บอร์ดไม่ทำอะไร ช่องได้ aria-readonly (หรือช่องพิมพ์เป็น readOnly เมื่อใช้ filterable) และ Toggle กับ Clear ถูกปิดใช้งาน
  • disabled ปิดใช้งานช่อง Toggle และ Clear
  • ช่องที่ปิดใช้งานไม่ render hidden input จึงไม่ถูกส่งไปกับฟอร์ม (เหมือน control ปกติที่ปิดใช้งาน) การ reset ฟอร์มคืนค่าที่เลือกแบบ uncontrolled กลับ

Parts

MultiSelect.Root

ไม่ render element ของตัวเอง render แค่ children และ hidden input หนึ่งตัวต่อหนึ่งค่าที่เลือกเมื่อมี name และไม่ได้ disabled

Prop Type ค่าเริ่มต้น
items ListItem[] รายการและกลุ่ม { label, options }
value string[] ค่าที่เลือก (controlled)
defaultValue string[] [] ค่าเริ่มต้น (uncontrolled)
onValueChange (value: string[]) => void หลังชุดค่าที่เลือกเปลี่ยน
onInputValueChange (text: string) => void filterable: ทุกครั้งที่ข้อความที่พิมพ์เปลี่ยน
selectionFeedback 'top-after-reopen' | 'top' | 'fixed' 'top-after-reopen' รายการที่เลือกย้ายขึ้นบนสุดเมื่อไร
selectAll boolean false มีแถว SelectAll

filter 'contains' | 'starts-with' | 'none' 'contains' ข้อความที่พิมพ์กรองรายการอย่างไร (filterable)

ปุ่ม ตอนรายการปิด ตอนรายการเปิด
↓, Enter, Space เปิดรายการ Enter และ Space ติ๊กหรือเอาติ๊กออกจากแถวที่ไฮไลต์ รายการยังเปิดอยู่
↓ / ↑, Page Down / Page Up, Home / End ↑ ไม่ทำอะไร ส่วน Home / End เปิดที่แถวแรก / สุดท้าย เลื่อนไฮไลต์
ตัวอักษร เปิดที่รายการถัดไปที่ขึ้นต้นด้วยตัวอักษรนั้น กระโดดไปรายการถัดไปที่ขึ้นต้นด้วยตัวอักษรนั้น

Tab ไปช่องถัดไป ปิดรายการแล้วไปช่องถัดไป

เมื่อใช้ filterable ตัวอักษร Space, Home, End, Delete และ Backspace ใช้แก้ข้อความ ↓ หรือ Enter เปิดรายการ Enter ติ๊กแถวที่ไฮไลต์ (หรือปิดรายการเมื่อไม่มีไฮไลต์) และ Esc ตอนรายการปิดจะล้างค่าที่เลือกและข้อความ

part ต่าง ๆ ตั้ง role="combobox", aria-haspopup, aria-expanded, aria-controls, aria-activedescendant, aria-readonly, aria-required และ aria-invalid ที่ช่อง และตั้ง aria-multiselectable, aria-selected และ aria-checked="mixed" ที่รายการ โฟกัสอยู่ที่ช่องตลอด

ส่วนที่คุณเพิ่มเอง

  • ข้อความ label ใน Label
  • aria-label ที่ Clear, ClearText และ Toggle
  • ตัวเลขจำนวนถ้าจะแสดง และช่องติ๊กที่วาดในแต่ละแถว (ซ่อนจาก screen reader เพราะ aria-selected บอกอยู่แล้ว)
  • ข้อความช่วยเหลือและ error ผูกด้วย aria-describedby ที่ช่อง
  • ข้อความ role="status" สำหรับ "กำลังโหลด…", "กำลังค้นหา…" และ "ไม่พบรายการที่ตรงกัน"
