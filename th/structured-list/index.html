Structured list

Structured list แสดงข้อความไม่กี่แถวเป็นคอลัมน์ เช่น เปรียบเทียบแพ็กเกจ หรือแสดงเงื่อนไขของสัญญา เบากว่า data table คือไม่มีการเรียงลำดับและไม่มี toolbar ถ้าใส่ selection ผู้ใช้จะเลือกได้หนึ่งแถว

แพ็กเกจ ผู้ใช้ ราคา สิ่งที่ได้ พื้นฐาน ไม่เกิน 5 คน ฟรี แม่แบบใช้ร่วมกัน เก็บประวัติการใช้งาน 30 วัน ทีม ไม่เกิน 50 คน ฿390 / คน ขั้นตอนอนุมัติ SSO เก็บประวัติการใช้งาน 1 ปี องค์กร ไม่จำกัด ติดต่อฝ่ายขาย เลือก region เอง กำหนดระยะเก็บข้อมูลเอง มี SLA

Structured list หรือ data table?

Component ใช้เมื่อ
Structured list มีไม่กี่แถวให้อ่าน เปรียบเทียบ หรือเลือกหนึ่งแถว ข้อความในเซลล์ตัดบรรทัดได้และใส่อะไรก็ได้
Data table มีหลายแถว ผู้ใช้ต้องเรียงลำดับ ค้นหา เลือกหลายแถว หรือเปลี่ยนหน้า
Contained list รายการคอลัมน์เดียว แต่ละรายการมีปุ่มของตัวเอง อยู่ใน panel หรือ tile

แถวหัวตาราง

head ที่แถวแรกทำให้เซลล์ในแถวนั้นเป็นหัวคอลัมน์ (ตัวหนา, columnheader) ไม่ต้องใส่ถ้าเป็นรายการคู่ ชื่อ–ค่า ที่คอลัมน์แรกบอกอยู่แล้วว่าแต่ละแถวคืออะไร

คู่สัญญา บริษัท เอซีเอ็ม จำกัด ลงนามเมื่อ 30 กันยายน 2569 ผู้รับผิดชอบ ฝ่ายกฎหมาย คุณสมชาย ก.

เลือกหนึ่งแถว

selection ทำให้แถวในตัวตารางเป็นตัวเลือกเดียว แต่ละแถวมี radio ในเซลล์แรก คลิกตรงไหนของแถวก็ได้ หรือกด Space หรือปุ่มลูกศรเพื่อเลือก ใส่ value ให้ทุกแถว value ของ list คือแถวที่เลือกอยู่ และ ui-change (onChange ใน React + Tailwind) ยิงเมื่อผู้ใช้เลือกแถวอื่น

แพ็กเกจ ผู้ใช้ ราคา พื้นฐาน ไม่เกิน 5 คน ฟรี ทีม ไม่เกิน 50 คน ฿390 / คน องค์กร ไม่จำกัด ติดต่อฝ่ายขาย

Skeleton

ระหว่างโหลดแถว ให้แสดง ui-structured-list-skeleton แทน คือหัวตารางเป็นแถบสามแถบ และแถวว่าง rows แถว (ค่าเริ่มต้น 5) มันซ่อนจาก screen reader จึงต้องบอก "กำลังโหลด" ที่ตัวที่ครอบอยู่ (เช่น aria-busy)

Accessibility

  • list เป็น role="table" มี role row, cell และ columnheader ส่วน React + Tailwind สร้าง <table> จริง
  • ใน list ที่เลือกได้ radio ของทุกแถวเป็นกลุ่มเดียวกัน Tab ไปถึงแถวที่เลือกอยู่ (ถ้าไม่มีก็แถวแรก) ปุ่มลูกศรย้ายและเลือก วนกลับเมื่อสุดปลาย แต่ละ radio บอกลำดับ เช่น "1 จาก 3"
  • แถวที่เลือกมี aria-selected เมื่อ focus จะมีเส้นขอบ 2px รอบทั้งแถว
  • list ที่เลือกได้ไม่ใช่ช่องในฟอร์ม ให้อ่าน value แล้วส่งเอง

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Structured list
