Slider

slider ใช้เลือกตัวเลขหนึ่งค่า หรือช่วงระหว่างสองค่า จากสเกล มีช่องตัวเลขข้างแถบให้ผู้ใช้พิมพ์ค่าที่ต้องการได้ตรง ๆ

HTMLReactReact + Tailwind<ui-slider label="ระดับเสียง" name="volume" value="40"></ui-slider> <UiSlider label="ระดับเสียง" name="volume" value={40} /> <Slider label="ระดับเสียง" name="volume" defaultValue={40} />

วิธีใช้

HTMLReactReact + Tailwind<script type="module">import '@purpurabog/ui/slider';</script> <ui-slider label="ระดับเสียง" name="volume" value="40"></ui-slider> import { UiSlider } from '@purpurabog/ui/react'; import type { UiSlider as SliderElement } from '@purpurabog/ui'; <UiSlider label="ระดับเสียง" name="volume" value={volume} onChange={(e) => setVolume((e.target as SliderElement).value)} /> import { Slider } from '@/components/ui/react-tw/slider'; <Slider label="ระดับเสียง" name="volume" value={volume} onChange={setVolume} />

web component ยิง input ขณะค่าขยับ (ลาก กดปุ่ม พิมพ์) และยิง change เมื่อค่าถูกยืนยัน: ปล่อยเมาส์ กดปุ่มลูกศร หรือออกจากช่องตัวเลข ใน React คือ onInput / onChange ของ UiSlider ส่วน Slider ของ Tailwind เรียก onChange(value) ทุกครั้งที่ค่าเปลี่ยน และ onRelease(value) เมื่อยืนยัน

สเกลและ step

min และ max กำหนดปลายทั้งสอง (ค่าเริ่มต้น 0 และ 100) ส่วน step คือระยะที่ขยับแต่ละครั้ง (1) ปุ่มลูกศรขยับหนึ่ง step ถ้ากด Shift ด้วยจะขยับ step-multiplier step (ค่าเริ่มต้น 4) min-label และ max-label เติมหน่วยต่อท้ายตัวเลขที่ปลาย

HTMLReactReact + Tailwind<ui-slider label="ส่วนลด" min="0" max="50" step="5" value="10" min-label="%" max-label="%"></ui-slider> <UiSlider label="ส่วนลด" min={0} max={50} step={5} value={10} minLabel="%" maxLabel="%" /> <Slider label="ส่วนลด" min={0} max={50} step={5} defaultValue={10} minLabel="%" maxLabel="%" />

จัดรูปตัวเลข

ถ้าต้องการคุมมากกว่านั้น property formatLabel (ฟังก์ชัน (value, label) => string) จัดรูปตัวเลขที่ปลายและค่าที่ screen reader อ่าน ใน web component เป็น property ใน React ทั้งสองแบบเป็น prop เมื่อใช้ hide-text-input tooltip บนปุ่มเลื่อนก็ใช้ฟังก์ชันนี้ด้วย จำนวนเงินจึงแสดงเป็นจำนวนเงิน

สองปุ่ม: เลือกเป็นช่วง

ใส่ value-upper แล้ว slider จะเลือกช่วงตั้งแต่ value ถึง value-upper ปุ่มเลื่อนทั้งสองไม่ข้ามกัน การกดบนแถบจะขยับปุ่มที่ใกล้กว่า และแต่ละปุ่มมีช่องตัวเลขของตัวเอง: ช่องล่างอยู่หน้าแถบ ช่องบนอยู่หลังแถบ

ค้นหาราคา 200 ถึง 600

HTMLReactReact + Tailwind<ui-slider id="slider-price" label="ราคา" min="0" max="1000" step="10" value="200" value-upper="600" name="min-price" name-upper="max-price"></ui-slider> <p>ค้นหาราคา <output id="slider-price-out">200 ถึง 600</output></p> <script type="module"> const price = document.getElementById('slider-price'); price.addEventListener('change', () => { document.getElementById('slider-price-out').textContent = `${price.value} ถึง ${price.valueUpper}`; }); </script> <UiSlider label="ราคา" min={0} max={1000} step={10} value={200} valueUpper={600} name="min-price" nameUpper="max-price" onChange={(e) => { const slider = e.target as SliderElement; search(slider.value, slider.valueUpper); }} /> <Slider label="ราคา" min={0} max={1000} step={10} defaultValue={200} defaultValueUpper={600} name="min-price" nameUpper="max-price" onRelease={(low, high) => search(low, high)} />

ฟอร์มได้ทั้งสองค่า: ค่าบนส่งภายใต้ name-upper หรือถ้าไม่ใส่ name-upper ทั้งสองค่าจะส่งภายใต้ name เดียวกัน ปุ่มเลื่อนถูกอ่านว่า "ขอบล่าง" และ "ขอบบน" ต่อจาก label ของ slider ส่วน input-label และ upper-input-label เปลี่ยนชื่อของช่องตัวเลข

ช่องตัวเลข

ช่องตัวเลขแสดงค่าเดียวกับ slider และการพิมพ์ก็เปลี่ยนค่าได้:

  • ตัวเลขที่อยู่ในช่วงมีผลทันที โดยปัดไปที่ step ที่ใกล้ที่สุด
  • ตอนออกจากช่องหรือกด Enter ตัวเลขที่อยู่นอก min / max ถูกปรับเป็นปลายที่ใกล้ที่สุด และ screen reader ได้ยินว่าค่าถูกปรับ (corrected-text เปลี่ยนข้อความได้ {value} คือตัวเลขที่พิมพ์)
  • ช่องที่ไม่มีตัวเลข (เช่น ลบจนว่าง) แสดง error "กรุณากรอกตัวเลข" และกันการส่งฟอร์มจนกว่าจะแก้

hide-text-input เอาช่องตัวเลขออก แล้วแสดงค่าเป็น tooltip บนปุ่มเลื่อนแทน:

HTMLReactReact + Tailwind<ui-slider label="ความสว่าง" value="70" hide-text-input></ui-slider> <UiSlider label="ความสว่าง" value={70} hideTextInput /> <Slider label="ความสว่าง" defaultValue={70} hideTextInput />

อ่านอย่างเดียวและปิดใช้งาน

readonly เก็บค่าและส่งไปกับฟอร์ม แต่ขยับปุ่มเลื่อนไม่ได้และแก้ช่องตัวเลขไม่ได้ ปุ่มเลื่อนที่อ่านอย่างเดียวจะออกจากลำดับ Tab ยกเว้นตอนที่ซ่อนช่องตัวเลข ผู้ใช้จึงยังไปถึงค่าได้เสมอ disabled ทำให้ทุกส่วนเป็นสีจางและไม่ส่งค่า

แสดงค่าระหว่างเลื่อน

ใช้ input อัปเดตสิ่งที่ขึ้นกับค่าระหว่างที่ปุ่มเลื่อนขยับ และใช้ change บันทึกเมื่อค่านิ่งแล้ว ใน React + Tailwind คือ onChange และ onRelease

คีย์บอร์ด

ที่ปุ่มเลื่อน:

ปุ่ม ผล
← / ↓ ลดหนึ่ง step
→ / ↑ เพิ่มหนึ่ง step
Shift + ลูกศร ขยับ step-multiplier step (ค่าเริ่มต้น 4)
Home / End ไปที่ min / max (โหมดช่วงไปได้ถึงปุ่มเลื่อนอีกตัว)

ในช่องตัวเลข กด Enter เพื่อยืนยันตัวเลขที่พิมพ์

Accessibility

  • ปุ่มเลื่อนแต่ละตัวเป็น role="slider" มี aria-valuemin, aria-valuemax, aria-valuenow และ aria-valuetext และใช้ label เป็นชื่อ ในโหมดช่วง ขอบเขตของแต่ละปุ่มหยุดที่ปุ่มอีกตัว
  • คลิกที่ label แล้วโฟกัสไปที่ปุ่มเลื่อน เหมือน label ของ range input แบบ native
  • ช่องตัวเลขเป็น number input แบบ native มีชื่อของตัวเอง ("ช่องกรอกค่าของแถบเลื่อน" หรือ "ขอบล่าง" / "ขอบบน" เปลี่ยนได้ด้วย input-label และ upper-input-label)
  • error ตั้ง aria-invalid และผูกด้วย aria-describedby ตัวเลขที่ถูกปรับจะถูกประกาศผ่าน live region แบบ polite

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Slider
