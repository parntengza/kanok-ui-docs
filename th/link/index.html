Link หรือ Button?

Component ใช้เมื่อ
Link พาไปที่อื่น: หน้าอื่น ส่วนอื่นของหน้านี้ หรือไฟล์ ความสามารถของลิงก์ใน browser ใช้ได้ครบ (เปิดในแท็บใหม่ คัดลอกที่อยู่)
Button ทำบางอย่างตรงนี้: ส่งฟอร์ม เปิด modal เริ่ม export

ถ้าต้องการให้หน้าตาเป็นปุ่มแต่พาไปหน้าอื่น ให้ใช้ปุ่มที่มี href ดู Button

ใช้กับ router ของแอปหน้าเดียว

การคลิกแบบปกติ (ปุ่มซ้าย ไม่กดปุ่ม modifier แท็บเดิม เว็บเดียวกัน ไม่ใช่การดาวน์โหลด) จะส่ง ui-navigate ที่ยกเลิกได้ก่อน โดยมี detail.href เรียก preventDefault() แล้วส่ง path ให้ router ของคุณ browser จะไม่โหลดหน้านั้น ส่วน Ctrl-, ⌘- และคลิกปุ่มกลางยังเป็นลิงก์ปกติ Link ของ React + Tailwind เป็น <a> ธรรมดา ให้จัดการใน onClick หรือครอบลิงก์ของ router เอง

Accessibility

  • ลิงก์เป็น <a href> จริง กด Enter เพื่อไปตามลิงก์ และเมนูของ browser (เปิดในแท็บใหม่ คัดลอกที่อยู่) ใช้ได้
  • เขียนข้อความที่เข้าใจได้แม้อ่านลำพัง ("ดาวน์โหลดเช็กลิสต์สัญญา" ไม่ใช่ "คลิกที่นี่") เพราะผู้ใช้ screen reader มักไล่ฟังทีละลิงก์
  • ไอคอนใน slot icon เป็นแค่การตกแต่ง ใส่ aria-hidden="true" และให้ความหมายอยู่ในข้อความ
  • ลิงก์ที่ปิดใช้งานจะถูกอ่านว่าเป็นลิงก์ที่ใช้ไม่ได้ แต่ไม่รับโฟกัส ผู้ใช้คีย์บอร์ดจึงไปไม่ถึง อธิบายเหตุผลไว้ในข้อความใกล้ ๆ
  • inline ขีดเส้นใต้ลิงก์ในประโยค จึงไม่ต้องพึ่งสีอย่างเดียว
