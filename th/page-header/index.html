Page header

Page header คือส่วนบนสุดของหน้าในระบบงาน (PageHeader ของ Carbon จาก Carbon for IBM Products) ประกอบด้วยแถบ breadcrumb ชื่อหน้าพร้อมปุ่มและข้อความสั้น ๆ และแถบแท็บ ส่วนหัวติดอยู่ด้านบนเมื่อเลื่อนหน้า: ชื่อและข้อความเลื่อนเข้าไปใต้แถบ breadcrumb ที่ยังอยู่ ชื่อหน้าไปปรากฏเป็น crumb สุดท้าย และปุ่มหลักของหน้าย้ายเข้าไปในแถบ ลองเลื่อนกล่องด้านล่างดู

ชื่อที่มี markup และระดับหัวข้อ

ชื่อหน้าเป็น <h1> heading-level (headingAs ใน React + Tailwind) เปลี่ยนเป็นระดับอื่น สำหรับส่วนหัวในหน้าที่มี <h1> แล้ว หัวข้อรองเป็น <h2> เปลี่ยนด้วย subtitle-level (subtitleAs) ถ้าชื่อมี markup ให้ใส่ใน slot="title" ของ content แทน heading ใน React + Tailwind heading รับ markup ได้เลย

ตัวเลือกของแถบ

ใต้ header ที่ fixed

เมื่อหน้ามี header ของ UI shell แบบ fixed อยู่ด้านบน page header จะวัดว่าตัวเองอยู่ห่างจากขอบบนของกล่องเลื่อนเท่าไร แล้วติดอยู่ใต้ shell ไม่ใช่ข้างหลัง คุณไม่ต้องตั้งค่าอะไร และมันวัดใหม่ทุกครั้งที่ขนาดเปลี่ยน

Accessibility

  • ชื่อหน้าเป็นหัวข้อจริง (<h1> โดยปริยาย) ให้มี <h1> หน้าละตัว
  • crumb ของชื่อหน้าซ่อนจาก screen reader และไม่อยู่ในลำดับ Tab จนกว่าจะปรากฏ breadcrumb จึงไม่ถูกอ่านซ้ำ
  • page actions ที่จางหายไปตอนเลื่อนพ้นถูกซ่อนจากทุกคน และ content actions ของแถบแสดงแทน ให้ใส่ปุ่มเดียวกันทั้งสองที่
  • ปุ่มในแถบเป็น toolbar ที่มีชื่อ แท็ก "+N" ประกาศว่ามีแท็กซ่อนอยู่กี่รายการ ("แท็กอื่นอีก 4 รายการ")
  • เมื่อผู้ใช้ตั้งลดการเคลื่อนไหว crumb ของชื่อหน้าจะจางเข้ามาโดยไม่เลื่อน
