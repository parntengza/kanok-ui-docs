Headless Side panel

part ของ SidePanel ให้พฤติกรรมเดียวกับ Side panel แบบมี style แต่ไม่มี style เลย ได้แก่ panel ที่เลื่อนเข้ามาจากขวาหรือซ้าย และเลื่อนออกก่อนถูกถอดออก Tab ที่วนอยู่ใน panel Esc และการคลิกที่ overlay ที่ขอปิด โฟกัสแรกข้างในและโฟกัสกลับเมื่อปิด และโหมด "slide-in" ที่ดันหน้าเว็บออกไปแทนการทับ

ส่วนที่คุณทำเองคือ markup หัวข้อ ปุ่ม ตำแหน่งของ panel และ style ทั้งหมด Root เป็นแบบ controlled: มันบอกเหตุผลที่ขอปิด และจะปิดเมื่อคุณตั้ง open เป็น false เท่านั้น ตำแหน่งของ panel เป็นของคุณ จะเป็น fixed ใต้ header ของแอป หรือ absolute ในกล่องอย่างตัวอย่างในหน้านี้ก็ได้

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { SidePanel } from '@purpurabog/ui/headless';

onRequestClose(reason) ได้ค่า 'close-button', 'escape' หรือ 'overlay' ตอนเปิด โฟกัสจะไปที่ selectorInitialFocus (selector ของ element ใน panel) ถ้าไม่ตั้งจะไปที่ช่องแรกของ panel ตอนปิดโฟกัสจะกลับไปที่ตัวเดิม ตั้งชื่อ panel ด้วย aria-label หรือ aria-labelledby

โครงสร้าง

<SidePanel.Root open={open} onRequestClose={onRequestClose}> <SidePanel.Overlay /> <SidePanel.Panel> <SidePanel.Close /> </SidePanel.Panel> </SidePanel.Root>

เข้าจากด้านซ้าย

placement="left" ทำให้ panel เลื่อนเข้ามาจากด้านซ้าย และ Panel ได้ data-placement="left" ไว้ให้คุณจัดตำแหน่ง ถ้าไม่มี Overlay หน้าเว็บข้าง panel ยังคลิกได้ แต่ Tab ยังวนอยู่ใน panel

ดันหน้าเว็บออกไป

slideIn ให้ element ที่ selectorPageContent ชี้ไปได้ margin กว้างเท่า panel พร้อม transition แทนการทับ panel แบบ slide-in ไม่ดึงโฟกัส ไม่กัก Tab ไว้ข้างใน และไม่สนใจ Esc หน้าเว็บข้าง ๆ จึงยังใช้งานได้

ขอยืนยันก่อนปิด

onRequestClose แค่แจ้ง panel จะปิดเมื่อคุณตั้ง open เป็น false closeOnOverlayClick={false} ทำให้การคลิกที่ overlay ไม่ขอปิดเลย panel นี้ปิดได้ด้วยปุ่มเสร็จสิ้นเท่านั้น และแสดงว่าอะไรขอปิด

ใส่ style

panel เลื่อน 320px พร้อมค่อย ๆ ปรากฏด้วย Web Animations API (เข้าและออกครั้งละ 150ms ตาม Carbon) จึงไม่ต้องทำ animation ใน CSS data-closing อยู่ที่ panel และ overlay ระหว่างที่เลื่อนออก เช่น ใช้กันไม่ให้คลิกโดนระหว่างนั้น

import { useState } from 'react'; import { SidePanel } from '@purpurabog/ui/headless'; export default function Example() { const [open, setOpen] = useState(false); const [placement, setPlacement] = useState<SidePanel.SidePanelPlacement>('right'); } /* className="panel" ที่ Panel และ "overlay" ที่ Overlay */ .panel { position: fixed; inset-block: 3rem 0; inline-size: 30rem; } .panel[data-placement='right'] { inset-inline-end: 0; } .panel[data-placement='left'] { inset-inline-start: 0; } .panel[data-closing], .overlay[data-closing] { pointer-events: none; } .overlay { position: fixed; inset: 0; background: rgb(0 0 0 / 0.6); }

Parts

SidePanel.Root

ไม่ render element ของตัวเอง render แค่ children ระหว่างที่ panel เปิดอยู่และระหว่างที่เลื่อนออก

Prop Type ค่าเริ่มต้น
open boolean แสดง panel (ต้องใส่)
onRequestClose (reason: SidePanel.SidePanelCloseReason) => void Esc, Close หรือการคลิกที่ Overlay ขอปิด: 'escape', 'close-button', 'overlay'
placement 'right' | 'left' 'right' ด้านที่เลื่อนเข้ามา
slideIn boolean false ดันหน้าเว็บออกไปแทนการทับ: ไม่กัก Tab ไม่รับ Esc ไม่มีโฟกัสแรก
closeOnOverlayClick boolean true คลิกที่ Overlay แล้วขอปิด
selectorInitialFocus string element ที่รับโฟกัสตอนเปิด (selector ใน panel) ถ้าไม่ตั้งจะเป็นช่องแรก
selectorPageContent string element ของหน้าที่ panel แบบ slideIn ดันออกไป
layerClassName string class ของ <dialog> ที่ panel เข้าไปอยู่เมื่อเปิดจาก modal (อยู่เหนือ modal ใน top layer) ให้ ::backdrop ของมันไม่มีสี (backdrop:bg-transparent)

panel แบบ slide-over อยู่ใน overlay stack ของหน้าร่วมกับ modal และ tearsheet: กด Esc หนึ่งครั้งปิดเฉพาะชั้นบนสุด (modal ที่เปิดจาก panel ปิดก่อน และโฟกัสกลับเข้า panel) และ panel ที่เปิดจาก modal จะอยู่เหนือ modal จึงใช้งานได้

SidePanel.useSidePanelContext() คืนสถานะของ Root (open, closing, placement, slideIn, requestClose …) ให้ component ที่อยู่ข้างใน

SidePanel.Panel

<aside> (landmark complementary) คือส่วนที่เลื่อน และเป็นที่ที่ Tab วนอยู่ ยกเว้น slideIn ตั้งชื่อด้วย aria-label หรือ aria-labelledby

Attribute เมื่อ
data-open open เป็น true
data-closing กำลังเลื่อนออก
data-placement right หรือ left

SidePanel.Overlay

<div aria-hidden="true"> ที่หรี่หน้าเว็บ ระหว่างที่เปิด หน้าเว็บจะเลื่อนไม่ได้ (ตัวล็อกการเลื่อนตัวเดียวที่ overlay ทุกตัวใช้ร่วมกัน บน <html> ปล่อยเมื่อ overlay ตัวสุดท้ายปิด) และคลิกที่มันจะขอปิด ('overlay' ยกเว้น closeOnOverlayClick เป็น false) ไม่ต้องใส่ถ้าไม่ต้องการหรี่หน้าเว็บ

Attribute เมื่อ
data-open open เป็น true
data-closing กำลังจางหาย

SidePanel.Close

<button type="button"> ที่ขอปิด ('close-button') ต้องใส่ aria-label

คีย์บอร์ดและ accessibility

ปุ่ม ทำอะไร
Tab / Shift+Tab เลื่อนไปมาระหว่างช่องและปุ่มใน panel และวนอยู่ข้างใน (ยกเว้น slideIn)
Esc เรียก onRequestClose('escape') (ยกเว้น slideIn)

part ต่าง ๆ ย้ายโฟกัสเข้า panel ตอนเปิดและกลับตอนปิด และกัก Tab ไว้ใน panel แบบ slide-over หน้าเว็บข้างหลังไม่ได้ถูกทำให้เป็น inert ผู้ใช้ screen reader ยังเข้าถึงได้

ส่วนที่คุณเพิ่มเอง

  • ชื่อของ panel (aria-label หรือ aria-labelledby ที่ชี้ไปที่หัวข้อของคุณ)
  • aria-label ที่ Close และที่ปุ่มย้อนกลับถ้าคุณทำขั้นตอน
  • ตำแหน่งและขนาดของ panel และระยะห่างจากด้านบนใต้ header ของคุณ
