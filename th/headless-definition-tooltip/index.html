Headless Definition tooltip

part ของ DefinitionTooltip ให้พฤติกรรมเดียวกับ Definition tooltip แบบมี style แต่ไม่มี style เลย ได้แก่ คำที่เป็นปุ่มจริง และ popup ใน top layer ข้างคำนั้น คลิก กด Enter หรือ Space เพื่อสลับเปิดปิด ได้โฟกัสแล้วเปิด blur, เมาส์ออก และ Esc ปิด คำนิยามเป็นคำอธิบายของคำด้วย screen reader จึงอ่านได้โดยไม่ต้องเปิด

ส่วนที่คุณทำเองคือเส้นใต้ หน้าตาของ popup ลูกศร และ style ทั้งหมด part ต่าง ๆ บอกสถานะผ่าน attribute data-* ให้คุณใช้ใส่ style

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { DefinitionTooltip } from '@purpurabog/ui/headless';

วิธีใช้

import { DefinitionTooltip } from '@purpurabog/ui/headless'; export default function Example() { return ( <div className="max-w-xl text-sm text-ink"> เลือก <DefinitionTooltip.Root> <DefinitionTooltip.Trigger className="cursor-pointer border-b border-dotted border-hairline-strong hover:border-interactive focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> การลงนามแบบคู่ขนาน </DefinitionTooltip.Trigger> <DefinitionTooltip.Popup className="max-w-44 rounded-xs bg-inverse-surface-1 px-4 py-2 text-sm text-inverse-ink"> รอบลงนามที่ผู้ลงนามทุกคนได้รับเอกสารพร้อมกัน </DefinitionTooltip.Popup> </DefinitionTooltip.Root>{' '} เมื่อลำดับผู้ลงนามไม่สำคัญ </div> ); }

โครงสร้าง

<DefinitionTooltip.Root> <DefinitionTooltip.Trigger /> <DefinitionTooltip.Popup /> </DefinitionTooltip.Root>

เปิดเมื่อชี้เมาส์

ปกติเมาส์จะเปิดคำนิยามได้ด้วยการกดเท่านั้น openOnHover ทำให้เปิดเมื่อวางเมาส์บนคำด้วย ไม่ว่าจะเปิดด้วยวิธีไหน กล่องจะปิดหลังเมาส์ออกจากคำและ popup ไป closeDelay (100ms) เมาส์จึงเลื่อนไปบน popup ได้

import { DefinitionTooltip } from '@purpurabog/ui/headless'; export default function Example() { return ( <div className="max-w-xl text-sm text-ink"> สัญญาที่มูลค่าเกิน 5 ล้านบาทต้องผ่าน <DefinitionTooltip.Root openOnHover> <DefinitionTooltip.Trigger className="cursor-pointer border-b border-dotted border-hairline-strong hover:border-interactive focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> การอนุมัติสองชั้น </DefinitionTooltip.Trigger> <DefinitionTooltip.Popup className="max-w-44 rounded-xs bg-inverse-surface-1 px-4 py-2 text-sm text-inverse-ink"> ผู้อนุมัติคนที่สองจากฝ่ายการเงิน เพิ่มจากหัวหน้าแผนก </DefinitionTooltip.Popup> </DefinitionTooltip.Root> ก่อนส่ง </div> ); }

ตำแหน่งและลูกศร

placement รับ bottom (ค่าเริ่มต้น), top, left, right แต่ละแบบเติม -start / -end ได้ ถ้าที่ไม่พอ popup จะพลิก และ data-side บอกว่าไปอยู่ฝั่งไหน gap คือระยะห่างจากคำ (ค่าเริ่มต้น 8px) เมื่อมี caret popup จะได้ --_caret-start คือจุดเริ่มของลูกศรที่กว้าง --_caret-w (12px ถ้าไม่ตั้ง) เพื่อให้ชี้ไปกลางคำ แบบมี style ใช้ gap={6} เท่ากับความสูงของลูกศร

import { DefinitionTooltip } from '@purpurabog/ui/headless'; const caret = [ 'pointer-events-none absolute left-(--_caret-start) h-1.5 w-3 bg-inherit', 'group-data-[side=bottom]:bottom-full group-data-[side=bottom]:[clip-path:polygon(50%_0,100%_100%,0_100%)]', 'group-data-[side=top]:top-full group-data-[side=top]:[clip-path:polygon(0_0,100%_0,50%_100%)]', ].join(' '); const terms = [ { term: 'ผู้เก็บรักษา', definition: 'ผู้ที่เก็บสำเนาที่ลงนามแล้ว', placement: 'top' }, { term: 'ผู้ตรวจทาน', definition: 'ผู้ที่ตรวจเงื่อนไขก่อนลงนาม', placement: 'bottom-start' }, ] as const; export default function Example() { return ( <div className="max-w-xl text-sm text-ink"> {terms.map(({ term, definition, placement }) => ( <span key={term}> สัญญาทุกฉบับต้องระบุ <DefinitionTooltip.Root placement={placement} gap={6} caret> <DefinitionTooltip.Trigger className="cursor-pointer border-b border-dotted border-hairline-strong hover:border-interactive focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> {term} </DefinitionTooltip.Trigger> <DefinitionTooltip.Popup className="group max-w-44 overflow-visible rounded-xs bg-inverse-surface-1 px-4 py-2 text-sm text-inverse-ink"> {definition} <span aria-hidden="true" className={caret} /> </DefinitionTooltip.Popup> </DefinitionTooltip.Root>{' '} </span> ))} </div> ); }

สถานะเปิด

ควบคุมสถานะเองด้วย open และ onOpenChange หรือให้ defaultOpen onOpenChange รายงานเฉพาะเมื่อค่าเปลี่ยน ใช้ได้ เช่น นับว่าผู้ใช้เปิดดูคำไหนบ้าง

import { useState } from 'react'; import { DefinitionTooltip } from '@purpurabog/ui/headless'; export default function Example() { const [open, setOpen] = useState(false); const [count, setCount] = useState(0); return ( <div className="grid gap-2 text-sm text-ink"> <div className="max-w-xl"> <DefinitionTooltip.Root open={open} onOpenChange={(next) => { setOpen(next); if (next) setCount((n) => n + 1); }} > <DefinitionTooltip.Trigger className="cursor-pointer border-b border-dotted border-hairline-strong hover:border-interactive focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> บัญชี escrow </DefinitionTooltip.Trigger> <DefinitionTooltip.Popup className="max-w-44 rounded-xs bg-inverse-surface-1 px-4 py-2 text-sm text-inverse-ink"> เงินที่บุคคลที่สามถือไว้จนกว่าทั้งสองฝ่ายจะทำตามเงื่อนไข </DefinitionTooltip.Popup> </DefinitionTooltip.Root> ช่วยคุ้มครองเงินมัดจำ </div> <p className="text-xs text-ink-muted">เปิดอยู่: {String(open)} เปิดดูแล้ว {count} ครั้ง</p> </div> ); }

ใส่ style

import { DefinitionTooltip } from '@purpurabog/ui/headless'; export default function Example() { return ( <div className="max-w-xl text-sm text-ink"> รายชื่อ <DefinitionTooltip.Root gap={6} caret> <DefinitionTooltip.Trigger className="cursor-pointer border-b border-dotted border-hairline-strong text-ink hover:border-interactive focus-visible:border-interactive focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus data-open:border-solid data-open:border-interactive"> POA </DefinitionTooltip.Trigger> <DefinitionTooltip.Popup className="group max-w-44 overflow-visible rounded-xs bg-inverse-surface-1 px-4 py-2 text-sm text-inverse-ink"> <strong>หนังสือมอบอำนาจ</strong>: ผู้ที่ลงนามแทนบริษัทได้ <span aria-hidden="true" className="pointer-events-none absolute bottom-full left-(--_caret-start) h-1.5 w-3 bg-inherit [clip-path:polygon(50%_0,100%_100%,0_100%)] group-data-[side=top]:top-full group-data-[side=top]:bottom-auto group-data-[side=top]:[clip-path:polygon(0_0,100%_0,50%_100%)]" /> </DefinitionTooltip.Popup> </DefinitionTooltip.Root> มาจากฝ่ายบุคคล </div> ); } /* className="term" ที่ Trigger, "definition" ที่ Popup */ .term { border-bottom: 1px dotted #8d8d8d; cursor: pointer; } .term:hover, .term[data-open] { border-bottom-color: #0f62fe; } .definition { max-width: 176px; padding: 8px 16px; background: #393939; color: #f4f4f4; }

Parts

DefinitionTooltip.Root

ไม่ render element ของตัวเอง เก็บสถานะเปิด วาง popup และปิดเมื่อกด Esc

Prop Type ค่าเริ่มต้น
open boolean แสดงอยู่ (ควบคุมเอง)
defaultOpen boolean false แสดงตั้งแต่แรก (ไม่ควบคุมเอง)
onOpenChange (open: boolean) => void หลังเปิดหรือปิด (เฉพาะเมื่อเปลี่ยน)
openOnHover boolean false วางเมาส์บนคำแล้วเปิดด้วย
placement Placement 'bottom' top, bottom, left, right แต่ละแบบเติม -start / -end ได้
gap number 8 ระยะห่างระหว่างคำกับ popup หน่วย px
caret boolean false เขียน --_caret-start ที่ popup
closeDelay number 100 เวลาหลังเมาส์ออกก่อนปิด หน่วย ms

DefinitionTooltip.useDefinitionTooltipContext() คืนสถานะของ Root (open, popupId …) ให้ component ใดก็ได้ที่อยู่ข้างใน

DefinitionTooltip.Trigger

<button type="button"> ที่มี tabIndex={0} (ค่าของคุณมาก่อน), aria-controls, aria-expanded และ aria-describedby ที่ชี้ไปที่ popup ต่อจากค่าที่คุณส่งมา การกดปุ่มเมาส์หลัก Enter หรือ Space สลับเปิดปิด popup ได้โฟกัสแล้วเปิด blur แล้วปิด รับ prop ทุกตัวของ button ยกเว้น type

Attribute เมื่อ
data-open popup แสดงอยู่

DefinitionTooltip.Popup

<span role="tooltip" popover="manual"> ใน top layer (เป็น <span> เหมือนของ Carbon คำจึงอยู่ใน <p> ได้) เนื้อหายัง render อยู่ตอนปิด คำอธิบายของคำจึงมีอยู่เสมอ รับ prop ทุกตัวของ span ยกเว้น popover, id และ role

Attribute เมื่อ
data-open แสดงอยู่
data-side top, bottom, left หรือ right คือฝั่งที่ไปอยู่

เมื่อ Root มี caret popup จะได้ CSS variable --_caret-start ด้วย

คีย์บอร์ดและ accessibility

ปุ่ม ผลลัพธ์
Tab โฟกัสมาถึงคำแล้วคำนิยามเปิด โฟกัสออกไปแล้วปิด
Enter, Space เปิดหรือปิดคำนิยาม
Esc ปิดเฉพาะคำนิยาม (dialog ที่ครอบอยู่ยังเปิดอยู่)

part ต่าง ๆ ตั้ง aria-expanded, aria-controls และ aria-describedby ที่คำ และ role="tooltip" ที่ popup

ส่วนที่คุณเพิ่มเอง

  • หน้าตาที่ทำให้คำต่างจากลิงก์ เช่น เส้นใต้แบบจุด
  • ไม่ใส่อะไรที่ต้องกดไว้ใน popup เพราะโฟกัสออกจากคำแล้ว popup ปิด ถ้าต้องการ ให้ใช้ Headless Popover
