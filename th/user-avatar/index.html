Accessibility

  • ถ้าไม่มี tooltip avatar เป็นข้อความธรรมดา (อักษรย่อ) หรือเป็นรูปที่มี image-description ให้เขียนชื่อของคนนั้นไว้ข้าง ๆ เพราะอักษรย่ออย่างเดียวไม่บอกว่าเป็นใคร
  • ถ้ามี tooltip-text avatar จะเป็นปุ่มที่ได้ชื่อจากข้อความนั้น ขึ้นต้นด้วยอักษรย่อ ผู้ใช้ที่สั่งด้วยเสียงจะพูดสิ่งที่เห็นได้
  • สีไม่มีความหมาย จึงไม่ต้องมีข้อความแทน
  • ไอคอนใน slot เป็นของตกแต่ง ใส่ aria-hidden="true" ที่ svg

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
name name string '' The person's name or initials; the avatar shows the initials.
image image string '' A photo's URL, shown instead of the initials.
image-description imageDescription string '' The photo's alt text.
size size UserAvatarSize 'md'
