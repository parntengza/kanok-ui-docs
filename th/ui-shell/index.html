web component ต่อสายกันเอง: ปุ่ม hamburger เปิดปิดเมนูด้านข้างใน document เดียวกันโดยไม่ต้องเขียนโค้ด และ <ui-content> ขยับหลบเมนูด้านข้างเอง ใน React + Tailwind ให้เก็บสถานะของเมนูด้านข้างเองตามตัวอย่างด้านบน

ตัวอย่างในหน้านี้

header และเมนูด้านข้างเป็น position: fixed จึงติดกับหน้าต่าง และปุ่ม hamburger กับพื้นที่เนื้อหาจะหาเมนูด้านข้างใน document ของตัวเอง หน้านี้มี shell อยู่แล้ว ตัวอย่างสดแต่ละอันด้านล่างจึงอยู่ในกล่องที่มี transform ซึ่งเก็บส่วนที่ fixed ไว้ในกล่อง และทำงานใน shadow root ของกล่องเอง (แบบ "micro app") ปุ่ม hamburger ของหน้ากับเมนูด้านข้างของตัวอย่างจึงไม่ควบคุมกันเอง script ของตัวอย่างยังยกเลิก ui-navigate ของลิงก์ด้วย คลิกในตัวอย่างจึงไม่พาออกจากหน้านี้

ในแอปของคุณไม่ต้องทำสิ่งเหล่านี้ แท็บ React แสดงโค้ดแบบที่คุณเขียนจริง

แถบเมนูของ header แสดงตั้งแต่ breakpoint lg ของ Carbon คือกว้าง 1056px ต่ำกว่านั้นปุ่ม hamburger จะปรากฏ และเมนูด้านข้างจะเลื่อนมาทับหน้า breakpoint วัดจากความกว้างของหน้าต่าง ไม่ใช่ของกล่อง ให้ย่อหน้าต่างเพื่อดู layout ของจอเล็ก
