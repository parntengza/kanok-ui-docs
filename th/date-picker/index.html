Date picker

date picker รับวันที่ที่ผู้ใช้พิมพ์เองหรือเลือกจากปฏิทิน หน้าภาษาไทยแสดงปีเป็น พ.ศ. แต่โค้ดของคุณได้วันที่แบบ ISO ปี ค.ศ. เสมอ

HTMLReactReact + Tailwind<ui-date-picker label="วันที่เริ่มสัญญา" name="start" clearable></ui-date-picker> <UiDatePicker label="วันที่เริ่มสัญญา" name="start" clearable /> <DatePicker label="วันที่เริ่มสัญญา" name="start" clearable />

สิ่งที่ผู้ใช้เห็นกับค่าที่คุณได้

ผู้ใช้เห็นและพิมพ์วันที่ตามภาษาและปีศักราชของหน้า ส่วนโค้ดของคุณอ่านวันที่ ISO ค่าเดียวกันทุกภาษา picker สองตัวด้านล่างใช้ค่าเดียวกัน ลองเปลี่ยนตัวไหนก็ได้

  • element ยิง change เมื่อค่าถูกยืนยัน: ออกจากช่อง กด Enter เลือกจากปฏิทิน หรือกดล้าง อ่านค่าจาก event.target.value (และ endValue ในโหมดช่วง)
  • ช่องว่างยังส่ง name= ไปกับฟอร์มเหมือน date input แบบ native ส่วน picker ที่ disabled ไม่ส่งอะไรเลย

พิมพ์หรือเลือกจากปฏิทิน

ปฏิทินเปิดเมื่อช่องได้โฟกัส ทั้งจากการคลิกและการกด Tab โดยโฟกัสยังอยู่ในช่อง ผู้ใช้จึงพิมพ์ต่อได้ และปฏิทินเลื่อนตามสิ่งที่พิมพ์

  • ข้อความที่เป็นวันที่ครบตามรูปแบบของช่องแล้ว เช่น 10/10/2569 เป็นค่าของช่องทันที ส่วน change เกิดตอนยืนยัน (ออกจากช่องหรือกด Enter) ไม่ใช่ระหว่างพิมพ์
  • นอกนั้นอ่านตอนออกจากช่องหรือกด Enter โดยดึงตัวเลขออกจากสิ่งที่พิมพ์ s10/12/2569x จึงกลายเป็น 10/12/2569
  • ไม่มีการเดา วันที่ไม่ครบ (10/12) วันที่ไม่มีจริง (31/04/2569) หรือข้อความที่ไม่มีวันที่อยู่เลย จะค้างอยู่ในช่องพร้อมข้อความบอกว่าผิดตรงไหน และ value เป็น ''
  • วันที่ครบแต่อยู่นอก min / max หรือเป็นวันที่ isDateDisabled ไม่รับ จะถูกเก็บและยืนยันพร้อมข้อความของมันเอง ฟอร์มจะส่งไม่ได้จนกว่าจะแก้

ลองดู: พิมพ์วันที่ที่ไม่มีจริง หรือวันที่นอกปีที่กำหนด แล้วออกจากช่อง

ข้อความเหล่านี้มีในตัวทั้งภาษาไทยและอังกฤษ error ขึ้นเมื่อไร และจะใส่ข้อความของตัวเองอย่างไร ดูที่ ฟอร์มและการตรวจค่า

พ.ศ. และภาษาไทย

ภาษามาจาก lang ที่ตัว element หรือ ancestor ที่ใกล้ที่สุด ถ้าไม่มีใช้ <html lang> ภาษาไทยให้ label และข้อความภาษาไทย ชื่อเดือนภาษาไทย และปีเป็น พ.ศ. (ค.ศ. + 543) ใส่ locale ถ้าต้องการกำหนดภาษาเฉพาะ picker ตัวนี้

HTMLReactReact + Tailwind<ui-date-picker lang="th" label="วันที่เริ่มสัญญา" value="2026-10-10"></ui-date-picker> <ui-date-picker lang="th" era="ce" label="วันที่เริ่มสัญญา (ค.ศ.)" value="2026-10-10"></ui-date-picker> <UiDatePicker lang="th" label="วันที่เริ่มสัญญา" value="2026-10-10" /> <UiDatePicker lang="th" era="ce" label="วันที่เริ่มสัญญา (ค.ศ.)" value="2026-10-10" /> <DatePicker locale="th" label="วันที่เริ่มสัญญา" defaultValue="2026-10-10" /> <DatePicker locale="th" era="ce" label="วันที่เริ่มสัญญา (ค.ศ.)" defaultValue="2026-10-10" />
  • era กำหนดปีที่ผู้ใช้เห็นและพิมพ์: be (พ.ศ. ค่าเริ่มต้นของภาษาไทย) หรือ ce (ค.ศ. ค่าเริ่มต้นของภาษาอื่น) ทุกภาษาเลือกได้ทั้งสองแบบ
  • ปีที่พิมพ์ใช้ศักราชเดียวกัน ในโหมด พ.ศ. ถ้าพิมพ์ปีต่ำกว่า 2400 (เช่น 2026) จะมีข้อความขอให้กรอกปี พ.ศ. ระบบไม่แปลงปีให้เองแบบเงียบ ๆ
  • ผู้ใช้พิมพ์เลขไทย (๐–๙) ได้ ระบบแปลงเป็น 0–9 ระหว่างพิมพ์
  • placeholder และข้อความช่วยตั้งต้นแสดงรูปแบบตามภาษาของหน้า: ภาษาไทยเป็น วว/ดด/ปปปป
  • React + Tailwind อ่าน <html lang> หรือ prop locale

รูปแบบวันที่

format กำหนดลำดับวัน เดือน ปี: dd/mm/yyyy (ค่าเริ่มต้น), mm/dd/yyyy หรือ yyyy-mm-dd เปลี่ยนแค่สิ่งที่ผู้ใช้เห็น value ยังเป็น ISO

HTMLReactReact + Tailwind<ui-date-picker label="วันครบกำหนด" format="yyyy-mm-dd" value="2026-10-10"></ui-date-picker> <UiDatePicker label="วันครบกำหนด" format="yyyy-mm-dd" value="2026-10-10" /> <DatePicker label="วันครบกำหนด" format="yyyy-mm-dd" defaultValue="2026-10-10" />

รูปแบบแสดงเป็นข้อความช่วยจนกว่าคุณจะใส่ helper-text (helperText ใน React + Tailwind) หลังจากนั้น screen reader ยังอ่านรูปแบบให้เหมือนเดิม

เลือกเป็นช่วง

range ให้สองช่องที่ใช้ปฏิทินร่วมกัน: value / name / label สำหรับวันเริ่ม และ end-value / end-name / end-label สำหรับวันสิ้นสุด ถ้าตั้งชื่อทั้งสองช่อง ฟอร์มจะได้ค่าสองรายการ ถ้าไม่มี end-name ตัว ui-date-picker จะส่งค่ารายการเดียวภายใต้ name เป็น start/end (2026-10-01/2026-10-05) แบบ cds-date-picker ของ Carbon ส่วน DatePicker ของ React + Tailwind จะส่งวันสิ้นสุดเฉพาะเมื่อมี endName

  • เลือกวันแรกแล้วปฏิทินยังเปิดค้างไว้ให้เลือกวันสิ้นสุด วันระหว่างกลางมีไฮไลต์แบบแถบริบบิ้นต่อเนื่อง และมี preview ทั้งก่อนและหลังวันเริ่มระหว่างเลือกวันสิ้นสุด (ตามเมาส์หรือคีย์บอร์ด วันที่เลือกไม่ได้ไม่ทำให้ preview ขยับ)
  • ถ้าเลือกวันสิ้นสุดก่อนวันเริ่ม ระบบสลับสองค่าให้
  • ถ้ามีช่วงครบแล้ว การเลือกครั้งถัดไปเริ่มช่วงใหม่ (แบบ Cally) และ change เกิดเมื่อเลือกครบทั้งสองวัน
  • ถ้าพิมพ์วันสิ้นสุดก่อนวันเริ่ม ค่าจะค้างไว้พร้อมข้อความแจ้ง ไม่สลับให้

  • แตะที่ช่องเพื่อเปิด โดยโฟกัสอยู่ที่วันหนึ่งวัน คีย์บอร์ดบนจอจึงไม่ขึ้นมาบัง แค่โฟกัสที่ช่องยังไม่เปิด หลัง sheet ปิดแล้ว แตะที่ช่องอีกครั้งจะเป็นการพิมพ์
  • ปิดได้ด้วย Esc ปุ่ม × การปัดลงที่แถบด้านบน หรือแตะที่หน้าเว็บที่มืดลง ข้อความที่พิมพ์ไว้ถูกบันทึก และโฟกัสกลับไปที่ช่อง
  • ระหว่างที่เปิด หน้าเว็บด้านหลังใช้และเลื่อนไม่ได้ และระยะขอบของ sheet เว้นพื้นที่ปลอดภัยของเครื่องไว้ (แถบ home ติ่งกล้อง)

ใช้ปฏิทินเดี่ยว ๆ

ปฏิทินใน picker เป็น element ของมันเองชื่อ ui-calendar มาพร้อม import เดียวกัน เป็น view แบบ controlled: มันเลื่อนโฟกัสเองได้ แต่วันที่เลือกเป็นหน้าที่ของคุณ ฟัง ui-pick (detail { date } เป็น Date) แล้วตั้ง value:

เดือนที่แสดงตาม property focusDate (เป็น Date ค่าเริ่มต้นคือวันนี้) ui-calendar ใช้ภาษาของหน้าเหมือน picker (lang ที่ใกล้ที่สุด) และแสดงปี พ.ศ. เมื่อเป็นภาษาไทย ใส่ locale และ era เพื่อกำหนดเอง รับ min, max, isDateDisabled, range กับ end-value, first-day และ show-today เหมือน picker ส่วน Calendar ของ React + Tailwind ก็เป็นแบบ controlled เช่นกัน ต้องส่ง focusDate, onFocusDateChange และ onPick เสมอ

เลือกเดือนและปี (แบบ Cally)

หัวปฏิทินมี select แบบ native สองตัวแบบ Cally คือ <ui-calendar-select-month> และ <ui-calendar-select-year> เดือนที่อยู่นอก min / max ทั้งเดือนจะเลือกไม่ได้ ส่วนรายการปีมี 20 ปีรอบปีที่แสดง และตัดตาม min / max หน้าภาษาไทยแสดงปีเป็น พ.ศ. ถ้าแสดงหลายเดือน หัวปฏิทินจะมีแค่ select ปี เพราะแต่ละตารางมีชื่อเดือนของตัวเองอยู่แล้ว

ใส่เนื้อหาของคุณเองใน slot heading เพื่อแทน select ทั้งสองได้ select ที่ใส่ไว้ใน slot นี้ หรืออยู่ข้างในสิ่งที่ใส่ จะทำงานตามปฏิทินด้วย:
HTML<ui-calendar locale="th" era="be"> <div slot="heading"> <ui-calendar-select-month format-month="short"></ui-calendar-select-month> <ui-calendar-select-year max-years="5"></ui-calendar-select-year> </div> </ui-calendar>
Element Attribute ทำอะไร

ui-calendar-select-year max-years จำนวนปีในรายการรอบปีที่แสดง (ค่าเริ่มต้น 20)

Tab ไปช่องถัดไป (โหมดช่วงจากช่องวันเริ่มไปช่องวันสิ้นสุด) บันทึกข้อความที่พิมพ์ และปฏิทินปิดเมื่อโฟกัสออกจาก picker
Shift + Tab จากช่องวันเริ่ม: ปิดปฏิทินแล้วย้อนกลับ
Enter ยืนยันข้อความที่พิมพ์ ปิดปฏิทิน และส่งฟอร์มที่ช่องอยู่
Esc ปิดปฏิทิน

ในปฏิทิน:

ปุ่ม ผล
← / → วันก่อนหน้า / ถัดไป
↑ / ↓ วันเดียวกันของสัปดาห์ก่อน / ถัดไป
Home / End วันแรก / วันสุดท้ายของสัปดาห์
Page Up / Page Down เดือนก่อน / เดือนถัดไป
Shift + Page Up / Page Down ปีก่อน / ปีถัดไป
Enter, Space เลือกวันนั้น แล้วปิดปฏิทิน (โหมดช่วงปิดหลังเลือกวันสิ้นสุด)
Esc ปิด แล้วโฟกัสกลับไปที่ช่องพิมพ์
Tab วนอยู่ในปฏิทิน: ‹ เดือน ปี › และวัน (และปุ่มวันนี้) จากตัวสุดท้ายกลับไปตัวแรก ออกจากปฏิทินด้วย Esc หรือเลือกวัน
Shift + Tab วนแบบเดียวกันย้อนกลับ

ถ้าใช้เมาส์ เลือกเดือนหรือปีจาก select ที่หัวปฏิทินได้

Accessibility

  • ช่องพิมพ์เป็น combobox ที่เปิด dialog (aria-haspopup="dialog", aria-expanded) ปฏิทินเป็น dialog ชื่อ "เลือกวันที่" ที่มี grid ของปุ่มวัน ตาม pattern date picker dialog ของ WAI-ARIA
  • แต่ละวันถูกอ่านเป็นวันที่เต็ม (เช่น "วันเสาร์ที่ 10 ตุลาคม พ.ศ. 2569") วันนี้มี aria-current="date" วันที่เลือกมี aria-pressed วันที่เลือกไม่ได้มี aria-disabled
  • การเปลี่ยนเดือนถูกประกาศผ่าน live region แบบ polite
  • bottom sheet เป็น modal dialog ชื่อเดียวกัน หน้าเว็บด้านหลังเป็น inert จนกว่าจะปิด
  • ไอคอนปฏิทินเป็นแค่ภาพประกอบแบบ Carbon ไม่ใช่จุดหยุดของ Tab และการคลิกที่ไอคอนเท่ากับคลิกในช่องพิมพ์
  • error ตั้ง aria-invalid และผูกกับช่องด้วย aria-describedby เช่นเดียวกับคำอธิบายรูปแบบ

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Date picker

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)
