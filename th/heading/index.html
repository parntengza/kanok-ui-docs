Heading

<ui-heading> สร้างหัวข้อที่ระดับถูกต้องโดยไม่ต้องนับเอง: <ui-section> แต่ละชั้นที่ครอบอยู่ทำให้ลึกลงหนึ่งระดับ markup เดียวกันจึงเป็น <h2> ในหน้าหนึ่ง และเป็น <h4> ใน panel ที่ซ้อนอยู่ ตัวอักษรเป็นไปตาม productive type scale ของ Carbon สำหรับระดับนั้น

วิธีใช้

<ui-heading> ที่ไม่อยู่ใน section ใดเลยเป็น <h1> section ชั้นแรกทำให้หัวข้อข้างในเป็น <h2> section ที่ซ้อนอยู่ข้างในเป็น <h3> ต่อไปเรื่อย ๆ จนถึง <h6>

HTMLReactReact + Tailwind<script type="module">import '@purpurabog/ui/heading';</script> <ui-heading>สัญญา</ui-heading> <ui-section> <ui-heading>รออนุมัติ</ui-heading> </ui-section> import { UiHeading, UiSection } from '@purpurabog/ui/react'; <UiHeading>สัญญา</UiHeading> <UiSection> <UiHeading>รออนุมัติ</UiHeading> </UiSection> import { Heading, Section } from '@/components/ui/react-tw/heading'; <Heading>สัญญา</Heading> <Section> <Heading>รออนุมัติ</Heading> </Section>

<ui-section> เป็นแค่ block ไม่มี role ส่วน Section ของ React + Tailwind สร้าง element <section> เปลี่ยนได้ด้วย as (เช่น as="div")

กำหนดระดับเอง

level บน section กำหนดระดับของหัวข้อข้างในโดยตรง แทนที่จะเป็นหนึ่งระดับลึกกว่า section ที่ครอบ ใช้เมื่อ block หนึ่งเริ่มอยู่ใต้หัวข้อที่ไม่ใช่ <ui-heading> เช่น ชื่อหน้าจาก layout ของคุณ section ที่ซ้อนข้างในจะนับต่อจากนั้น ระดับสูงสุดคือ 6

block เดียวกันที่ความลึกใดก็ได้

block ที่ใช้ซ้ำ เช่น การ์ดสรุป ใส่ <ui-heading> ไว้ได้และถูกต้องเสมอไม่ว่าจะวางไว้ที่ไหน: อยู่ใน section ชั้นเดียวเป็น <h4> อยู่ในสองชั้นเป็น <h5>

Accessibility

  • ผู้ใช้ screen reader กระโดดไปตามหัวข้อและเรียกดูรายการหัวข้อเพื่อหาทาง ระดับที่เป็นไปตามการซ้อนทำให้รายการนั้นตรงกับหน้า
  • ให้มี <h1> หน้าละตัว ถ้าชื่อหน้ามาจากที่อื่น ให้ block เริ่มที่ level ลึกกว่า
  • <ui-section> ไม่เพิ่ม landmark ถ้าส่วนใดของหน้าต้องมี ให้ครอบด้วย <section aria-labelledby> หรือ <nav> ของคุณเอง
