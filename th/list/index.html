Accessibility

  • screen reader บอกว่าเป็นรายการและมีกี่ข้อ ui-list-item ได้ role="listitem" (ถ้าคุณไม่ได้ตั้ง role เอง) และ <ul> / <ol> ของรายการอยู่ใน shadow root ของ element รอบรายการเหล่านั้น
  • ใช้รายการเรียงลำดับเฉพาะเมื่อลำดับสำคัญ เพราะตัวเลขจะถูกอ่านออกเสียง
  • เครื่องหมายหน้ารายการวาดด้วย CSS จึงไม่ถูกอ่าน อย่าใส่ความหมายไว้ในเครื่องหมาย
  • เขียนแต่ละข้อให้สั้นและเป็นแบบเดียวกัน ขึ้นต้นเหมือนกันทุกข้อ (เป็นคำนามทั้งหมด หรือเป็นคำกริยาทั้งหมด)
