Pagination nav

Pagination หรือ Pagination nav?

Component ใช้เมื่อ
Pagination ใต้ตาราง data table: ผู้ใช้เลือกได้ว่าหน้าหนึ่งแสดงกี่แถว และเห็น "1–10 จาก 240 รายการ"
Pagination nav เนื้อหาที่แบ่งหน้าแบบหนังสือ: ผลการค้นหา รายงานยาว ๆ หน้าของสัญญาที่สแกนไว้

หน้าเริ่มต้นและการเปลี่ยนหน้า

page คือหน้าปัจจุบัน นับจาก 0: page="3" แสดงหน้า 4 ui-change จะเกิดหลังผู้ใช้เลือกหน้าอื่น โดยมีหน้า (นับจาก 0) อยู่ใน detail.page

หน้า:

HTMLReactReact + Tailwind<ui-pagination-nav id="pagination-nav-start" total-items="25" page="3"></ui-pagination-nav> <p>หน้า: <output id="pagination-nav-start-out"></output></p> <script type="module"> const nav = document.getElementById('pagination-nav-start'); const out = document.getElementById('pagination-nav-start-out'); out.value = `${nav.page + 1} จาก ${nav.totalItems}`; nav.addEventListener('ui-change', (event) => (out.value = `${event.detail.page + 1} จาก ${nav.totalItems}`)); </script> const [page, setPage] = useState(3); <UiPaginationNav totalItems={25} page={page} onUiChange={(e) => setPage(e.detail.page)} /> <p>หน้า: <output>{page + 1} จาก 25</output></p> const [page, setPage] = useState(3); <PaginationNav totalItems={25} page={page} onChange={setPage} /> <p>หน้า: <output>{page + 1} จาก 25</output></p>

React + Tailwind รับ defaultPage ได้ด้วย ถ้าไม่ต้องการควบคุมค่าเอง

ทุกหน้าพอดี

ถ้าจำนวนหน้าไม่เกิน items-shown จะแสดงทุกหมายเลข และไม่มีเมนู "…"

HTMLReactReact + Tailwind<ui-pagination-nav total-items="5"></ui-pagination-nav> <UiPaginationNav totalItems={5} /> <PaginationNav totalItems={5} />

จำนวนรายการที่แสดง

items-shown (itemsShown) คือจำนวนรายการในแถว รวมเมนู "…" ด้วย ค่าเริ่มต้น 10 และอย่างน้อย 4 ลดค่าลงเมื่อแถวมีที่น้อย

HTMLReactReact + Tailwind<ui-pagination-nav total-items="25" items-shown="5" page="12"></ui-pagination-nav> <UiPaginationNav totalItems={25} itemsShown={5} page={12} /> <PaginationNav totalItems={25} itemsShown={5} defaultPage={12} />

ถ้าหน้าต่างแคบกว่า 320px แถวจะลดจำนวนรายการลงเอง

วนรอบ

เมื่อใส่ loop ปุ่มก่อนหน้าในหน้าแรกจะไปหน้าสุดท้าย และปุ่มถัดไปในหน้าสุดท้ายจะไปหน้าแรก ถ้าไม่ใส่ ปุ่มทั้งสองจะปิดใช้งานที่ปลายแถว

HTMLReactReact + Tailwind<ui-pagination-nav total-items="8" loop></ui-pagination-nav> <UiPaginationNav totalItems={8} loop /> <PaginationNav totalItems={8} loop />

ปิดเมนู "…"

disable-overflow (disableOverflow) ยังแสดง "…" ในแถว แต่เปิดไม่ได้ ผู้ใช้จะย้ายหน้าด้วยปุ่มก่อนหน้า ถัดไป และหมายเลขที่แสดงอยู่

HTMLReactReact + Tailwind<ui-pagination-nav total-items="25" page="12" disable-overflow></ui-pagination-nav> <UiPaginationNav totalItems={25} page={12} disableOverflow /> <PaginationNav totalItems={25} defaultPage={12} disableOverflow />

ตำแหน่ง tooltip

ปุ่มก่อนหน้าและถัดไปเป็นปุ่มไอคอน ชื่อของปุ่มแสดงเป็น tooltip ตอน hover และตอนโฟกัส ค่าเริ่มต้นอยู่ด้านล่าง tooltip-placement (tooltipPlacement) ย้ายตำแหน่งได้ เช่น ขึ้นด้านบนเมื่อแถวอยู่ล่างสุดของหน้าต่าง

HTMLReactReact + Tailwind<ui-pagination-nav total-items="25" tooltip-placement="top"></ui-pagination-nav> <UiPaginationNav totalItems={25} tooltipPlacement="top" /> <PaginationNav totalItems={25} tooltipPlacement="top" />

    Accessibility

    • แถวเป็น landmark <nav> ชื่อ "การแบ่งหน้า" (แปลตามภาษาของหน้า) ที่มีรายการอยู่ข้างใน
    • แต่ละหน้าเป็นปุ่มที่ screen reader อ่านว่า "หน้า 4" หน้าปัจจุบันอ่านว่า "หน้าปัจจุบัน, หน้า 4" และมี aria-current="page"
    • "…" แต่ละตัวเป็น <select> ชื่อ "เลือกหมายเลขหน้า" คีย์บอร์ดและมือถือเปิดได้เหมือน select ทั่วไป
    • หลังเปลี่ยนหน้า live region แบบ polite จะบอกว่า "หน้า 5 จาก 25"
    • ปุ่มก่อนหน้าและถัดไปเป็นปุ่มไอคอนชื่อ "ก่อนหน้า" และ "ถัดไป" มี tooltip และจะปิดใช้งานที่ปลายแถว เว้นแต่ใส่ loop

    ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Pagination nav

    API

    สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

    <ui-pagination-nav> · React UiPaginationNav

    Attribute

    Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
    page page number 0 The current page, 0-based (Carbon).
    total-items totalItems number 1
    items-shown itemsShown number 10 Page items in the row (at least 4).
    loop loop boolean false Previous on the first page goes to the last, Next on the last to the first.
    disable-overflow disableOverflow boolean false The "…" selects can't be opened.
    size size NavSize 'lg'
    tooltip-placement tooltipPlacement TooltipPlacement 'bottom' Where Previous / Next show their tooltip.

    Event

    Event React คำอธิบาย
    ui-change onUiChange detail: { page } (0-based) after the user chose a page

    CSS part

    Part คำอธิบาย
    base The <nav>
    page Each page button
    overflow Each "…" select

    CSS custom property

    Custom property ค่าเริ่มต้น คำอธิบาย
    --ui-button-radius Corner radius of the page buttons (the button setting)
    --ui-focus-offset outline-offset of its focus ring (default -2px: inside; Kanok: 2px outside)
    --ui-pagination-nav-mark-height Height of the current page's underline (default 4px; Kanok: 2px)
