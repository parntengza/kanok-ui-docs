Modal สร้างบน <dialog> ของ browser: browser วางมันไว้ใน top layer ทำให้หน้าเว็บข้างหลังเป็น inert และให้ Tab วนอยู่ข้างใน เปิดได้ด้วย attribute open, show() หรือ open = true ปิดได้ด้วย close() หรือ open = false เมื่อปิดแล้วจะส่ง ui-close ไม่ว่าจะปิดด้วยวิธีไหน ระหว่างที่เปิด หน้าเว็บจะเลื่อนไม่ได้

React + Tailwind เป็นแบบ controlled: onClose(reason) บอกว่ามีการกด × กด Esc คลิกข้างนอก หรือ <form method="dialog"> ข้างในสั่งปิด ให้ตั้ง open เป็น false เพื่อปิด หรือไม่ตั้งเพื่อให้เปิดค้างไว้

คลิกข้างนอก

เหมือน Carbon คือ modal ที่มีปุ่มด้านล่างจะไม่ปิดเมื่อคลิกข้างนอก ข้อมูลที่พิมพ์ไว้จึงไม่หาย ส่วน modal แบบ passive จะปิด ยกเว้นตั้ง persistent ซึ่งจะปิดได้แค่ด้วย × กด Esc หรือปุ่มของคุณเอง

ขอยืนยันก่อนปิด

× กด Esc และคลิกข้างนอก จะส่ง ui-request-close ก่อน ซึ่งยกเลิกได้ และมี reason เป็น close-button, escape หรือ backdrop เรียก preventDefault() เพื่อให้ modal เปิดค้างไว้ เช่น ตอนที่ยังมีการแก้ไขที่ไม่ได้บันทึก ลองพิมพ์บันทึกด้านล่าง แล้วลองปิด modal

ui-request-close และ ui-close bubble ขึ้นมา และ notification ที่อยู่ใน modal ก็ส่ง event ชื่อเดียวกัน จึงต้องเช็กว่า event.target คือ modal ส่วน UiModal ของ React เช็กให้แล้ว onUiRequestClose และ onUiClose ได้รับเฉพาะ event ของ modal เอง close() และ open = false ปิดทันทีโดยไม่ถาม ส่วน requestClose(reason) ถามก่อนเหมือนปุ่ม × การแจ้งผลใน modal ให้ใช้ Notification แบบ inline อย่างในตัวอย่างนี้ เพราะ toast จะอยู่หลังหน้าเว็บที่เป็น inert

Accessibility

  • <dialog> แบบ modal ของ browser ทำให้ส่วนอื่นของหน้าเว็บเป็น inert ทั้งกับเมาส์ คีย์บอร์ด และ screen reader และคืนโฟกัสให้ตัวที่เปิด modal
  • หัวข้อเป็นชื่อของ dialog ถ้าไม่มีหัวข้อ slot label จะเป็นชื่อแทน ถ้าไม่มีทั้งสองอย่างให้ตั้ง label (React + Tailwind ใช้ aria-label)
  • alert ทำให้เป็น alertdialog ที่ใช้เนื้อหาเป็นคำอธิบาย ใช้กับการยืนยันเท่านั้น
  • ปุ่ม × มีชื่อว่า "ปิด" ตามภาษาของหน้า เปลี่ยนได้ด้วย close-label (closeLabel)

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Modal

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-modal> · React UiModal

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
open open boolean false
heading heading string ''
label label string '' Accessible name when there is no heading (Carbon aria-label); the label slot is used before it.
size size 'sm' | 'md' | 'lg' 'md' Dialog width (Carbon modal sizes): sm 480px, md 672px, lg 1056px — never wider than the viewport minus 16px a side.
persistent persistent boolean false A passive modal (no footer) ignores outside clicks too; one with footer buttons always does (Carbon).
close-label closeLabel string '' Accessible name for the close button.
alert alert boolean false Interrupting confirmation: role="alertdialog", focus starts on the safest action.

Method

Method คำอธิบาย
requestClose(reason) Ask to close — fires cancelable ui-request-close first.
focus(options) Focus inside the open dialog (the least destructive control, as on open).

Event

Event React คำอธิบาย
ui-close onUiClose After the modal has closed
ui-request-close onUiRequestClose Cancelable; detail: { reason }. preventDefault() keeps it open.

Slot

Slot คำอธิบาย
(ค่าเริ่มต้น) Body content
label Small label above the heading (the row renders only when slotted)
footer Action buttons (laid out full-bleed, Carbon style)
header-actions Controls at the top end of the header, beside the close button (one 48px button fits)

CSS part

Part คำอธิบาย
dialog The native <dialog> panel
header Header row
header-actions Wrapper of the header-actions slot
label The small label above the heading
heading The heading
close-button The × button
body Scrollable body
footer Footer holding the action buttons
