ฟอร์มและการตรวจค่า

ช่องกรอกทุกตัวเป็น custom element แบบ form-associated คือทำงานใน <form> ธรรมดาได้เหมือน <input> ทั้ง submit, FormData, reset และ constraint validation ของ browser โดยไม่ต้องเขียนโค้ดเชื่อมเพิ่ม

wrapper จาก @purpurabog/ui/react render element ตัวเดียวกัน ทุกอย่างในหน้านี้จึงใช้กับ wrapper ได้ด้วย ส่วน component แบบ React + Tailwind ที่ copy มาด้วย shadcn ทำงานแบบ Carbon React: การตรวจค่าเป็นหน้าที่ของแอป component แสดงตามที่คุณส่งเข้า invalid และ invalidText (จำนวนที่เกิน maxCount ยังนับเป็น error เองเหมือนเดิม) เรื่อง wrapper, event และการตั้งค่าอื่น ๆ ดูที่ ใช้กับ framework ต่าง ๆ

ส่งค่าด้วยฟอร์ม

ใส่ name ให้ทุกช่อง ช่องจะส่งค่าในชื่อนั้น FormData จึงอ่านค่าได้เหมือน input ปกติ:

  • <ui-button type="submit"> ส่งฟอร์มที่ปุ่มอยู่ข้างใน ส่วน type="reset" ล้างฟอร์ม ค่าเริ่มต้นของ type คือ button ซึ่งไม่ทำทั้งสองอย่าง
  • กด Enter ในช่องข้อความแล้วฟอร์มถูกส่ง แบบเดียวกับ text input ปกติ: ส่งผ่านปุ่ม submit ปุ่มแรกของฟอร์ม และไม่ส่งเลยถ้าปุ่มนั้น disabled อยู่ ถ้าฟอร์มไม่มีปุ่ม submit จะส่งด้วย Enter เฉพาะเมื่อมีช่องข้อความช่องเดียว
  • <fieldset disabled> หรือ <ui-form-group disabled> ทำให้ทุกช่องและทุก <ui-button> ข้างใน disabled: ไม่ถูกส่ง ไม่กันฟอร์ม และกดส่งฟอร์มไม่ได้
  • ช่องที่ไม่มี label ของตัวเอง ใช้ชื่อจาก aria-label หรือ aria-labelledby ที่ใส่ไว้ หรือจาก <label for> ที่ชี้มาที่ช่อง เหมือน control ปกติ
  • event submit เกิดเมื่อทุกช่องผ่านการตรวจแล้วเท่านั้น
  • reset คืนค่าทุกช่องเป็นค่าตอนเริ่ม และซ่อน error ไปด้วย

กำหนดช่องที่ต้องกรอก

ใส่ required แล้วฟอร์มจะไม่ถูกส่งตราบที่ช่องนั้นยังว่าง

ทุกช่องมีข้อความของตัวเองที่แปลตามภาษาของหน้า (มีไทยและอังกฤษให้แล้ว):

ช่อง ข้อความเมื่อยังว่าง
ui-dropdown, ui-combobox, ui-multi-select มีในตัว: "กรุณาเลือกรายการ"
ui-radio-group มีในตัว: "กรุณาเลือกรายการ" (เปลี่ยนได้ด้วย required-text)
ui-checkbox-group มีในตัว: "กรุณาเลือกอย่างน้อยหนึ่งรายการ" (เปลี่ยนได้ด้วย required-text)
ui-date-picker มีในตัว: "กรุณากรอกวันที่" และข้อความสำหรับรูปแบบผิด วันที่ไม่มีอยู่จริง และวันที่นอกช่วง min / max
ui-file-uploader มีในตัว: "กรุณาเพิ่มไฟล์อย่างน้อยหนึ่งไฟล์" (เปลี่ยนได้ด้วย required-text)
ui-text-input, ui-text-area, ui-number-input มีในตัว: "กรุณากรอกข้อมูล"
ui-select มีในตัว: "กรุณาเลือกรายการ"

การตรวจอื่นของ browser เช่นอีเมลผิดรูปแบบหรือ pattern ยังใช้ข้อความของ browser ซึ่งเป็นภาษาของ browser ทุกช่องในตารางนี้ยกเว้น file uploader ใช้ invalid-text แทนข้อความในตัวหรือข้อความของ browser ได้ ไม่ว่าช่องจะผิดด้วยเหตุอะไร ใส่เมื่ออยากใช้คำของคุณเอง หรืออยากให้ทุกช่องเป็นภาษาเดียวกัน:

HTMLReact<ui-text-input label="ชื่อ-นามสกุล" name="name" required invalid-text="กรุณากรอกชื่อ-นามสกุล"></ui-text-input> <UiTextInput label="ชื่อ-นามสกุล" name="name" required invalidText="กรุณากรอกชื่อ-นามสกุล" />

error ขึ้นเมื่อไร

error จะรอจนผู้ใช้กรอกช่องนั้นเสร็จ จะไม่มีใครเห็นคำว่า "ต้องกรอก" ระหว่างที่ยังพิมพ์อยู่

  • ช่องจะแสดง error หลังผู้ใช้ออกจากช่อง
  • พอกดส่ง ทุกช่องที่ผิดแสดง error พร้อมกัน และโฟกัสย้ายไปช่องแรกที่ผิด ไม่มี bubble ของ browser ขึ้นมา reportValidity() (ของฟอร์มหรือของช่อง) ก็เช่นกัน
  • checkValidity() ไม่แสดงอะไร เหมือน control ปกติ: แอปที่ตรวจฟอร์มทุกครั้งที่พิมพ์ (เช่น เพื่อเปิดปุ่มบันทึก) จะไม่ทำให้ error ขึ้นหรือโฟกัสย้าย
  • จำนวนเกิน max-count และ invalid ที่โค้ดของคุณตั้ง แสดงทันที
  • ช่องที่ disabled หรือ readonly ไม่แสดง error

แสดง error จากการตรวจของแอป

ตั้ง invalid คู่กับ invalid-text สำหรับ error ที่แอปหรือ server เท่านั้นที่รู้ error จะขึ้นทันที ถ้า form library เป็นผู้ตรวจค่า ให้ส่งผลการตรวจเข้า invalid และ invalidText:

ใน web component และ wrapper ของ React invalid ทำให้ช่องนั้นไม่ผ่านการตรวจของฟอร์มด้วย ฟอร์มจึงส่งซ้ำไม่ได้จนกว่าคุณจะล้างค่านี้ ตัวอย่าง React + Tailwind ใช้ React Hook Form ถ้าใช้ schema ของ Zod เพิ่ม zodResolver จาก @hookform/resolvers

ตรวจเงื่อนไขเองด้วย custom validity

setCustomValidity() ใช้เหมือนบน <input>: ใส่ข้อความแล้วช่องไม่ผ่าน ใส่ '' เพื่อล้าง ต่างจาก invalid ตรงที่ข้อความจะรอให้ผู้ใช้ออกจากช่องก่อน เหมือนการตรวจในตัว:

const password = document.querySelector('ui-text-input[name="password"]'); const confirm = document.querySelector('ui-text-input[name="confirm"]'); confirm.addEventListener('input', () => { confirm.setCustomValidity(confirm.value === password.value ? '' : 'รหัสผ่านไม่ตรงกัน'); });

ทุกช่องมี checkValidity(), reportValidity(), validity, validationMessage, willValidate และ form เหมือน control ปกติ สิ่งเหล่านี้เป็น method ของ element ใน React ให้เรียกผ่าน ref ของ wrapper ส่วน React + Tailwind เงื่อนไขแบบนี้เป็นส่วนหนึ่งของการตรวจค่าของแอปคุณเอง

  • แสดงทีละบรรทัด: error ชนะคำเตือน และคำเตือนชนะข้อความช่วย

แต่งหน้าตาช่องที่กำลังแสดง error

ระหว่างที่บรรทัด error แสดงอยู่ ช่องจะมี data-show-error ที่ตัวเอง (คำเตือนเป็น data-show-warn) ต่างจาก invalid ที่คุณตั้งเอง attribute นี้ตรงกับสิ่งที่ผู้ใช้เห็นจริง มันอยู่บน web component จึงใช้กับ wrapper ของ React ได้ด้วย:

ui-text-input[data-show-error]::part(label) { color: var(--ui-error); } form:has([data-show-error]) .error-summary { display: block; }

ปิดช่องหรือทั้งกลุ่ม

  • disabled ทำให้ช่องเป็นสีจาง ช่องที่ disabled ไม่ถูกส่งและไม่ถูกตรวจ เหมือน control ปกติ
  • readonly แสดงค่าและส่งค่าไปกับฟอร์ม แต่ผู้ใช้แก้ไม่ได้
  • <fieldset disabled> ปิดทุกช่องข้างใน <ui-form-group disabled> ก็เช่นกัน (fieldset ของ Carbon ที่มี label เป็น legend):

วันที่: สิ่งที่ผู้ใช้เห็นกับค่าที่คุณได้

date picker แสดงวันที่แบบที่ผู้อ่านคุ้น แต่โค้ดของคุณได้วันที่แบบ ISO เหมือนกันเสมอ:

หน้าภาษาไทย (lang="th") หน้าภาษาอังกฤษ
ผู้ใช้เห็นและพิมพ์ 10/10/2569 (พ.ศ.) 10/10/2026
value และค่าที่ฟอร์มส่ง 2026-10-10 2026-10-10
  • value, min และ max เป็น yyyy-mm-dd ปี ค.ศ. เสมอ
  • หน้าภาษาไทยแสดงและรับปีเป็น พ.ศ. ใส่ era="ce" ถ้าต้องการ ค.ศ.
  • ผู้ใช้พิมพ์เลขไทย (๐–๙) ได้ ระบบแปลงเป็น 0–9 ให้
  • ในโหมด พ.ศ. ถ้าพิมพ์ปีต่ำกว่า 2400 (เช่น 2026) จะมีข้อความขอให้กรอกเป็นปี พ.ศ. ระบบไม่แปลงปีให้เองแบบเงียบ ๆ
  • format กำหนดลำดับ: dd/mm/yyyy (ค่าเริ่มต้น), mm/dd/yyyy หรือ yyyy-mm-dd รูปแบบจะแสดงเป็นข้อความช่วยจนกว่าคุณจะใส่ helper-text ของตัวเอง
  • ภาษามาจาก lang ที่ตัว element หรือ ancestor ที่ใกล้ที่สุด ใส่ locale ถ้าต้องการกำหนดภาษาเฉพาะ date picker
HTMLReactReact + Tailwind<ui-date-picker label="วันที่เริ่มสัญญา" name="start" value="2026-10-10" min="2026-01-01" required></ui-date-picker> <UiDatePicker label="วันที่เริ่มสัญญา" name="start" value="2026-10-10" min="2026-01-01" required /> <DatePicker label="วันที่เริ่มสัญญา" name="start" defaultValue="2026-10-10" min="2026-01-01" required />

date picker แบบช่วง (range) ส่งค่าสองรายการ คือ name และ end-name:

HTMLReactReact + Tailwind<ui-date-picker range label="วันเริ่ม" end-label="วันสิ้นสุด" name="from" end-name="to"></ui-date-picker> <UiDatePicker range label="วันเริ่ม" endLabel="วันสิ้นสุด" name="from" endName="to" /> <DatePicker range label="วันเริ่ม" endLabel="วันสิ้นสุด" name="from" endName="to" />

ถ้าจะปิดบางวัน (วันหยุด เสาร์-อาทิตย์) ตั้ง isDateDisabled เป็นฟังก์ชันที่คืน true หรือคืนข้อความเพื่อใช้เป็นข้อความแจ้งผู้ใช้ ใน web component เป็น property จึงต้องตั้งด้วย JavaScript ส่วน React และ React + Tailwind เป็น prop:

HTMLReactReact + Tailwindconst picker = document.querySelector('ui-date-picker[name="start"]'); picker.isDateDisabled = (date) => (date.getDay() === 0 ? 'ไม่มีบริการส่งในวันอาทิตย์' : false); <UiDatePicker label="วันที่เริ่มสัญญา" name="start" isDateDisabled={(date) => (date.getDay() === 0 ? 'ไม่มีบริการส่งในวันอาทิตย์' : false)} /> <DatePicker label="วันที่เริ่มสัญญา" name="start" isDateDisabled={(date) => (date.getDay() === 0 ? 'ไม่มีบริการส่งในวันอาทิตย์' : false)} />

นับตัวอักษรและนับคำ

max-count เพิ่มตัวนับให้ ui-text-input และ ui-text-area เป็นขีดจำกัดแบบไม่บังคับ ผู้ใช้วางข้อความยาว ๆ แล้วค่อยตัดทีหลังได้ พอเกินแล้วตัวนับเป็นสีแดง ขึ้น error และฟอร์มส่งไม่ได้ screen reader จะบอกเมื่อใกล้ครบ

HTMLReactReact + Tailwind<ui-text-area label="หมายเหตุ" name="notes" max-count="200"></ui-text-area> <UiTextArea label="หมายเหตุ" name="notes" maxCount={200} /> <TextArea label="หมายเหตุ" name="notes" maxCount={200} />

ui-text-area ใส่ counter-mode="word" เพื่อนับคำแทน ภาษาไทยไม่มีช่องว่างระหว่างคำ จึงนับด้วย word segmenter ของ browser ตามภาษาของช่อง "สวัสดีครับ ผมชื่อสมชาย" นับได้ 5 คำ

HTMLReactReact + Tailwind<ui-text-area label="สรุป" name="summary" max-count="50" counter-mode="word"></ui-text-area> <UiTextArea label="สรุป" name="summary" maxCount={50} counterMode="word" /> <TextArea label="สรุป" name="summary" maxCount={50} counterMode="word" />

เปลี่ยนข้อความได้ด้วย too-long-text ({max} จะถูกแทนด้วยจำนวนที่กำหนด) และ near-limit-text ถ้าต้องการขีดจำกัดที่กันไม่ให้พิมพ์เกิน ใช้ maxlength แทน

ใช้ฟอร์มแบบ fluid

ช่องที่อยู่ใน <ui-fluid-form> จะเป็นช่องแบบ fluid ของ Carbon: label อยู่ในกล่องสูง 64px และ error แสดงในกล่อง ช่องแบบ fluid ไม่มีบรรทัดข้อความช่วย ui-fluid-form ไม่ใช่ฟอร์ม จึงต้องครอบด้วย <form> ของคุณเอง:

HTMLReactReact + Tailwind<form method="dialog"> <ui-fluid-form> <ui-text-input label="ชื่อ" name="first" required></ui-text-input> <ui-text-input label="นามสกุล" name="last" required></ui-text-input> <ui-date-picker label="วันเกิด" name="birth"></ui-date-picker> </ui-fluid-form> </form> <form method="dialog"> <UiFluidForm> <UiTextInput label="ชื่อ" name="first" required /> <UiTextInput label="นามสกุล" name="last" required /> <UiDatePicker label="วันเกิด" name="birth" /> </UiFluidForm> </form> import { FluidForm } from '@/components/ui/react-tw/field'; <form> <FluidForm> <TextInput label="ชื่อ" name="first" /> <TextInput label="นามสกุล" name="last" /> <DatePicker label="วันเกิด" name="birth" /> </FluidForm> </form>

ถ้าจะให้ช่องเดียวเป็นแบบ fluid ใส่ attribute fluid ที่ช่องนั้น (prop fluid ใน React และ React + Tailwind)
