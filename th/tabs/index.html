Tabs, Content switcher หรือ Accordion?

Component ใช้เมื่อ
Tabs แต่ละมุมมองเป็นส่วนหนึ่งของเรื่องเดียวกัน (เงื่อนไข คู่สัญญา ประวัติของสัญญาหนึ่งฉบับ) และผู้อ่านดูทีละส่วน
Content switcher เนื้อหาเดิมในรูปแบบหรือตัวกรองอื่น เช่น ตารางหรือกริด คำขอทั้งหมดหรือของฉัน
Accordion หน้ายาวที่มีหลายส่วน ผู้อ่านอาจเปิดหลายส่วนพร้อมกัน หรืออ่านจากบนลงล่าง

แท็บเริ่มต้นและการเปลี่ยนแท็บ

value คือ name ของ panel ที่แสดง ถ้าไม่ใส่ จะเลือกแท็บแรกที่ใช้งานได้ ui-tab-change จะเกิดหลังผู้ใช้เลือกแท็บอื่น โดยมีชื่อ panel อยู่ใน detail.name

ร่าง ฝ่ายกฎหมายตรวจ ลงนาม ผู้ขอกรอกแบบฟอร์มสัญญา ฝ่ายกฎหมายตรวจเงื่อนไขและคู่สัญญา ทั้งสองฝ่ายลงนาม แล้วจัดเก็บสัญญา

Accessibility

  • แถบเป็น tablist ที่มีชื่อจาก label แต่ละแท็บเป็น tab ที่มี aria-selected และ aria-controls และแต่ละ panel เป็น tabpanel ที่ใช้แท็บของมันเป็นชื่อ
  • มีจุดหยุดของ Tab จุดเดียว: Tab ไปที่แท็บที่เลือก แล้วต่อเข้า panel ปุ่ม ← และ → ย้ายระหว่างแท็บและวนรอบ (↑ และ ↓ ในคอลัมน์แนวตั้ง) Home และ End ไปแท็บแรกและแท็บสุดท้าย ข้ามแท็บที่ปิดใช้งาน
  • panel ที่ข้างในไม่มีอะไรรับโฟกัสได้จะรับ Tab เอง ผู้ใช้คีย์บอร์ดจึงไปถึงและเลื่อนอ่านข้อความได้
  • แท็บแบบไอคอนอย่างเดียวต้องมี label ซึ่งเป็นทั้งชื่อของแท็บและ tooltip
  • ในแท็บที่ปิดได้ ปุ่มปิดซ่อนจาก screen reader แต่ละแท็บจะบอกว่า Delete คือคีย์ลัด (aria-keyshortcuts)

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Tabs
