Headless Tree view

TreeView คือพฤติกรรมของ Tree view แบบมี style ในรูป React parts ที่ไม่มี style ตามแบบ tree ของ WAI-ARIA: role="tree" ของ Node ที่ซ้อนกัน Tab หยุดที่เดียว ปุ่มลูกศร Home / End พิมพ์เพื่อกระโดด เลือกได้หนึ่งหรือหลาย node มี node ที่ active และโหลด node ลูกเมื่อเปิด

ส่วนที่คุณเขียนเอง: Row ของแต่ละ node (ลูกศร ไอคอน label) การเยื้อง และ style ทั้งหมด สถานะแสดงเป็น attribute data-* ที่ node และแถวของมัน useNodeContext() ให้ความลึกของ node สำหรับการเยื้อง

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { TreeView } from '@purpurabog/ui/headless';

วิธีใช้

import type { ReactNode } from 'react'; import { TreeView } from '@purpurabog/ui/headless'; interface Item { value: string; label: string; children?: Item[]; } const folders: Item[] = [ { value: 'contracts', label: 'สัญญา', children: [ { value: 'c1', label: 'สัญญาบริการ – เอซีเอ็ม' }, { value: 'c2', label: 'NDA – โกลเบ็กซ์' }, ] }, { value: 'templates', label: 'แม่แบบ', children: [{ value: 't1', label: 'NDA มาตรฐาน' }] }, ]; function Row({ children }: { children: ReactNode }) { const node = TreeView.useNodeContext(); return ( <TreeView.Row style={{ paddingInlineStart: 8 + node.depth * 24 }} className="flex h-8 cursor-pointer items-center gap-2 pe-4 text-sm text-ink-muted hover:bg-ghost-hover hover:text-ink data-selected:bg-layer-selected-1 data-selected:text-ink"> {node.branch ? ( <TreeView.Toggle className="flex size-4 items-center justify-center"> <svg viewBox="0 0 16 16" className={`size-4 fill-current transition-transform ${node.expanded ? '' : '-rotate-90'}`}><path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /></svg> </TreeView.Toggle> ) : ( <span className="size-4" /> )} {children} </TreeView.Row> ); } function Branch({ item }: { item: Item }) { return ( <TreeView.Node value={item.value} label={item.label} hasChildren={!!item.children} defaultExpanded className="outline-none [&:focus-visible>:first-child]:outline-2 [&:focus-visible>:first-child]:-outline-offset-2 [&:focus-visible>:first-child]:outline-focus"> <Row>{item.label}</Row> {item.children ? โครงสร้าง

<TreeView.Root> <TreeView.Node value="…" hasChildren> <TreeView.Row> <TreeView.Toggle /> label </TreeView.Row> <TreeView.Group> <TreeView.Node value="…"> <TreeView.Row>label</TreeView.Row> </TreeView.Node> </TreeView.Group> </TreeView.Node> </TreeView.Root>

hasChildren บอก Node ว่าเป็นกิ่ง tree หา node จาก DOM ดังนั้น node จะมาจาก component ไหน ลึกแค่ไหนก็ได้

การเลือกและ node ที่ active

คลิก Space หรือ Enter เลือก node และทำให้มันเป็น node ที่ active เก็บทั้งสองค่าเองด้วย selected / onSelect และ active / onActivate หรือตั้งค่าเริ่มด้วย defaultSelected / defaultActive เมื่อใส่ multiselect Ctrl / ⌘ + คลิก และ Space สลับ node เข้าออก และ Ctrl / ⌘ + A เลือกทุก node ที่ใช้งานได้

import { useState, type ReactNode } from 'react'; import { TreeView } from '@purpurabog/ui/headless'; function Row({ children }: { children: ReactNode }) { const node = TreeView.useNodeContext(); return ( <TreeView.Row style={{ paddingInlineStart: 8 + node.depth * 24 }} className="flex h-8 cursor-pointer items-center gap-2 border-s-4 border-transparent pe-4 text-sm text-ink-muted hover:bg-ghost-hover data-active:border-interactive data-selected:bg-layer-selected-1 data-selected:text-ink data-disabled:cursor-not-allowed data-disabled:text-ink-disabled data-disabled:hover:bg-transparent"> {node.branch ? <TreeView.Toggle className="w-4 text-center">{node.expanded ? '▾' : '▸'}</TreeView.Toggle> : <span className="w-4" />} {children} </TreeView.Row> ); } const nodeClass = 'outline-none [&:focus-visible>:first-child]:outline-2 [&:focus-visible>:first-child]:-outline-offset-2 [&:focus-visible>:first-child]:outline-focus'; export default function Example() { const [multiselect, setMultiselect] = useState(true); const [selected, setSelected] = useState<string[]>(['contracts-team']); const [active, setActive] = useState('contracts-team'); return ( <div className="grid max-w-xs gap-3"> <label className="flex items-center gap-2 text-sm text-ink"> <input type="checkbox" checked={multiselect} onChange={(e) => setMultiselect(e.target.checked)} /> multiselect </label> <TreeView.Root aria-label="แชร์ให้" multiselect={multiselect} selected={selected} onSelect={(next) => setSelected(next)} active={active} onActivate={setActive} className="bg-layer-1"> <TreeView.Node value="legal" label="ฝ่ายกฎหมาย" hasChildren defaultExpanded className={nodeClass}> <Row>ฝ่ายกฎหมาย</Row> <TreeView.Group> <TreeView.Node value="contracts-team" label="ทีมสัญญา" className={nodeClass}><Row>ทีมสัญญา</Row></TreeView.Node> <TreeView.Node value="litigation" label="ทีมคดีความ" className={nodeClass}><Row>ทีมคดีความ</Row></TreeView.Node> </TreeView.Group> </TreeView.Node> <TreeView.Node value="finance" label="ฝ่ายการเงิน" className={nodeClass}><Row>ฝ่ายการเงิน</Row></TreeView.Node> <TreeView.Node value="archive" label="แฟ้มเก่า (อ่านอย่างเดียว)" disabled className={nodeClass}><Row>แฟ้มเก่า (อ่านอย่างเดียว)</Row></TreeView.Node> </TreeView.Root> <p className="text-xs text-ink-muted">ที่เลือก: {selected.join(', ') || '(ไม่มี)'} · active: {active || '(ไม่มี)'}</p> </div> ); }

node ที่ disabled เลือกหรือเปิดไม่ได้ และปุ่มลูกศรจะข้ามไป

เปิดปิดกิ่ง

แต่ละ Node เก็บสถานะเปิดของตัวเอง (defaultExpanded) หรือรับ expanded กับ onToggle เมื่อคุณเก็บเอง เช่น สำหรับปุ่ม "ขยายทั้งหมด" ลูกศรขวาเปิดกิ่ง ลูกศรซ้ายปิด ส่วน Toggle ทำแบบเดียวกันด้วยเมาส์

import { useState, type ReactNode } from 'react'; import { TreeView } from '@purpurabog/ui/headless'; const branches = ['hq', 'legal', 'branches']; function Row({ children }: { children: ReactNode }) { const node = TreeView.useNodeContext(); return ( <TreeView.Row style={{ paddingInlineStart: 8 + node.depth * 24 }} className="flex h-8 cursor-pointer items-center gap-2 pe-4 text-sm text-ink-muted hover:bg-ghost-hover data-selected:bg-layer-selected-1 data-selected:text-ink"> {node.branch ? <TreeView.Toggle className="w-4 text-center">{node.expanded ? '▾' : '▸'}</TreeView.Toggle> : <span className="w-4" />} {children} </TreeView.Row> ); } const nodeClass = 'outline-none [&:focus-visible>:first-child]:outline-2 [&:focus-visible>:first-child]:-outline-offset-2 [&:focus-visible>:first-child]:outline-focus'; const button = 'h-8 px-3 text-sm text-link hover:bg-ghost-hover focus-visible:outline-2 focus-visible:outline-focus'; export default function Example() { const [open, setOpen] = useState<string[]>(['hq']); const props = (value: string) => ({ expanded: open.includes(value), onToggle: (expanded: boolean) => setOpen((now) => (expanded ? [...now, value] : now.filter((v) => v !== value))), }); return ( <div className="grid max-w-xs gap-2"> <div className="flex gap-2"> <button type="button" className={button} onClick={() => setOpen(branches)}>ขยายทั้งหมด</button> <button type="button" className={button} onClick={() => setOpen([])}>ยุบทั้งหมด</button> </div> <TreeView.Root aria-label="องค์กร" className="bg-layer-1"> <TreeView.Node value="hq" label="สำนักงานใหญ่" hasChildren {...props('hq')} className={nodeClass}> <Row>สำนักงานใหญ่</Row> <TreeView.Group> <TreeView.Node value="legal" label="ฝ่ายกฎหมาย" hasChildren {...props('legal')} className={nodeClass}> <Row>ฝ่ายกฎหมาย</Row> <TreeView.Group> <TreeView.Node value="contracts" label="ทีมสัญญา" className={nodeClass}><Row>ทีมสัญญา</Row></TreeView.Node> </TreeView.Group> </TreeView.Node> <TreeView.Node value="finance" label="ฝ่ายการเงิน" className={nodeClass}><Row>ฝ่ายการเงิน</Row></TreeView.Node> </TreeView.Group> </TreeView.Node> <TreeView.Node value="branches" label="สาขา" hasChildren {...props('branches')} className={nodeClass}> <Row>สาขา</Row> <TreeView.Group> <TreeView.Node value="cnx" label="เชียงใหม่" className={nodeClass}><Row>เชียงใหม่</Row></TreeView.Node> </TreeView.Group> </TreeView.Node> </TreeView.Root> <p className="text-xs text-ink-muted">ที่เปิด: {open.join(', ') || '(ไม่มี)'}</p> </div> ); }

โหลด node ลูกเมื่อเปิด

lazy ทำให้ node เป็นกิ่งก่อนจะมีลูก ครั้งแรกที่เปิด มันจะมี data-loading และ aria-busy และเรียก onLazyLoad(value) ให้ render ลูกเมื่อข้อมูลมาถึง promise ที่คืนมาแล้ว resolve โดยยังไม่มีลูกจะทำให้ node เป็นใบ ส่วนที่ reject จะปิด node เปิดอีกครั้งจึงลองใหม่

import { useState, type ReactNode } from 'react'; import { TreeView } from '@purpurabog/ui/headless'; function Row({ children }: { children: ReactNode }) { const node = TreeView.useNodeContext(); let caret: ReactNode = <span className="w-4" />; if (node.loading) caret = <span className="size-3 animate-spin rounded-full border-2 border-border-subtle-1 border-t-interactive" aria-hidden="true" />; else if (node.branch) caret = <TreeView.Toggle className="w-4 text-center">{node.expanded ? '▾' : '▸'}</TreeView.Toggle>; return ( <TreeView.Row style={{ paddingInlineStart: 8 + node.depth * 24 }} className="flex h-8 cursor-pointer items-center gap-2 pe-4 text-sm text-ink-muted hover:bg-ghost-hover data-selected:bg-layer-selected-1 data-selected:text-ink"> {caret} {children} {node.loading ? <span className="sr-only">, กำลังโหลด</span> : null} </TreeView.Row> ); } const nodeClass = 'outline-none [&:focus-visible>:first-child]:outline-2 [&:focus-visible>:first-child]:-outline-offset-2 [&:focus-visible>:first-child]:outline-focus'; const folders = [ { value: 'civil', label: 'คดีแพ่ง' }, { value: 'criminal', label: 'คดีอาญา' }, { value: 'empty', label: 'แฟ้มว่าง' }, ]; /** server สมมุติ: ตอบสามไฟล์หลัง 800ms แฟ้มว่างไม่มีไฟล์ */ const fetchFolder = (value: string) => new Promise<string[]>((resolve) => setTimeout(() => resolve(value === 'empty' ? [] : [1, 2, 3].map((n) => `${value}-${n}`)), 800)); export default function Example() { const [children, setChildren] = useState<Record<string, string[]>>({}); const load = async (value: string) => { const files = await fetchFolder(value); setChildren((now) => ({ ...now, [value]: files })); }; return ( <TreeView.Root aria-label="แฟ้มคดีบน server" className="max-w-xs bg-layer-1"> {folders.map((folder) => { const files = children[folder.value] ?? []; return ( <TreeView.Node key={folder.value} value={folder.value} label={folder.label} lazy hasChildren={files.length > 0} onLazyLoad={load} className={nodeClass}> <Row>{folder.label}</Row> <TreeView.Group> {files.map((file) => ( <TreeView.Node key={file} value={file} label={file} className={nodeClass}> <Row>ไฟล์ {file}</Row> </TreeView.Node> ))} </TreeView.Group> </TreeView.Node> ); })} </TreeView.Root> ); }

ลิงก์

ใส่ <a> ใน Row ของ node ปุ่ม Enter จะไปตามลิงก์ของ node นั้น (หลังเลือกมัน) เอาลิงก์ออกจากลำดับ Tab ด้วย tabIndex={-1} เพราะ node เป็นตัวรับคีย์บอร์ด

import { useState } from 'react'; import { TreeView } from '@purpurabog/ui/headless'; const policies = [ { value: 'retention', label: 'นโยบายการเก็บเอกสาร', href: '#retention' }, { value: 'signing', label: 'อำนาจการลงนาม', href: '#signing' }, ]; export default function Example() { const [opened, setOpened] = useState(''); return ( <div className="grid max-w-xs gap-2"> <TreeView.Root aria-label="นโยบาย" className="bg-layer-1"> {policies.map((p) => ( <TreeView.Node key={p.value} value={p.value} label={p.label} className="outline-none [&:focus-visible>:first-child]:outline-2 [&:focus-visible>:first-child]:-outline-offset-2 [&:focus-visible>:first-child]:outline-focus"> <TreeView.Row className="flex h-8 items-center px-4 text-sm hover:bg-ghost-hover data-selected:bg-layer-selected-1"> <a href={p.href} tabIndex={-1} className="text-link no-underline" onClick={(e) => { e.preventDefault(); // ให้แอปเปลี่ยนหน้าเองแทน setOpened(p.href); }} > {p.label} </a> </TreeView.Row> </TreeView.Node> ))} </TreeView.Root> <p className="text-xs text-ink-muted">จะเปิด: {opened}</p> </div> ); }

Parts

TreeView.Root

สร้าง <div role="tree"> จัดการปุ่ม คลิก และ Tab ที่หยุดที่เดียวให้ทุก node ข้างใน รับ prop ทุกตัวของ <div> ยกเว้น role

Prop Type ค่าเริ่มต้น
multiselect boolean false Ctrl / ⌘ + คลิก และ Space สลับ node Ctrl / ⌘ + A เลือกทั้งหมด (aria-multiselectable)
selected readonly string[] value ของ node ที่เลือก (ควบคุมเอง)
defaultSelected readonly string[] [] ที่เลือกตอนเริ่ม (ไม่ควบคุมเอง)
onSelect (selected: string[], value: string) => void หลังผู้ใช้เปลี่ยนที่เลือก value คือ node ที่ทำให้เปลี่ยน
active string node ที่ active ล่าสุด (ควบคุมเอง)
defaultActive string '' node ที่ active ตอนเริ่ม (ไม่ควบคุมเอง)
onActivate (value: string) => void หลัง node หนึ่งกลายเป็น node ที่ active
Attribute เมื่อ
data-multiselect ตั้ง multiselect

TreeView.useTreeViewContext() คืน multiselect, selected, active และ tabStop ให้ component ใดก็ได้ที่อยู่ใน Root

TreeView.Node

สร้าง <div role="treeitem"> ที่มี aria-expanded (เฉพาะกิ่ง) aria-selected, aria-disabled และ aria-busy ใส่ Row และ Group (ถ้าเป็นกิ่ง) ไว้ข้างใน รับ prop ทุกตัวของ <div> ยกเว้น role

Prop Type ค่าเริ่มต้น
value string ระบุ node ใน selected และ active (ต้องใส่)
label string value ข้อความที่การพิมพ์ใช้จับคู่
hasChildren boolean false node มีลูกใน Group ของมัน: เป็นกิ่ง
disabled boolean false เลือกหรือเปิดไม่ได้ ปุ่มลูกศรข้ามไป
expanded boolean เปิดอยู่ (ควบคุมเอง)
defaultExpanded boolean false เปิดตอนเริ่ม (ไม่ควบคุมเอง)
onToggle (expanded: boolean) => void หลังกิ่งเปิดหรือปิด
lazy boolean false กิ่งที่ยังไม่ได้โหลดลูก
onLazyLoad (value: string) => void | Promise<void> เรียกครั้งแรกที่ node แบบ lazy เปิด
Attribute เมื่อ
data-selected node ถูกเลือก
data-active node นี้คือ node ที่ active
data-disabled ตั้ง disabled
data-branch มีลูก หรือเป็น lazy ที่อาจมีลูก
data-expanded กิ่งที่เปิดอยู่
data-loading node แบบ lazy ที่รอลูกอยู่

TreeView.useNodeContext() คืน value, branch, expanded, loading, selected, active, disabled, depth (0 ที่ชั้นบนสุด), rowId และ toggle(expanded) ของ node

TreeView.Row

สร้าง <div> คือส่วนที่ผู้ใช้เห็นและคลิก id ของมันใช้ตั้งชื่อ Group ของ node มี attribute data-* ชุดเดียวกับ Node ของมัน

TreeView.Toggle

สร้าง <button type="button"> ที่เปิดปิดกิ่ง คลิกที่ส่วนอื่นของแถวจะเป็นการเลือกแทน ปุ่มนี้อยู่นอกลำดับ Tab และซ่อนจากเทคโนโลยีช่วยเหลือ (aria-hidden) เพราะ node เป็นตัวรับคีย์บอร์ด

Attribute เมื่อ

TreeView.Group

สร้าง <div role="group"> ที่เก็บ node ลูก ตั้งชื่อด้วยแถว (aria-labelledby) และเป็น hidden ขณะกิ่งปิด Group แต่ละชั้นเพิ่มความลึกของ node ข้างในหนึ่งระดับ

Attribute เมื่อ
data-expanded กิ่งเปิดอยู่

คีย์บอร์ดและ accessibility

  • ทั้ง tree หยุด Tab ที่เดียว: node ที่ focus ล่าสุด ถ้าไม่มีก็ node ที่เลือก ถ้าไม่มีอีกก็ node แรกที่มองเห็น
  • ขึ้น / ลง ย้ายไปตาม node ที่มองเห็น Home / End ไปที่ node แรก / สุดท้าย ขวาเปิดกิ่งหรือไปที่ลูกตัวแรก ซ้ายปิดกิ่งหรือไปที่ node แม่
  • Enter เปิดหรือปิดกิ่ง เลือก node และไปตามลิงก์ของ node นั้น Space เลือก (สลับเข้าออกใน tree แบบ multiselect) พิมพ์ตัวอักษรเพื่อไปที่ node ถัดไปที่ label ขึ้นต้นด้วยตัวนั้น
  • สิ่งที่คุณต้องใส่เอง: ชื่อของ tree (aria-label หรือ aria-labelledby ที่ Root) การเยื้อง ลูกศร และ style ของ focus ที่มองเห็นได้บนแถว
  • บอก "กำลังโหลด" ในแถวของ node ที่กำลังโหลด (เช่น ข้อความที่ซ่อนจากสายตา) อย่างที่ tree แบบมี style ทำ
