Select, Dropdown, Combobox หรือ MultiSelect?

Component ใช้เมื่อ
Select ช่องในฟอร์มธรรมดา browser เป็นคนวาดรายการ มือถือเปิดตัวเลือกแบบ native และ screen reader คุ้นเคยที่สุด แต่ละรายการเป็นข้อความบรรทัดเดียว
Dropdown อยากให้รายการหน้าตาเหมือนกันทุก browser หรือรายการต้องมีบรรทัดที่สอง (data-description)
Combobox รายการยาวจนพิมพ์หาเร็วกว่าเลื่อนหา รายการมาจากการค้นหาบน server หรือยอมให้พิมพ์ค่าเองได้
Multi-select ผู้ใช้เลือกได้หลายค่า

ถ้ามีสองถึงห้าตัวเลือกที่ควรเห็นพร้อมกันทั้งหมด ให้ใช้ radio group (เลือกหนึ่ง) หรือ checkbox (เลือกหลายอัน)

Placeholder และค่าเริ่มต้น

placeholder เพิ่มตัวเลือกว่างเป็นอันแรกด้วยสีจาง ถ้าใส่ required ด้วย ผู้ใช้ต้องเลือกอย่างอื่นก่อนจึงจะส่งฟอร์มได้

ถ้าไม่มี placeholder ค่าเริ่มต้นคือ value ถ้าไม่มีก็เป็น <option selected> ถ้าไม่มีอีกก็เป็นรายการแรก เหมือน select แบบ native การ reset จะกลับไปที่ค่าเริ่มต้นนี้ event change ยิงเมื่อผู้ใช้เลือกรายการ

ถ้าใส่ required คู่กับ placeholder ฟอร์มจะส่งไม่ได้จนกว่าผู้ใช้จะเลือกรายการ ลองกดส่งโดยยังไม่เลือกเพื่อดู error ถ้าไม่ใส่ invalid-text จะเห็นข้อความในตัว "กรุณาเลือกรายการ" ตามภาษาของหน้า

Skeleton

ระหว่างโหลดรายการ ให้แสดง ui-select-skeleton แทนช่อง เป็นแถบ label กับแถบช่องที่ size เดียวกัน skeleton ถูกซ่อนจาก screen reader จึงต้องบอกว่ากำลังโหลดที่ container เช่น aria-busy

Accessibility

  • ตัวควบคุมเป็น <select> จริง ใช้ปุ่มของ browser เปิดและเปลี่ยนค่า และมือถือแสดงตัวเลือกของระบบ
  • label ผูกกับ select ไว้แล้ว ใช้ hide-label เพื่อให้เหลือไว้ให้ screen reader อ่านอย่างเดียว เฉพาะเมื่อบริบทรอบ ๆ บอกอยู่แล้วว่าช่องนี้คืออะไร
  • ข้อความช่วยเหลือ คำเตือน และ error เป็นคำอธิบายของ select จึงถูกอ่านเมื่อโฟกัสเข้ามา
  • รายการใส่ markup หรือบรรทัดที่สองไม่ได้ ถ้าต้องการ ให้ใช้ Dropdown

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Select

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-select> · React UiSelect

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
label label string '' Visible label text; the label slot replaces it when markup is needed.
hide-label hideLabel boolean false Keep the label for screen readers but don't show it.
helper-text helperText string '' Helper text under the field, shown while there is no error or warning.
invalid-text invalidText string '' Error text shown while invalid or while the field fails validation.
invalid invalid boolean false Forces the error state, e.g. after server-side validation.
warn warn boolean false Non-blocking warning; shown when there is no error.
warn-text warnText string '' Text of the warning shown while warn.
placeholder placeholder string '' Shown as an empty first choice; with required the user must pick something else.
value value string ''
name name string '' Reflected: form-associated elements submit under the name attribute.
size size 'sm' | 'md' | 'lg' 'md' Field height: sm 32px, md 40px, lg 48px (tokens --ui-field-height-*).
disabled disabled boolean false Disables the control; a disabled <fieldset> ancestor does the same.
required required boolean false Blocks form submission while the field is empty.
readonly readonly boolean false Shows and submits the value but blocks changes.
fluid fluid boolean false Carbon FluidSelect: the label inside a 64px box, an error / warning inside it. <ui-fluid-form> sets it for every field inside.
inline inline boolean false Label beside a compact, borderless select.

Property ชนิด คำอธิบาย

Method

Method คำอธิบาย
