Headless Edit in place

EditInPlace คือพฤติกรรมของ Edit in place แบบมี style ในรูป React part ที่ไม่มี style: ค่าที่แสดงในช่องข้อความและแก้ไขได้ตรงที่มันอยู่ พร้อมปุ่มแก้ไข ยกเลิก และบันทึก part เก็บค่าและค่าตอนเริ่มแก้ไข เริ่มแก้ไขเมื่อ focus หรือพิมพ์ บันทึกเมื่อกด Enter คืนค่าเมื่อกด Escape และบันทึกหรือคืนค่าเมื่อ focus ออกไป แต่ละปุ่มแสดงเฉพาะตอนที่ใช้ได้ และการกดปุ่มทำให้ focus ยังอยู่ในช่อง

ส่วนที่คุณทำเองคือ markup และ style ทั้งหมด: ไอคอน สีตอน hover เส้น focus ข้อความ error และข้อความของโหมดอ่านอย่างเดียว สถานะแสดงเป็น attribute data-* ให้ใช้ใส่ style

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { EditInPlace } from '@purpurabog/ui/headless';

วิธีใช้

import { EditInPlace } from '@purpurabog/ui/headless'; const button = 'inline-flex size-10 items-center justify-center text-ink hover:bg-layer-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus disabled:cursor-not-allowed disabled:text-ink-disabled disabled:hover:bg-transparent'; export default function Example() { return ( <div className="max-w-sm"> <EditInPlace.Root defaultValue="สัญญาเช่าคลังสินค้า บางนา"> <EditInPlace.Group className="group flex items-center hover:bg-field-1 data-editing:bg-field-1 has-[input:focus]:outline-2 has-[input:focus]:outline-focus"> <EditInPlace.Input aria-label="ชื่อสัญญา" className="h-10 min-w-0 flex-1 cursor-pointer bg-transparent px-4 text-sm text-ink outline-none" /> <EditInPlace.Action action="edit" aria-label="แก้ไข" className={`${button} invisible group-hover:visible`}>✎</EditInPlace.Action> <EditInPlace.Action action="cancel" aria-label="ยกเลิก" className={button}>✕</EditInPlace.Action> <EditInPlace.Action action="save" aria-label="บันทึก" className={button}>✓</EditInPlace.Action> </EditInPlace.Group> </EditInPlace.Root> </div> ); }

Anatomy

<EditInPlace.Root> <EditInPlace.Group> <EditInPlace.Input /> <EditInPlace.Action action="edit" /> <EditInPlace.Action action="cancel" /> <EditInPlace.Action action="save" /> </EditInPlace.Group> <EditInPlace.InvalidText /> </EditInPlace.Root>

Root ไม่สร้าง element ของตัวเอง Group คือกล่องที่ฟังว่า focus ย้ายไปมาระหว่างช่องกับปุ่ม ให้ใส่ทุก part ที่รับ focus ไว้ข้างใน

บันทึกและยกเลิก

onSave ได้รับค่าเมื่อบันทึกการเปลี่ยนแปลง: กดบันทึก กด Enter หรือ focus ออกจาก group พร้อมการเปลี่ยนแปลงที่ถูกต้อง onCancel ได้รับค่าที่คืนกลับ: กดยกเลิก กด Escape หรือ focus ออกไปโดยไม่มีการเปลี่ยนแปลงที่ถูกต้อง ปุ่มบันทึกและยกเลิกกดได้เมื่อค่าเปลี่ยนแล้วเท่านั้น (ช่องว่างหัวท้ายไม่นับ)

import { useState } from 'react'; import { EditInPlace } from '@purpurabog/ui/headless'; const button = 'inline-flex size-10 items-center justify-center text-ink hover:bg-layer-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus disabled:cursor-not-allowed disabled:text-ink-disabled disabled:hover:bg-transparent'; export default function Example() { const [last, setLast] = useState(''); return ( <div className="grid max-w-sm gap-2"> <EditInPlace.Root defaultValue="PO-2026-0815" onSave={(value) => setLast(`บันทึก "${value}"`)} onCancel={(value) => setLast(`คืนค่าเป็น "${value}"`)} > <EditInPlace.Group className="group flex items-center hover:bg-field-1 data-editing:bg-field-1 has-[input:focus]:outline-2 has-[input:focus]:outline-focus"> <EditInPlace.Input aria-label="เลขที่ใบสั่งซื้อ" className="h-10 min-w-0 flex-1 cursor-pointer bg-transparent px-4 text-sm text-ink outline-none" /> <EditInPlace.Action action="edit" aria-label="แก้ไข" className={`${button} invisible group-hover:visible`}>✎</EditInPlace.Action> <EditInPlace.Action action="cancel" aria-label="ยกเลิก" className={button}>✕</EditInPlace.Action> <EditInPlace.Action action="save" aria-label="บันทึก" className={button}>✓</EditInPlace.Action> </EditInPlace.Group> </EditInPlace.Root> <p className="text-xs text-ink-muted">เหตุการณ์ล่าสุด: {last}</p> </div> ); }

ค่าแบบ controlled

เก็บค่าเองด้วย value และ onValueChange onValueChange ได้รับทุกครั้งที่พิมพ์ และค่าที่คืนกลับเมื่อยกเลิก ส่งค่าไป server ใน onSave

import { useState } from 'react'; import { EditInPlace } from '@purpurabog/ui/headless'; const button = 'inline-flex size-10 items-center justify-center text-ink hover:bg-layer-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus disabled:cursor-not-allowed disabled:text-ink-disabled disabled:hover:bg-transparent'; export default function Example() { const [reference, setReference] = useState('REF-104'); const [saved, setSaved] = useState('REF-104'); return ( <div className="grid max-w-sm gap-2"> <EditInPlace.Root value={reference} onValueChange={setReference} onSave={(value) => setTimeout(() => setSaved(value.trim()), 400)}> <EditInPlace.Group className="group flex items-center hover:bg-field-1 data-editing:bg-field-1 has-[input:focus]:outline-2 has-[input:focus]:outline-focus"> <EditInPlace.Input aria-label="เลขอ้างอิง" className="h-10 min-w-0 flex-1 cursor-pointer bg-transparent px-4 text-sm text-ink outline-none" /> <EditInPlace.Action action="edit" aria-label="แก้ไข" className={`${button} invisible group-hover:visible`}>✎</EditInPlace.Action> <EditInPlace.Action action="cancel" aria-label="ยกเลิก" className={button}>✕</EditInPlace.Action> <EditInPlace.Action action="save" aria-label="บันทึก" className={button}>✓</EditInPlace.Action> </EditInPlace.Group> </EditInPlace.Root> <p className="text-xs text-ink-muted">ค่า: {reference} · บันทึกบน server แล้ว: {saved}</p> </div> ); }

ค่าไม่ถูกต้อง พร้อมข้อความ error

invalid ไม่ให้บันทึก: ปุ่มบันทึกกดไม่ได้ Enter ไม่บันทึก และ focus ออกไปจะคืนค่า ตั้ง aria-invalid ที่ช่อง และ data-invalid ที่ group กับช่อง ใส่ข้อความ error ใน InvalidText: แสดงเฉพาะตอน invalid และอธิบายช่อง (aria-describedby)

import { useState } from 'react'; import { EditInPlace } from '@purpurabog/ui/headless'; const button = 'inline-flex size-10 items-center justify-center text-ink hover:bg-layer-hover-1 focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus disabled:cursor-not-allowed disabled:text-ink-disabled disabled:hover:bg-transparent'; export default function Example() { const [taxId, setTaxId] = useState('0105556012345'); return ( <div className="max-w-sm"> <EditInPlace.Root value={taxId} onValueChange={setTaxId} invalid={!/^\d{13}$/.test(taxId)}> <EditInPlace.Group className="group flex items-center hover:bg-field-1 data-editing:bg-field-1 has-[input:focus]:outline-2 has-[input:focus]:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error"> <EditInPlace.Input aria-label="เลขประจำตัวผู้เสียภาษี" className="h-10 min-w-0 flex-1 cursor-pointer bg-transparent px-4 text-sm text-ink outline-none" /> <EditInPlace.Action action="edit" aria-label="แก้ไข" className={`${button} invisible group-hover:visible`}>✎</EditInPlace.Action> <EditInPlace.Action action="cancel" aria-label="ยกเลิก" className={button}>✕</EditInPlace.Action> <EditInPlace.Action action="save" aria-label="บันทึก" className={button}>✓</EditInPlace.Action> </EditInPlace.Group> <EditInPlace.InvalidText className="mt-2 text-xs text-error-text">เลขประจำตัวผู้เสียภาษีมี 13 หลัก</EditInPlace.InvalidText> </EditInPlace.Root> </div> ); }

อ่านอย่างเดียว

readOnly คงค่าไว้: ช่องเป็น readonly ไม่มีปุ่มแสดง และการคลิกที่ช่องตั้ง noteOpen ใน context ให้แสดงข้อความของคุณตามค่านี้ เช่น ใน Headless Popover แล้วปิดด้วย setNoteOpen(false)

import { EditInPlace } from '@purpurabog/ui/headless'; function ReadOnlyNote() { const { noteOpen, setNoteOpen } = EditInPlace.useEditInPlaceContext(); if (!noteOpen) return null; return ( <div role="status" className="mt-2 flex items-start justify-between gap-4 bg-inverse-surface-1 p-4 text-sm text-inverse-ink"> เลขที่สัญญากำหนดตอนลงนามสัญญา <button type="button" onClick={() => setNoteOpen(false)} className="underline focus-visible:outline-2 focus-visible:outline-focus-inverse">ปิด</button> </div> ); } export default function Example() { return ( <div className="max-w-sm"> <EditInPlace.Root defaultValue="CT-2026-0142" readOnly> <EditInPlace.Group className="flex items-center data-readonly:cursor-not-allowed"> <EditInPlace.Input aria-label="เลขที่สัญญา" className="h-10 min-w-0 flex-1 bg-transparent px-4 text-sm text-ink outline-none focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus" /> </EditInPlace.Group> <ReadOnlyNote /> </EditInPlace.Root> </div> ); }

Action แสดงเฉพาะในโหมดของตัวเอง: edit ตอนปกติ cancel และ save ระหว่างแก้ไข และไม่มีปุ่มไหนในโหมดอ่านอย่างเดียว ถ้าต้องการปุ่ม "แก้ไขไม่ได้" ข้างช่องอ่านอย่างเดียว ให้สร้างปุ่มของคุณเองที่เรียก setNoteOpen

ปุ่มของคุณเอง

render บน Action สร้าง component ของคุณด้วย props ของ action (type disabled data-disabled onMouseDown onClick และ props ของคุณ) เช่น icon button ที่มี style และ tooltip ให้กระจาย props ทั้งหมดลงบนปุ่ม การกดจะได้ไม่ดึง focus ออกจากช่อง

''}`}> {children} </button> ); } export default function Example() { return ( <div className="max-w-sm"> <EditInPlace.Root defaultValue="สยามโลจิสติกส์"> <EditInPlace.Group className="group flex items-center hover:bg-field-1 data-editing:bg-field-1 has-[input:focus]:outline-2 has-[input:focus]:outline-focus"> <EditInPlace.Input aria-label="ชื่อผู้ขาย" className="h-12 min-w-0 flex-1 cursor-pointer bg-transparent px-4 text-sm text-ink outline-none" /> <EditInPlace.Action action="edit" render={(props) => <IconButton {...props} label="แก้ไขชื่อผู้ขาย">✎</IconButton>} /> <EditInPlace.Action action="cancel" render={(props) => <IconButton {...props} label="ย้อนการแก้ไข">✕</IconButton>} /> <EditInPlace.Action action="save" render={(props) => <IconButton {...props} label="บันทึกชื่อผู้ขาย">✓</IconButton>} /> </EditInPlace.Group> </EditInPlace.Root> </div> ); }

Parts

EditInPlace.Root

เก็บค่า สถานะการแก้ไข และค่าตอนเริ่มแก้ไข สร้างแค่ children ของมัน

Prop Type Default
value string — ค่าแบบ controlled (ใช้คู่กับ onValueChange)
defaultValue string '' ค่าแรกแบบ uncontrolled
onValueChange (value: string) => void — ทุกครั้งที่พิมพ์ และค่าที่คืนกลับเมื่อยกเลิก
onSave (value: string) => void — บันทึกการเปลี่ยนแปลงแล้ว (บันทึก, Enter, ออกจาก group)
onCancel (value: string) => void — คืนค่าแล้ว (ยกเลิก, Escape, ออกไปโดยไม่มีการเปลี่ยนแปลงที่ถูกต้อง)
invalid boolean false ไม่ให้บันทึก ตั้ง aria-invalid ที่ช่อง
readOnly boolean false แสดงอย่างเดียว ไม่ให้แก้

EditInPlace.Group

สร้าง <div> focus ที่เข้ามาเริ่มการแก้ไข focus ที่ออกจากทั้งหมดจะบันทึกการเปลี่ยนแปลงที่ถูกต้องหรือคืนค่า รับ prop ของ <div> ได้ทุกตัว

Attribute เมื่อ
data-editing ระหว่างแก้ไข
data-invalid ตั้ง invalid
data-readonly ตั้ง readOnly

EditInPlace.Input

สร้าง <input type="text"> ที่มีค่า Enter บันทึก หรือหยุดแก้ไขเมื่อไม่มีอะไรให้บันทึก (focus ยังอยู่) Escape คืนค่า คลิกเริ่มการแก้ไข หรือเปิดข้อความเมื่ออ่านอย่างเดียว รับ prop ของ <input> ได้ทุกตัว ยกเว้น value defaultValue type และ readOnly ที่มาจาก Root id ของช่องเป็นของคุณถ้าให้มา ไม่อย่างนั้นคือ ${id}input ส่วน aria-describedby เป็นของคุณถ้าให้มา ไม่อย่างนั้นคือ InvalidText ที่แสดงอยู่

Attribute เมื่อ
data-editing ระหว่างแก้ไข
data-invalid ตั้ง invalid
data-readonly ตั้ง readOnly

EditInPlace.InvalidText

สร้าง <p> ที่มีข้อความ error ของคุณระหว่างที่ Root เป็น invalid และไม่สร้างอะไรในเวลาอื่น ระหว่างที่แสดงจะอธิบายช่อง id เป็นของคุณถ้าให้มา ไม่อย่างนั้นคือ ${id}error รับ prop ของ <p> ได้ทุกตัว

EditInPlace.Action

สร้าง <button type="button"> เฉพาะในโหมดของมัน mousedown ถูกยกเลิก การกดจึงไม่ดึง focus ออกจากช่อง รับ prop ของ <button> ได้ทุกตัว ยกเว้น type

Prop Type Default
action 'edit' | 'cancel' | 'save' — edit ตอนปกติ: focus ที่ช่อง cancel ระหว่างแก้ไขเมื่อค่าเปลี่ยนแล้ว: คืนค่า save ระหว่างแก้ไขเมื่อค่าเปลี่ยนและถูกต้อง: บันทึก
render (props) => ReactElement — สร้างปุ่มของคุณเองด้วย props เหล่านี้
Attribute เมื่อ
data-disabled ตั้ง disabled หรือ action ยังทำไม่ได้ (cancel ที่ยังไม่มีการเปลี่ยนแปลง, save ที่ยังไม่มีการเปลี่ยนแปลงที่ถูกต้อง)

EditInPlace.useEditInPlaceContext()

อ่านสถานะของ Root ที่ครอบอยู่จาก component ใดก็ได้ข้างใน: id (ช่องคือ ${id}input และข้อความ error คือ ${id}error ถ้าคุณไม่ได้ให้ id เอง) value editing mode ('rest' 'editing' หรือ 'readonly') canSave canCancel invalid readOnly noteOpen และ setNoteOpen และ action begin save cancel refocus ถ้าเรียกนอก Root จะ throw

คีย์บอร์ดและ accessibility

  • Tab เข้าช่องเริ่มการแก้ไข จากนั้น Tab ไปที่ยกเลิกและบันทึกเมื่อกดได้แล้ว การออกจาก group บันทึกการเปลี่ยนแปลงที่ถูกต้องหรือคืนค่า
  • Enter บันทึกการเปลี่ยนแปลงที่ถูกต้องและแก้ไขต่อ ถ้าไม่มีอะไรให้บันทึกจะหยุดแก้ไข โดย focus ยังอยู่ในช่อง Escape คืนค่าและแก้ไขต่อ
  • หลังบันทึก ยกเลิก หรือ Escape focus กลับไปที่ช่องพร้อมเคอร์เซอร์ที่ท้ายข้อความ
  • ช่องตั้ง aria-invalid เมื่อ invalid และ InvalidText อธิบายช่องระหว่างที่แสดง ส่วนที่คุณต้องเพิ่มเองคือชื่อของช่อง (aria-label หรือ <label> ของ id ช่อง) และชื่อของปุ่ม ซึ่งมักมีแค่ไอคอน
  • ช่องอ่านอย่างเดียวเป็น readonly: ยังรับ focus และถูกอ่านได้ ข้อความของคุณควรบอกว่าทำไมแก้ไม่ได้
