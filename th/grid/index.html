Grid

Grid คือ 2x Grid ของ Carbon: จอเล็กมี 4 คอลัมน์ ตั้งแต่ 672px (md) มี 8 และตั้งแต่ 1056px (lg) มี 16 คอลัมน์ ช่องไฟ (gutter) กว้าง 32px <ui-grid> ใส่ <ui-column> ไว้ข้างใน แต่ละคอลัมน์บอกว่ากินกี่คอลัมน์ในแต่ละขนาดจอ กล่องสีในหน้านี้มีไว้ให้เห็นตำแหน่งคอลัมน์เท่านั้น

subgrid ตัดสินครั้งเดียวตอนถูกใส่ลงหน้าว่าอยู่ในคอลัมน์หรือไม่ ถ้าย้าย <ui-grid> เข้าหรือออกจากคอลัมน์ทีหลัง จะไม่เปลี่ยนตาม

ผสมแบบช่องไฟ

subgrid เป็นแบบ narrow หรือ condensed ได้ ขณะที่ grid ด้านนอกเป็นแบบปกติ <ui-column-hang> ข้างในยังตรงกับข้อความแบบปกติรอบ ๆ

เปอร์เซ็นต์นับจากจำนวนคอลัมน์ของขนาดจอ (4, 8 หรือ 16) ไม่ใช่ของ subgrid ใน subgrid ที่แคบกว่า grid ให้ใส่เป็นตัวเลข เหมือนคอลัมน์ condensed ด้านล่าง

ใช้ element อื่นเป็น grid หรือคอลัมน์

Accessibility

  • grid แค่จัดวาง ไม่มี role และ screen reader อ่านคอลัมน์ตามลำดับใน markup ให้ลำดับนั้นมีความหมาย อย่าใช้ offset ย้ายเนื้อหาไปไว้หน้าสิ่งที่มาก่อนใน markup
  • คอลัมน์ที่ซ่อนด้วยจำนวน 0 เป็น display: none ในขนาดนั้น screen reader จึงไม่เห็นเช่นกัน
  • ใช้ หัวข้อ และ landmark บอกโครงสร้าง grid ไม่ได้เพิ่มให้

<ui-grid> · React UiGrid

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
narrow narrow boolean false No start gutter: text hangs on the gutter (Carbon narrow).
condensed condensed boolean false 1px gutters (Carbon condensed).
full-width fullWidth boolean false No max width.
align align 'start' | 'center' | 'end' | undefined Pin a max-width grid to a side (centred by default).
with-row-gap withRowGap boolean false Rows spaced like columns.
