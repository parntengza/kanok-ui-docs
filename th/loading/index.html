Loading, inline loading, progress bar หรือ skeleton?

  • Loading: ใช้ทั้งหน้าจอหรือพื้นที่หนึ่งไม่ได้จนกว่าข้อมูลจะมา
  • Inline loading: สถานะเล็ก ๆ ข้างสิ่งที่กำลังบันทึกหรือส่ง แล้วจบด้วย "เสร็จแล้ว" หรือ "ไม่สำเร็จ"
  • Progress bar: งานที่รู้ขนาด เช่น อัปโหลดไฟล์ไปแล้วกี่ไฟล์จากห้าไฟล์
  • Skeleton: การโหลดครั้งแรกของหน้า เมื่อรู้รูปร่างของเนื้อหาที่จะมา
  • ในปุ่ม ให้ใช้ loading ของปุ่มเอง ดู Button

คลุมพื้นที่เดียว

contained ห่อพื้นที่หนึ่ง เช่น การ์ดหรือตาราง แทนการคลุมทั้งหน้า ระหว่าง active overlay จะคลุมแค่กล่องนั้น และเนื้อหาข้างใต้เป็น inert และ aria-busy ส่วนอื่นของหน้ายังใช้ได้ Carbon ไม่มี loading แบบ contained ส่วนนี้เราเพิ่มเอง

คลุมทั้งหน้า

overlay คลุมหน้าด้วยสี overlay ระหว่างที่ spinner แสดง และยึดโฟกัสไว้: Tab และการคลิกที่อื่นจะกลับมาที่ spinner เมื่อหยุด โฟกัสกลับไปที่เดิม modal dialog ที่เปิดซ้อนอยู่ด้านบนไม่ถูกยุ่ง ใช้เฉพาะตอนที่ใช้ทั้งหน้าจอไม่ได้ และตั้ง active จาก state ของคุณเองเสมอ

overlay เป็น position: fixed ในตัวอย่างนี้วางไว้ในกล่องที่มี transform จึงคลุมแค่กล่อง ในแอปของคุณจะคลุมทั้งหน้าต่าง

Accessibility

  • spinner เป็นรูปภาพที่ใช้ description เป็นชื่อ อยู่ใน live region แบบ assertive ระหว่างแสดง screen reader จึงอ่านออกมา
  • เมื่อใช้ overlay spinner เป็น modal dialog ที่ใช้ description เป็นชื่อ และรับโฟกัสไว้ เมื่อหยุด โฟกัสกลับไปที่เดิม
  • เมื่อใช้ contained เนื้อหาเป็น inert และ aria-busy ระหว่างแสดง และ spinner เป็น group ที่ใช้ description เป็นชื่อ โฟกัสที่อยู่ข้างในจะรอที่ spinner แล้วกลับที่เดิม
  • เขียน description ว่ากำลังโหลดอะไร ("กำลังโหลดรายการสัญญา") ไม่ใช่แค่ "กำลังโหลด"
  • เมื่อผู้ใช้ตั้ง prefers-reduced-motion spinner จะหมุนช้าลง

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Loading

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-loading> · React UiLoading

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
active active boolean true On by default; active="false" stops it.
small small boolean false
overlay overlay boolean false Cover the page and trap focus while active.
description description string '' Accessible description; defaults to the translation ("Loading").
contained contained boolean false Cover just this element's content (the slot) instead of the page; the content is inert while active (no Carbon counterpart).
delay delay number 0 Milliseconds active must last before the spinner shows (default 0, as Carbon).
min-duration minDuration number 0 Once shown, the least milliseconds it stays (default 0).

Slot

Slot คำอธิบาย
(ค่าเริ่มต้น) The area contained covers

CSS part

Part คำอธิบาย
base The spinner wrapper (aria-live)
overlay The page overlay (overlay), or the area's (contained)
area The covered content (contained)
spinner The <svg>
