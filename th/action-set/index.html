Action set

Action set คือแถวปุ่มใหญ่ที่ท้าย side panel หรือ tearsheet (ActionSet ของ Carbon for IBM Products) ปุ่มสูง 64px ข้อความอยู่ด้านบน มีเส้นบาง ๆ คั่น และแบ่งความกว้างกันตามกฎที่ขึ้นกับจำนวนปุ่มและความกว้างของชุด ชุดที่แคบจะวางปุ่มซ้อนกัน โดยปุ่ม primary อยู่บนสุด

ยกเลิก ส่งกลับผู้ส่ง อนุมัติ

Side panel และ tearsheet จัดปุ่ม slot="actions" ของตัวเองตามกฎเดียวกันอยู่แล้ว จึงไม่ต้องใช้ <ui-action-set> ในนั้น ใช้มันกับ panel หรือท้ายหน้าที่คุณสร้างเอง

web component รับ <ui-button> เป็น children ส่วน React + Tailwind รับปุ่มเป็นข้อมูลใน actions แต่ละปุ่มคือ props ของ Button บวก label

Action set หรือ button set?

Component ใช้เมื่อ
Action set ท้าย side panel, tearsheet หรือ panel เต็มความกว้าง: ปุ่ม 64px ที่แบ่งความกว้างตามกฎของ Carbon และซ้อนกันเมื่อ panel แคบ
Button set ปุ่มท้ายฟอร์ม: ปุ่มสูงปกติวางเรียงกัน แต่ละปุ่มกว้างไม่เกิน 196px

ขนาดและการซ้อนปุ่ม

size คือขนาดของ panel ที่ชุดปุ่มอยู่: sm md (ค่าเริ่มต้น) lg xl หรือ 2xl (xs ของ side panel นับเป็น sm) ชุดขนาดเล็กซ้อนปุ่มเสมอ ชุดขนาดกลางซ้อนเมื่อมีตั้งแต่สามปุ่ม เมื่อวางเรียงกัน สองปุ่มได้คนละครึ่ง สามหรือสี่ปุ่มในชุดขนาดใหญ่ได้ปุ่มละหนึ่งในสี่ (ไม่เกิน 232px) และในชุด xl กับ 2xl ทุกปุ่มได้หนึ่งในสี่

ลำดับของปุ่ม

ลำดับของ Carbon เมื่อวางเรียงกันคือ ghost, tertiary, secondary, danger, primary ปุ่ม primary จึงอยู่ท้ายแถว เมื่อซ้อนกันจะกลับด้าน ปุ่ม primary อยู่บนสุด

  • web component และ wrapper ของ React: เขียนปุ่มตามลำดับนี้ element คงลำดับของคุณไว้ ตอนซ้อนแค่กลับด้านบนจอ
  • React + Tailwind: ActionSet เรียง actions ตามลำดับนี้ให้เอง
ยกเลิก ส่งให้ลงนาม
HTMLReactReact + Tailwind<ui-action-set size="sm" style="max-width: 320px"> <ui-button kind="secondary">ยกเลิก</ui-button> <ui-button>ส่งให้ลงนาม</ui-button> </ui-action-set> <UiActionSet size="sm" style={{ maxWidth: 320 }}> <UiButton kind="secondary">ยกเลิก</UiButton> <UiButton>ส่งให้ลงนาม</UiButton> </UiActionSet> // ลำดับไหนก็ได้: ActionSet วางปุ่ม primary ไว้บนสุดของชุดที่ซ้อน <ActionSet size="sm" className="max-w-80" actions={[{ label: 'ส่งให้ลงนาม' }, { label: 'ยกเลิก', kind: 'secondary' }]} />

Carbon ให้มีปุ่ม primary และปุ่ม ghost อย่างละไม่เกินหนึ่งปุ่มต่อชุด และในชุดที่ซ้อนกัน Carbon แนะนำไม่ให้มีปุ่ม ghost ปนกับปุ่มอื่น ชุดที่ผิดกฎเหล่านี้ หรือมีปุ่มมากกว่าที่ขนาดนั้นรับได้ จะเตือนใน console ของ browser เหมือน ActionSet ของ Carbon โดยเตือนครั้งเดียวจนกว่าปุ่มจะเปลี่ยน side panel และ tearsheet ก็ตรวจปุ่มของตัวเองเช่นกัน

ปุ่ม ghost กินที่ที่เหลือ

ปุ่ม ghost ในแถวกินความกว้างที่ปุ่มอื่นเหลือไว้: 75% ข้างปุ่มเดียว 50% ข้างสองปุ่ม 25% ข้างสามปุ่ม ข้อความเริ่มเข้าไป 16px ใช้กับปุ่มยกเลิกใน panel กว้าง

Accessibility

  • ปุ่มเป็นปุ่มจริงตามลำดับที่คุณเขียน Tab ไปตาม markup ทั้งแบบแถวและแบบซ้อน ในชุดที่ซ้อนกัน web component แสดงกลับด้าน ปุ่ม primary ที่อยู่บนสุดจึงเป็นปุ่มสุดท้ายที่ Tab ไปถึง เหมือน Carbon
  • ตั้งชื่อปุ่มให้บอกว่าจะเกิดอะไร ("อนุมัติ" ไม่ใช่ "ตกลง")
  • เส้นบาง ๆ ระหว่างปุ่มจะหายไปข้างปุ่มที่มี focus กรอบ focus จึงเห็นชัด

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-action-set> · React UiActionSet

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
size size ActionSetSize 'md' The set's size (a side panel's size; xs counts as sm): how the buttons share the row, or stack.
condensed condensed boolean false 48px buttons instead of 64px (Carbon condensedActions of a side panel).
disable-stacking disableStacking boolean false Keep the buttons in a row even where Carbon would stack them.

Property

Property ชนิด คำอธิบาย
stacked (อ่านอย่างเดียว) Whether the buttons stack, one per row.

Slot

Slot คำอธิบาย
(ค่าเริ่มต้น) The buttons

CSS part

Part คำอธิบาย
base The row of buttons

CSS custom property

Custom property ค่าเริ่มต้น คำอธิบาย
--ui-actions-gap / --ui-actions-padding - Gap between the action buttons and padding round them (default none: full-bleed buttons that touch; Kanok: 8px / 16px 20px)
--ui-actions-button-flex flex of each action button (default: Carbon's widths by count; Kanok: their own width)
--ui-actions-button-align / --ui-actions-button-padding-top - Where a button's label sits (default: at the top, 16px in)
--ui-actions-stacked-direction / --ui-actions-stacked-wrap / --ui-actions-stacked-width - Where Carbon stacks the actions (narrow): flex-direction, flex-wrap and each button's width (default column-reverse, nowrap, 100%; Kanok: one row that wraps)
