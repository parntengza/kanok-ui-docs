การพิมพ์กรองรายการอย่างไร

การพิมพ์จะเปิดรายการและไฮไลต์รายการแรกที่ชื่อมีข้อความนั้นอยู่ filter กำหนดว่ารายการอื่นจะยังอยู่หรือไม่

filter รายการระหว่างพิมพ์
none (ค่าเริ่มต้น เหมือน Carbon) ทุกรายการยังอยู่ มีแค่ไฮไลต์ที่ย้าย
contains เหลือเฉพาะรายการที่ชื่อมีข้อความนั้นอยู่ตรงไหนก็ได้
starts-with เหลือเฉพาะรายการที่ชื่อขึ้นต้นด้วยข้อความนั้น

การจับคู่ไม่สนตัวพิมพ์เล็กใหญ่ ถ้า filter กรองจนไม่เหลือรายการ จะแสดง "ไม่พบรายการที่ตรงกัน" ลองพิมพ์ "เชียง" ในทั้งสองช่องด้านล่างเพื่อเทียบกัน

คีย์บอร์ด

ปุ่ม ทำอะไร
พิมพ์ข้อความ เปิดรายการและไฮไลต์รายการแรกที่มีข้อความนั้น
↓ / ↑ เปิดรายการที่รายการที่เลือกไว้ (ถ้าไม่มีก็รายการแรก / สุดท้าย) จากนั้นเลื่อนไฮไลต์ (ไม่วนกลับ)
Alt+↓ เปิดรายการโดยไม่ไฮไลต์อะไร
Alt+↑ เลือกรายการที่ไฮไลต์แล้วปิด
Enter เลือกรายการที่ไฮไลต์ ถ้าไม่มีไฮไลต์ จะเลือกรายการแรกที่มีข้อความนั้น (หรือเก็บข้อความไว้เมื่อใช้ allow-custom-value)
Esc ปิดรายการ ถ้ารายการปิดอยู่แล้ว จะล้างค่าในช่อง
Tab ไปช่องถัดไปโดยไม่เลือกรายการที่ไฮไลต์ ข้อความจะถูกยืนยันหรือเด้งกลับตามที่อธิบายไว้ข้างบน

Accessibility

  • ทำตาม pattern combobox แบบ list autocomplete ของ WAI-ARIA ช่องพิมพ์มี role="combobox" รายการเป็น listbox และไฮไลต์ถูกอ่านผ่าน aria-activedescendant
  • ปุ่ม × และลูกศรไม่อยู่ในลำดับ Tab (เหมือน Carbon) กด Tab จึงไปช่องถัดไปทันที และใช้ Esc ล้างค่าจากคีย์บอร์ดได้
  • "กำลังค้นหา…" และ "ไม่พบรายการที่ตรงกัน" ถูกประกาศให้ screen reader ได้ยิน

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Combobox
