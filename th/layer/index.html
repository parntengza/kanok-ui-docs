Layer

<ui-layer> คือ Layer ของ Carbon: ทุกอย่างข้างในใช้ชุดสีของ layer ถัดไปในธีม ช่องกรอกบน tile สีเทาจึงไม่เป็นสีเทาเดียวกับ tile ช่องกรอก เมนู เส้นขอบ เส้นคั่น และสีตอน hover ล้วนเปลี่ยนตาม คู่มือ ธีมและ layer อธิบายเรื่อง layer ไว้แล้ว หน้านี้แสดงตัว element

ระดับ

level เป็น 0 1 หรือ 2 ระดับ 0 คือชุดสีของหน้าเว็บเอง เหมือนอยู่นอก layer ส่วน 1 และ 2 ลึกลงไป ถ้าไม่ใส่ level web component และ wrapper ของ React เริ่มที่ 0 และ layer ที่ซ้อนอยู่ลึกลงหนึ่งระดับ เหมือน cds-layer ของ Carbon ส่วน Layer ของ React + Tailwind ทำตาม Carbon React คือเริ่มที่ 1

ซ้อนลึกกว่าระดับ 2 ก็ยังเป็น 2

ช่องกรอกบน tile

tile ทาสีตาม layer ปัจจุบัน แต่ไม่ได้เปลี่ยน layer ของสิ่งที่อยู่ข้างใน ให้ใส่ช่องกรอกไว้ใน layer ที่สูงขึ้นหนึ่งระดับ เพื่อให้เห็นแยกจาก tile

มีหรือไม่มีพื้นหลัง

layer เปล่า ๆ แค่เปลี่ยน token ของสิ่งที่อยู่ข้างใน ไม่ได้ทาสีอะไร with-background (withBackground) ทาสี layer ด้วย layer background ของ Carbon คือพื้นที่เนื้อหาวางอยู่ ไม่ต้องใส่ถ้ากล่องของคุณเอง (tile, panel) ทาพื้นไว้แล้ว

เมนู ตาราง และ component อื่น

ทุกอย่างที่อ่าน token ของ layer จะเปลี่ยนตาม layer: รายการของ dropdown แถวของตาราง เส้นคั่นของ structured list และสีตอน hover ของปุ่ม ghost

ในโซนสีมืด

อ่านระดับ

property level ของ element บอกระดับ ทั้งที่คิดเองและที่กำหนดไว้ ใน React + Tailwind useLayerLevel() คืนระดับของ Layer ที่ใกล้ที่สุด (-1 ถ้าไม่อยู่ใน layer ใด) สำหรับ component ของคุณเองที่ทาสีตาม layer

ระดับ:

HTMLReactReact + Tailwind<ui-layer id="layer-outer" with-background style="padding: 16px"> <ui-layer id="layer-inner" with-background style="padding: 16px">layer ที่ซ้อนอยู่</ui-layer> </ui-layer> <p>ระดับ: <output id="layer-out"></output></p> <script type="module"> const outer = document.getElementById('layer-outer'); const inner = document.getElementById('layer-inner'); document.getElementById('layer-out').value = `ด้านนอก ${outer.level}, ด้านใน ${inner.level}`; </script> import type { UiLayer as LayerElement } from '@purpurabog/ui'; const inner = useRef<LayerElement>(null); const [level, setLevel] = useState<number>(); useEffect(() => setLevel(inner.current?.level), []); <UiLayer withBackground style={{ padding: 16 }}> <UiLayer ref={inner} withBackground style={{ padding: 16 }}>layer ที่ซ้อนอยู่</UiLayer> </UiLayer> <p>ระดับด้านใน: <output>{level}</output></p> import { Layer, useLayerLevel } from '@/components/ui/react-tw/layer'; function LevelBadge() { const level = useLayerLevel(); return <span className="type-caption text-ink-muted">ระดับ {level}</span>; } <Layer withBackground className="p-4"> <LevelBadge /> <Layer withBackground className="mt-4 p-4"><LevelBadge /></Layer> </Layer>

web component คิดระดับของตัวเองตอนถูกใส่ลงหน้า รวมถึงข้าม shadow root ถ้าจะย้าย layer ไปที่อื่นทีหลัง ให้กำหนด level เอง

Accessibility

  • layer เป็นแค่สี ไม่มี role และไม่เพิ่มอะไรให้ screen reader
  • layer ทำให้ช่องกรอกเห็นชัดจากพื้นด้านล่าง ช่วยให้ทุกคนเห็นว่าต้องพิมพ์ตรงไหน อย่าใช้สีของ layer อย่างเดียวแยกพื้นที่ ให้มีหัวข้อและ label ด้วย

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-layer> · React UiLayer

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
level level 0, 1 or 2. Computed from the nearest ancestor layer when not set.
with-background withBackground boolean false Paint the layer with Carbon's layer-background (withBackground): the colour its content sits on (white theme, level 1: #f4f4f4 under #ffffff fields).

Method

Method คำอธิบาย
syncLevel() An automatic level follows the layer around it (also called by a layer whose level changed); a set one stays.
