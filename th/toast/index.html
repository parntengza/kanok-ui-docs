Toast

Toast คือข้อความสั้น ๆ ที่โผล่ขึ้นที่มุมจอหลังมีอะไรเกิดขึ้นที่อื่นในหน้า เช่น บันทึกสัญญาแล้ว หรืออัปโหลดเบื้องหลังไม่สำเร็จ toast จะซ้อนกัน ตัวใหม่สุดอยู่ใกล้มุมที่สุด และตัวที่ไม่สำคัญจะหายไปเอง Carbon ไม่มีตัวจัดการ toast ส่วน ui-toaster และ toast() เป็นของไลบรารีนี้ ถ้าข้อความควรอยู่ในหน้า ให้ใช้ Notification แบบ inline

toast(options) สร้าง <ui-notification variant="toast"> แล้วเพิ่มเข้า <ui-toaster> ของหน้า ครั้งแรกจะสร้าง toaster ไว้ท้าย <body> ให้ และคืนค่า { element, close } ตัวเลือกมี kind, title, subtitle, caption, timeout, actionLabel, onAction, lowContrast และ id

ตัวอย่างที่ใช้งานได้ในหน้านี้ import module ไม่ได้ จึงทำสิ่งที่ toast() ทำด้วยมือ คือสร้าง element แล้วส่งให้ add() ของ toaster ในแอปของคุณให้เรียก toast() React + Tailwind มี toast() ของตัวเอง และมี <Toaster> ที่ต้อง mount ครั้งเดียว toast() ของมันคืนค่า { close } และ toast.clear() ลบ toast ทั้งหมด

toaster เป็น live region แบบสุภาพหนึ่งอัน ชื่อ "การแจ้งเตือน" ซึ่งอยู่ในหน้าก่อนจะมี toast ใด ๆ screen reader จึงอ่านทุกตัว มันอยู่ใน top layer ห่างมุมบนด้านท้าย 16px หรือห่าง 16px ใต้ ui-header

ชนิดและเวลาที่อยู่

kind เริ่มต้นเป็น info toast แบบ info และ success ปิดเองหลัง 5 วินาที แบบ error และ warning อยู่จนกว่าจะปิด เพราะต้องอ่าน timeout ตั้งเวลาอื่นเป็นมิลลิวินาที หรือ 0 เพื่อให้อยู่ตลอด การนับเวลาหยุดชั่วคราวระหว่างที่เมาส์ชี้อยู่หรือโฟกัสอยู่ใน toast

  • toast แต่ละตัวถูกอ่านผ่าน region ของ toaster ตัว toast เองไม่มี live role ส่วน toast ที่มีปุ่มคำสั่งยังเป็น alertdialog และดึงโฟกัส
  • toast ที่ปิดแล้วจะถูกลบออกจากหน้า
  • เขียน toast ให้สั้น และอย่าใส่สิ่งที่ผู้ใช้หาได้จาก toast เท่านั้น เพราะเมื่อหายไปแล้วก็หายไปเลย

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Toast

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-toaster> · React UiToaster

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
placement placement ToasterPlacement 'top-end' Corner: newest toast nearest the edge.
max max number 3 Most toasts shown at once; a new one closes the oldest.

Method

Method คำอธิบาย
add(toast) Adds toast, closes the oldest beyond max, and lifts the region above anything opened since.

Slot

Slot คำอธิบาย
(ค่าเริ่มต้น) <ui-notification variant="toast"> elements (added by toast())

CSS custom property

Custom property ค่าเริ่มต้น คำอธิบาย
--ui-toaster-offset Distance from the top (or bottom) edge (default 16px; 64px under a ui-header)
