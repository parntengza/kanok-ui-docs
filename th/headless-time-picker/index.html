Headless Time picker

TimePicker ให้พฤติกรรมของ time picker โดยไม่มี class เลย: ช่องข้อความสั้นสำหรับ hh:mm ที่ร่วมการตรวจค่าของฟอร์มผ่าน pattern และ select แบบ native ข้าง ๆ สำหรับ AM / PM หรือ time zone Root ส่ง disabled, readOnly และ invalid ให้ทุกชิ้นส่วน select ที่อ่านอย่างเดียวยังรับโฟกัสได้ แต่ไม่เปิดและไม่เปลี่ยนค่า

label, ข้อความ error, layout และ style ทั้งหมดเป็นของคุณ การตรวจค่าก็เป็นของคุณเหมือน Carbon React: ใส่ invalid เมื่อการตรวจของคุณไม่ผ่าน ตัวที่มี style อยู่ที่ Time picker

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { TimePicker } from '@purpurabog/ui/headless';

วิธีใช้

import { useState } from 'react'; import { TimePicker } from '@purpurabog/ui/headless'; const label = 'text-xs text-ink-muted'; const input = 'h-10 w-24 border-b border-border-strong-1 bg-field-1 px-4 text-sm text-ink placeholder:text-ink-placeholder focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error data-disabled:cursor-not-allowed data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; const select = 'h-10 border-b border-border-strong-1 bg-field-1 px-2 text-sm text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; const button = 'h-10 w-fit bg-primary px-4 text-sm text-on-primary hover:bg-blue-hover focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus'; export default function Example() { const [sent, setSent] = useState<Record<string, FormDataEntryValue>>(); return ( <form className="grid gap-4" onSubmit={(e) => { e.preventDefault(); setSent(Object.fromEntries(new FormData(e.currentTarget))); }} > <TimePicker.Root> <div className="grid gap-2"> <label htmlFor="time" className={label}>เวลาเริ่ม</label> <div className="flex gap-0.5"> <TimePicker.Input id="time" name="time" placeholder="hh:mm" className={input} /> <TimePicker.Select aria-label="AM หรือ PM" name="period" className={select}> <option value="AM">AM</option> <option value="PM">PM</option> </TimePicker.Select> <TimePicker.Select aria-label="เขตเวลา" name="zone" className={select}> <option value="ict">กรุงเทพฯ (ICT)</option> <option value="utc">UTC</option> </TimePicker.Select> </div> </div> </TimePicker.Root> <button type="submit" className={button}>ส่ง</button> {sent && <p className="text-xs text-ink-muted">ส่งแล้ว: {JSON.stringify(sent)}</p>} </form> ); }

แต่ละชิ้นส่วนส่งค่าไปกับฟอร์มเองภายใต้ name ของมัน: เวลาตามที่พิมพ์ และค่า <option> ของแต่ละ select ไม่มีการแปลงค่าใด ๆ

โครงสร้าง

<TimePicker.Root> <label /> <TimePicker.Input /> <TimePicker.Select /> </TimePicker.Root>

Select ใช้นอก Root ได้ด้วย

12 ชั่วโมงหรือ 24 ชั่วโมง

Input รับเวลาแบบ 12 ชั่วโมงเป็นค่าเริ่มต้น: h:mm หรือ hh:mm ยาวไม่เกิน 5 ตัวอักษร (TimePicker.TWELVE_HOUR_PATTERN) ถ้าต้องการ 24 ชั่วโมง ให้ใส่ pattern ของคุณเองและไม่ต้องมี select AM / PM:

import { useState } from 'react'; import { TimePicker } from '@purpurabog/ui/headless'; const label = 'text-xs text-ink-muted'; const input = 'h-10 w-24 border-b border-border-strong-1 bg-field-1 px-4 text-sm text-ink placeholder:text-ink-placeholder focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error data-disabled:cursor-not-allowed data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; const button = 'h-10 w-fit bg-primary px-4 text-sm text-on-primary hover:bg-blue-hover focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus'; export default function Example() { const [sent, setSent] = useState<Record<string, FormDataEntryValue>>(); // ลองส่ง 7:5 หรือ 25:00 เบราว์เซอร์จะหยุดฟอร์มไว้ที่ pattern return ( <form className="grid gap-4" onSubmit={(e) => { e.preventDefault(); setSent(Object.fromEntries(new FormData(e.currentTarget))); }} > <TimePicker.Root> <div className="grid gap-2"> <label htmlFor="departure" className={label}>เวลาออกเดินทาง</label> <TimePicker.Input id="departure" name="departure" placeholder="hh:mm" pattern="([01]?[0-9]|2[0-3]):[0-5][0-9]" className={input} /> </div> </TimePicker.Root> <button type="submit" className={button}>ส่ง</button> {sent && <p className="text-xs text-ink-muted">ส่งแล้ว: {JSON.stringify(sent)}</p>} </form> ); }

maxLength เปลี่ยนความยาวสูงสุด

error

pattern ร่วมการตรวจค่าของฟอร์ม แต่ไม่มีข้อความขึ้นเอง ใส่ invalid ที่ Root เมื่อการตรวจของคุณไม่ผ่าน ช่องจะได้ aria-invalid และ data-invalid ข้อความเป็น markup ของคุณ ผูกกับช่องด้วย aria-describedby

import { useState } from 'react'; import { TimePicker } from '@purpurabog/ui/headless'; const label = 'text-xs text-ink-muted'; const input = 'h-10 w-24 border-b border-border-strong-1 bg-field-1 px-4 text-sm text-ink placeholder:text-ink-placeholder focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error data-disabled:cursor-not-allowed data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; // การตรวจของคุณเอง: ร้านปิด 12:00 น. function afterClosing(time: string) { const [hours, minutes] = time.split(':').map(Number); return hours * 60 + minutes > 12 * 60; } export default function Example() { const [pickup, setPickup] = useState('13:30'); const late = afterClosing(pickup); return ( <TimePicker.Root invalid={late}> <div className="grid gap-2"> <label htmlFor="pickup" className={label}>เวลารับของ</label> <TimePicker.Input id="pickup" value={pickup} onChange={(e) => setPickup(e.target.value)} pattern="([01]?[0-9]|2[0-3]):[0-5][0-9]" aria-describedby="pickup-error" className={input} /> <p id="pickup-error" className="text-xs text-error-text">{late ? 'ร้านปิด 12:00 น.' : ''}</p> </div> </TimePicker.Root> ); }

ไม่มีสถานะคำเตือน คำเตือนก็เป็น markup ของคุณเช่นกัน

อ่านอย่างเดียวและปิดใช้งาน

import { TimePicker } from '@purpurabog/ui/headless'; const input = 'h-10 w-24 border-b border-border-strong-1 bg-field-1 px-4 text-sm text-ink placeholder:text-ink-placeholder focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error data-disabled:cursor-not-allowed data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; const select = 'h-10 border-b border-border-strong-1 bg-field-1 px-2 text-sm text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; export default function Example() { return ( <div className="grid gap-6"> <TimePicker.Root readOnly> <div className="grid gap-2"> <label htmlFor="start" className="text-xs text-ink-muted">เวลาเริ่ม</label> <div className="flex gap-0.5"> <TimePicker.Input id="start" defaultValue="9:30" className={input} /> <TimePicker.Select aria-label="AM หรือ PM" className={select}> <option value="AM">AM</option> <option value="PM">PM</option> </TimePicker.Select> </div> </div> </TimePicker.Root> <TimePicker.Root disabled> <div className="grid gap-2"> <label htmlFor="end" className="text-xs text-ink-disabled">เวลาสิ้นสุด</label> <div className="flex gap-0.5"> <TimePicker.Input id="end" defaultValue="5:00" className={input} /> <TimePicker.Select aria-label="AM หรือ PM" defaultValue="PM" className={select}> <option value="AM">AM</option> <option value="PM">PM</option> </TimePicker.Select> </div> </div> </TimePicker.Root> </div> ); }

readOnly เก็บทุกค่าและส่งไปกับฟอร์ม: ช่องเวลาแก้ไม่ได้ ส่วน select รับโฟกัสได้แต่ไม่เปิดและไม่เปลี่ยนค่า (aria-readonly) disabled ปิดทั้งช่องเวลาและ select ทุกตัว

ใส่ style

import { useState } from 'react'; import { TimePicker } from '@purpurabog/ui/headless'; export default function Example() { const [invalid, setInvalid] = useState(true); const [disabled, setDisabled] = useState(false); return ( <div className="grid gap-4"> <TimePicker.Root invalid={invalid} disabled={disabled}> <div className="flex gap-0.5"> <TimePicker.Input aria-label="เวลา" defaultValue="13:30" className="h-10 w-24 bg-field-1 px-4 text-sm text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error data-disabled:text-ink-disabled" /> <TimePicker.Select aria-label="AM หรือ PM" className="h-10 bg-field-1 px-2 text-sm text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:text-ink-disabled data-readonly:bg-transparent"> <option value="AM">AM</option> <option value="PM">PM</option> </TimePicker.Select> </div> </TimePicker.Root> <div className="flex gap-4 text-sm text-ink"> <label className="flex items-center gap-2"> <input type="checkbox" checked={invalid} onChange={(e) => setInvalid(e.target.checked)} /> invalid </label> <label className="flex items-center gap-2"> <input type="checkbox" checked={disabled} onChange={(e) => setDisabled(e.target.checked)} /> disabled </label> </div> </div> ); } .time-input[data-invalid] { outline: 2px solid #da1e28; } .time-input[data-disabled], .time-select[data-disabled] { color: #c6c6c6; } .time-select[data-readonly] { background: transparent; }

ชิ้นส่วน

TimePicker.Root

ไม่ render element ใด ๆ แค่เก็บ disabled, readOnly และ invalid ให้ชิ้นส่วนข้างใน

Prop Type ค่าเริ่มต้น
disabled boolean false ปิดช่องเวลาและ select ทุกตัว
readOnly boolean false เก็บทุกค่าไว้
invalid boolean false ตั้ง aria-invalid และ data-invalid ที่ช่องเวลา

TimePicker.Input

render <input type="text" autocomplete="off"> ค่า disabled และ readOnly มาจาก Root

Prop Type ค่าเริ่มต้น
pattern string TWELVE_HOUR_PATTERN 12 ชั่วโมง h:mm / hh:mm ตามด้วยช่องว่างได้หนึ่งตัว
maxLength number 5
Attribute เมื่อ
data-invalid invalid ที่ Root
data-disabled disabled ที่ Root
data-readonly readOnly ที่ Root

TimePicker.Select

render <select> แบบ native ถูกปิดตาม Root หรือตาม disabled ของตัวเอง

Attribute เมื่อ
data-disabled ถูกปิดใช้งาน
data-readonly readOnly ที่ Root

TimePicker.useTimePickerContext() ใน Root ให้ค่า disabled, readOnly และ invalid

คีย์บอร์ดและ accessibility

ปุ่ม ผล
Enter (ในช่องเวลา) ส่งฟอร์มที่ช่องอยู่ เหมือน input แบบ native
↑ / ↓, Space, Enter (ที่ select) ปุ่มของ select ตามเบราว์เซอร์ ไม่มีผลขณะอ่านอย่างเดียว

สิ่งที่ชิ้นส่วนจัดการให้:

  • ใช้ element แบบ native ทั้งหมด: text input และ <select>
  • aria-invalid ที่ช่องเวลาขณะ invalid และ aria-readonly ที่ select ที่อ่านอย่างเดียว
  • select ที่อ่านอย่างเดียวรับโฟกัสเมื่อคลิกโดยไม่เปิดรายการ

สิ่งที่คุณต้องใส่เอง:

  • <label htmlFor> ของช่องเวลา และ aria-label ของ select แต่ละตัว (ไม่มีชื่อตั้งต้นให้)
  • ข้อความ error ผูกกับช่องด้วย aria-describedby
