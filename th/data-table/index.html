Data table

Data table แสดงข้อมูลเป็นแถวและคอลัมน์ (Carbon DataTable) web component ทำตาม Carbon web components (cds-table): คุณเขียนตารางเป็น element — <ui-table-head> ที่มีหัวคอลัมน์ และ <ui-table-body> ที่มีแถวของเซลล์ — แล้วตารางจะเรียงลำดับ ค้นหา เลือก ขยาย และแบ่งหน้าแถวที่อยู่ในตัวมัน นอกจากที่ Carbon มี ยังซ่อนและตรึงคอลัมน์ ส่งออก CSV แก้ไขเซลล์ในตาราง และปรับความกว้างคอลัมน์ได้ ส่วน DataTable ของ React + Tailwind ขับเคลื่อนด้วยข้อมูล: คุณส่ง headers และ rows ให้

is-sortable บนตารางให้หัวคอลัมน์ทุกตัวมีปุ่มเรียง ส่วน is-sortable บนหัวคอลัมน์บางตัวทำให้เรียงได้เฉพาะตัวนั้น (attribute ของตารางตั้งให้หัวคอลัมน์ทุกตัว) การกดแต่ละครั้งเลื่อน sort-direction ของหัวคอลัมน์ไปตาม sort-cycle (ค่าเริ่มต้น none → ascending → descending → none) หัวคอลัมน์อื่นกลับเป็น none แล้วตารางย้ายแถวตามลำดับนั้น ตัวเลขเรียงตามค่า ข้อความเรียงตาม locale (ค่าเริ่มต้นคือ lang ของหน้า) และ none คืนลำดับเดิมของแถว หัวคอลัมน์ที่มี sort-direction ใน markup จะเรียงแถวตอนโหลด หัวคอลัมน์ยิง ui-table-header-cell-sort ที่ยกเลิกได้พร้อม { oldSortDirection, sortDirection } ก่อนย้ายแถว และตารางยิง ui-table-sorted พร้อม { sortedHeader } หลังย้าย

Accessibility


    

  • ตารางมี role ของตาราง (table, rowgroup, row, columnheader, cell และเป็น grid เมื่อมีคอลัมน์ที่แก้ไขได้) คอลัมน์ที่เรียงอยู่มี aria-sort ตั้งชื่อตารางด้วย aria-label บน <ui-table>: เหมือน Carbon ชื่อตารางที่แสดงไม่ได้ผูกกับตาราง checkbox, radio และลูกศรของแต่ละแถวตั้งชื่อด้วยเซลล์แรกของแถว ("เลือกแถว, สัญญาบริการ")
    • 

  • ตารางที่เลื่อนได้ (sticky-header หรือกว้างกว่ากล่อง) รับ focus ได้เพื่อให้ผู้ใช้คีย์บอร์ดเลื่อนได้ และมีชื่อตาม aria-label หรือชื่อตาราง
    • 

  • ขณะ loading ตารางเป็น aria-busy และมีสถานะบอกว่า "กำลังโหลดข้อมูล" จำนวนในแถบ batch เป็น status จำนวนใหม่จึงถูกอ่านเมื่อเลือกแถว DataTable ของ React + Tailwind ยังบอก "เรียงตามคอลัมน์ สัญญา จากน้อยไปมาก" หลังกดเรียง และ "แสดง 3 จาก 12 แถว" เมื่อหยุดพิมพ์ค้นหา
