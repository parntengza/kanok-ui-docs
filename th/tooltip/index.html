Tooltip

Tooltip คือข้อความสั้น ๆ บรรทัดเดียวที่อธิบาย control ที่มันครอบอยู่ เปิดเมื่อวางเมาส์ไว้บน control หรือเมื่อโฟกัสจากคีย์บอร์ดมาถึง และปิดเมื่อออกไป ใช้บอกชื่อไอคอนหรือให้คำแนะนำสั้น ๆ ห้ามใช้กับเนื้อหาที่ผู้ใช้ต้องอ่านหรือต้องกดเพื่อทำงานต่อ

Tooltip, toggletip, definition tooltip หรือ popover?

Component ใช้เมื่อ
Tooltip คำแนะนำสั้น ๆ เป็นข้อความล้วน หรือชื่อของไอคอน เปิดเมื่อชี้เมาส์และเมื่อโฟกัส และไม่มีอะไรให้กด
Toggletip คำอธิบายมีลิงก์หรือปุ่ม หรือควรเปิดค้างจนผู้ใช้ปิดเอง เปิดด้วยการคลิก
Definition tooltip คำในเนื้อความต้องมีคำนิยาม คำนั้นจะมีเส้นใต้แบบจุด
Popover เนื้อหาของคุณเอง (ตัวกรอง ฟอร์มเล็ก ๆ) ข้าง trigger

ตำแหน่ง

กล่องข้อความเปิดเหนือ trigger (placement="top") ใช้ bottom, left และ right เพื่อย้ายตำแหน่ง ถ้าที่ไม่พอก็จะพลิกไปอีกฝั่ง align คือชื่อแบบ Carbon ของ attribute เดียวกัน

ชิดขอบต้นและขอบปลาย

Trigger อะไรก็ได้ที่รับโฟกัส

Trigger เป็น element ใดก็ได้ที่รับโฟกัสได้ เช่น ปุ่มของเรา <button> ธรรมดา หรือลิงก์ ให้ครอบแค่ตัวเดียว ข้อความจะต่อท้ายคำอธิบายเดิมของ trigger (aria-describedby) โดยไม่แทนที่ <span> ธรรมดาหรือไอคอนไม่ได้รับโฟกัสจากคีย์บอร์ด ผู้ใช้คีย์บอร์ดจึงไม่มีทางเห็น tooltip ของมัน ให้ครอบปุ่มแทน

เปิดค้างไว้: "คัดลอกแล้ว"

open ทำให้กล่องแสดง เมื่อใช้คู่กับ pinned กล่องจะเปิดค้างไม่ว่าเมาส์ โฟกัส การคลิก หรือ Esc จะเป็นอย่างไร จนกว่าคุณจะเอา open ออก ใช้กับข้อความยืนยันสั้น ๆ แบบเดียวกับปุ่มคัดลอกของ Carbon ลองคลิกเลขที่สัญญาด้านล่าง

คีย์บอร์ด

ปุ่ม ผลลัพธ์
Tab โฟกัสมาถึง trigger แล้ว tooltip เปิด โฟกัสออกไปแล้วปิด
Esc ปิดเฉพาะ tooltip โฟกัสยังอยู่ที่ trigger และ modal ที่ครอบอยู่ยังเปิดอยู่
Enter, Space สั่งงาน trigger แล้วปิด tooltip เพื่อไม่ให้บังผลลัพธ์

การคลิกเมาส์ทำให้ trigger ได้โฟกัสโดยไม่เปิด tooltip ซ้ำ เพราะตอนชี้เมาส์ก็แสดงไปแล้ว

Accessibility

  • กล่องมี role="tooltip" ข้อความเป็นคำอธิบาย (accessible description) ของ trigger หรือถ้ามี as-label จะเป็นชื่อ (accessible name) screen reader อ่านได้โดยไม่ต้องให้กล่องแสดง
  • ทำตาม WCAG 1.4.13 เลื่อนเมาส์ไปบนกล่องได้โดยกล่องไม่ปิด และกด Esc เพื่อปิดได้
  • ห้ามใส่ลิงก์ ปุ่ม หรืออะไรก็ตามที่ต้องกดไว้ใน tooltip เพราะไม่มีใครกดถึง ให้ใช้ toggletip หรือ popover
  • ข้อความต้องไม่ใช่ที่เดียวที่มีข้อมูลที่ผู้ใช้ต้องรู้เพื่อทำงานให้เสร็จ จอสัมผัสไม่มีการชี้เมาส์

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Tooltip

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
align Carbon's name for placement (same values)
text text string ''
placement placement TooltipPlacement 'top'
as-label asLabel boolean false Use the text as the trigger's accessible name instead of its description.
small small boolean false The icon tooltip's look (as as-label: 8px off, 2px / 16px padding, 8×4 caret) without naming the trigger.
open open boolean false Whether the bubble is showing. Hover / focus manage it; set it yourself together with pinned.
pinned pinned boolean false Keep the bubble open regardless of hover, focus, clicks and Escape — for a confirmation such as "Copied!" (Carbon copy button). While pinned, only open closes it.

Property ชนิด คำอธิบาย
