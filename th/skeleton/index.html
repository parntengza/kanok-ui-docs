Skeleton

Skeleton คือแถบสีเทาในรูปร่างของเนื้อหาที่จะมา แสดงระหว่างที่หน้าโหลดข้อมูลครั้งแรก <ui-skeleton> วาดบรรทัดข้อความ หัวข้อ ช่องกรอก ปุ่ม หรือบล็อก component ส่วนใหญ่ก็มี skeleton element ของตัวเองด้วย ดูรายการทั้งหมดที่ท้ายหน้า

Skeleton หรือ loading?

ใช้ skeleton ตอนหน้าโหลดครั้งแรก เมื่อรู้ layout ของสิ่งที่จะมา: หน้าปรากฏทันทีแล้วเนื้อหาค่อยเติมเข้ามา ใช้ Loading หรือ Inline loading เมื่อผู้ใช้รอผลของการกระทำ เช่น การบันทึก ซึ่ง skeleton จะไปบังสิ่งที่เขากำลังทำอยู่

Skeleton ของช่องกรอกแบบ fluid

skeleton ของช่องกรอกรับ fluid สำหรับ skeleton ของช่องกรอกแบบ fluid: กล่องสูง 64px ที่มีแถบสองเส้น ใน <ui-fluid-form> (FluidForm ใน React + Tailwind) จะเป็น fluid โดยไม่ต้องใส่ attribute skeleton ของ time picker เป็น fluid เสมอ เพราะ Carbon มีแค่แบบนั้น

HTMLReactReact + Tailwind<div aria-busy="true" style="display: grid; grid-template-columns: repeat(auto-fill, minmax(240px, 1fr)); gap: 32px 24px"> <ui-text-input-skeleton fluid></ui-text-input-skeleton> <ui-select-skeleton fluid></ui-select-skeleton> <ui-date-picker-skeleton fluid></ui-date-picker-skeleton> <ui-time-picker-skeleton></ui-time-picker-skeleton> </div> import { UiTextInputSkeleton, UiSelectSkeleton, UiDatePickerSkeleton, UiTimePickerSkeleton } from '@purpurabog/ui/react'; <UiTextInputSkeleton fluid /> <UiSelectSkeleton fluid /> <UiDatePickerSkeleton fluid /> <UiTimePickerSkeleton /> <TextInputSkeleton fluid /> <SelectSkeleton fluid /> <DatePickerSkeleton fluid /> <TimePickerSkeleton />

Skeleton ของทุก component

หน้าของแต่ละ component แสดง skeleton พร้อมตัวเลือกของมัน skeleton ของช่องกรอก (text input, number input, dropdown, select, date picker) รับ size (sm, md, lg), hide-label และ fluid ด้วย

ui-table-skeleton มากับ @purpurabog/ui/table ทุก element ในตารางนี้มี wrapper ของ React ชื่อตาม element เช่น ui-accordion-skeleton คือ UiAccordionSkeleton และ ui-table-skeleton คือ UiTableSkeleton prop ของมันคือ attribute ที่เขียนแบบ camelCase (hideLabel, noTrailingSlash) ใน React + Tailwind ให้ import …Skeleton จากไฟล์ของ component นั้น เช่น TextInputSkeleton จาก @/components/ui/react-tw/text-input ส่วน RadioSkeleton มาจาก radio-group

Accessibility

  • skeleton ทุกตัวถูกซ่อนจาก screen reader (aria-hidden) และไม่รับโฟกัส
  • บอก "กำลังโหลด" ที่ container: aria-busy="true" และข้อความสถานะสั้น ๆ เช่น role="status" "กำลังโหลดสัญญา…" แล้วเอาทั้งสองออกเมื่อเนื้อหามาถึง
  • แถบมีแสงวิ่ง 3 วินาทีแบบ Carbon เมื่อผู้ใช้ตั้ง prefers-reduced-motion จะหยุดวิ่ง

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)
