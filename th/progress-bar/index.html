Progress bar

Progress bar แสดงว่างานหนึ่งไปถึงไหนแล้ว เช่น การอัปโหลดหรือการนำเข้าข้อมูล รางจะเต็มตาม value / max ถ้าไม่มี value จะมีแถบวิ่งผ่านระหว่างที่ยังไม่รู้ความยาว label บอกชื่อ และข้อความช่วยด้านล่างบอกรายละเอียด

Progress bar, progress indicator หรือ loading?

  • Progress bar: ระบบกำลังทำงานหนึ่งงาน และบอกได้ว่าไปถึงไหนแล้ว
  • Progress indicator: ผู้ใช้กรอกฟอร์มทีละขั้น
  • Loading หรือ Inline loading: มีอะไรกำลังทำงานอยู่ แต่บอกไม่ได้ว่าไปถึงไหน

ค่าและค่าสูงสุด

value คือความคืบหน้า และ max คือทั้งหมด (ค่าเริ่มต้น 100) ใช้หน่วยของงานเมื่อมีความหมาย เช่น จำนวนไฟล์ ค่าที่ต่ำกว่า 0 หรือเกิน max จะถูกจำกัดไว้ที่ปลาย

ซ่อน label

hide-label (hideLabel ใน React) ซ่อน label จากตาเมื่อข้อความรอบ ๆ บอกอยู่แล้วว่าอะไรกำลังคืบหน้า label ยังเป็นชื่อของ bar สำหรับ screen reader จึงต้องเขียนไว้เสมอ

Accessibility

  • รางเป็น progressbar ที่ใช้ label เป็นชื่อ และใช้ข้อความช่วยเป็นคำอธิบาย มี aria-valuemin, aria-valuemax และ aria-valuenow เมื่อมีค่า และไม่มีระหว่างที่ไม่รู้ความยาว
  • เป็น aria-busy จนกว่าจะเสร็จ
  • เมื่อผิดพลาด screen reader ได้ยิน "เกิดข้อผิดพลาด" ต่อจาก label แปลตามภาษาของหน้า
  • เขียน label เสมอ แม้ใช้ hide-label
  • เมื่อผู้ใช้ตั้ง prefers-reduced-motion แถบที่วิ่งจะช้าลง

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-progress-bar> · React UiProgressBar

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
label label string '' Required. What is progressing; shown above (or beside) the track and read as the bar's name.
hide-label hideLabel boolean false Visually hides the label (it still names the bar).
helper-text helperText string ''
value value number | undefined Current progress; leave unset for an indeterminate bar.
max max number 100
size size ProgressBarSize 'md'
status status ProgressBarStatus 'active'
type type ProgressBarType 'default'

CSS part

Part คำอธิบาย
base The wrapper
label Label row (text + status icon)
track The progressbar element
bar The filled portion
helper-text Helper text below the track

CSS custom property

Custom property ค่าเริ่มต้น คำอธิบาย
--ui-progress-track The track's fill (default --ui-surface-1; Kanok: a hairline grey); --ui-progress-radius its corners (default square; Kanok: round)
