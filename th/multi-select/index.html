คีย์บอร์ด

ปุ่ม ตอนรายการปิด ตอนรายการเปิด
↓, Enter, Space เปิดรายการ Enter และ Space ติ๊กหรือเอาติ๊กออกจากแถวที่ไฮไลต์ รายการยังเปิดอยู่
↓ / ↑, Page Down / Page Up, Home / End ↑ ไม่ทำอะไร ส่วน Home / End เปิดที่แถวแรก / สุดท้าย เลื่อนไฮไลต์
ตัวอักษร เปิดที่รายการถัดไปที่ขึ้นต้นด้วยตัวอักษรนั้น กระโดดไปรายการถัดไปที่ขึ้นต้นด้วยตัวอักษรนั้น
Delete, Backspace, Esc ล้างทุกค่าที่เลือก Esc ปิดรายการ
Tab ไปช่องถัดไป ปิดรายการแล้วไปช่องถัดไป

เมื่อใช้ filterable ช่องจะเป็นช่องพิมพ์ ตัวอักษร Space, Home, End, Delete และ Backspace ใช้แก้ข้อความ ↓ หรือ Enter เปิดรายการ Enter ติ๊กแถวที่ไฮไลต์ และ Esc ตอนรายการปิดจะล้างทั้งค่าที่เลือกและข้อความ

Accessibility

  • รายการเป็น listbox ที่มี aria-multiselectable และไฮไลต์ถูกอ่านผ่าน aria-activedescendant โฟกัสจึงอยู่ที่ช่องตลอด
  • ปุ่ม × ไม่อยู่ในลำดับ Tab (เหมือน Carbon) ใช้ Delete, Backspace หรือ Esc ล้างค่าจากคีย์บอร์ด
  • "กำลังโหลด…", "กำลังค้นหา…" และ "ไม่พบรายการที่ตรงกัน" ถูกประกาศให้ screen reader ได้ยิน

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Multi-select
