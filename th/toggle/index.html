Toggle หรือ checkbox?

ใช้ toggle เมื่อการเปลี่ยนมีผลทันที เช่น การตั้งค่า ถ้าเป็นฟอร์มที่ผู้ใช้กดส่งทีหลัง หรือการยอมรับเงื่อนไข ให้ใช้ Checkbox

เปิดและปิด

checked คือสถานะ event change ยิงหลังผู้ใช้สลับ โดย checked อัปเดตแล้ว

แจ้งเตือนทางอีเมล: ปิด

'เปิด' : 'ปิด'; // saveSetting('alerts', alerts.checked); }); </script> import type { UiToggle as ToggleElement } from '@purpurabog/ui'; <UiToggle label="แจ้งเตือนทางอีเมล" checked={on} onChange={(e) => setOn((e.target as ToggleElement).checked)} /> <p>แจ้งเตือนทางอีเมล: <output>{on ? saveSetting แทนโค้ดของคุณเอง

Label

  • label คือข้อความเหนือสวิตช์ (slot label รับ markup ได้)
  • label-a และ label-b คือข้อความสถานะข้างสวิตช์ตอนปิดและตอนเปิด ค่าเริ่มต้นคือ "ปิด" / "เปิด" แปลตามภาษาของหน้า
  • hide-label เอา label ด้านบนออก แล้ว label จะไปแทนข้อความสถานะข้างสวิตช์ เหมือน Carbon

ใช้ในฟอร์ม

Accessibility

  • สวิตช์เป็น <button role="switch"> ที่มี aria-checked ใช้ label ด้านบนเป็นชื่อ (หรือ label ข้างสวิตช์เมื่อใช้ hide-label) screen reader ได้ยิน "เปิด" หรือ "ปิด" จาก role อยู่แล้ว ข้อความสถานะข้างสวิตช์จึงถูกซ่อนจาก screen reader
  • คลิกที่รางหรือข้อความสถานะก็สลับสวิตช์ได้ เหมือน Carbon และโฟกัสยังอยู่ที่สวิตช์
  • เขียน label เป็นชื่อการตั้งค่า ("แจ้งเตือนทางอีเมล") ไม่ใช่คำสั่ง ("เปิดการแจ้งเตือนทางอีเมล")

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Toggle

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-toggle> · React UiToggle

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
label label string '' Label above the switch; the label slot replaces it when markup is needed.
hide-label hideLabel boolean false Hide the label above; it then replaces the On / Off text beside the switch (Carbon hideLabel).
label-a labelA string '' Side text while off (Carbon labelA).
label-b labelB string '' Side text while on (Carbon labelB).
checked checked boolean false
value value string 'on' Submitted under name while checked.
name name string '' Reflected: form-associated elements submit under the name attribute.
size size ToggleSize 'md' md: 48×24 track (default) · sm: 32×16 with a check mark in the knob.
disabled disabled boolean false Disables the control; a disabled <fieldset> ancestor does the same.
readonly readonly boolean false Shows and submits the state but blocks toggling.

Property

Property ชนิด คำอธิบาย
