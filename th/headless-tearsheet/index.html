Headless Tearsheet

part ของ Tearsheet ให้พฤติกรรมเดียวกับ Tearsheet แบบมี style แต่ไม่มี style เลย ได้แก่ <dialog> ของ browser ที่เปิดด้วย showModal() (top layer หน้าเว็บข้างหลังเป็น inert) ซึ่ง sheet เลื่อนขึ้นมาจากด้านล่างตอนเปิดและเลื่อนลงก่อนถูกถอดออก Tab ที่วนอยู่ใน sheet Esc ปุ่มปิด และการคลิกนอก sheet ที่ขอปิด โฟกัสแรกและโฟกัสกลับ หน้าเว็บที่เลื่อนไม่ได้ และการซ้อน tearsheet แบบ Carbon

ส่วนที่คุณทำเองคือ markup ส่วนหัว ปุ่มคำสั่ง และ style ทั้งหมด Root เป็นแบบ controlled: มันบอกเหตุผลที่ขอปิด และจะปิดเมื่อคุณตั้ง open เป็น false เท่านั้น

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Tearsheet } from '@purpurabog/ui/headless';

Tearsheet ซ้อนกัน

tearsheet ที่เปิดทับอีกตัวจะซ้อนบนตัวนั้น ระหว่างที่เปิดมากกว่าหนึ่งตัว data-stack ที่ Dialog และ Sheet บอกตำแหน่งของแต่ละตัว: 1-of-2, 2-of-2, 1-of-3 … ซ้อนได้ถึงสามชั้น ให้ย่อตัวที่อยู่ข้างใต้ และหรี่หน้าเว็บน้อยลง แบบที่ Carbon ทำ

ใส่ style

sheet เลื่อนขึ้นด้วย Web Animations API (240ms) และเลื่อนลงตอนปิด backdrop จางไปพร้อมกัน จึงไม่ต้องทำ animation ใน CSS ใช้ data-stack กำหนด style ตอนซ้อนกัน

Parts

Tearsheet.Root

ไม่ render element ของตัวเอง render แค่ children ระหว่างที่ tearsheet เปิดอยู่และระหว่างที่เลื่อนลง

Prop Type ค่าเริ่มต้น
open boolean แสดง tearsheet (ต้องใส่)
onRequestClose (reason: Tearsheet.TearsheetCloseReason) => void Esc, Close หรือการคลิกนอก sheet ขอปิด: 'escape', 'close-button', 'outside'
closeOnOutsideClick boolean true กดและปล่อยนอก Sheet แล้วขอปิด
selectorInitialFocus string element ที่รับโฟกัสตอนเปิด (selector ใน dialog) ถ้าไม่ตั้งจะเป็น Close แล้วจึงเป็นช่องแรกของ sheet

Tearsheet.useTearsheetContext() คืนสถานะของ Root (open, closing, stackPlace, requestClose …) ให้ component ที่อยู่ข้างใน

Tearsheet.Dialog

<dialog> ที่เปิดด้วย showModal() ให้ใส่ style ให้เต็มจอ และใส่สีหรี่ที่ ::backdrop รับ prop ของ dialog ได้ทุกตัว ยกเว้น open และ onClose aria-labelledby ของมันคือ id ของ Title ถ้าคุณไม่ได้ใส่เอง ระหว่างที่ tearsheet เปิดอยู่ หน้าเว็บ (<html>) จะเลื่อนไม่ได้

Attribute เมื่อ
data-open open เป็น true
data-closing กำลังเลื่อนลง
data-stack 1-of-2, 2-of-2, 1-of-3, 2-of-3 หรือ 3-of-3 ระหว่างที่เปิดมากกว่าหนึ่งตัว

Tearsheet.Sheet

<div> คือ sheet ที่มองเห็น มันเลื่อนขึ้นลง Tab วนอยู่ข้างใน และการคลิกนอกมันจะขอปิด

Attribute เมื่อ
data-open open เป็น true
data-closing กำลังเลื่อนลง
data-stack เหมือนที่ Dialog

Tearsheet.Title

<h2> ที่มี id (ของคุณ หรือ <id>-title) ใช้เป็นชื่อของ dialog

Tearsheet.Close

<button type="button"> ที่ขอปิด ('close-button') รับโฟกัสแรก ยกเว้น selectorInitialFocus กำหนดเป็นอย่างอื่น ต้องใส่ aria-label

คีย์บอร์ดและ accessibility

ปุ่ม ทำอะไร
Tab / Shift+Tab เลื่อนไปมาระหว่างช่องและปุ่มใน sheet และวนอยู่ข้างใน
Esc เรียก onRequestClose('escape') tearsheet จะเปิดอยู่จนกว่าคุณตั้ง open เป็น false

dialog แบบ modal ของ browser ทำให้ส่วนอื่นของหน้าเป็น inert part ต่าง ๆ ตั้งชื่อจาก Title กัก Tab ไว้ใน sheet และย้ายโฟกัสเข้าตอนเปิดและกลับตอนปิด

ส่วนที่คุณเพิ่มเอง

  • Title หรือ aria-label ที่ Dialog
  • aria-label ที่ Close
  • ปุ่มคำสั่ง ปุ่มในส่วนหัว แท็บ และบานข้าง ซึ่งเป็น markup ธรรมดาใน Sheet
