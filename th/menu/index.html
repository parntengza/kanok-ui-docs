ใช้ trigger แบบไหน?

Trigger ใช้เมื่อ
Menu button (ui-menu-button) ปุ่มที่มีชื่อรวมคำสั่งประเภทเดียวกันไว้หลายคำสั่ง ("คำสั่ง", "ส่งออก")
Overflow menu (ui-overflow-menu) พื้นที่จำกัด คำสั่งรองของแถวในตาราง การ์ด หรือ toolbar ซ่อนไว้หลัง "⋮"
Combo button (ui-combo-button) มีคำสั่งหลักที่ใช้บ่อย และคำสั่งอื่นเป็นแบบที่ใกล้เคียงกัน ("บันทึก" แล้วตามด้วย "บันทึกร่าง")
Menu (ui-menu) ไม่มีแบบไหนข้างบนที่เหมาะ และคุณมี trigger ของตัวเอง

Overflow menu

<ui-overflow-menu> คือปุ่มไอคอนแบบ ghost ที่มี "⋮" และเปิด menu (OverflowMenu ของ Carbon) label เป็นชื่อปุ่มและแสดงใน tooltip ถ้าไม่ตั้งจะเป็น "ตัวเลือก" ในแถวของตาราง ให้ใช้ placement="bottom-end" เพื่อให้ menu อยู่ในขอบตาราง ui-select บอกว่าเลือกรายการไหน detail มี value (ถ้าไม่มีก็เป็นชื่อรายการ), label และ checked

Combo button

<ui-combo-button> คือปุ่ม primary สำหรับคำสั่งที่ใช้บ่อย ติดกับปุ่มลูกศรที่เปิดคำสั่งอื่น (ComboButton ของ Carbon) ปุ่มหลักยิง ui-click ส่วนรายการยิง ui-select ปุ่มลูกศรชื่อ "การกระทำเพิ่มเติม" ถ้าไม่ตั้ง trigger-label เมื่อ placement="bottom" (ค่าเริ่มต้น) menu จะกว้างเท่าทั้งชุดปุ่ม

  • shortcut แสดงคีย์ลัดท้ายแถว เป็นแค่ข้อความ คุณต้องผูกปุ่มลัดเอง
  • disabled ยังแสดงรายการ แต่การกดลูกศรจะข้ามไป และคลิกแล้วไม่มีอะไรเกิดขึ้น

  • <ui-menu-divider> วาดเส้นคั่นระหว่างกลุ่มรายการ

Accessibility

  • ทำตาม pattern menu button ของ WAI-ARIA trigger มี aria-haspopup และ aria-expanded รายการมี role="menu" ชื่อมาจากชื่อของ trigger รายการย่อยเป็น menuitem, menuitemcheckbox หรือ menuitemradio พร้อม aria-checked
  • โฟกัสย้ายเข้า menu เมื่อเปิด และกลับไปที่ trigger เมื่อ menu ปิดด้วยปุ่มบนคีย์บอร์ดหรือการเลือกรายการ
  • ปุ่มของ overflow menu ใช้ label เป็นชื่อและแสดงใน tooltip ตั้งให้ไม่ซ้ำกันในหน้า
  • menu ใช้สำหรับคำสั่ง ถ้าจะเลือกค่าให้ช่องในฟอร์ม ให้ใช้ Dropdown หรือ Select
