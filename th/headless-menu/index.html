Headless Menu

part ของ Menu ให้พฤติกรรมเดียวกับ Menu แบบมี style แต่ไม่มี style เลย ตาม pattern menu button ของ WAI-ARIA ได้แก่ trigger ที่เปิด popup role="menu" ใน top layer ย้ายโฟกัสไปที่รายการแรก (หรือสุดท้าย) ↑ / ↓ ที่วนรอบและข้ามรายการที่ปิดใช้งาน Home / End พิมพ์ตัวอักษรเพื่อกระโดด และ Esc, Tab, การกดข้างนอก หรือการเลือกรายการที่ปิด menu แล้วคืนโฟกัส รายการเป็นคำสั่ง checkbox หรือ radio ได้ และเปิด submenu ได้

ส่วนที่คุณทำเองคือหน้าตาของ trigger ทุกแถว เครื่องหมายถูกและลูกศร และ style ทั้งหมด part ต่าง ๆ บอกสถานะผ่าน attribute data-* รายการที่ไฮไลต์คือรายการที่ได้โฟกัส จึงใส่ style ด้วย focus:

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Menu } from '@purpurabog/ui/headless';

วิธีใช้

import { useState } from 'react'; import { Menu } from '@purpurabog/ui/headless'; const item = 'flex h-8 cursor-pointer items-center px-4 text-sm text-ink-muted outline-none hover:bg-ghost-hover hover:text-ink focus:bg-ghost-hover focus:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:bg-transparent data-disabled:text-ink-disabled'; export default function Example() { const [picked, setPicked] = useState('ยังไม่ได้เลือก'); return ( <div className="grid justify-items-start gap-2"> <Menu.Root> <Menu.Trigger className="group flex h-10 min-w-48 items-center justify-between gap-2 bg-interactive px-4 text-sm text-on-primary hover:bg-blue-hover focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> คำสั่ง <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current transition-transform group-data-popup-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Menu.Trigger> <Menu.Popup className="min-w-48 bg-layer-1 py-1 shadow-lg"> <Menu.Item className={item} onClick={() => setPicked('ส่งให้ลงนาม')}>ส่งให้ลงนาม</Menu.Item> <Menu.Item className={item} onClick={() => setPicked('บันทึกร่าง')}>บันทึกร่าง</Menu.Item> <Menu.Item className={item} disabled>ส่งออก PDF</Menu.Item> <Menu.Separator className="my-1 h-px border-0 bg-hairline" /> <Menu.Item className={`${item} hover:bg-button-danger hover:text-on-primary focus:bg-button-danger focus:text-on-primary`} onClick={() => setPicked('ทิ้ง')}> ทิ้ง </Menu.Item> </Menu.Popup> </Menu.Root> <p className="text-xs text-ink-muted">เลือก: {picked}</p> </div> ); }

popup ได้ชื่อจาก trigger (aria-labelledby) ถ้าคุณไม่ให้ aria-label onClick ของรายการทำงานเมื่อคลิกและเมื่อกด Enter หรือ Space จากนั้น menu ทุกชั้นจะปิด

ตำแหน่งและความกว้าง

popup เปิดใต้ trigger ชิดขอบต้น (placement="bottom-start" ที่ Popup) ใช้ตำแหน่งไหนก็ได้ และจะพลิกเมื่อที่ไม่พอ data-side บอกว่าไปอยู่ฝั่งไหน matchWidth ทำให้กว้างเท่า trigger เหมือน menu button ของ Carbon ที่ใช้ bottom

import { Menu } from '@purpurabog/ui/headless'; const item = 'flex h-10 cursor-pointer items-center px-4 text-sm text-ink-muted outline-none hover:bg-ghost-hover hover:text-ink focus:bg-ghost-hover focus:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; const trigger = 'h-10 border border-interactive px-4 text-sm text-interactive hover:bg-interactive hover:text-on-primary focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus data-popup-open:bg-interactive data-popup-open:text-on-primary'; export default function Example() { return ( <div className="flex flex-wrap items-center gap-4"> <Menu.Root> <Menu.Trigger className={`${trigger} min-w-48 text-start`}>กว้างเท่าปุ่ม</Menu.Trigger> <Menu.Popup matchWidth className="bg-layer-1 py-1 shadow-lg"> <Menu.Item className={item}>ส่งออก PDF</Menu.Item> <Menu.Item className={item}>ส่งออก Word (.docx)</Menu.Item> </Menu.Popup> </Menu.Root> <Menu.Root> <Menu.Trigger className={trigger}>ชิดขอบปลาย ด้านบน</Menu.Trigger> <Menu.Popup placement="top-end" className="bg-layer-1 py-1 shadow-lg data-[side=top]:shadow-[0_-2px_6px_rgb(0_0_0/0.3)]"> <Menu.Item className={item}>ส่งออก PDF</Menu.Item> <Menu.Item className={item}>ส่งออก Word (.docx) พร้อมความเห็น</Menu.Item> </Menu.Popup> </Menu.Root> </div> ); }

Checkbox และกลุ่ม radio

  • CheckboxItem คือรายการเปิด/ปิด (menuitemcheckbox) ใช้ checked กับ onCheckedChange หรือ defaultChecked
  • RadioGroup เก็บ RadioItem (menuitemradio) ที่ถูกเลือกได้หนึ่งตัวเสมอ ใช้ value กับ onValueChange หรือ defaultValue
  • ทั้งสองแบบได้ aria-checked และ data-checked ไว้วาดเครื่องหมายถูก Menu.useMenuItemContext() ให้ค่า checked กับ component ที่อยู่ในรายการ
  • Group ที่มี GroupLabel ตั้งชื่อให้ชุดรายการ RadioGroup ก็เป็น Group เช่นกัน
  • ทุกรายการปิด menu เมื่อถูกเลือก closeOnClick={false} ทำให้ menu เปิดค้าง เหมาะกับ checkbox
import { useState } from 'react'; import { Menu } from '@purpurabog/ui/headless'; const item = 'group flex h-8 cursor-pointer items-center gap-2 px-4 text-sm text-ink-muted outline-none hover:bg-ghost-hover hover:text-ink focus:bg-ghost-hover focus:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; function Check() { return ( <svg viewBox="0 0 16 16" aria-hidden="true" className="invisible size-4 fill-current group-data-checked:visible"> <path d="M6 12.4 2.3 8.7l.7-.7 3 3 6.3-6.3.7.7z" /> </svg> ); } export default function Example() { const [archived, setArchived] = useState(true); const [drafts, setDrafts] = useState(false); const [sort, setSort] = useState('date'); return ( <div className="grid justify-items-start gap-2"> <Menu.Root> <Menu.Trigger className="h-10 px-4 text-sm text-link hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus">ตัวเลือกการแสดงผล</Menu.Trigger> <Menu.Popup className="min-w-56 bg-layer-1 py-1 shadow-lg"> <Menu.CheckboxItem className={item} checked={archived} onCheckedChange={setArchived} closeOnClick={false}> <Check /> แสดงที่เก็บถาวร </Menu.CheckboxItem> <Menu.CheckboxItem className={item} checked={drafts} onCheckedChange={setDrafts} closeOnClick={false}> <Check /> แสดงฉบับร่าง </Menu.CheckboxItem> <Menu.Separator className="my-1 h-px border-0 bg-hairline" /> <Menu.RadioGroup value={sort} onValueChange={setSort}> <Menu.GroupLabel className="px-4 pt-2 pb-1 text-xs font-semibold text-ink-muted">เรียงตาม</Menu.GroupLabel> <Menu.RadioItem value="name" className={item}><Check />ชื่อ</Menu.RadioItem> <Menu.RadioItem value="date" className={item}><Check />วันที่แก้ไข</Menu.RadioItem> <Menu.RadioItem value="expiry" className={item}><Check />วันหมดอายุ</Menu.RadioItem> </Menu.RadioGroup> </Menu.Popup> </Menu.Root> <p className="text-xs text-ink-muted"> ที่เก็บถาวร: {String(archived)} ฉบับร่าง: {String(drafts)} เรียงตาม: {sort} </p> </div> ); }

Submenu

SubmenuRoot ใน popup เก็บ SubmenuTrigger ซึ่งเป็นรายการที่เปิด Popup ของ submenu (วางไว้ข้างในมัน) ข้าง ๆ ตัวเอง เมื่อชี้เมาส์ค้าง delay (150ms โฟกัสไม่ย้าย) คลิก กด Enter, Space หรือ → (← ในหน้าขวาไปซ้าย) ← หรือ Esc ปิดเฉพาะชั้นนั้น การเลือกรายการใน submenu ปิดทุกชั้น

import { useState } from 'react'; import { Menu } from '@purpurabog/ui/headless'; const item = 'flex h-8 cursor-pointer items-center justify-between gap-4 px-4 text-sm text-ink-muted outline-none hover:bg-ghost-hover hover:text-ink focus:bg-ghost-hover focus:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-popup-open:bg-ghost-hover data-popup-open:text-ink'; const popup = 'min-w-40 bg-layer-1 py-1 shadow-lg'; function Chevron() { return ( <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current rtl:-scale-x-100"> <path d="M11 8 6 13l-.7-.7L9.6 8 5.3 3.7 6 3z" /> </svg> ); } export default function Example() { const [picked, setPicked] = useState('ยังไม่ได้เลือก'); const pick = (label: string) => () => setPicked(label); return ( <div className="grid justify-items-start gap-2"> <Menu.Root> <Menu.Trigger className="h-10 px-4 text-sm text-link hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus">คำสั่งของเอกสาร</Menu.Trigger> <Menu.Popup className={popup}> <Menu.Item className={item} onClick={pick('เปิด')}>เปิด</Menu.Item> <Menu.SubmenuRoot> <Menu.SubmenuTrigger className={item} label="ส่งออกเป็น"> ส่งออกเป็น <Chevron /> <Menu.Popup className={popup}> <Menu.Item className={item} onClick={pick('PDF')}>PDF</Menu.Item> <Menu.Item className={item} onClick={pick('Word (.docx)')}>Word (.docx)</Menu.Item> <Menu.SubmenuRoot> <Menu.SubmenuTrigger className={item} label="รูปภาพ"> รูปภาพ <Chevron /> <Menu.Popup className={popup}> <Menu.Item className={item} onClick={pick('PNG')}>PNG</Menu.Item> <Menu.Item className={item} onClick={pick('JPEG')}>JPEG</Menu.Item> </Menu.Popup> </Menu.SubmenuTrigger> </Menu.SubmenuRoot> </Menu.Popup> </Menu.SubmenuTrigger> </Menu.SubmenuRoot> </Menu.Popup> </Menu.Root> <p className="text-xs text-ink-muted">เลือก: {picked}</p> </div> ); }

label ของรายการคือข้อความที่ใช้จับคู่ตอนพิมพ์ (เก็บเป็น data-label) ให้ใส่เมื่อรายการมีอย่างอื่นนอกจากชื่อ เช่น ลูกศรหรือคีย์ลัด

Combo button

trigger เป็นปุ่มแบบไหนก็ได้ render ส่ง prop ของ trigger และสถานะเปิดมาให้ใส่ใน element ของคุณเอง anchor ที่ Popup วาง menu ข้าง element อื่น ในที่นี้คือปุ่มทั้งคู่ และ matchWidth ทำให้กว้างเท่ากัน

import { useRef, useState } from 'react'; import { Menu } from '@purpurabog/ui/headless'; const item = 'flex h-10 cursor-pointer items-center px-4 text-sm text-ink-muted outline-none hover:bg-ghost-hover hover:text-ink focus:bg-ghost-hover focus:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; export default function Example() { const pair = useRef<HTMLDivElement>(null); const [last, setLast] = useState('ยังไม่มี'); return ( <div className="grid justify-items-start gap-2"> <div ref={pair} className="inline-flex gap-px"> <button type="button" onClick={() => setLast('บันทึก')} className="h-10 min-w-28 bg-interactive px-4 text-start text-sm text-on-primary hover:bg-blue-hover focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> บันทึก </button> <Menu.Root> <Menu.Trigger aria-label="การกระทำเพิ่มเติม" render={(props, { open }) => ( <button {...props} className="grid size-10 place-items-center bg-interactive text-on-primary hover:bg-blue-hover focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-focus"> <svg viewBox="0 0 16 16" aria-hidden="true" className={`size-4 fill-current transition-transform ${open ? 'rotate-180' : ''}`}> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </button> )} /> <Menu.Popup anchor={pair} matchWidth className="bg-layer-1 py-1 shadow-lg"> <Menu.Item className={item} onClick={() => setLast('บันทึกร่าง')}>บันทึกร่าง</Menu.Item> <Menu.Item className={item} onClick={() => setLast('บันทึกแล้วส่ง')}>บันทึกแล้วส่ง</Menu.Item> </Menu.Popup> </Menu.Root> </div> <p className="text-xs text-ink-muted">คำสั่งล่าสุด: {last}</p> </div> ); }

สถานะเปิด

ควบคุมสถานะเองด้วย open และ onOpenChange หรือให้ defaultOpen onOpenChange รายงานเฉพาะเมื่อค่าเปลี่ยน พร้อมเหตุผล คือ trigger-press, trigger-hover (submenu), item-press, escape-key, list-navigation (กด ← ออกจาก submenu), focus-out หรือ outside-press initialFocus ที่ Root บังคับว่ารายการไหนได้โฟกัสตอนเปิด (first, last หรือ none) ถ้าไม่ตั้ง กด ↑ ที่ trigger จะเริ่มที่รายการสุดท้าย ส่วนแบบอื่นเริ่มที่รายการแรก

import { useState } from 'react'; import { Menu } from '@purpurabog/ui/headless'; const item = 'flex h-10 cursor-pointer items-center px-4 text-sm text-ink-muted outline-none hover:bg-ghost-hover hover:text-ink focus:bg-ghost-hover focus:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; export default function Example() { const [open, setOpen] = useState(false); const [why, setWhy] = useState('ยังไม่มี'); return ( <div className="grid justify-items-start gap-2"> <Menu.Root open={open} onOpenChange={(next, reason) => { setOpen(next); setWhy(reason); }} > <Menu.Trigger aria-label="ตัวเลือกของ สัญญาเช่า สำนักงานสีลม" className="grid size-10 place-items-center text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-popup-open:bg-layer-1 data-popup-open:shadow-lg"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current"> <circle cx="8" cy="4" r="1.5" /> <circle cx="8" cy="8" r="1.5" /> <circle cx="8" cy="12" r="1.5" /> </svg> </Menu.Trigger> <Menu.Popup className="min-w-40 bg-layer-1 py-1 shadow-lg"> <Menu.Item className={item}>แก้ไข</Menu.Item> <Menu.Item className={item}>ทำสำเนา</Menu.Item> <Menu.Item className={item}>ลบ</Menu.Item> </Menu.Popup> </Menu.Root> <p className="text-xs text-ink-muted">เปิดอยู่: {String(open)} เหตุผลล่าสุด: {why}</p> </div> ); }

Parts

Menu.Root

ไม่ render element ของตัวเอง เก็บสถานะเปิด

Prop Type ค่าเริ่มต้น
open boolean เปิดอยู่ (ควบคุมเอง)
defaultOpen boolean false เปิดตั้งแต่แรก (ไม่ควบคุมเอง)
onOpenChange (open: boolean, reason: OpenChangeReason) => void หลังเปิดหรือปิด (เฉพาะเมื่อเปลี่ยน) พร้อมเหตุผล
initialFocus 'first' | 'last' | 'none' รายการที่ได้โฟกัสตอนเปิด ถ้าไม่ตั้ง trigger เป็นคนตัดสิน (↑ รายการสุดท้าย นอกนั้นรายการแรก)
id string สร้างให้ ฐานของ id คือ <id>-trigger, <id>-menu

Menu.useMenuContext() คืนสถานะของ Root หรือ SubmenuRoot ที่ใกล้ที่สุด (open, popupId, setOpen …) เช่น ไว้หมุนลูกศร Menu.ownItems(popup) คืนรายการของ popup นั้นเอง (ไม่รวมของ submenu)

Menu.Trigger

<button type="button"> ที่มี aria-haspopup="menu" (ค่าของคุณมาก่อน), aria-expanded และ aria-controls และ id <id>-trigger ซึ่งใช้ตั้งชื่อ popup คลิกแล้วสลับเปิดปิด ↓ เปิดที่รายการแรก ↑ เปิดที่รายการสุดท้าย

Prop Type ค่าเริ่มต้น
render (props, { open }) => ReactElement render element ของคุณเองด้วย prop ของ trigger แทน <button>
Attribute เมื่อ
data-popup-open menu เปิดอยู่

Menu.Popup

<div role="menu" tabindex="-1" popover="manual"> ใน top layer มี id <id>-menu ได้ชื่อจาก trigger ถ้าคุณไม่ให้ aria-label หรือ aria-labelledby รายการข้างในถูก render เสมอ (ซ่อนตอนปิด) ถ้าอยู่ใน SubmenuTrigger มันคือ submenu ของรายการนั้น วางข้างรายการทางขอบปลาย

Prop Type ค่าเริ่มต้น
anchor RefObject<Element | null> trigger element ที่ menu วางข้าง
placement Placement 'bottom-start' ตำแหน่งที่เปิดข้าง anchor (ไม่ใช้กับ submenu)
matchWidth boolean false กว้างเท่า anchor (ไม่ใช้กับ submenu)
Attribute เมื่อ
data-open เปิดอยู่
data-side top, bottom, left หรือ right คือฝั่งที่ไปอยู่

Menu.Item, CheckboxItem, RadioItem

<div tabindex="-1"> ที่มี role="menuitem", "menuitemcheckbox" หรือ "menuitemradio" คลิก กด Enter หรือ Space เพื่อสั่งงาน CheckboxItem จะสลับค่า RadioItem จะกลายเป็นค่าของกลุ่ม จากนั้น onClick ทำงานและ menu ปิด รายการที่ปิดใช้งานยังแสดงและถูกอ่าน (aria-disabled) แต่การกดลูกศรจะข้ามไป และสั่งงานแล้วไม่มีอะไรเกิดขึ้น

Prop Type ค่าเริ่มต้น
onClick (event) => void เมื่อคลิกและเมื่อกด Enter / Space ก่อน menu ปิด (ไม่ทำงานเมื่อปิดใช้งาน)
label string ข้อความของรายการ ข้อความที่ใช้จับคู่ตอนพิมพ์ เก็บเป็น data-label
disabled boolean false การกดลูกศรจะข้ามไป สั่งงานไม่ได้
closeOnClick boolean true สั่งงานแล้วปิดทุกชั้น
checked boolean CheckboxItem: เปิดอยู่ (ควบคุมเอง)
defaultChecked boolean false CheckboxItem: เปิดตั้งแต่แรก
onCheckedChange (checked: boolean) => void CheckboxItem: หลังสลับค่า
value string RadioItem: ค่าที่มันแทนในกลุ่ม (ต้องใส่)
Attribute เมื่อ
data-disabled ปิดใช้งาน
data-checked CheckboxItem หรือ RadioItem ที่ถูกเลือก

Menu.useMenuItemContext() คืน { checked } ของรายการที่ครอบอยู่

Menu.RadioGroup

Group ของ RadioItem ที่ถูกเลือกได้หนึ่งตัวเสมอ

Prop Type ค่าเริ่มต้น
value string ค่าของรายการที่ถูกเลือก (ควบคุมเอง)
defaultValue string '' ค่าเริ่มต้น (ไม่ควบคุมเอง)
onValueChange (value: string) => void หลังเลือกรายการอื่น

Menu.Group, GroupLabel

Group คือ <div role="group"> ที่ได้ชื่อจาก GroupLabel (เป็น <div>) ถ้าคุณไม่ให้ aria-labelledby ไม่มี prop หรือ data attribute เพิ่ม

Menu.Separator

<hr> คั่นระหว่างรายการ

Menu.SubmenuRoot, SubmenuTrigger

SubmenuRoot เก็บสถานะของ submenu และรับ prop เดียวกับ Root SubmenuTrigger คือ <div role="menuitem" aria-haspopup="menu"> ที่มี aria-expanded Popup ของ submenu วางไว้ข้างในมัน

Prop Type ค่าเริ่มต้น
label string ข้อความของรายการ ข้อความที่ใช้จับคู่ตอนพิมพ์ เก็บเป็น data-label
disabled boolean false submenu ไม่เปิด
delay number 150 เวลาชี้เมาส์ค้างก่อน submenu เปิดหรือปิด หน่วย ms
Attribute เมื่อ
data-popup-open submenu เปิดอยู่
data-disabled ปิดใช้งาน

คีย์บอร์ดและ accessibility

ปุ่ม ที่ trigger ใน menu
Enter, Space เปิดที่รายการแรก สั่งงานรายการที่โฟกัสอยู่ (หรือเปิด submenu ของมัน)
↓ เปิดที่รายการแรก รายการถัดไป วนรอบ ข้ามรายการที่ปิดใช้งาน
↑ เปิดที่รายการสุดท้าย รายการก่อนหน้า วนรอบ
Home / End รายการแรก / สุดท้าย
ตัวอักษร รายการถัดไปที่ label (หรือข้อความ) ขึ้นต้นด้วยตัวอักษรนั้น
→ (← ในหน้าขวาไปซ้าย) เปิด submenu ของรายการที่โฟกัสอยู่
← (→ ในหน้าขวาไปซ้าย) ใน submenu: ปิด แล้วโฟกัสกลับไปที่รายการแม่
Esc ปิดชั้นนี้แล้วคืนโฟกัส
Tab ปิด menu แล้วคืนโฟกัสไปที่ trigger

part ต่าง ๆ ตั้ง role="menu", role ของรายการ, aria-haspopup, aria-expanded, aria-controls, aria-checked และ aria-disabled และย้ายโฟกัสเข้าออกให้

ส่วนที่คุณเพิ่มเอง

  • ชื่อของ trigger ที่มีแต่ไอคอน (aria-label)
  • ไฮไลต์ที่มองเห็นได้บนรายการที่โฟกัสอยู่ (focus:) และเครื่องหมายถูกสำหรับ data-checked
  • สำหรับรายการอันตราย ให้บอกผลที่ตามมาเป็นคำ (เช่น ข้อความที่ซ่อนจากสายตาว่า "ย้อนกลับไม่ได้")
