ใช้ tile แบบไหน?

Tile Element ใช้เมื่อ
Tile ui-tile กล่องเนื้อหา เช่น ตัวเลข สรุปสั้น ๆ
Tile ที่คลิกได้ ui-tile href ทั้ง tile พาไปหน้าเดียว
Tile ที่ขยายได้ ui-expandable-tile สรุปที่กดเปิดดูเพิ่มได้
Tile แบบเลือกได้ ui-selectable-tile checkbox ที่มีที่สำหรับหัวข้อและคำอธิบาย ดูเพิ่มที่หน้า checkbox
Radio tile ui-radio-tile ตัวเลือก radio ที่มีที่สำหรับหัวข้อและคำอธิบาย ดูเพิ่มที่หน้า radio

Tile แบบเลือกได้

อากรแสตมป์

คีย์บอร์ด

ปุ่ม ทำอะไร
Tab ไปที่ tile ที่คลิกได้ ปุ่มของ tile ที่ขยายได้ tile แบบเลือกได้ หรือ radio tile ที่เลือกอยู่ tile ธรรมดาไม่ใช่จุดที่ Tab หยุด
Enter ไปตามลิงก์ของ tile ที่คลิกได้ เปิดหรือปิด tile ที่ขยายได้
Space เปิดหรือปิด tile ที่ขยายได้ เลือกหรือไม่เลือก tile แบบเลือกได้
ปุ่มลูกศร ย้ายไปมาระหว่าง radio tile และเลือก

Accessibility

  • tile ธรรมดาเป็นกล่องที่ไม่มี role ให้ใช้หัวข้อจริงในเนื้อหา โครงหัวข้อของหน้าจะได้ถูกต้อง
  • tile ที่คลิกได้คือลิงก์เดียว ข้อความทั้งหมดใน tile คือชื่อลิงก์ ควรสั้น และอย่าใส่ control อื่นข้างใน
  • ปุ่มของ tile ที่ขยายได้มี aria-expanded และ aria-controls ส่วนสรุปเป็นส่วนหนึ่งของชื่อปุ่ม จึงต้องเป็นข้อความอย่างเดียว
  • tile แบบเลือกได้คือ checkbox จริง และ radio tile คือ radio จริง screen reader จึงอ่านสถานะได้ และข้อความใน tile คือชื่อของมัน
