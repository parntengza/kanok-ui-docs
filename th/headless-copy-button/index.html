Headless Copy button

Copy คือพฤติกรรมของ Copy button แบบมี style ในรูป React part ที่ไม่มี style Root เก็บข้อความและตัวจับเวลาของข้อความหลังคัดลอก Trigger ใส่ข้อความลงคลิปบอร์ดแล้วรายงาน copied อยู่สองวินาที และ Status เป็น live region แบบ polite ที่อ่านข้อความหลังคัดลอกของคุณในช่วงนั้น ถ้าคัดลอกไม่สำเร็จจะไม่แสดงอะไร Copy.useCopy ให้พฤติกรรมเดียวกันในรูป hook สำหรับ control ของคุณเอง

ส่วนที่คุณทำเองคือไอคอน tooltip ข้อความหลังคัดลอก และ style ทั้งหมด Code snippet แบบมี style ใช้ part ชุดนี้กับชิป inline ด้วย

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Copy } from '@purpurabog/ui/headless';

วิธีใช้

import { Copy } from '@purpurabog/ui/headless'; export default function Example() { return ( <div className="flex items-center gap-2 text-sm text-ink"> <span>RQ-2026-00123</span> <Copy.Root text="RQ-2026-00123"> <Copy.Trigger aria-label="คัดลอกเลขที่คำขอ" className="grid size-10 cursor-pointer place-items-center bg-surface-1 text-icon-primary hover:bg-ghost-hover active:bg-ghost-active focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current"> <path d="M14 5v9H5V5h9m0-1H5a1 1 0 0 0-1 1v9a1 1 0 0 0 1 1h9a1 1 0 0 0 1-1V5a1 1 0 0 0-1-1Z" /> <path d="M2 9H1V2a1 1 0 0 1 1-1h7v1H2Z" /> </svg> </Copy.Trigger> <Copy.Status className="sr-only">คัดลอกแล้ว</Copy.Status> </Copy.Root> </div> ); }

Trigger คือ <button type="button"> ที่ไม่มีชื่อในตัว trigger ที่มีแต่ไอคอนต้องมี aria-label (หรือ tooltip ที่ตั้งชื่อให้ ดูด้านล่าง)

โครงสร้าง

<Copy.Root text="…"> <Copy.Trigger /> <Copy.Status /> </Copy.Root>

แสดงผลหลังคัดลอก

ในช่วงหลังคัดลอก Trigger มี data-copied สลับไอคอนเป็นเครื่องหมายถูกด้วย group-data-copied: หรืออ่าน copied จาก Copy.useCopyContext() ใน component ที่อยู่ใน Root

import { Copy } from '@purpurabog/ui/headless'; function Label() { const { copied } = Copy.useCopyContext(); return <span className="text-sm">{copied ? 'คัดลอกแล้ว' : 'คัดลอกลิงก์'}</span>; } export default function Example() { return ( <Copy.Root text="https://contracts.example.com/CT-2026-0142"> <Copy.Trigger className="group inline-flex h-10 cursor-pointer items-center gap-2 bg-surface-1 px-4 text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-copied:text-success"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current group-data-copied:hidden"> <path d="M14 5v9H5V5h9m0-1H5a1 1 0 0 0-1 1v9a1 1 0 0 0 1 1h9a1 1 0 0 0 1-1V5a1 1 0 0 0-1-1Z" /> <path d="M2 9H1V2a1 1 0 0 1 1-1h7v1H2Z" /> </svg> <svg viewBox="0 0 16 16" aria-hidden="true" className="hidden size-4 fill-current group-data-copied:block"> <path d="M6 10.6 2.7 7.3 2 8l4 4 8-8-.7-.7z" /> </svg> <Label /> </Copy.Trigger> <Copy.Status className="sr-only">คัดลอกลิงก์แล้ว</Copy.Status> </Copy.Root> ); }

แสดงผลใน tooltip

Carbon แสดง label และข้อความหลังคัดลอกใน tooltip ของปุ่ม ใช้ Copy คู่กับ Tooltip แบบ headless: label ของ tooltip เป็นชื่อปุ่มไอคอน และ open ทำให้ tooltip ค้างอยู่ระหว่างที่ copied เป็น true

import { Copy, Tooltip } from '@purpurabog/ui/headless'; function CopyWithTooltip({ label, feedback }: { label: string; feedback: string }) { const { copied } = Copy.useCopyContext(); const text = copied ? feedback : label; return ( <> <Tooltip.Root label={text} placement="bottom" open={copied || undefined}> <Tooltip.Trigger className="inline-block"> <Copy.Trigger className="grid size-10 cursor-pointer place-items-center bg-surface-1 text-icon-primary hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current"> <path d="M14 5v9H5V5h9m0-1H5a1 1 0 0 0-1 1v9a1 1 0 0 0 1 1h9a1 1 0 0 0 1-1V5a1 1 0 0 0-1-1Z" /> <path d="M2 9H1V2a1 1 0 0 1 1-1h7v1H2Z" /> </svg> </Copy.Trigger> </Tooltip.Trigger> <Tooltip.Popup className="w-max rounded-xs bg-inverse-surface-1 px-4 py-0.5 text-sm text-inverse-ink">{text}</Tooltip.Popup> </Tooltip.Root> <Copy.Status className="sr-only">{feedback}</Copy.Status> </> ); } export default function Example() { return ( <div className="flex items-center gap-2 text-sm text-ink"> <span>0105556012345</span> <Copy.Root text="0105556012345"> <CopyWithTooltip label="คัดลอกเลขผู้เสียภาษี" feedback="คัดลอกเลขผู้เสียภาษีแล้ว" /> </Copy.Root> </div> ); }

เวลาแสดงผล

feedbackTimeout ที่ Root คือเวลาที่ copied เป็น true หน่วยเป็น ms (2000) กดซ้ำจะเริ่มนับใหม่

import { Copy } from '@purpurabog/ui/headless'; export default function Example() { return ( <Copy.Root text="CT-2026-0142" feedbackTimeout={5000}> <Copy.Trigger className="h-10 cursor-pointer bg-surface-1 px-4 text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-copied:bg-layer-selected-1"> คัดลอก CT-2026-0142 </Copy.Trigger> <Copy.Status className="ms-3 text-sm text-ink-muted">คัดลอกแล้ว (แสดง 5 วินาที)</Copy.Status> </Copy.Root> ); }

Status ในตัวอย่างนี้มองเห็นได้ ข้อความของมันมีอยู่เฉพาะช่วงหลังคัดลอก จึงใช้เป็นผลที่มองเห็นได้ไปด้วย

คัดลอกเอง

onCopy ที่ Root ทำงานก่อนคัดลอกพร้อมข้อความ คืนค่า false เพื่อคัดลอกค่าอื่นเอง ข้อความหลังคัดลอกยังแสดง ถ้าไม่คืนค่าอะไร part จะคัดลอกตามปกติ (ใช้บันทึกการคัดลอกได้)

import { useState } from 'react'; import { Copy } from '@purpurabog/ui/headless'; export default function Example() { const [copiedText, setCopiedText] = useState(''); return ( <div className="grid justify-items-start gap-3"> <Copy.Root text="CT-2026-0142" onCopy={(text) => { const summary = `${text}: วัสดุสำนักงาน 120,000 บาท ฝ่ายจัดซื้อ`; navigator.clipboard?.writeText(summary).catch(() => {}); setCopiedText(summary); return false; }} > <Copy.Trigger className="h-10 cursor-pointer bg-surface-1 px-4 text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> คัดลอกสรุปสัญญา </Copy.Trigger> <Copy.Status className="sr-only">คัดลอกสรุปแล้ว</Copy.Status> </Copy.Root> <p className="text-xs text-ink-muted">คัดลอกแล้ว: {copiedText}</p> </div> ); }

ปิดใช้งาน

disabled ที่ Trigger ปิดปุ่ม: ไม่รับโฟกัส ไม่คัดลอก ถ้ามี focusableWhenDisabled ปุ่มยังอยู่ในลำดับ Tab พร้อม aria-disabled และไม่คัดลอกอะไร แบบเดียวกับ code snippet แบบ inline ของ Carbon ผู้ใช้จึงยังไปถึงและอ่านเหตุผลได้ ทั้งสองแบบตั้ง data-disabled

import { Copy } from '@purpurabog/ui/headless'; const button = 'h-10 cursor-pointer bg-surface-1 px-4 text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:bg-surface-1 data-disabled:text-ink-disabled'; export default function Example() { return ( <div className="flex flex-wrap gap-4"> <Copy.Root text=""> <Copy.Trigger disabled className={button}>คัดลอก (ปิดใช้งาน)</Copy.Trigger> </Copy.Root> <Copy.Root text="ak_live_7f3c9a1e"> <Copy.Trigger disabled focusableWhenDisabled className={button}>คัดลอก API key (ยังรับโฟกัส)</Copy.Trigger> </Copy.Root> </div> ); }

ใช้แค่ hook

Copy.useCopy(text, { onCopy, feedbackTimeout }) คืน { copied, copy } โดยไม่ต้องใช้ part ใช้เมื่อ control ที่คัดลอกเป็นอย่างอื่น เช่น รายการในเมนู ปุ่มหน้าตาแบบลิงก์ หรือคีย์ลัด แล้วเพิ่ม live region เอง

import { Copy } from '@purpurabog/ui/headless'; export default function Example() { const { copied, copy } = Copy.useCopy('finance@example.com', { feedbackTimeout: 3000 }); return ( <p className="text-sm text-ink"> มีคำถาม เขียนถึง finance@example.com{' '} <button type="button" onClick={() => void copy()} className="cursor-pointer border-0 bg-transparent p-0 text-link underline hover:text-link-hover focus-visible:outline-2 focus-visible:outline-focus"> {copied ? 'คัดลอกแล้ว' : 'คัดลอกอีเมล'} </button> <span role="status" className="sr-only">{copied ? 'คัดลอกอีเมลแล้ว' : ''}</span> </p> ); }

Parts

Copy.Root

render แค่ children เก็บข้อความและตัวจับเวลาของข้อความหลังคัดลอก ซึ่งหยุดพร้อม component

Prop Type ค่าเริ่มต้น
text string สิ่งที่คัดลอก (ต้องมี)
onCopy (text: string) => boolean | void ก่อนคัดลอก คืน false เพื่อคัดลอกเอง (ข้อความหลังคัดลอกยังแสดง)
feedbackTimeout number 2000 เวลาที่ copied เป็น true หน่วย ms

Copy.useCopyContext() คืน text, copied และ copy() ให้ component ที่อยู่ใน Root

Copy.Trigger

<button type="button"> กดแล้วคัดลอก ยกเว้นตอนปิดใช้งาน รับ prop ของ button ได้ทุกตัว ยกเว้น type

Prop Type ค่าเริ่มต้น
disabled boolean false ไม่คัดลอก ใช้ disabled ของ button เว้นแต่มี focusableWhenDisabled
focusableWhenDisabled boolean false ปิดใช้งานแต่ยังอยู่ในลำดับ Tab พร้อม aria-disabled
Attribute เมื่อ
data-copied อยู่ในช่วงหลังคัดลอก
data-disabled ปิดใช้งาน

Copy.Status

<span role="status"> เป็น live region แบบ polite children ของมัน (ข้อความหลังคัดลอกของคุณ) render เฉพาะช่วงหลังคัดลอก screen reader จึงอ่านหนึ่งครั้ง ซ่อนด้วย sr-only หรือให้เป็นผลที่มองเห็นได้ก็ได้

Copy.useCopy

useCopy(text, { onCopy?, feedbackTimeout? }) คืน { copied, copy }: copy() คัดลอก (เว้นแต่ onCopy คืน false) แล้วตั้ง copied เป็นเวลา feedbackTimeout ms Root ใช้ hook นี้

คีย์บอร์ดและ accessibility

ปุ่ม ทำอะไร
Enter, Space ที่ Trigger: คัดลอก
Tab ไปตัวควบคุมถัดไป (trigger ที่มี focusableWhenDisabled ยังอยู่ในลำดับ)

part ให้ปุ่มจริงและ live region แบบ polite ที่พูดเฉพาะหลังคัดลอกสำเร็จ ถ้าไม่มี Clipboard API (หน้า intranet แบบ http ธรรมดา) จะใช้ document.execCommand('copy') แทน

ส่วนที่คุณเพิ่มเอง

  • ชื่อของ Trigger ที่มีแต่ไอคอน: aria-label หรือ label ของ Tooltip แบบ headless
  • ข้อความหลังคัดลอกใน Status ("คัดลอกแล้ว", "คัดลอกลิงก์แล้ว")
  • ผลที่มองเห็นได้สำหรับผู้ใช้ที่มองเห็น: style ของ data-copied, tooltip หรือ Status ที่มองเห็นได้
  • style ของโฟกัสที่มองเห็นได้
