12 ชั่วโมงหรือ 24 ชั่วโมง

ค่าเริ่มต้นช่องรับเวลาแบบ 12 ชั่วโมง h:mm หรือ hh:mm (9:30, 09:30, 12:45) ยาวไม่เกิน 5 ตัวอักษร pattern ของ Carbon เองไม่รับเลข 0 นำหน้า แต่ตัวนี้รับ ผู้ใช้จึงพิมพ์ตามที่ placeholder hh:mm แสดงได้

Skeleton

ระหว่างที่หน้ากำลังโหลดข้อมูล ให้แสดง <ui-time-picker-skeleton> แทนที่ picker Carbon มีแค่ skeleton ของ time picker แบบ fluid ตัวนี้จึงเป็นแบบนั้น: ช่องเวลา select AM / PM และ select time zone ส่วน is-only-two (isOnlyTwo ใน React + Tailwind) วาดสองส่วนเท่ากันแทน ตัวนี้ import แยกจาก @purpurabog/ui/time-picker-skeleton และ screen reader มองไม่เห็น

คีย์บอร์ด

ปุ่ม ผล
Enter (ในช่องเวลา) ส่งฟอร์มที่ช่องอยู่ เหมือน input แบบ native
↑ / ↓, Space (ที่ select) ปุ่มของ select ตามปกติของ browser ใช้ไม่ได้ขณะอ่านอย่างเดียว

Accessibility

  • ช่องเวลาเป็น text input แบบ native ที่มี <label> ส่วน select เป็น <select> แบบ native
  • ตั้งชื่อ select แต่ละตัวด้วย label ถ้าไม่ตั้ง web component และ React + Tailwind จะใช้ "เปิดรายการตัวเลือก" แบบที่ Carbon ทำ
  • error ตั้ง aria-invalid ที่ช่องเวลาและผูกกับช่องด้วย aria-describedby
  • select ที่อ่านอย่างเดียวมี aria-readonly

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Time picker
