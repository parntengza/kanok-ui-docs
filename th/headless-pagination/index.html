Headless Pagination

Pagination คือพฤติกรรมของ Pagination แบบมี style ในรูป React parts ที่ไม่มี style Root เก็บหน้า ขนาดหน้า และจำนวนทั้งหมด ข้างในมี PageSizeSelect (เปลี่ยนขนาดแล้วกลับไปหน้า 1 เหมือน Carbon) PageSelect (หนึ่งตัวเลือกต่อหน้า) และปุ่ม Prev / Next ที่ปิดเองเมื่อถึงปลาย และส่ง focus ให้กัน

ส่วนที่คุณเขียนเอง: label ข้อความช่วง ("1–10 จาก 95 รายการ") ไอคอน และ style ทั้งหมด usePaginationContext() ให้ตัวเลขสำหรับข้อความเหล่านี้

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Pagination } from '@purpurabog/ui/headless';

วิธีใช้

import { Pagination } from '@purpurabog/ui/headless'; function Range() { const { min, max, totalItems } = Pagination.usePaginationContext(); return <span className="px-4 text-ink">{min}–{max} จาก {totalItems} รายการ</span>; } const select = 'h-10 cursor-pointer border-x border-hairline bg-transparent px-4 text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; const arrow = 'size-10 border-s border-hairline text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:text-ink-disabled data-disabled:hover:bg-transparent'; export default function Example() { return ( <Pagination.Root totalItems={95} className="flex items-center justify-between border-t border-hairline bg-surface-1 text-sm"> <div className="flex items-center"> <label htmlFor="pagination-size" className="ps-4 pe-2 text-ink-muted">รายการต่อหน้า:</label> <Pagination.PageSizeSelect id="pagination-size" pageSizes={[10, 25, 50]} className={select} /> <Range /> </div> <div className="flex items-center"> <Pagination.PageSelect aria-label="หมายเลขหน้า" className={select} /> <Pagination.Prev aria-label="หน้าก่อนหน้า" className={arrow}>‹</Pagination.Prev> <Pagination.Next aria-label="หน้าถัดไป" className={arrow}>›</Pagination.Next> </div> </Pagination.Root> ); }

โครงสร้าง

<Pagination.Root> <label /> <Pagination.PageSizeSelect /> <Pagination.PageSelect /> <Pagination.Prev /> <Pagination.Next /> </Pagination.Root>

ทุก part ไม่บังคับ bar ที่มีแค่ Prev กับ Next ก็ใช้ได้

ข้อความ

usePaginationContext() คืน min และ max (รายการแรกและรายการสุดท้ายของหน้า) totalItems, page, pageSize และ pageCount เขียนเป็นคำและภาษาของคุณเอง PageSelect รับ renderPage สำหรับข้อความของแต่ละตัวเลือก

import { Pagination } from '@purpurabog/ui/headless'; function Status() { const { min, max, totalItems, page, pageCount } = Pagination.usePaginationContext(); return ( <p className="text-sm text-ink"> สัญญาที่ {min}–{max} จาก {totalItems} ฉบับ · หน้า {page} จาก {pageCount} </p> ); } const button = 'h-8 border border-border-strong-1 px-3 text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:border-border-disabled data-disabled:text-ink-disabled'; export default function Example() { return ( <Pagination.Root totalItems={57} defaultPageSize={20} className="grid max-w-md gap-3"> <Status /> <div className="flex items-center gap-2"> <Pagination.Prev className={button}>ก่อนหน้า</Pagination.Prev> <Pagination.PageSelect aria-label="ไปหน้า" renderPage={(p) => `หน้า ${p}`} className="h-8 border-b border-border-strong-1 bg-field-1 px-2 text-sm text-ink focus-visible:outline-2 focus-visible:outline-focus" /> <Pagination.Next className={button}>ถัดไป</Pagination.Next> </div> </Pagination.Root> ); }

แสดงแถวของหน้านั้น

เก็บ page และ pageSize เองด้วย onChange แล้วตัดแถวตามค่านี้ (หรือขอหน้านั้นจาก server)

import { useState } from 'react'; import { Pagination } from '@purpurabog/ui/headless'; const contracts = Array.from({ length: 23 }, (_, i) => `สัญญาเลขที่ ${String(i + 1).padStart(3, '0')}`); const arrow = 'size-8 text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:text-ink-disabled data-disabled:hover:bg-transparent'; export default function Example() { const [paging, setPaging] = useState({ page: 1, pageSize: 5 }); const start = (paging.page - 1) * paging.pageSize; return ( <div className="grid max-w-sm gap-2 text-sm text-ink"> <ol start={start + 1} className="list-decimal ps-6"> {contracts.slice(start, start + paging.pageSize).map((name) => ( <li key={name}>{name}</li> ))} </ol> <Pagination.Root totalItems={contracts.length} page={paging.page} pageSize={paging.pageSize} onChange={setPaging} className="flex items-center gap-2 border-t border-hairline pt-2"> <label htmlFor="pagination-rows-size" className="text-ink-muted">ต่อหน้า</label> <Pagination.PageSizeSelect id="pagination-rows-size" pageSizes={[5, 10]} className="h-8 bg-field-1 px-2 focus-visible:outline-2 focus-visible:outline-focus" /> <span className="ms-auto" /> <Pagination.Prev aria-label="หน้าก่อนหน้า" className={arrow}>‹</Pagination.Prev> <Pagination.Next aria-label="หน้าถัดไป" className={arrow}>›</Pagination.Next> </Pagination.Root> <p className="text-xs text-ink-muted">หน้า {paging.page} ขนาดหน้า {paging.pageSize}</p> </div> ); }

ไม่รู้จำนวนทั้งหมด

ถ้าใส่ pagesUnknown ตัว Root ไม่ต้องมี totalItems และไม่มีหน้าสุดท้าย ไม่ต้องใส่ PageSelect และตั้ง isLastPage เมื่อ API แบบ cursor บอกว่าไม่มีหน้าถัดไปแล้ว

import { useState } from 'react'; import { Pagination } from '@purpurabog/ui/headless'; const button = 'h-8 border border-border-strong-1 px-3 text-sm text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:border-border-disabled data-disabled:text-ink-disabled'; function PageText() { const { page, min, max } = Pagination.usePaginationContext(); return <span className="text-sm text-ink">หน้า {page} · รายการที่ {min}–{max}</span>; } export default function Example() { const [page, setPage] = useState(1); return ( <Pagination.Root pagesUnknown isLastPage={page >= 4} page={page} pageSize={25} onChange={(change) => setPage(change.page)} className="flex items-center gap-3"> <Pagination.Prev className={button}>ก่อนหน้า</Pagination.Prev> <PageText /> <Pagination.Next className={button}>ถัดไป</Pagination.Next> </Pagination.Root> ); }

ในตัวอย่างนี้ "server" มีสี่หน้า isLastPage เป็นจริงที่หน้า 4

แต่ง style

ทุก part มี data-disabled เมื่อใช้ไม่ได้: Prev ที่หน้าแรก Next ที่หน้าสุดท้าย และทุก part เมื่อ Root เป็น disabled

import { useState } from 'react'; import { Pagination } from '@purpurabog/ui/headless'; const select = 'h-10 cursor-pointer border-x border-hairline bg-transparent px-4 text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:text-ink-disabled data-disabled:hover:bg-transparent'; const arrow = 'size-10 border-s border-hairline text-ink hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-disabled:cursor-not-allowed data-disabled:text-ink-disabled data-disabled:hover:bg-transparent'; export default function Example() { const [disabled, setDisabled] = useState(false); return ( <div className="grid gap-3"> <Pagination.Root totalItems={95} disabled={disabled} className="flex items-center justify-end border-t border-hairline bg-surface-1 text-sm data-disabled:opacity-75"> <Pagination.PageSelect aria-label="หมายเลขหน้า" className={select} /> <Pagination.Prev aria-label="หน้าก่อนหน้า" className={arrow}>‹</Pagination.Prev> <Pagination.Next aria-label="หน้าถัดไป" className={arrow}>›</Pagination.Next> </Pagination.Root> <label className="flex items-center gap-2 text-sm text-ink"> <input type="checkbox" checked={disabled} onChange={(e) => setDisabled(e.target.checked)} /> disabled </label> </div> ); } .pagination select:hover, .pagination button:hover { background: #e8e8e8; } .pagination [data-disabled] { color: #c6c6c6; cursor: not-allowed; } .pagination [data-disabled]:hover { background: transparent; }

Parts

Pagination.Root

สร้าง <div> ครอบ part อื่นและส่ง state ให้ รับ prop ทุกตัวของ <div>

Prop Type ค่าเริ่มต้น
page number หน้า เริ่มที่ 1 (ควบคุมเอง)
defaultPage number 1 หน้าเริ่มต้น (ไม่ควบคุมเอง)
pageSize number จำนวนรายการต่อหน้า (ควบคุมเอง)
defaultPageSize number 10 ขนาดหน้าเริ่มต้น (ไม่ควบคุมเอง)
totalItems number 0 จำนวนรายการทุกหน้ารวมกัน
pagesUnknown boolean false ไม่มีจำนวนหน้า Next หยุดเมื่อมี isLastPage เท่านั้น
isLastPage boolean false ใช้กับ pagesUnknown: นี่คือหน้าสุดท้าย
disabled boolean false ปิดทุกตัวเลือกและทุกปุ่ม
onChange (change: { page, pageSize }) => void หลังผู้ใช้เปลี่ยนหน้าหรือขนาดหน้า
Attribute เมื่อ
data-disabled ตั้ง disabled

Pagination.usePaginationContext() คืน page, pageSize, totalItems, pageCount, min, max, atFirst, atLast, pagesUnknown, disabled และ goTo(page), setPageSize(size), step(1 | -1) ให้ component ใดก็ได้ที่อยู่ใน Root

Pagination.PageSizeSelect

สร้าง <select> ของขนาดหน้า ใส่ <label> ให้ด้วย เปลี่ยนขนาดแล้วกลับไปหน้า 1 รับ prop ทุกตัวของ <select> ยกเว้น value และ defaultValue

Prop Type ค่าเริ่มต้น
pageSizes readonly number[] [] ตัวเลือก ตัวละหนึ่ง <option> (ยกเว้นคุณใส่ <option> เป็น children เอง)
Attribute เมื่อ
data-disabled Root หรือ select นี้ถูกปิด

Pagination.PageSelect

สร้าง <select> หนึ่งตัวเลือกต่อหน้า ตั้งชื่อด้วย aria-label รับ prop ทุกตัวของ <select> ยกเว้น value, defaultValue และ children

Prop Type ค่าเริ่มต้น
renderPage (page: number) => ReactNode String ข้อความของตัวเลือกแต่ละหน้า
Attribute เมื่อ
data-disabled Root หรือ select นี้ถูกปิด

Pagination.Prev, Pagination.Next

แต่ละตัวสร้าง <button type="button"> ที่เลื่อนไปหนึ่งหน้า ปุ่มที่มีแต่ไอคอนให้ตั้งชื่อด้วย aria-label

Attribute เมื่อ
data-disabled อยู่หน้าแรก (Prev) อยู่หน้าสุดท้าย (Next) หรือ Root ถูกปิด

คีย์บอร์ดและ accessibility

  • ตัวเลือกเป็น select จริง ปุ่มของ browser และตัวเลือกบนมือถือจึงใช้ได้
  • Prev และ Next เป็นปุ่มที่ Tab ไปถึง (tabIndex={0} เหมือน Carbon Safari จึง focus เมื่อคลิก) เมื่อปุ่มที่กดปิดลงที่หน้าแรกหรือหน้าสุดท้าย focus จะย้ายไปปุ่มอีกตัว
  • สิ่งที่คุณต้องใส่เอง: <label> ของขนาดหน้า aria-label ของตัวเลือกหน้าและของปุ่มที่มีแต่ไอคอน และข้อความช่วง
  • บอกผู้ใช้ screen reader ว่าแถวเปลี่ยนแล้ว เช่น ด้วยบรรทัดสถานะแบบ polite
