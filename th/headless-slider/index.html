Headless Slider

Slider ให้พฤติกรรมของ slider โดยไม่มี class เลย มีปุ่มเลื่อนหนึ่งปุ่ม หรือสองปุ่มสำหรับช่วง ปุ่มเลื่อนแต่ละปุ่มเป็น role="slider" ที่ Tab ไปถึงได้และขยับด้วยปุ่มลูกศร การกดบนแถบจะย้ายปุ่มที่ใกล้กว่าและเริ่มลาก ซึ่งตาม pointer ไปได้ทั่วหน้า ช่องตัวเลขข้างแถบรับตัวเลขที่พิมพ์ และ hidden input ส่งแต่ละค่าไปกับฟอร์ม

markup, ตัวเลขที่ปลายแถบ, ข้อความ และ style ทั้งหมดเป็นของคุณ รวมถึงตำแหน่งของปุ่มเลื่อนด้วย โดย Control ให้ตำแหน่งมาเป็น CSS variable ตัวที่มี style อยู่ที่ Slider

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Slider } from '@purpurabog/ui/headless';

วิธีใช้

import { useState } from 'react'; import { Slider } from '@purpurabog/ui/headless'; const label = 'text-xs text-ink-muted data-disabled:text-ink-disabled'; const box = 'h-10 w-16 border-b border-border-strong-1 bg-field-1 px-2 text-center text-sm text-ink [appearance:textfield] focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; export default function Example() { const [volume, setVolume] = useState(50); const [committed, setCommitted] = useState(50); return ( <Slider.Root value={[volume]} onValueChange={([v]) => setVolume(v)} onValueCommit={([v]) => setCommitted(v)}> <div className="grid gap-2"> <Slider.Label className={label}>ระดับเสียง</Slider.Label> <Slider.Group className="flex items-center gap-4"> <Rails /> <Slider.Input aria-label="ระดับเสียง" className={box} /> </Slider.Group> <p className="text-xs text-ink-muted">onValueChange: {volume} · onValueCommit: {committed}</p> </div> <Slider.HiddenInput name="volume" /> </Slider.Root> ); } // แถบและปุ่มเลื่อน ตัวอย่างแต่ละอันในหน้านี้เป็นโมดูลเต็ม จึงมี <Rails /> นี้ซ้ำทุกอัน function Rails({ range = false }: Readonly<{ range?: boolean }>) { const thumb = 'absolute top-2.5 size-3.5 -translate-x-1/2 rounded-full bg-layer-selected-inverse hover:scale-125 focus-visible:bg-interactive focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus data-dragging:scale-125 data-disabled:bg-border-disabled data-disabled:hover:scale-100'; return ( <Slider.Control className="relative h-8 w-64 cursor-pointer touch-none data-disabled:cursor-not-allowed data-readonly:cursor-default"> <Slider.Track className="absolute inset-x-0 top-4 h-0.5 bg-hairline data-disabled:bg-border-disabled" /> <Slider.Indicator className="absolute top-4 h-0.5 bg-layer-selected-inverse start-[calc(var(--slider-range-start)*100%)] end-[calc((1-var(--slider-range-end))*100%)] data-invalid:bg-error data-disabled:bg-border-disabled" /> {range && <Slider.Thumb index={0} aria-label="ขอบล่าง" className={`${thumb} start-[calc(var(--slider-range-start)*100%)]`} />} <Slider.Thumb index={range ? 1 : 0} aria-label={range ? 'ขอบบน' : undefined} className={`${thumb} start-[calc(var(--slider-range-end)*100%)]`} /> </Slider.Control> ); }

ค่าเป็น array หนึ่งช่องต่อหนึ่งปุ่มเลื่อน: [value] หรือ [lower, upper] onValueChange ตามทุกการเปลี่ยน (ลาก กดปุ่ม พิมพ์) ส่วน onValueCommit ได้ยินเฉพาะตอนยืนยัน: ปล่อย pointer กดปุ่มลูกศร หรือยืนยันช่องตัวเลข ช่องไหนใน value ที่เป็น undefined ปุ่มเลื่อนนั้นจะเป็นแบบ uncontrolled

โครงสร้าง

<Slider.Root> <Slider.Label /> <Slider.Group> <Slider.Input index={0} /> <Slider.Control> <Slider.Track /> <Slider.Indicator /> <Slider.Thumb index={0} /> <Slider.Thumb index={1} /> </Slider.Control> <Slider.Input index={1} /> </Slider.Group> <Slider.HiddenInput index={0} /> <Slider.HiddenInput index={1} /> </Slider.Root>

ถ้ามีปุ่มเลื่อนเดียว ไม่ต้องใส่ชิ้นส่วนที่มี index={1}

สเกลและ step

min และ max กำหนดปลายทั้งสอง (0 และ 100) ส่วน step กำหนดระยะขยับ (1) ปุ่มลูกศรขยับหนึ่ง step ถ้ากด Shift ด้วยจะขยับ stepMultiplier step (4) ตัวเลขที่ปลายแถบเป็น markup ของคุณ

ช่องตัวเลข

Input แสดงค่าของปุ่มเลื่อนของมัน ตัวเลขที่อยู่ในขอบเขตมีผลทันทีระหว่างพิมพ์ โดยปัดไปที่ step ที่ใกล้ที่สุด ตอนออกจากช่องหรือกด Enter ตัวเลขที่เกินขอบเขตจะถูกปรับให้อยู่ในช่วง และข้อความที่ไม่ใช่ตัวเลขทำให้ slider เป็น invalid หลังการปรับ corrected ใน context เก็บตัวเลขที่พิมพ์ไว้ให้คุณประกาศ:

import { Slider } from '@purpurabog/ui/headless'; const label = 'text-xs text-ink-muted data-disabled:text-ink-disabled'; const box = 'h-10 w-16 border-b border-border-strong-1 bg-field-1 px-2 text-center text-sm text-ink [appearance:textfield] focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-invalid:outline-2 data-invalid:-outline-offset-2 data-invalid:outline-error data-disabled:border-transparent data-disabled:text-ink-disabled data-readonly:border-border-subtle-1 data-readonly:bg-transparent'; function Corrected() { const { corrected } = Slider.useSliderContext(); return ( <span role="status" className="text-xs text-ink-muted"> {corrected === undefined ? '' : `ปรับค่า ${corrected} ให้อยู่ในช่วงแล้ว`} </span> ); } // พิมพ์ 250 หรือ "abc" ในช่อง แล้วกด Enter export default function Example() { return ( <Slider.Root min={0} max={200} defaultValue={[120]}> <div className="grid gap-2"> <Slider.Label className={label}>ความกว้าง (px)</Slider.Label> <Slider.Group className="flex items-center gap-4"> <Rails /> <Slider.Input aria-label="ความกว้าง" className={box} /> </Slider.Group> <Corrected /> </div> </Slider.Root> ); } // Rails: แถบและปุ่มเลื่อนจาก "วิธีใช้" function Rails({ range = false }: Readonly<{ range?: boolean }>) { const thumb = 'absolute top-2.5 size-3.5 -translate-x-1/2 rounded-full bg-layer-selected-inverse hover:scale-125 focus-visible:bg-interactive focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus data-dragging:scale-125 data-disabled:bg-border-disabled data-disabled:hover:scale-100'; return ( <Slider.Control className="relative h-8 w-64 cursor-pointer touch-none data-disabled:cursor-not-allowed data-readonly:cursor-default"> <Slider.Track className="absolute inset-x-0 top-4 h-0.5 bg-hairline data-disabled:bg-border-disabled" /> <Slider.Indicator className="absolute top-4 h-0.5 bg-layer-selected-inverse start-[calc(var(--slider-range-start)*100%)] end-[calc((1-var(--slider-range-end))*100%)] data-invalid:bg-error data-disabled:bg-border-disabled" /> {range && <Slider.Thumb index={0} aria-label="ขอบล่าง" className={`${thumb} start-[calc(var(--slider-range-start)*100%)]`} />} <Slider.Thumb index={range ? 1 : 0} aria-label={range ? ถ้าไม่ต้องการช่องตัวเลข ไม่ต้องใส่ Slider.Input ถ้าต้องการ tooltip แสดงค่าบนปุ่มเลื่อน ให้ทำเป็น markup ของคุณเอง:

readOnly เก็บค่าและส่งไปกับฟอร์ม ไม่มีอะไรขยับ และช่องตัวเลขแก้ไม่ได้ ปุ่มเลื่อนที่อ่านอย่างเดียวจะออกจากลำดับ Tab เว้นแต่คุณใส่ tabIndex={0} ส่วน disabled ก็ไม่ให้ขยับเช่นกัน และ HiddenInput ไม่ส่งค่า

slider แบบ uncontrolled กลับไปที่ defaultValue เมื่อฟอร์มถูก reset

ใส่ style

import { useState } from 'react'; import { Slider } from '@purpurabog/ui/headless'; export default function Example() { const [invalid, setInvalid] = useState(false); const [disabled, setDisabled] = useState(false); return ( <div className="grid gap-4"> <Slider.Root defaultValue={[40]} invalid={invalid} disabled={disabled}> <Slider.Label className="sr-only">ความทึบ</Slider.Label> <Slider.Group> <Slider.Control className="relative h-8 w-64"> <Slider.Track className="absolute inset-x-0 top-4 h-0.5 bg-hairline" /> <Slider.Indicator className="absolute top-4 h-0.5 bg-layer-selected-inverse start-[calc(var(--slider-range-start)*100%)] end-[calc((1-var(--slider-range-end))*100%)] data-invalid:bg-error data-disabled:bg-border-disabled" /> <Slider.Thumb className="absolute top-2.5 size-3.5 -translate-x-1/2 rounded-full bg-layer-selected-inverse start-[calc(var(--slider-range-end)*100%)] focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus data-dragging:scale-125 data-disabled:bg-border-disabled" /> </Slider.Control> </Slider.Group> </Slider.Root> <div className="flex gap-4 text-sm text-ink"> <label className="flex items-center gap-2"> <input type="checkbox" checked={invalid} onChange={(e) => setInvalid(e.target.checked)} /> invalid </label> <label className="flex items-center gap-2"> <input type="checkbox" checked={disabled} onChange={(e) => setDisabled(e.target.checked)} /> disabled </label> </div> </div> ); } .slider-control { position: relative; height: 2rem; } .slider-indicator { position: absolute; inset-inline-start: calc(var(--slider-range-start) * 100%); inset-inline-end: calc((1 - var(--slider-range-end)) * 100%); } .slider-indicator[data-invalid] { background: #da1e28; } .slider-thumb { position: absolute; inset-inline-start: calc(var(--slider-range-end) * 100%); translate: -50% 0; } .slider-thumb[data-dragging] { scale: 1.25; } .slider-thumb[data-disabled] { background: #c6c6c6; }

--slider-range-start คือจุดเริ่มของส่วนที่ถูกเติม (0 เมื่อมีปุ่มเดียว) และ --slider-range-end คือจุดสิ้นสุด เป็นสัดส่วน 0…1 ของแถบ วางปุ่มล่างที่จุดเริ่ม และปุ่มบน (หรือปุ่มเดียว) ที่จุดสิ้นสุด

ชิ้นส่วน

Slider.Root

ไม่ render element ใด ๆ แค่เก็บค่าให้ชิ้นส่วนข้างใน

Prop Type ค่าเริ่มต้น
value readonly (number | undefined)[] หนึ่งช่องต่อหนึ่งปุ่มเลื่อน แบบ controlled ช่องที่เป็น undefined ทำให้ปุ่มนั้นเป็น uncontrolled
defaultValue readonly number[] [min]
onValueChange (values: number[]) => void ทุกการเปลี่ยน
onValueCommit (values: number[]) => void การเปลี่ยนที่ยืนยันแล้ว: ปล่อย pointer กดปุ่ม หรือยืนยันช่องตัวเลข
min number 0
max number 100
step number 1
stepMultiplier number 4 Shift + ลูกศรขยับ step × stepMultiplier
disabled boolean false
readOnly boolean false เก็บค่าไว้ ปุ่มเลื่อนออกจากลำดับ Tab
invalid boolean false แสดง error

Slider.Label

render <label> ที่เป็นชื่อของกลุ่มและปุ่มเลื่อน คลิกแล้วโฟกัสไปที่ปุ่มเลื่อนแรก htmlFor ตั้งต้นเป็น id ของปุ่มเลื่อนแรก

Attribute เมื่อ
data-disabled disabled

Slider.Group, Slider.Control, Slider.Track, Slider.Indicator

แต่ละตัว render <div> Group เป็น role="group" ที่มีชื่อจาก Label ครอบแถบ ตัวเลขที่ปลาย และช่องตัวเลข Control เป็นพื้นที่รับ pointer: กดตรงนั้นแล้วปุ่มที่ใกล้กว่า (หรือปุ่มที่ถูกกด) ย้ายมาและเริ่มลาก และตั้ง --slider-range-start กับ --slider-range-end Track คือราง และ Indicator คือส่วนที่ถูกเติม

Attribute เมื่อ
data-disabled disabled
data-readonly readOnly
data-invalid กำลังแสดง error
data-dragging มีปุ่มเลื่อนกำลังถูกลาก
data-orientation เป็น horizontal เสมอ (เฉพาะ Group และ Control)

Slider.Thumb

render <div role="slider"> ที่มี aria-valuemin, aria-valuemax และ aria-valuenow มีชื่อจาก Label เว้นแต่คุณใส่ aria-label หรือ aria-labelledby

Prop Type ค่าเริ่มต้น
index number 0 ขยับค่าช่องไหน
Attribute เมื่อ
data-index เสมอ: ค่า index ของมัน
data-disabled disabled
data-readonly readOnly
data-invalid กำลังแสดง error
data-dragging ปุ่มนี้กำลังถูกลาก

Slider.Input

render <input type="number"> ที่ min / max เป็นขอบเขตของปุ่มเลื่อน และ step มาจาก Root

Prop Type ค่าเริ่มต้น
index number 0 แก้ค่าช่องไหน
Attribute เมื่อ
data-index เสมอ: ค่า index ของมัน
data-disabled disabled

Slider.HiddenInput

render <input type="hidden"> ที่มีค่า ให้ใส่ name เอง และถูกปิด (ไม่ส่งค่า) ขณะ Root disabled

Prop Type ค่าเริ่มต้น
index number 0 ส่งค่าช่องไหน

คีย์บอร์ดและ accessibility

ที่ปุ่มเลื่อน:

ปุ่ม ผล
← / ↓ ลดหนึ่ง step
→ / ↑ เพิ่มหนึ่ง step
Shift + ลูกศร ขยับ stepMultiplier step
Home / End ไปที่ min / max (ในโหมดช่วงไปได้ไกลเท่าที่อีกปุ่มยอม)

ในช่องตัวเลข Enter ยืนยันตัวเลขที่พิมพ์

สิ่งที่ชิ้นส่วนจัดการให้:

  • role="slider" พร้อม aria-valuemin, aria-valuemax และ aria-valuenow ที่ปุ่มเลื่อนแต่ละปุ่ม ในโหมดช่วงขอบเขตของแต่ละปุ่มหยุดที่อีกปุ่ม
  • aria-disabled, aria-readonly และ aria-invalid ที่ปุ่มเลื่อน และ aria-invalid ที่ช่องตัวเลข
  • role="group" ที่มีชื่อจาก Label และคลิกที่ label แล้วโฟกัสไปที่ปุ่มเลื่อนแรก
  • โฟกัสย้ายไปที่ปุ่มเลื่อนที่การกดบนแถบย้ายไป

สิ่งที่คุณต้องใส่เอง:

  • aria-label ของปุ่มเลื่อนแต่ละปุ่มในโหมดช่วง ("ขอบล่าง", "ขอบบน") และของช่องตัวเลขแต่ละช่อง
  • aria-valuetext ถ้าค่ามีรูปแบบ
  • ข้อความ error (ผูกด้วย aria-describedby) และการประกาศเมื่อตัวเลขถูกปรับ
