Pagination

Pagination แบ่งรายการยาว ๆ เป็นหน้า มี "รายการต่อหน้า" ช่วงที่แสดงอยู่ ตัวเลือกหน้า และปุ่มก่อนหน้า / ถัดไป (Carbon Pagination) วางไว้ใต้ตารางหรือรายการ มันเก็บแค่หน้าและขนาดหน้า การแสดงแถวให้ตรงหน้าเป็นงานของโค้ดคุณ

HTMLReactReact + Tailwind<ui-pagination total-items="95"></ui-pagination> <UiPagination totalItems={95} /> <Pagination totalItems={95} />

Pagination หรือ pagination nav?

Component ใช้เมื่อ
Pagination อยู่ใต้ตารางหรือรายการข้อมูล ผู้ใช้เลือกขนาดหน้าและกระโดดไปหน้าไหนก็ได้ ไม่รู้จำนวนทั้งหมดก็ใช้ได้
Pagination nav เลขหน้าเป็นลิงก์ สำหรับผลการค้นหาหรือรายการบทความ ที่แต่ละหน้ามี URL ของตัวเอง

Data table มี pagination นี้ในตัว แค่ตั้ง page-size

หน้าและขนาดหน้า

page (เริ่มที่ 1) และ page-size บอกว่าเริ่มที่หน้าไหน page-sizes คือตัวเลือกขนาดหน้า (ค่าเริ่มต้น 10,25,50) ui-change ยิงพร้อม { page, pageSize } หลังผู้ใช้เปลี่ยนอย่างใดอย่างหนึ่ง การเปลี่ยนขนาดหน้าจะกลับไปหน้า 1 เหมือน Carbon

หน้า: 3 ขนาดหน้า: 20

React + Tailwind รับ pageSizes เป็น array ของตัวเลข และรับ defaultPage / defaultPageSize เมื่อให้ตัว bar เก็บค่าเอง

แสดงแถวของหน้านั้น

    page-sizes ว่างจะซ่อน "รายการต่อหน้า" เมื่อขนาดหน้าคงที่ เช่น ใน panel แคบ ๆ

    ไม่รู้จำนวนทั้งหมด

    ถ้าใส่ pages-unknown ไม่ต้องมี total-items ตัวเลือกหน้าจะกลายเป็นข้อความ ("หน้า 3") และช่วงที่แสดงไม่มีจำนวนรวม ใช้กับ API แบบ cursor ที่บอกแค่ว่ามีหน้าถัดไปหรือไม่ ตั้ง is-last-page เมื่อ server บอกว่าไม่มีแล้ว ปุ่มถัดไปจะปิด

    server ในตัวอย่างนี้มี 4 หน้า

    เปลี่ยนข้อความได้ทุกจุด ข้อความช่วงและหน้าเป็นแม่แบบ {min}, {max}, {total} และ {page} จะถูกแทนด้วยตัวเลข ถ้าไม่ตั้ง bar จะใช้คำแปลของตัวเอง เป็นไทยหรืออังกฤษตาม lang ของหน้า ส่วนข้อความว่างจะไม่แสดงอะไร เหมือน Carbon

    disabled ปิดตัวเลือกทั้งสองและปุ่มทั้งสอง เช่น ระหว่างโหลดหน้าถัดไป

    Accessibility

    • ตัวเลือกขนาดหน้ามี label ที่มองเห็นได้ ตัวเลือกหน้ามีชื่อว่า "หมายเลขหน้า" (page-select-label)
    • ปุ่มลูกศรชื่อ "หน้าก่อนหน้า" และ "หน้าถัดไป" (previous-label, next-label) เมื่อถึงหน้าแรกหรือหน้าสุดท้าย ปุ่มที่เพิ่งกดจะปิด และ focus ย้ายไปปุ่มอีกตัวแทนที่จะหลุดไปที่หน้าเว็บ
    • ตัวเลือกเป็น select จริง ปุ่มของ browser และตัวเลือกบนมือถือจึงใช้ได้
    • บอกผู้ใช้ screen reader ว่าแถวเปลี่ยนแล้ว เช่น ด้วยบรรทัดสถานะแบบ polite ("แสดง 21–40 จาก 230")

    ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Pagination

    API

    สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

    <ui-pagination> · React UiPagination

    Attribute

    Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
    page page number 1 1-based current page.
    page-size pageSize number 10
    page-sizes pageSizes string '10,25,50' Choices for the page-size select, e.g. "10,25,50". Empty hides the select.
    total-items totalItems number 0
    pages-unknown pagesUnknown boolean false Total unknown: no page select, next never disabled (Carbon pagesUnknown).
    is-last-page isLastPage boolean false With pages-unknown: this is the last page, so Next is disabled (Carbon isLastPage; cursor-based APIs).
    size size PaginationSize 'md'
    disabled disabled boolean false
    items-per-page-text itemsPerPageText string | undefined
    item-range-text itemRangeText string | undefined
    item-text itemText string | undefined Range text while the total is unknown.
    page-range-text pageRangeText string | undefined
    page-text pageText string | undefined Label of each page option and the page text while unknown.
    page-select-label pageSelectLabel string | undefined
    previous-label previousLabel string | undefined
    next-label nextLabel string | undefined

    Method

    Method คำอธิบาย
    focus(options) Focus the first control that shows (the page-size select; narrow, an arrow).

    Event

    Event React คำอธิบาย
    ui-change onUiChange detail: { page, pageSize } after the user changed either

    CSS part

    Part คำอธิบาย
    base The bar
    page-size-select The items-per-page select
    range The item range text
    page-select The page select
    pages The "of N pages" text
    previous-button Previous page
    next-button Next page

    CSS custom property

    Custom property ค่าเริ่มต้น คำอธิบาย
    --ui-pagination-border / --ui-pagination-background / --ui-pagination-divider - The bar's top rule, fill and the rules between its parts (default hairline, the layer, hairline; Kanok: open, undivided)
    --ui-pagination-gap / --ui-pagination-range-ink - Space within each side and the range text colour (default none, ink)
    --ui-pagination-select-border / --ui-pagination-select-radius / --ui-pagination-button-radius - The selects' outline and corners, the arrows' corners (default none, 0, 0; Kanok: outlined 6px selects, round arrows)
    --ui-focus-offset outline-offset of its focus ring (default -2px: inside; Kanok: 2px outside)
