Button

ปุ่มใช้สั่งให้ทำงานบางอย่าง เช่น บันทึก ส่งฟอร์ม หรือเปิด dialog ถ้าจะไปหน้าอื่น ให้ใส่ href แล้วปุ่มจะกลายเป็นลิงก์จริง

ทุกตัวอย่างด้านล่างมี 3 แบบ: web component (HTML ใช้ได้ทุก framework), wrapper ของ React (@purpurabog/ui/react) และไฟล์ React + Tailwind ที่ copy ด้วย shadcn เลือกแท็บครั้งเดียว ทั้งเว็บจะเปิดแท็บนั้นตาม

ระหว่างที่ข้อมูลของหน้ากำลังโหลด <ui-button-skeleton> จองที่ของปุ่มไว้ เป็นแถบกว้าง 150px สูงตาม size ของปุ่ม screen reader ข้ามแถบนี้ จึงต้องบอกว่า "กำลังโหลด" ที่บริเวณรอบ ๆ แทน (เช่น aria-busy="true")

ลิงก์ที่หน้าตาเป็นปุ่ม

ถ้าใส่ href ปุ่มจะสร้าง <a> และ screen reader จะอ่านว่าเป็นลิงก์ ฝั่ง web component การคลิกปกติจะยิง event ui-navigate ที่ยกเลิกได้ ให้ router ของ SPA จัดการต่อ (ดู ใช้กับ framework) ในตัวอย่างนี้ event ถูกยกเลิกและแสดง href แทน

ส่งฟอร์ม

ใน <form> ปุ่ม type="submit" ส่งฟอร์ม และ type="reset" ล้างฟอร์ม เหมือนปุ่ม native ค่าเริ่มต้นของ type คือ button ปุ่มอื่นจึงไม่ส่งฟอร์มโดยไม่ตั้งใจ ตั้ง loading ระหว่างรอ request ผู้ใช้จะได้ไม่ส่งซ้ำ

Accessibility

  • ข้างในเป็น <button> จริง กด Enter หรือ Space ได้ และ type="submit" / type="reset" ทำงานใน <form>
  • ปุ่มที่มีแต่ไอคอนต้องมีชื่อ: web component ใช้ label (aria-label ที่ตัว element ไปไม่ถึงปุ่มข้างใน) ปุ่ม Tailwind ใช้ aria-label
  • pressed ทำให้เป็นปุ่มกดค้าง (aria-pressed) ส่วน haspopup กับ expanded ใช้กับปุ่มที่เปิดเมนูหรือ dialog
  • ปุ่มชนิด danger ใส่ danger description ได้ ข้อความนี้จะถูกอ่านต่อจากชื่อปุ่ม (เช่น "ลบสัญญาถาวร")
