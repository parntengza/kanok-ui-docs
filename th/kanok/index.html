ดีไซน์ Kanok

Kanok (กนก ตามลายกนกของไทย) คือรูปแบบของไลบรารีเราเอง อยู่คู่กับ Carbon ออกแบบมาสำหรับระบบงานภายในองค์กร: สะอาด สงบ แยกพื้นผิวด้วยสีพื้นแทนเส้น และมีเอกลักษณ์งานช่างไทยในสีกับรายละเอียดหนึ่งอย่างที่ใช้ซ้ำ ทุก component ใช้ HTML, JavaScript และการเข้าถึงได้แบบเดิม ต่างกันแค่ stylesheet

หน้าตา

  • สี สีน้ำเงินสำหรับปุ่มและการกระทำ (#0068d6 โหมดมืดเป็นคราม #5563db) สีชาดสำหรับการลบหรืออันตราย เทาเย็นเกือบเป็นกลางบนพื้นขาว (ธีม paper) และดำครั่งอมม่วง (ธีม lacquer) ทุกสีสร้างด้วยสคริปต์และตรวจ contrast ตาม WCAG 2.2 ทุกครั้งที่ build
  • อยู่ตรงนี้ เส้นสีน้ำเงินบอกแท็บที่เลือก หน้าปัจจุบันใน header และแถวตารางที่เลือก (--ui-border-interactive: สีหลักในธีม paper และครามที่อ่อนลงในธีม lacquer ให้ยังมองเห็นชัด) ส่วน side nav, tree และ vertical tabs ใช้พื้นอ่อนที่แถวที่เลือก ไม่มีแถบ
  • ใช้สีพื้นแทนเส้น การ์ดและ tile ไม่มีเส้นขอบ แยกจากหน้าด้วยพื้นเทาอ่อน ห่างจากพื้นที่วางอยู่หนึ่งขั้นเสมอ รวมใน layer การแจ้งเตือนและ toast ไม่มีแถบสี icon บอกชนิด
  • Focus วงเดียวกันทุกที่: สีน้ำเงินทึบ (ธีม lacquer เป็นครามอ่อน) 2px มุมโค้ง และขึ้นเฉพาะตอนใช้คีย์บอร์ด คลิกปุ่ม checkbox หรือ toggle ไม่มีวง กด Tab ถึงมี (ห่างออกไป 2px และอยู่ด้านในแถวที่ชี้ในเมนู) ช่องกรอก (ช่องพิมพ์ dropdown select) แสดง focus ทุกครั้ง เป็นวงแสงสีฟ้าโปร่ง 4px รอบนอกช่องแบบ Pixiv ไม่มีเส้นทับขอบ ช่องที่ผิดเป็นวงสีแดง (Carbon: 2px เหลี่ยม คลิกก็มี)
  • รูปทรง ปุ่มทรงแคปซูล (pill) ช่องกรอกมุม 6px เป็นพื้นเทาอ่อนไม่มีขอบ (หรือมีขอบ ดูช่องกรอกแบบมีขอบ) 12px ที่การ์ด tile และ dialog (การ์ดตัดรูปตามมุม ปุ่มใน footer ของการ์ดเว้นจากขอบ 8px) 8px ที่เมนู การแจ้งเตือน และ code snippet ส่วนแท็กมุมเล็ก 4px เพื่อไม่ให้สถานะดูเหมือนปุ่ม
  • ไม่มีก้อนสีดำ ปุ่ม secondary เป็นพื้นเทาอ่อนไม่มีกรอบ สิ่งที่ถูกเลือกเป็นสีหลัก ไม่ใช่สีดำ: แท็กที่เลือก tile ที่เลือก slider และป้ายนับของ multi-select
  • ความหนาแน่น ปุ่มและช่องกรอกสูง 40px โดยปกติ (sm 32px lg 48px เท่าช่องกรอกของ Carbon) ปุ่มจึงสูงเท่าช่องที่อยู่ข้างกัน แถวเมนู 32px แถวตาราง 40px ปุ่มขนาดใหญ่ยังเป็นแคปซูล: xl สูง 48px 2xl 56px ข้อความอยู่กลาง (Carbon สูง 64 / 80px ข้อความชิดบน)
  • Select เป็น select ของเบราว์เซอร์เหมือน Carbon เปิดรายการของระบบ และตัวเลือกของมือถือเอง ถ้าต้องการรายการแบบเมนู ใช้ dropdown (หรือตั้ง --ui-select-appearance: base-select สำหรับ customizable select ของ Chrome 135+)
  • ตัวอักษร Bai Jamjuree ทั้งไทยและละติน label และหัวข้อตัวหนาปานกลาง ระยะบรรทัดสูงพอให้สระและวรรณยุกต์ที่ซ้อนกันไม่ชนกัน

วิธีใช้

โหลด kanok.css ต่อจาก tokens.css (ดู ติดตั้ง) แล้วระบุว่าใช้ Kanok ตรงไหน:

<html data-design="kanok" data-theme="paper">

data-design ใส่ที่ element ไหนก็ได้ ไม่จำเป็นต้องเป็น <html> แอปที่ทำงานอยู่ในกรอบของระบบอื่น (portal ที่มีแถบด้านบนและเมนูข้างของตัวเอง) ให้ใส่ที่ element รากของแอปเอง หน้าของ host จะไม่ถูกเปลี่ยน:

<div id="contracts-app" data-design="kanok" data-theme="paper">…</div>

React + Tailwind

component แบบ React + Tailwind อ่านค่าชุดเดียวกัน จึงเป็น Kanok ได้เหมือนกัน คัดลอก kanok.css ไปไว้ข้าง token (npx shadcn@4 add @kanok-ui/kanok) แล้ว import ต่อจาก token:

@import 'tailwindcss'; @import './components/ui/primitives/tokens.css'; @import './components/ui/primitives/kanok.css'; @import './components/ui/react-tw/theme.css';

จากนั้นใส่ data-design แบบด้านบน ถ้าเป็น micro app (React อยู่ใน shadow root) ให้ใส่ data-design และ data-theme ที่ element ที่เป็น host

ช่องกรอกแบบมีขอบ

ช่องกรอกของ Kanok เป็นแบบ filled โดยปกติ คือพื้นเทาอ่อน ไม่มีขอบ ถ้าต้องการแบบมีขอบ เช่นฟอร์มยาวที่ช่องเรียงติดกันเยอะ หรือฟอร์มที่วางบนพื้นเทา (tile, layer) ซึ่งพื้นเทาอ่อนของช่องจะมองยาก ใช้แบบ outlined ได้

วิธีใช้:

  1. เปิด Kanok ตามวิธีใช้ (kanok.css และ data-design="kanok")
  2. ใส่ data-field-variant="outlined" ที่ element ที่ครอบช่องกรอก เช่น <form>, <section> หรือ <html> ถ้าต้องการทั้งแอป ช่องกรอกทุกตัวข้างในจะเปลี่ยนตาม ไม่ต้องตั้งที่ช่องทีละตัว และไม่ต้องเปลี่ยนโค้ดของ component
  3. ใช้ได้เหมือนกันทั้ง web component, React wrapper และ React + Tailwind เพราะเป็นแค่ attribute ของ HTML

ตัวอย่างด้านล่างวางแบบ filled (ซ้าย) กับแบบ outlined (ขวา) ไว้คู่กัน:

สว่างและมืด

Kanok มีสองธีม: paper (สว่าง) และ lacquer (มืด) ส่วน data-theme="auto" ตามการตั้งค่าของระบบ <ui-theme-switcher> และ useThemeMode ใช้ได้เลยโดยไม่ต้องแก้: ในหน้า Kanok ตัวเลือกสว่าง / มืด จะกลายเป็น paper / lacquer ให้เอง ฟังก์ชันหลักอยู่ใน @purpurabog/ui/core:

ฟังก์ชัน ทำอะไร
applyDesign('kanok') ตั้ง data-design ที่ <html> และย้ายธีมไปโหมดเดียวกันใน Kanok
designScript() สคริปต์สำหรับ <head> วาดรูปแบบที่จำไว้ (หรือ ?design= จาก URL) ตั้งแต่เฟรมแรก ใส่ก่อน themeScript()
themeIn('kanok', 'g100') ธีมที่ดีไซน์นั้นใช้กับโหมดนี้: lacquer

ปรับแต่ง

Kanok คือชุดค่าของ CSS custom property สาธารณะ: สี (--ui-primary, --ui-border-interactive, …) และรูปทรง (--ui-button-radius, --ui-field-border, --ui-card-radius, --ui-menu-item-radius, …) เขียนทับค่าไหนก็ได้ในโซนที่ต้องการ ตาม ปรับแต่งหน้าตา รายการค่าของแต่ละ element อยู่ใน API reference ของ element นั้น

สถานะ

Kanok ยังใหม่ component ที่ได้รูปทรง Kanok แล้ว: ปุ่ม ช่องกรอกในฟอร์ม (text input, text area, number, select, search, dropdown, combobox, multi-select, date และ time picker) checkbox, radio, toggle, tag, tabs, tile, card, ตาราง (แถวที่เลือกมีเส้นสีคราม) เมนู การแจ้งเตือน modal ชุดปุ่ม code snippet แท็บแบบ contained (เป็น segmented control) ปฏิทิน แถบ header, side nav, content switcher, pagination, slider, file uploader, tooltip, popover, toggletip, overflow menu, side panel และ tearsheet ส่วน component อื่นได้สี ฟอนต์ และขนาดของ Kanok แล้ว และจะได้รูปทรงในรุ่นถัดไป component แบบ React + Tailwind ก็เป็น Kanok ได้แล้วเช่นกัน
