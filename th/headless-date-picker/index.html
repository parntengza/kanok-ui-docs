Headless Date picker

DatePicker และ Calendar ให้พฤติกรรมของ date picker โดยไม่มี class เลย ชิ้นส่วนเหล่านี้อ่านสิ่งที่ผู้ใช้พิมพ์ (รวมเลขไทย) เปิดปฏิทินเมื่อช่องได้โฟกัส ย้ายโฟกัสระหว่างช่องกับปฏิทิน ตรวจวันที่กับ min, max และ isDateDisabled กันไม่ให้ฟอร์มส่งขณะวันที่ผิด และส่งวันที่แบบ ISO ไปกับฟอร์ม

markup, label, placeholder, ข้อความ error, ไอคอน และ style ทั้งหมดเป็นของคุณ ชิ้นส่วนไม่แสดงข้อความของตัวเองนอกจากชื่อเดือนและชื่อวัน ตัวที่มี style อยู่ที่ Date picker

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Calendar, DatePicker } from '@purpurabog/ui/headless';

Root เรียก onValueChange พร้อมสตริง ISO (yyyy-mm-dd ปี ค.ศ.) ทุกครั้งที่วันที่ที่ยืนยันแล้วเปลี่ยน: ยืนยันตอนออกจากช่องหรือกด Enter (วันที่ที่พิมพ์ครบเป็นค่าทันทีและแจ้งตอนนั้น) เลือกจากปฏิทิน หรือกดล้าง ถ้าใส่ name จะมี hidden input ส่งสตริงเดียวกันไปกับฟอร์ม Calendar.Root ที่อยู่ใน Popup รับ state ของ picker ไปเอง

ภาษา ศักราช และรูปแบบ

Root ใช้ภาษาของหน้า ถ้าไม่ใส่ locale จะใช้ <html lang> หรือภาษาของ browser หน้าภาษาไทยจึงได้ข้อความและชื่อเดือนเป็นภาษาไทย ใส่ locale เพื่อกำหนดเอง เมื่อเป็นภาษาไทย era จะตั้งต้นเป็น be (พ.ศ.) ใส่ era="ce" ถ้าต้องการ ค.ศ. ส่วน format กำหนดลำดับที่ผู้ใช้เห็นและพิมพ์ value ยังเป็น ISO

ปุ่มล้างและปุ่มวันนี้

บนมือถือ (จอสัมผัสที่แคบกว่า 42rem) picker="auto" (ค่าเริ่มต้น) เปิดปฏิทินใน bottom sheet โดย Popup render อยู่ใน modal <dialog data-sheet> (หน้าเว็บด้านหลังเป็น inert และเลื่อนไม่ได้ โฟกัสอยู่ข้างใน) ปิดได้ด้วย Esc ปุ่ม DatePicker.SheetClose การปัดลงที่ DatePicker.SheetGrip หรือแตะที่ฉากหลัง แค่โฟกัสที่ช่องยังไม่เปิด ช่องจึงยังพิมพ์ได้ ปรับหน้าตา dialog ด้วย sheetClassName (ฉากหลังใช้ backdrop:) และกล่องด้านในด้วย data-sheet โดยให้ระยะขอบเว้น env(safe-area-inset-*) ไว้ SheetGrip กับ SheetClose แสดงเฉพาะใน sheet

DatePicker.SheetGrip

render <div> ที่มี touch-action: none เฉพาะใน bottom sheet ปัดลงบนส่วนนี้เพื่อปิด sheet (64px หรือปัดเร็ว ๆ) ถ้าสั้นกว่านั้น sheet เด้งกลับ ระหว่างที่นิ้วลาก dialog มี data-dragging และ translate ใส่ขีดจับกับ SheetClose ไว้ข้างใน

DatePicker.SheetClose

render <button type="button"> เฉพาะใน bottom sheet ปิด sheet เหมือนกด Esc ใส่ aria-label ให้ด้วย

ชิ้นส่วนของ Calendar

Calendar.Root

render <div> เมื่ออยู่ใน DatePicker.Popup จะรับค่า ช่วง โฟกัส ขอบเขต locale และ era จาก picker แต่ prop ที่คุณส่งเองยังชนะ

Prop Type ค่าเริ่มต้น
value string วันที่เลือก ISO แบบ controlled (วันเริ่มในโหมดช่วง)
defaultValue string '' วันที่เลือกตอนแรก (วันเดียว)
endValue string '' วันสิ้นสุดของช่วง
range boolean false
activeField 'start' | 'end' 'start' การเลือกจะตั้งปลายไหน (ใช้กับ preview)
focusDate Date วันที่ถือ tab stop และกำหนดเดือนที่แสดง (controlled)
defaultFocusDate Date ค่า value ถ้าไม่มีคือวันนี้
onFocusDateChange (date: Date) => void
onPick (date: Date) => void ผู้ใช้เลือกวันที่เลือกได้
min, max string ''
isDateDisabled (date: Date) => boolean | string
locale string <html lang> หรือภาษาของ browser locale แบบ BCP 47 สำหรับชื่อเดือนและวัน
era 'be' | 'ce' 'be' เมื่อ locale เป็นไทย นอกนั้น 'ce'
firstDay number 0 0 อาทิตย์ … 6 เสาร์
handle Ref<CalendarHandle> focusDay() ย้ายโฟกัสไปที่วันที่ถือ tab stop
Attribute เมื่อ
data-range range

Calendar.PrevButton, Calendar.NextButton

แต่ละตัว render <button type="button"> ที่แสดงเดือนก่อนหน้าหรือถัดไป และถูกปิดเมื่อทั้งเดือนนั้นอยู่นอก min / max

Calendar.MonthName

render <span aria-hidden="true"> ที่มีชื่อเดือน children ใช้แทนชื่อได้

Calendar.Heading

render <div aria-live="polite"> ที่มีเดือนและปี เป็นชื่อของ grid จึงต้องคงไว้ (ซ่อนจากสายตาได้) children ใช้แทนข้อความได้

Calendar.YearInput

render <input type="number"> ที่มีปีที่แสดงตามศักราชของปฏิทิน พิมพ์ปีครบสี่หลักแล้วปฏิทินไปที่ปีนั้น ออกจากช่องแล้วช่องกลับเป็นปีที่แสดง

Calendar.YearStep

render <button type="button"> ที่มี tabIndex={-1} เลื่อนปีที่แสดง และถูกปิดเมื่อเลยปีที่ min / max อนุญาต

Prop Type ค่าเริ่มต้น
delta number จำนวนปีที่เลื่อน เช่น 1 หรือ -1 (ต้องใส่)

Calendar.Grid

render <table role="grid"> ที่มีชื่อจาก Heading และจัดการปุ่มคีย์บอร์ด

Calendar.GridHeader, Calendar.HeaderCell

GridHeader render <thead> หนึ่งแถว และเรียกฟังก์ชัน children ทีละวันของสัปดาห์ HeaderCell render <th scope="col"> ที่มีชื่อวันแบบสั้น และชื่อเต็มใน abbr

Prop Type ค่าเริ่มต้น
children (GridHeader) (date: Date) => ReactNode render วันหนึ่งของสัปดาห์ (ต้องใส่)
date (HeaderCell) Date วันของสัปดาห์ (ต้องใส่)

Calendar.GridBody, Calendar.Cell

GridBody render <tbody> หกสัปดาห์ และเรียกฟังก์ชัน children ทีละวัน Cell render <td role="gridcell" aria-selected>

Prop Type ค่าเริ่มต้น
children (GridBody) (date: Date) => ReactNode render วันหนึ่ง (ต้องใส่)
date (Cell) Date วันนั้น (ต้องใส่)

Calendar.Day

render <button type="button"> ที่มีเลขวัน (children ใช้แทนได้) วางไว้ใน Cell มีแค่วันที่ถือ tab stop ที่ได้ tabIndex={0}

Attribute เมื่อ
data-selected วันที่เลือก (ปลายใดปลายหนึ่งของช่วง)
data-today วันนี้
data-outside-month วันของเดือนก่อนหรือเดือนถัดไป
data-disabled เลือกไม่ได้: อยู่นอก min / max หรือ isDateDisabled ไม่รับ
data-in-range อยู่ระหว่างวันเริ่มกับวันสิ้นสุดของช่วง (ที่เลือกแล้วหรือกำลัง preview)
data-range-start วันเริ่มของช่วง
data-range-end วันสิ้นสุดของช่วง ที่เลือกแล้วหรือกำลัง preview

Calendar.TodayButton

render <button type="button"> ที่เลือกวันนี้ และถูกปิดเมื่อวันนี้เลือกไม่ได้

Hook

DatePicker.useDatePickerContext() ใน Root ให้ state ของ picker: state (ข้อความ ค่า สถานะเปิด) problems errors (ข้อความตามภาษาของ locale) และ showsError(field) ส่วน Calendar.useCalendarContext() ให้เดือนที่แสดงและชื่อต่าง ๆ และ Calendar.useCellContext() ใน Cell ให้สถานะของวันนั้นเป็นค่า

คีย์บอร์ดและ accessibility

ในช่องพิมพ์:

ปุ่ม ผล
พิมพ์ กรอกวันที่ เลขไทยถูกแปลงเป็น 0–9
↓ เปิดปฏิทินและย้ายโฟกัสเข้าไป
Tab ขณะปฏิทินเปิด: ย้ายเข้าปฏิทิน
Shift + Tab จากช่องวันเริ่ม: ปิดปฏิทิน
Enter ยืนยันข้อความที่พิมพ์และปิดปฏิทิน แล้ว Enter ของฟอร์มก็ส่งฟอร์มต่อ
Esc ปิดปฏิทิน

ใน grid ของปฏิทิน:

ปุ่ม ผล
← / → วันก่อนหน้า / ถัดไป
↑ / ↓ วันเดียวกันของสัปดาห์ก่อน / ถัดไป
Home / End วันแรก / วันสุดท้ายของสัปดาห์
Page Up / Page Down เดือนก่อน / เดือนถัดไป
Shift + Page Up / Page Down ปีก่อน / ปีถัดไป
Enter, Space เลือกวันนั้น ใน picker ปฏิทินจะปิด (โหมดช่วงปิดหลังเลือกวันสิ้นสุด)
Esc ปิด แล้วโฟกัสกลับไปที่ช่องพิมพ์
Tab โหมดช่วงจากช่องวันเริ่ม: ไปช่องวันสิ้นสุด นอกนั้นโฟกัสกลับไปที่ช่อง ปฏิทินปิด แล้ว Tab ไปต่อ
Shift + Tab กลับไปที่ช่องพิมพ์

สิ่งที่ชิ้นส่วนจัดการให้:

  • role="combobox", aria-haspopup="dialog", aria-expanded, aria-controls และ aria-invalid ที่แต่ละช่อง และ role="dialog" ที่ Popup
  • grid ของปุ่มวันที่มี tab stop เดียวแบบ roving แต่ละวันมีชื่อเป็นวันที่เต็ม วันนี้มี aria-current="date" วันที่เลือกมี aria-pressed และวันที่เลือกไม่ได้มี aria-disabled
  • การเปลี่ยนเดือนถูกประกาศผ่าน Heading
  • การตรวจค่าของฟอร์ม: ช่องแรกที่ผิดถือข้อความ ไม่มี bubble ของเบราว์เซอร์ และเมื่อการส่งถูกกัน โฟกัสย้ายไปที่ช่องนั้น

สิ่งที่คุณต้องใส่เอง:

  • <label htmlFor> ของแต่ละช่อง และ aria-label ที่ Popup ("เลือกวันที่"), PrevButton, NextButton, YearInput, YearStep, Clear และ Trigger
  • ข้อความ error และคำอธิบายรูปแบบ ผูกกับช่องด้วย aria-describedby:
