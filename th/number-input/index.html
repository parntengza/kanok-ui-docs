Number input

ช่องกรอกตัวเลข เช่น จำนวน ยอดเงิน หรือเปอร์เซ็นต์ มีปุ่ม − และ + แบบ Carbon อยู่ท้ายช่อง และกด ↑ / ↓ เพื่อเพิ่มลดค่าจากคีย์บอร์ดได้

ระยะเพิ่มลด ค่าต่ำสุด และค่าสูงสุด

step (ค่าเริ่มต้น 1) คือระยะที่ − / + และ ↑ / ↓ เพิ่มหรือลด ค่าจะอยู่ในช่วง min ถึง max เสมอ และปุ่มที่ปลายช่วงจะกดไม่ได้ ถ้าพิมพ์ค่านอกช่วงจะเป็น error

ถ้าช่องว่าง การกดครั้งแรกจะไปที่ step-start-value ถ้าตั้งไว้ ถ้าไม่ได้ตั้งและมีแค่ min จะไปที่ min นอกนั้นไปที่ 1 หรือ −1 แบบ Carbon

ทศนิยม

การเพิ่มลดจะปัดตามจำนวนตำแหน่งทศนิยมของค่าหรือของ step แล้วแต่อันไหนมากกว่า 0.1 + 0.2 จึงได้ 0.3 ไม่ใช่ 0.30000000000000004 ใน type="number" (ค่าเริ่มต้น) step ยังเป็นความละเอียดที่เบราว์เซอร์ยอมรับด้วย ถ้า step="0.01" ค่า 12.345 จะเป็น error

สกุลเงิน หน่วย และรูปแบบตัวเลข

prefix-text และ suffix-text ใส่ข้อความไว้ในช่อง หน้าหรือหลังตัวเลข เช่น ฿, กก., บาท/เดือน ข้อความนี้อยู่ให้เห็นตลอดระหว่างพิมพ์และไม่เป็นส่วนของค่า Carbon ไม่มีสิ่งนี้

ถ้าต้องการช่องจัดรูปแบบแบบ Carbon ให้ตั้ง type="text" คู่กับ format-options ซึ่งรับ option ของ Intl.NumberFormat ได้ทั้งหมด เช่น ตัวคั่นหลักพัน สกุลเงิน เปอร์เซ็นต์ หน่วย ระหว่างพิมพ์ผู้ใช้พิมพ์อะไรก็ได้ แล้วช่องจะจัดรูปแบบให้เมื่อออกจากช่อง ค่ายังคงเป็นตัวเลขธรรมดา: ฿1,234.50 ส่งค่า 1234.5 และรูปแบบเปอร์เซ็นต์ให้ค่าเป็นเศษส่วน (0.5 สำหรับ 50%) locale ใช้ภาษาของหน้า หรือกำหนดด้วย locale

ปุ่มเพิ่มลดและล้อเมาส์

  • hide-steppers เอาปุ่ม − / + ออก แต่ ↑ / ↓ ยังใช้ได้
  • disable-wheel ไม่ให้ล้อเมาส์เปลี่ยนค่าในช่องที่โฟกัสอยู่ ซึ่งเกิดขึ้นง่ายเวลาเลื่อนดูฟอร์มยาว ๆ
  • decrement-label และ increment-label เปลี่ยนชื่อปุ่มที่ screen reader อ่าน (ค่าเริ่มต้นคือ "ลดค่า" และ "เพิ่มค่า" ตามภาษาของหน้า)

ขนาด ข้อความ อ่านอย่างเดียว และปิดใช้งาน

  • helper-text, warn + warn-text และ invalid + invalid-text ทำงานเหมือน text input ค่าที่อยู่นอก min / max จะได้ข้อความของเบราว์เซอร์หรือข้อความในตัว เว้นแต่ตั้ง invalid-text ไว้ ดูเพิ่มที่ ฟอร์มและการตรวจค่า
  • readonly แสดงและส่งค่าไปกับฟอร์ม และปุ่มเพิ่มลดจะกดไม่ได้ ส่วน disabled ทำให้ช่องเป็นสีเทาและไม่ส่งค่า

Skeleton

ระหว่างที่ข้อมูลของฟอร์มกำลังโหลด <ui-number-input-skeleton> จองที่ของช่องไว้ เป็นแถบ label กับแถบช่องสูงตาม size หรือเป็นกล่องแบบ fluid เมื่อใส่ fluid screen reader ข้ามแถบนี้ จึงต้องบอกว่า "กำลังโหลด" ที่ฟอร์มแทน (เช่น aria-busy="true")

คีย์บอร์ด

ปุ่ม ผล
↑ / ↓ เพิ่มหรือลดหนึ่ง step ภายในช่วง min / max
Enter ยืนยันค่าและส่งฟอร์มที่ช่องนี้อยู่

ปุ่ม − / + ไม่อยู่ในลำดับ Tab แบบ Carbon เพราะลูกศรในช่องทำงานเดียวกันได้

Accessibility

  • label เป็น <label> จริงที่ผูกกับ <input> ข้างใน ส่วน prefix, suffix และบรรทัดข้อความใต้ช่องเป็นคำอธิบายของมัน
  • ปุ่ม − / + มีชื่อ ("ลดค่า", "เพิ่มค่า") และกดไม่ได้เมื่อถึงปลายช่วง
  • inputmode="decimal" เปิดคีย์บอร์ดที่มีจุดทศนิยมบนมือถือ

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Number input

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)
