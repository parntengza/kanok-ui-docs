Headless UI shell

namespace สามตัวให้พฤติกรรมเดียวกับ UI shell แบบมี style แต่ไม่มี style เลย:

  • Shell: Shell.Root เก็บว่าเมนูด้านข้างเปิดอยู่หรือไม่ ปุ่ม hamburger กับเมนูด้านข้างจึงต่อสายกันเอง ส่วน Shell.Content คือ <main> ที่บอกว่าเมนูด้านข้างข้าง ๆ วางตัวแบบไหน
  • Header: <header> ลิงก์ข้ามไปยังเนื้อหา ปุ่ม hamburger เมนูลิงก์ที่เปิดปิดได้ ปุ่มไอคอน และ panel ใต้ header พร้อม Esc การคลิกข้างนอก และการคืนโฟกัส
  • SideNav: <nav> พร้อมโหมดต่าง ๆ (ปกติ rail fixed collapsible) พื้นหลังมืด ลิงก์และเมนูย่อย พร้อม Esc และการโฟกัสออก

ส่วนที่คุณทำเองคือหน้าตาและตำแหน่งของทุก element: แถบสูง 48px เมนูกว้าง 256px การเยื้องเนื้อหา ไอคอน และข้อความ part ต่าง ๆ บอกสถานะผ่าน attribute data-* ให้คุณใช้ใส่ style

ตัวอย่างอยู่ในกล่องที่มี transform ซึ่งเก็บส่วนที่เป็น position: fixed ไว้ในกล่อง และลิงก์ในตัวอย่างแค่เปลี่ยน state ของตัวอย่าง คลิกจึงไม่พาออกจากหน้านี้ ในแอปของคุณ header และเมนูจะติดกับหน้าต่าง

คำสั่งส่วนกลางและ panel

Header.GlobalAction เป็นปุ่มไอคอนสองแบบ: มี active จะเป็น toggle (aria-pressed) มี expanded จะเป็น disclosure (aria-expanded) สำหรับ panel Header.Panel เป็นแบบ controlled: ขอปิดผ่าน onClose(reason) เมื่อกด Esc (คืนโฟกัสให้สิ่งที่เปิด) เมื่อโฟกัสออก หรือเมื่อกดข้างนอก แต่ไม่นับปุ่มที่มี aria-controls ตรงกับ id ของ panel ซึ่งเป็นตัวเปิดปิด

PanelContent เป็น <section> เมื่อตั้งชื่อด้วย aria-label จะเป็น region landmark และมี hidden ขณะ panel ปิดอยู่

โหมดของเมนูด้านข้าง

SideNav.Root รับโหมด Nav เขียนโหมดไว้ใน data-ui-side-nav และ Shell.Content คัดลอกไปไว้ใน data-side-nav ของตัวเอง ให้คุณใช้เยื้องหน้า:

  • ปกติ: ทับหน้าเมื่อต่ำกว่า lg อยู่ข้างหน้าตั้งแต่ lg (data-open ตั้งแต่ 1056px)
  • rail: แถบไอคอนที่เป็น data-open เมื่อเมาส์อยู่บนแถบหรือโฟกัสอยู่ข้างใน (มี data-expanded ด้วย)
  • fixed: เป็น data-open ตลอด ไม่มีพื้นหลังมืด
  • collapsible: ปิดอยู่ทุกความกว้างหน้าจอ จนปุ่ม hamburger เปิดทับหน้า

ถ้าไม่ใส่ sideNav Content จะหา [data-ui-side-nav] ตัวแรกใน document (และใน shadow root ของตัวเอง) หลังทุก render หน้าที่มี shell เดียวแบบแอปทั่วไปไม่ต้องใส่ prop นี้ แต่หน้านี้มีหลายอัน ตัวอย่างหลังจากตัวแรกจึงบอกโหมดเอง

Parts

Shell.Root

ไม่ render element ของตัวเอง มีแต่ children เก็บสถานะเปิดปิดของเมนูด้านข้างให้ Header.MenuButton และ SideNav.Root ที่อยู่ข้างใน

Prop Type Default
sideNavExpanded boolean เมนูด้านข้างเปิดอยู่ (controlled)
defaultSideNavExpanded boolean false เปิดตั้งแต่ render ครั้งแรก (uncontrolled)
onSideNavExpandedChange (expanded: boolean) => void ปุ่ม hamburger, Esc, พื้นหลังมืด หรือการโฟกัสออกขอสถานะนี้

Shell.useShellContext() คืน { sideNavExpanded, setSideNavExpanded, sideNavId } หรือ null เมื่ออยู่นอก Shell.Root

Shell.Content

<main> ที่มี id main-content (เป้าหมายเริ่มต้นของลิงก์ข้ามไปยังเนื้อหา)

Prop Type Default
sideNav 'default' | 'rail' | 'fixed' | 'collapsible' | 'none' หาจากหน้า เมนูด้านข้างข้าง ๆ วางตัวแบบไหน
id string 'main-content' เป้าหมายของลิงก์ข้ามไปยังเนื้อหา
Attribute เมื่อ
data-side-nav โหมด: sideNav ไม่อย่างนั้นใช้ [data-ui-side-nav] ตัวแรกใน document (หรือใน shadow root ของตัวเอง) ไม่อย่างนั้นเป็น none

Header.Root

<header> เป็น banner landmark ให้ตั้งชื่อด้วย aria-label ตั้ง data-ui-header ซึ่ง toaster ใช้เพื่อเริ่มแสดงใต้ header ไม่มี prop ของตัวเอง

Header.SkipToContent

<a> ที่พาไปยังเนื้อหา ซ่อนไว้จนได้รับโฟกัส ภายใน shadow root (micro app) การคลิกจะย้ายโฟกัสไปที่เป้าหมายเอง เพราะ browser หาเป้าหมายในนั้นไม่เจอ

Prop Type Default
href string '#main-content' id ของเนื้อหาแบบ fragment

Header.MenuButton

<button type="button"> ที่มี aria-expanded และ aria-controls (id ของเมนูด้านข้างจาก Shell.Root ถ้าคุณไม่ได้ใส่เอง) ตั้งชื่อด้วย aria-label จะเปลี่ยนตามสถานะก็ได้ ("เปิดเมนู" / "ปิดเมนู")

Prop Type Default
active boolean สถานะของ shell ไม่อย่างนั้น false เมนูด้านข้างที่ปุ่มควบคุมเปิดอยู่
onToggle (active: boolean) => void ผู้ใช้ขอสถานะตรงข้าม
Attribute เมื่อ
data-active เมนูด้านข้างเปิดอยู่

Header.Menu

<li> ที่มี MenuTrigger และ MenuPopup

Prop Type Default
open boolean เปิดอยู่ (controlled)
defaultOpen boolean false เปิดตั้งแต่ render ครั้งแรก
onOpenChange (open: boolean) => void ผู้ใช้เปิดหรือปิด
current boolean false แสดงเครื่องหมายหมวดปัจจุบันแม้เมนูเปิดอยู่ (isActive ของ Carbon)
Attribute เมื่อ
data-open เปิดอยู่
data-current ตั้ง current หรือปิดอยู่และมีรายการข้างในเป็น current

Header.useMenuContext() คืนสถานะของเมนู Header.useOptionalMenuContext() คืนสถานะนั้นหรือ null เมื่ออยู่ในแถบเมนู

Header.MenuTrigger

<button type="button"> ที่มี aria-expanded aria-controls (popup ของตัวเอง) และ tabindex="0" (Safari จึงโฟกัสเมื่อคลิก และ Tab ไปถึง) มี data-open และ data-current เหมือนเมนูของตัวเอง

Header.MenuPopup

<ul> ที่มี id ของเมนู ตั้งชื่อด้วย aria-label (ข้อความของหัวเมนู) และซ่อนเมื่อไม่มี data-open

Attribute เมื่อ
data-open เมนูเปิดอยู่

Header.MenuItem

<a> ของแถบเมนูหรือของเมนู ถ้าอยู่ในเมนู การไปตามลิงก์จะปิดเมนูและโฟกัสที่หัวเมนู คง target และ rel ไว้

Prop Type Default
current boolean false หน้าปัจจุบัน (aria-current="page")
Attribute เมื่อ
data-current ตั้ง current

Header.GlobalAction

<button type="button"> ที่มี tabindex="0" ตั้งชื่อด้วย aria-label (หรือ tooltip ที่เป็น label)

Prop Type Default
active boolean false ถูกกดค้าง: เป็น toggle (aria-pressed)
expanded boolean panel ของปุ่มเปิดอยู่: เป็น disclosure (aria-expanded) ใช้คู่กับ aria-controls = id ของ panel
Attribute เมื่อ
data-active ถูกกดค้าง หรือ panel ของปุ่มเปิดอยู่

Header.Panel

<div>: panel ใต้ header ให้มี id ตามที่ aria-controls ของปุ่มระบุ

Prop Type Default
expanded boolean เปิดอยู่ (ต้องใส่, controlled)
onClose (reason: 'escape' | 'blur' | 'outside') => void ขอปิด: Esc (คืนโฟกัสให้สิ่งที่เปิด) โฟกัสออก หรือกดข้างนอก (ไม่นับปุ่มของ panel)
Attribute เมื่อ
data-open เปิดอยู่

Header.PanelContent

<section> ภายใน panel มี hidden ขณะ panel ปิดอยู่ ตั้งชื่อ (aria-label) เพื่อให้เป็น region landmark

Attribute เมื่อ
data-open panel เปิดอยู่

SideNav.Root

ไม่ render element ของตัวเอง มีแต่ children เก็บสถานะเปิดปิด hover และ breakpoint

Prop Type Default
expanded boolean สถานะของ shell ไม่อย่างนั้น false เปิดอยู่ (controlled)
onToggle (expanded: boolean) => void Esc, พื้นหลังมืด หรือการโฟกัสออกขอสถานะนี้
rail boolean false แถบไอคอนที่เปิดเมื่อ hover / โฟกัส
fixed boolean false เปิดอยู่ข้างหน้าตลอด
collapsible boolean false ปิดอยู่ทุกความกว้างหน้าจอจนถูกเปิดทับหน้า

SideNav.useSideNavContext() คืน { expanded, hoverOpen, open, hidden, mode, rail, fixed, collapsible, large, … }

SideNav.Overlay

<div aria-hidden="true"> ที่ทับหน้าขณะเมนูเปิดอยู่ คลิกที่นี่จะขอปิด ให้แสดงเฉพาะเมื่อต่ำกว่า lg

Attribute เมื่อ
data-open เมนูเปิดอยู่และไม่ได้เป็น fixed

SideNav.Nav

<nav tabindex="-1"> ตั้งชื่อด้วย aria-label id เป็น id ของเมนูด้านข้างจาก shell ถ้าคุณไม่ได้ใส่เอง hover และโฟกัสเปิด rail Esc ขอปิดและคืนโฟกัสให้สิ่งที่เปิด เมื่อทับหน้าอยู่ (ต่ำกว่า lg หรือ collapsible) โฟกัสออกจะขอปิด เมื่อไม่ได้แสดงและไม่ใช่ rail จะเป็น inert

Attribute เมื่อ
data-ui-side-nav โหมด: default, rail, fixed หรือ collapsible
data-open แสดงเต็มความกว้าง: ถูกเปิด rail ที่ถูก hover, fixed หรือแบบปกติตั้งแต่ lg
data-expanded ถูกขอให้เปิด หรือ rail ที่เมาส์อยู่บนแถบหรือโฟกัสอยู่ข้างใน
data-collapsed ซ่อนอยู่และเป็น inert

SideNav.Link

<a> ที่ออกจากลำดับ Tab ขณะเมนูซ่อนอยู่ คง target และ rel ไว้

Prop Type Default
current boolean false หน้าปัจจุบัน (aria-current="page")
Attribute เมื่อ
data-current ตั้ง current

SideNav.Menu, MenuTrigger, MenuPopup, MenuItem

Menu คือ <li> MenuTrigger คือ <button type="button"> ที่มี aria-expanded และ aria-controls MenuPopup คือ <ul> ที่ต้องซ่อนเมื่อไม่มี data-open และ MenuItem คือ <a> ที่มี current (aria-current="page", data-current)

Prop ของ Menu Type Default
expanded boolean เปิดอยู่ (controlled)
defaultExpanded boolean false เปิดตั้งแต่ render ครั้งแรก
onExpandedChange (expanded: boolean) => void ผู้ใช้เปิดหรือปิด
Attribute ที่ เมื่อ
data-open Menu, MenuTrigger, MenuPopup เมนูเปิดอยู่
data-current Menu, MenuTrigger มีรายการข้างในเป็น current (ทั้งตอนเปิดและปิด)

SideNav.useMenuContext() คืน { expanded, current, menuId, toggle }
