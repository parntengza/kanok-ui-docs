Select, Dropdown, Combobox หรือ MultiSelect?

Component ใช้เมื่อ
Select ช่องในฟอร์มธรรมดา browser เป็นคนวาดรายการ มือถือเปิดตัวเลือกแบบ native และ screen reader คุ้นเคยที่สุด
Dropdown อยากให้รายการหน้าตาเหมือนกันทุก browser หรือรายการต้องมีบรรทัดที่สอง
Combobox รายการยาวจนพิมพ์หาเร็วกว่าเลื่อนหา รายการมาจากการค้นหาบน server หรือยอมให้พิมพ์ค่าเองได้
Multi-select ผู้ใช้เลือกได้หลายค่า

รายการ กลุ่ม และคำอธิบาย

web component รับ children เป็น <option value> แบบเดียวกับ Select

  • <optgroup label> สร้างกลุ่มที่มีหัวข้อในรายการ
  • data-description ที่ option เพิ่มบรรทัดที่สองใต้ชื่อรายการ การพิมพ์เพื่อกระโดดไปหารายการจะค้นเฉพาะชื่อ
  • disabled ยังแสดงรายการอยู่แต่ข้ามไป

React + Tailwind รับข้อมูลชุดเดียวกันผ่าน items รายการเป็น { value, label, description?, disabled? } และกลุ่มเป็น { label, options }

โหลดรายการตอนเปิดรายการ

loading แสดงแถว "กำลังโหลด…" แถวเดียวแทนรายการ และปุ่มต่าง ๆ จะเลือกอะไรไม่ได้ ใช้คู่กับ event ที่ยิงหลังรายการเปิดหรือปิด เพื่อดึงรายการครั้งแรกที่มีคนเปิด ลองเปิดรายการด้านล่าง รายชื่อจะมาหลังจากหนึ่งวินาที

loadOwners, load และ owners เหมือนกันในทุกแบบของ React

อ่านอย่างเดียวและปิดใช้งาน

  • readonly (readOnly ใน React + Tailwind) แสดงค่าและส่งค่าไปกับฟอร์ม แต่เปิดรายการไม่ได้
  • disabled ทำให้ช่องเป็นสีเทาและไม่ถูกส่งไปกับฟอร์ม

บังคับเลือกในฟอร์ม

dropdown ที่ required แล้วยังว่างจะบล็อกการส่งฟอร์ม และมีข้อความในตัวทั้งภาษาไทยและอังกฤษ ใส่ invalid-text เพื่อเปลี่ยนข้อความ error จะรอจนผู้ใช้ออกจากช่องหรือกดส่ง ลองกดส่งโดยยังไม่เลือกเพื่อดู

Skeleton

ระหว่างโหลดรายการ ให้แสดง ui-dropdown-skeleton แทนช่อง เป็นแถบ label กับแถบช่องที่ size เดียวกัน skeleton ถูกซ่อนจาก screen reader จึงต้องบอกว่ากำลังโหลดที่ container เช่น aria-busy

Accessibility

  • ทำตาม pattern select-only combobox ของ WAI-ARIA ช่องเป็นปุ่มที่มี role="combobox" รายการเป็น listbox โฟกัสอยู่ที่ช่องตลอด และรายการที่ไฮไลต์ถูกอ่านผ่าน aria-activedescendant
  • ช่องนี้กด Tab ไปถึงได้ทุก browser รวมถึง Safari
  • loading ทำให้รายการอยู่ในสถานะ busy และประกาศว่า "กำลังโหลด…"
  • ใช้ hide-label เฉพาะเมื่อบริบทรอบ ๆ บอกอยู่แล้วว่าช่องนี้คืออะไร label จะยังอยู่ให้ screen reader อ่าน

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Dropdown
