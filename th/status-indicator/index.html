Status indicator

Status indicator แสดงสถานะของสิ่งหนึ่งด้วยไอคอนสีเล็ก ๆ กับ label เช่น งานที่สำเร็จแล้ว หรือระดับความรุนแรงของเหตุขัดข้อง <ui-icon-indicator> ใช้ไอคอนสถานะของ Carbon ส่วน <ui-shape-indicator> ใช้รูปทรงง่าย ๆ สำหรับระดับความรุนแรงและสถานะ ทั้งสองตาม status indicator ของ Carbon ซึ่ง Carbon ยังติดป้าย preview อยู่

ไอคอนหรือรูปทรง?

  • Icon indicator: สถานะของกระบวนการหรือรายการ เช่น การชำระเงิน การนำเข้าข้อมูล หรือเซิร์ฟเวอร์
  • Shape indicator: ระดับ เช่น ความรุนแรงของเหตุขัดข้องหรือความเสี่ยง และสถานะบางแบบ (stable, draft, incomplete)
  • ถ้าเป็นป้ายที่ผู้ใช้คลิกหรือลบได้ ให้ใช้ Tag แทน

แต่ละ kind มีไอคอนและสีของตัวเอง สถานะจึงไม่ได้ขึ้นกับสีอย่างเดียว เขียน label เสมอ

Accessibility

  • ไอคอนหรือรูปทรงถูกซ่อนจาก screen reader label เป็นตัวบอกสถานะ เขียนเป็นสถานะ ("ลงนามแล้ว") ไม่ใช่สี
  • แบบย่อ: ไอคอนเป็นปุ่มที่เปิด definition tooltip ที่มี label และ screen reader อ่าน label หรือคำอธิบาย
  • การเปลี่ยนสถานะไม่ถูกประกาศเอง ให้เพิ่มข้อความสถานะเมื่อสำคัญ

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-icon-indicator> · React UiIconIndicator

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
align Carbon's name for placement (same values)
kind kind IconIndicatorKind | undefined
label label string ''
size size 16 | 20 16 16 (body-compact-01) or 20 (body-compact-02).
compact compact boolean false Only the icon; the label in a tooltip.
icon-description iconDescription string | undefined Read by screen readers in compact mode instead of the label.
placement placement Placement 'right' Where the compact tooltip opens.

CSS part

Part คำอธิบาย
icon The icon
label The label (not compact)

<ui-shape-indicator> · React UiShapeIndicator

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
align Carbon's name for placement (same values)
kind kind ShapeIndicatorKind | undefined
label label string ''
text-size textSize 12 | 14 12 12 (helper-text-01) or 14 (body-compact-01).
compact compact boolean false Only the shape; the label in a tooltip.
shape-description shapeDescription string | undefined Read by screen readers in compact mode instead of the label.
placement placement Placement 'right' Where the compact tooltip opens.

CSS part

Part คำอธิบาย

label The label (not compact)
