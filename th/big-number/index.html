Big number

Big number แสดงตัวเลขสำคัญตัวเดียวขนาดใหญ่ ใต้ label เล็ก ๆ เช่น จำนวนสัญญาที่ใช้งานอยู่ ยอดใช้จ่าย หรือ uptime (BigNumber ของ Carbon for IBM Products) ย่อเลขยาว ๆ ให้สั้น ("12.3K") แสดงค่าเทียบกับยอดรวม ("12.3K/50.0K") แสดงเป็นเปอร์เซ็นต์ และมีลูกศรขึ้นบอกแนวโน้มที่เพิ่มขึ้นได้

กำลังโหลดและ skeleton

ระหว่างโหลดตัวเลข ให้ใส่ loading element จะแสดง skeleton ของตัวเองที่ size เดียวกัน ui-big-number-skeleton คือ skeleton อย่างเดียว สำหรับ layout ที่วาดก่อนมีข้อมูล ทั้งคู่ซ่อนจาก screen reader จึงต้องบอกว่า "กำลังโหลด" ที่กล่องที่ครอบ (เช่น aria-busy)

HTMLReactReact + Tailwind<div style="display: flex; flex-wrap: wrap; gap: 48px; align-items: flex-start"> <ui-big-number id="big-number-loading" label="สัญญาที่ใช้งานอยู่" value="12345" loading></ui-big-number> <ui-big-number-skeleton size="lg"></ui-big-number-skeleton> <ui-big-number-skeleton size="xl"></ui-big-number-skeleton> </div> <ui-toggle id="big-number-loading-toggle" label="กำลังโหลด" checked></ui-toggle> <script type="module"> const figure = document.getElementById('big-number-loading'); document.getElementById('big-number-loading-toggle').addEventListener('change', (event) => { figure.loading = event.target.checked; }); </script> const [loading, setLoading] = useState(true); <UiBigNumber label="สัญญาที่ใช้งานอยู่" value={12345} loading={loading} /> <UiBigNumberSkeleton size="lg" /> <UiBigNumberSkeleton size="xl" /> import { BigNumber, BigNumberSkeleton } from '@/components/ui/react-tw/big-number'; const [loading, setLoading] = useState(true); <BigNumber label="สัญญาที่ใช้งานอยู่" value={12345} loading={loading} /> <BigNumberSkeleton size="lg" /> <BigNumberSkeleton size="xl" />

ใน web component import skeleton จาก @purpurabog/ui/big-number-skeleton ส่วน <ui-big-number> โหลดให้เอง

Accessibility

  • big number เป็น <figure> ที่มี label เป็น <figcaption> label จึงเป็นชื่อของ figure
  • screen reader อ่านเลขที่ย่อแล้ว: "12.3K" ถ้าเลขที่แน่นอนสำคัญ ใช้ truncate="false" หรือเขียนไว้ในข้อความใกล้ ๆ
  • ลูกศรแนวโน้มซ่อนจาก screen reader ให้บอกความหมายเป็นคำ
  • ปุ่มข้อมูลของ tooltip-description เป็นปุ่มจริง Tab ไปถึงได้

API

สร้างจากแพ็กเกจโดยตรง ใน React ส่ง property เป็น prop ชื่อเดียวกัน ส่วน event ก็เป็น prop เช่นกัน (ดูคอลัมน์ React)

<ui-big-number> · React UiBigNumber

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
value value number | undefined The value (the numerator of a fraction).
total total number | undefined The total after the slash; shown only when larger than value and different once abbreviated.
label label string '' The label above the value.
locale locale string '' How the numbers are written (Intl locale); en-US when empty or invalid.
fraction-digits fractionDigits number 1 Fraction digits of an abbreviated number.
truncate truncate boolean true Abbreviate the numbers (12,345 → 12.3K); truncate="false" writes them in full.
percentage percentage boolean false Add "%" after the value; the total never shows.
trending trending boolean false An up arrow before the value.
force-show-total forceShowTotal boolean false Show the total even when it would be hidden ("Unknown" without one).
tooltip-description tooltipDescription string '' Text of an info button after the label, shown in a tooltip.
size size BigNumberSize 'default'
loading loading boolean false Show the skeleton instead.

Slot

Slot คำอธิบาย
label Replaces the label text (e.g. with your own info toggletip)
trending-icon Replaces the up arrow of trending
icon-button An icon button after the value

CSS part

Part คำอธิบาย
figure The figure
label The label
value The value
total The "/total"
info The info button of tooltip-description
