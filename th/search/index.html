ใช้ในฟอร์ม

  • ใส่ name แล้วช่องจะส่งค่าเหมือน <input type="search"> กด Enter แล้วฟอร์มที่ช่องอยู่จะถูกส่ง
  • required, pattern, minlength และ maxlength ทำงานเหมือน search input ปกติ ช่องค้นหาของ Carbon ไม่มีบรรทัด error ถ้าไม่ผ่านการตรวจจึงขึ้นเป็น bubble ของเบราว์เซอร์
  • readonly คงข้อความไว้และซ่อนปุ่มล้าง ส่วน disabled ทำให้ช่องเป็นสีเทา
  • fluid หรือการครอบด้วยฟอร์มแบบ fluid แสดง label ในกล่องสูง 64px (FluidSearch ของ Carbon)

Accessibility

  • เป็น landmark role="search" ที่ใช้ label เป็นชื่อ ผู้ใช้ screen reader จึงกระโดดมาที่ช่องนี้ได้
  • label ถูกซ่อนจากจอแบบ Carbon แต่ช่องและ landmark ยังใช้ label เป็นชื่อ aria-label ที่ตัว element ไปไม่ถึง input ข้างใน ให้ใช้ label แทน
  • กดปุ่มล้างแล้วโฟกัสยังอยู่ในช่อง ผู้ใช้คีย์บอร์ดพิมพ์ต่อได้ทันที

Part คำอธิบาย

magnifier The search icon
clear-button The clear button

CSS custom property

Custom property ค่าเริ่มต้น คำอธิบาย
--ui-field-border Border on every side of the box (default none: Carbon's underline only; Kanok: a 1px outline)
--ui-field-disabled-border-color Border colour when disabled (default: the underline transparent)
--ui-field-readonly-border-color Border colour when read-only (default: a hairline underline)
--ui-field-radius Corner radius of the box (default 0; Kanok: 6px)
--ui-field-background Fill of the box (default --ui-surface-1; Kanok: transparent)
--ui-label-font Font of the label (default --ui-font-caption; Kanok: 14px semibold)
--ui-label-color Colour of the label (default --ui-ink-muted; Kanok: --ui-ink)
--ui-icon-control-radius Corners of its small icon buttons, their hover fill and ring (default 0; Kanok: round)
