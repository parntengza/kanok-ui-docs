Radio button

Radio ต้องอยู่ในกลุ่มเสมอ กลุ่มเป็นตัวเก็บ label, name และค่า และส่ง value ของตัวเลือกที่ติ๊กไว้ไปกับฟอร์ม ถ้ามีมากกว่าห้าตัวเลือกหรือที่ไม่พอ ให้ใช้ Select หรือ Dropdown

ค่าเริ่มต้นและการเปลี่ยนค่า

value ของกลุ่มคือตัวเลือกที่ติ๊กไว้ ถ้าไม่มี <ui-radio checked> จะเป็นค่าเริ่มต้น ถ้าไม่มีทั้งสองอย่างก็ไม่มีตัวไหนถูกติ๊ก การ reset จะกลับไปที่ค่าเริ่มต้น event change ยิงที่กลุ่มเมื่อผู้ใช้เลือกตัวเลือกอื่น

ตัวเลือกที่ปิดใช้งาน อ่านอย่างเดียว และปิดใช้งาน

  • disabled ที่ radio ตัวเดียวจะข้ามตัวนั้น ถ้าใส่ที่กลุ่มจะปิดทุกตัวเลือกและกลุ่มไม่ถูกส่งไปกับฟอร์ม

Skeleton

คีย์บอร์ด

ปุ่ม ทำอะไร
Tab เข้ากลุ่มที่ตัวเลือกที่ติ๊กไว้ (ถ้าไม่มีก็ตัวแรก) และออกจากกลุ่มเมื่อกด Tab อีกครั้ง
↓ / → ย้ายไปตัวเลือกถัดไปและติ๊ก วนจากตัวสุดท้ายกลับไปตัวแรก
↑ / ← ย้ายไปตัวเลือกก่อนหน้าและติ๊ก วนจากตัวแรกไปตัวสุดท้าย
Space ติ๊กตัวเลือกที่โฟกัสอยู่

Accessibility

  • กลุ่มเป็น role="radiogroup" ที่ใช้ label เป็นชื่อ และมีจุดหยุดของ Tab จุดเดียวตาม pattern radio group ของ WAI-ARIA ตัวเลือกที่ปิดใช้งานจะถูกข้าม
  • ข้อความช่วยเหลือ คำเตือน หรือ error ของกลุ่มเป็นคำอธิบายของกลุ่ม และ radio แต่ละตัวทวน error ซ้ำ screen reader จึงได้ยินที่ตัวเลือกที่ไปถึง
  • ใช้ hide-label เฉพาะเมื่อบริบทรอบ ๆ บอกอยู่แล้วว่ากลุ่มนี้คืออะไร label จะยังอยู่ให้ screen reader อ่าน

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Radio button
