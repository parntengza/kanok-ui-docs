Accessibility

  • เส้นทางเป็น landmark <nav> ชื่อ "เส้นทางหน้า" (หรือ label) ที่มีรายการแบบมีลำดับ screen reader จึงบอกได้ว่ามีกี่ชั้น
  • หน้าปัจจุบันเป็นข้อความที่มี aria-current="page" ไม่ใช่ลิงก์ไปหาตัวเอง
  • / วาดด้วย CSS จึงไม่ถูกอ่านออกเสียง
  • ลิงก์แต่ละตัวรับ Tab ได้ ในเส้นทางที่ย่อ ปุ่ม "…" ก็รับ Tab อีกหนึ่งจุด และเมนูของมันแสดงรายการที่ถูกซ่อน
