Headless Truncated text

TruncatedText คือพฤติกรรมของ Truncated text แบบมี style ในรูป React part ที่ไม่มี style Root วัดว่าข้อความใน Content ถูกตัดที่ lines บรรทัดหรือไม่ (วัดใหม่ทุกครั้งที่ขนาดกล่องหรือข้อความเปลี่ยน) และ Toggle ("ดูเพิ่มเติม / ดูน้อยลง") เปิดส่วนที่เหลือพร้อม animation ความสูงสั้น ๆ Content ได้ตัวแปร CSS สำหรับตัดบรรทัด และสถานะแสดงเป็น attribute data-*

ส่วนที่คุณทำเองคือการตัดบรรทัด (class เดียว) จุดไข่ปลา tooltip ของข้อความที่ถูกตัด ข้อความบนปุ่ม และ style ทั้งหมด

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { TruncatedText } from '@purpurabog/ui/headless';

วิธีใช้

import { TruncatedText } from '@purpurabog/ui/headless'; const note = 'ฝ่ายการเงินขอแก้สองจุดก่อนลงนาม: ระยะเวลาชำระเงินควรเป็น 30 วันหลังส่งของแทน 15 วัน และการทบทวนราคาหลังหกเดือนต้องปรับขึ้นได้ไม่เกิน 5% ฝ่ายกฎหมายไม่มีความเห็นเพิ่ม'; function ToggleText() { const { expanded } = TruncatedText.useTruncatedTextContext(); return <>{expanded ? 'ดูน้อยลง' : 'ดูเพิ่มเติม'}</>; } export default function Example() { return ( <TruncatedText.Root value={note} lines={2} className="w-80 max-w-full text-sm text-ink"> <TruncatedText.Content className="overflow-hidden line-clamp-(--truncated-text-lines)" /> <TruncatedText.Toggle className="cursor-pointer border-0 bg-transparent px-0.5 text-link hover:text-link-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> <ToggleText /> </TruncatedText.Toggle> </TruncatedText.Root> ); }

Content ตั้ง --truncated-text-lines เป็นจำนวนบรรทัดที่แสดง หรือ none ตอนเปิดอ่าน line-clamp-(--truncated-text-lines) ของ Tailwind แปลงค่านี้เป็นการตัดบรรทัดพร้อมจุดไข่ปลา

โครงสร้าง

<TruncatedText.Root value="…"> <TruncatedText.Content /> <TruncatedText.Toggle /> </TruncatedText.Root>

ข้อความเต็มใน tooltip

อีกทางเลือกของ Carbon: ไม่มีปุ่มเปิด แต่แสดงข้อความเต็มใน tooltip เมื่อถูกตัด อ่าน overflowing จาก context แล้วครอบข้อความด้วยปุ่มกับ Tooltip แบบ headless เฉพาะตอนนั้น label ของ tooltip ตั้งชื่อปุ่มเป็นข้อความเต็ม

import { TruncatedText, Tooltip } from '@purpurabog/ui/headless'; function Text() { const { value, overflowing } = TruncatedText.useTruncatedTextContext(); const content = <TruncatedText.Content className="overflow-hidden line-clamp-(--truncated-text-lines)" />; if (!overflowing) return content; return ( <Tooltip.Root label={value}> <Tooltip.Trigger className="block"> <button type="button" className="block w-full cursor-default border-0 bg-transparent p-0 text-start [font:inherit] text-inherit focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> {content} </button> </Tooltip.Trigger> <Tooltip.Popup className="w-max max-w-72 rounded-xs bg-inverse-surface-1 px-4 py-0.5 text-sm text-inverse-ink">{value}</Tooltip.Popup> </Tooltip.Root> ); } export default function Example() { return ( <div className="grid w-60 max-w-full gap-3 text-sm text-ink"> <TruncatedText.Root value="CT-2026-0141: ทำความสะอาด" lines={1}> <Text /> </TruncatedText.Root> <TruncatedText.Root value="CT-2026-0142: วัสดุสำนักงานสำหรับสำนักงานใหญ่และสาขาภูมิภาคสามแห่ง" lines={1}> <Text /> </TruncatedText.Root> </div> ); }

จำนวนบรรทัด

lines (2) คือจำนวนบรรทัดที่แสดงก่อนตัด ถ้าเป็น 0 จะแสดงทั้งหมดและไม่นับว่าถูกตัด ข้อความที่พอดีจะไม่ overflowing และ Toggle ไม่ render อะไร

import { TruncatedText } from '@purpurabog/ui/headless'; const scope = 'จัดซื้อกระดาษ A4 หมึกพิมพ์ และเครื่องเขียนสำหรับสำนักงานใหญ่และสาขาภูมิภาคทั้งสามแห่ง ส่งของทุกเดือนตั้งแต่มกราคมถึงธันวาคม 2569 และทบทวนราคาหลังหกเดือน'; function Status() { const { overflowing } = TruncatedText.useTruncatedTextContext(); return <p className="text-xs text-ink-muted">{overflowing ? 'ถูกตัด' : 'พอดี'}</p>; } export default function Example() { return ( <div className="grid w-80 max-w-full gap-4 text-sm text-ink"> {[1, 3, 0].map((lines) => ( <TruncatedText.Root key={lines} value={scope} lines={lines}> <TruncatedText.Content className="overflow-hidden line-clamp-(--truncated-text-lines)" /> <Status /> </TruncatedText.Root> ))} </div> ); }

เก็บสถานะเปิดเอง

expanded คู่กับ onExpandedChange ใช้เก็บสถานะเอง ส่วน defaultExpanded ตั้งแค่ค่าเริ่มต้น onExpandedChange ยิงเมื่อกด Toggle การเปลี่ยน expanded เองจะเปิดหรือปิดโดยไม่มี animation ซึ่งเล่นเฉพาะตอนกดปุ่ม

import { useState } from 'react'; import { TruncatedText } from '@purpurabog/ui/headless'; const notes = [ { id: 'finance', text: 'ฝ่ายการเงิน: ระยะเวลาชำระเงินควรเป็น 30 วันหลังส่งของแทน 15 วัน และการทบทวนราคาหลังหกเดือนต้องปรับขึ้นได้ไม่เกิน 5% ส่วนอื่นใช้ได้' }, { id: 'legal', text: 'ฝ่ายกฎหมาย: ข้อ 7.2 (ค่าปรับส่งของล่าช้า) ควรนับเป็นวันทำการ ไม่ใช่วันปฏิทิน ข้อ 9 (การบอกเลิกสัญญา) ใช้ได้ตามที่เขียน' }, ]; const toggle = 'cursor-pointer border-0 bg-transparent px-0.5 text-link hover:text-link-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; const button = 'h-8 cursor-pointer bg-transparent px-4 text-sm text-link hover:bg-ghost-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; export default function Example() { const [open, setOpen] = useState<Record<string, boolean>>({}); const setAll = (value: boolean) => setOpen(Object.fromEntries(notes.map((n) => [n.id, value]))); return ( <div className="grid w-96 max-w-full gap-4 text-sm text-ink"> <div className="flex gap-2"> <button type="button" className={button} onClick={() => setAll(true)}>เปิดบันทึกทั้งหมด</button> <button type="button" className={button} onClick={() => setAll(false)}>ปิดบันทึกทั้งหมด</button> </div> {notes.map((note) => ( <TruncatedText.Root key={note.id} value={note.text} expanded={!!open[note.id]} onExpandedChange={(value) => setOpen((o) => ({ ...o, [note.id]: value }))}> <TruncatedText.Content className="overflow-hidden line-clamp-(--truncated-text-lines)" /> <TruncatedText.Toggle className={toggle}>{open[note.id] ? 'ดูน้อยลง' : 'ดูเพิ่มเติม'}</TruncatedText.Toggle> </TruncatedText.Root> ))} <p className="text-xs text-ink-muted">เปิดอยู่: {JSON.stringify(open)}</p> </div> ); }

เนื้อหาของคุณเอง

Content แสดง value ถ้าคุณไม่ได้ใส่ children ใส่ children เมื่อต้องการ markup เพิ่ม (ตัวหนา ลิงก์) โดยให้ value เป็นข้อความธรรมดาไว้ใช้กับ tooltip และใช้วัดใหม่เมื่อข้อความเปลี่ยน

import { TruncatedText } from '@purpurabog/ui/headless'; const text = 'ฝ่ายกฎหมาย: ข้อ 7.2 (ค่าปรับส่งของล่าช้า) ควรนับเป็นวันทำการ ไม่ใช่วันปฏิทิน ข้อ 9 (การบอกเลิกสัญญา) ใช้ได้ตามที่เขียน กรุณาส่งร่างที่แก้แล้วภายในวันศุกร์'; export default function Example() { return ( <TruncatedText.Root value={text} lines={2} className="w-80 max-w-full text-sm text-ink"> <TruncatedText.Content className="overflow-hidden line-clamp-(--truncated-text-lines)"> <strong>ฝ่ายกฎหมาย:</strong> ข้อ 7.2 (ค่าปรับส่งของล่าช้า) ควรนับเป็นวันทำการ ไม่ใช่วันปฏิทิน ข้อ 9 (การบอกเลิกสัญญา) ใช้ได้ตามที่เขียน กรุณาส่งร่างที่แก้แล้วภายในวันศุกร์ </TruncatedText.Content> <TruncatedText.Toggle className="cursor-pointer border-0 bg-transparent px-0.5 text-link focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> อ่านบันทึกทั้งหมด </TruncatedText.Toggle> </TruncatedText.Root> ); }

ใส่ style

import { TruncatedText } from '@purpurabog/ui/headless'; const notes = [ 'หัวหน้าฝ่ายอนุมัติแล้ว', 'อนุมัติแบบมีเงื่อนไข: ผู้ขายต้องส่งตารางส่งของก่อนการสั่งซื้อครั้งแรก และฝ่ายการเงินต้องได้เห็นด้วย', ]; export default function Example() { return ( <div className="grid w-80 max-w-full gap-4 text-sm text-ink"> {notes.map((note) => ( <TruncatedText.Root key={note} value={note} lines={1} className="group data-overflowing:border-s-2 data-overflowing:border-border-interactive data-overflowing:ps-2"> <TruncatedText.Content className="overflow-hidden line-clamp-(--truncated-text-lines)" /> <TruncatedText.Toggle className="cursor-pointer border-0 bg-transparent px-0.5 text-link focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus"> <span className="group-data-expanded:hidden">ดูเพิ่มเติม</span> <span className="hidden group-data-expanded:inline">ดูน้อยลง</span> </TruncatedText.Toggle> </TruncatedText.Root> ))} </div> ); } /* className="note" ที่ Root, "text" ที่ Content */ .text { display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: var(--truncated-text-lines); overflow: hidden; } .note[data-overflowing] { border-inline-start: 2px solid #0f62fe; padding-inline-start: 8px; }

Parts

TruncatedText.Root

<div> เก็บสถานะและวัดว่าข้อความถูกตัดหรือไม่เมื่อขนาดกล่องเปลี่ยน รับ prop ของ <div> ได้ทุกตัว

Prop Type ค่าเริ่มต้น
value string ข้อความ (ต้องมี วัดใหม่เมื่อเปลี่ยน)
lines number 2 จำนวนบรรทัดก่อนตัด 0 คือทั้งหมด
expanded boolean แสดงข้อความเต็มหรือไม่ (controlled)
defaultExpanded boolean false สถานะเริ่มต้น (uncontrolled)
onExpandedChange (expanded: boolean) => void เมื่อกด Toggle
Attribute เมื่อ
data-overflowing ข้อความถูกตัด (ยังอยู่ตอนเปิดอ่าน)
data-expanded เปิดอยู่

TruncatedText.useTruncatedTextContext() คืน value, overflowing, expanded, closing (กำลังเล่น animation ตอนพับ), clamp และ toggle() ให้ component ที่อยู่ใน Root

TruncatedText.Content

<div> ที่มีข้อความ: value หรือ children ของคุณ ได้ id ที่ Toggle ชี้มา และ style --truncated-text-lines: จำนวนบรรทัด หรือ none ตอนเปิดอ่าน ตอนกำลังพับ หรือเมื่อ lines เป็น 0 animation ความสูงเล่นที่ element นี้ (--ui-duration-moderate 110ms และไม่มี animation เมื่อค่านี้เป็น 0 เช่น ตอนผู้ใช้ตั้งลดการเคลื่อนไหว)

TruncatedText.Toggle

<button type="button"> ที่มี aria-expanded และ aria-controls (ชี้ไปที่ Content) render เฉพาะตอนข้อความถูกตัดหรือเปิดอยู่ กดแล้วเปิดหรือพับ รับ prop ของ button ได้ทุกตัว ยกเว้น type ใส่ข้อความเอง

Attribute เมื่อ
data-expanded เปิดอยู่

คีย์บอร์ดและ accessibility

ปุ่ม ทำอะไร
Tab ไปที่ Toggle (หรือปุ่ม tooltip ของคุณ)
Enter, Space ที่ Toggle: เปิดหรือพับข้อความ

part ตั้ง aria-expanded และ aria-controls ที่ Toggle และไม่ render ปุ่มเมื่อข้อความพอดี

ส่วนที่คุณเพิ่มเอง

  • การตัดบรรทัดที่ Content (line-clamp-(--truncated-text-lines) คู่กับ overflow-hidden)
  • ข้อความบนปุ่ม ("ดูเพิ่มเติม" / "ดูน้อยลง")
  • ถ้าใช้แบบ tooltip: ปุ่มที่ได้ชื่อจากข้อความเต็ม เฉพาะตอนที่ถูกตัด screen reader จะได้อ่านทั้งหมด
  • style ของโฟกัสที่มองเห็นได้
