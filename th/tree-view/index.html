คีย์บอร์ด

ปุ่ม ทำอะไร
Tab เข้าและออกจาก tree: ทั้ง tree หยุด Tab ที่เดียว (node ที่ focus ล่าสุด ถ้าไม่มีก็ node ที่เลือก ถ้าไม่มีอีกก็ node แรก)
ขึ้น / ลง node ที่มองเห็นก่อนหน้า / ถัดไป
Home / End node แรก / สุดท้ายที่มองเห็น
ขวา เปิดกิ่งที่ปิดอยู่ ถ้าเปิดแล้วจะไปที่ลูกตัวแรก
ซ้าย ปิดกิ่งที่เปิดอยู่ ถ้าปิดอยู่แล้วหรือเป็นใบจะไปที่ node แม่
Enter เปิดหรือปิดกิ่ง เลือก node และไปตามลิงก์ของมัน
Space เลือก node ใน tree แบบ multiselect จะเพิ่มหรือเอาออก
Ctrl / ⌘ + A เลือกทุก node (multiselect)
ตัวอักษร ไปที่ node ถัดไปที่มองเห็นและ label ขึ้นต้นด้วยตัวนั้น

Accessibility

  • tree เป็น role="tree" ของ treeitem กิ่งมี aria-expanded และทุก node มี aria-selected ลูกของแต่ละกิ่งเป็น group ที่ตั้งชื่อด้วยแถวของกิ่ง
  • label ตั้งชื่อ tree ลูกศรซ่อนจาก screen reader เพราะปุ่มด้านบนทำหน้าที่แทน
  • node ที่กำลังโหลดมี aria-busy และบอกว่า "กำลังโหลด"

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Tree view

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย

Property

Property ชนิด คำอธิบาย
