Accessibility

  • แถวต่าง ๆ เป็น role="list" ของ listitem ตั้งชื่อด้วย label ของหัว (aria-labelledby) ส่วน React + Tailwind สร้าง <ul> และ <li> จริง
  • แถวที่คลิกได้เป็น <button> จริง Tab ไปถึง Enter และ Space กดได้ แถวที่ปิดใช้งานจะถูกข้าม
  • ตั้งชื่อปุ่มไอคอนทุกตัวพร้อมชื่อแถว เช่น "ลบ ภาคผนวก ก.pdf" ผู้ใช้ screen reader จะแยกปุ่มแต่ละตัวได้
  • หัวจะติดอยู่ด้านบนเมื่อ list เลื่อนอยู่ในกล่อง (position: sticky)
