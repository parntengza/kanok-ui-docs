ธีมและ layer

สีทั้งหมดมาจาก 4 ธีมของ Carbon ซึ่งสร้างจาก @carbon/themes ลงใน tokens.css เลือกธีมได้ด้วย attribute เดียวคือ data-theme จะใส่ทั้งหน้าหรือแค่บางส่วนก็ได้ ส่วน <ui-layer> ใช้เลื่อนช่องกรอกและเมนูไปชั้นถัดไปตาม layering model ของ Carbon เพื่อให้ยังมองเห็นแยกจากพื้นข้างล่าง

ธีม หน้าตา
white สว่าง พื้นขาว (ค่าเริ่มต้น)
g10 สว่าง พื้นเทา 10
g90 มืด พื้นเทา 90
g100 มืด พื้นเทา 100

data-theme และ token ใช้ได้เหมือนกันทั้ง web component, wrapper ของ React และ React + Tailwind ซึ่ง class อ่าน token ชุดเดียวกัน ส่วน part ของ headless ไม่มีสีของตัวเอง

เปลี่ยนธีมทั้งหน้า

ใส่ data-theme ที่ <html> ถ้าไม่ใส่ หน้าจะเป็น white

<html data-theme="g100">

ธีมมืด (g90, g100) ตั้ง color-scheme: dark ให้ด้วย scrollbar และ control พื้นฐานของ browser จึงเป็นสีมืดตาม

ทำให้บางโซนเป็นสีมืด

data-theme ใส่ที่ element ไหนก็ได้ ทุกอย่างข้างในจะใช้ธีมนั้น ส่วนอื่นของหน้าไม่เปลี่ยน และโซนซ้อนกันได้

โซนเปลี่ยนแค่ token เท่านั้น ถ้าอยากให้พื้นของโซนเปลี่ยนสีด้วย ให้ตั้งสีพื้นและสีตัวอักษรของธีมเอง:

HTMLReactReact + Tailwind<div data-theme="g100" style="padding: 16px; background: var(--ui-canvas); color: var(--ui-ink)"> <ui-text-input label="ชื่อ (field-01 ของ g100)"></ui-text-input> <ui-layer level="1" with-background style="padding: 16px; margin-top: 16px"> <ui-text-input label="อยู่บนชั้นถัดไป (field-02)"></ui-text-input> </ui-layer> </div> <div data-theme="g100" style={{ padding: 16, background: 'var(--ui-canvas)', color: 'var(--ui-ink)' }}> <UiTextInput label="ชื่อ (field-01 ของ g100)" /> <UiLayer level={1} withBackground style={{ padding: 16, marginTop: 16 }}> <UiTextInput label="อยู่บนชั้นถัดไป (field-02)" /> </UiLayer> </div> <div data-theme="g100" className="bg-canvas p-4 text-ink"> <TextInput label="ชื่อ (field-01 ของ g100)" /> <Layer withBackground className="mt-4 p-4"> <TextInput label="อยู่บนชั้นถัดไป (field-02)" /> </Layer> </div>

ช่องที่อยู่ใน layer ใช้สีของชั้นถัดไป จึงยังแยกออกจากพื้นที่วางอยู่ได้

ให้ธีมตามการตั้งค่าของระบบ

data-theme="auto" จะแสดง white หรือ g100 เมื่อระบบตั้งเป็นโหมดมืด (prefers-color-scheme: dark) ต้องเลือกใช้เอง เพราะ Carbon เองไม่สลับธีมอัตโนมัติ

<html data-theme="auto">

ใช้ auto ที่ <html> หรือที่โซนก็ได้ โซน auto ที่ซ้อนอยู่ในธีมอื่นก็ยังแสดง white หรือ g100 ตามการตั้งค่าของระบบ

ให้ผู้ใช้เลือกสว่าง มืด หรือตามระบบ

<ui-theme-switcher> คือ content switcher แบบไอคอนที่มี 3 ตัวเลือก: สว่าง มืด และตามระบบ Carbon ไม่มี component นี้ ตัวที่อยู่ในเมนูตั้งค่ามุมขวาบนของเว็บนี้ก็คือ element นี้

HTMLReactReact + Tailwind<script type="module">import '@purpurabog/ui/theme-switcher';</script> <ui-theme-switcher></ui-theme-switcher> import { UiThemeSwitcher } from '@purpurabog/ui/react'; <UiThemeSwitcher /> // npx shadcn@4 add @kanok-ui/tw-theme-switcher import { ThemeSwitcher } from '@/components/ui/react-tw/theme-switcher'; <ThemeSwitcher />

ถ้าจะวาดปุ่มเองใน React โดยไม่มี style ให้ใช้ hook useThemeMode ดูที่ Headless

สิ่งที่มันทำ:

  • แสดงค่าที่เลือกที่ <html data-theme> สว่างคือ light-theme (ค่าเริ่มต้น white) มืดคือ dark-theme (ค่าเริ่มต้น g100) ส่วนตามระบบจะเปลี่ยนตาม OS ทันทีแม้ตอนที่ระบบเปลี่ยนโหมด
  • จำค่าไว้ ใน localStorage ที่ key storage-key (ค่าเริ่มต้น ui-theme; storage-key="" คือไม่จำ)
  • เริ่มจาก ค่าที่จำไว้ ถ้าไม่มีใช้ value ถ้าไม่มีอีกใช้สิ่งที่ <html data-theme> แสดงอยู่ สุดท้ายคือสว่าง
  • ทุกตัวเปลี่ยนตามกัน ตัวสลับธีมทุกตัวในหน้า (ทั้ง Lit และ React) และในแท็บอื่นเปลี่ยนตามกันหมด
Attribute ค่า ค่าเริ่มต้น
value light, dark, system ค่าที่จำไว้
light-theme white, g10 white
dark-theme g90, g100 g100
storage-key key อะไรก็ได้; "" = ไม่จำ ui-theme
size sm, md, lg md
low-contrast boolean ปิด
tooltip-placement ตำแหน่ง tooltip ของไอคอน top
label ชื่อของกลุ่มปุ่ม "Theme" ตามภาษา

ใน React และ React + Tailwind ชื่อ prop เป็น camelCase (lightTheme, darkTheme, storageKey, lowContrast, tooltipPlacement) และตัวสลับของ Tailwind ใช้ aria-label แทน label

ใน web component, part ของมันคือ switcher (ตัว content switcher) และ item (แต่ละตัวเลือก)

บันทึกค่าที่เลือกลงโปรไฟล์ผู้ใช้

เมื่อผู้ใช้เลือก จะมี event ui-theme-change พร้อม { mode, theme } (onUiThemeChange ใน wrapper ของ React และ onChange ในตัวสลับของ React + Tailwind) เก็บ mode ไว้ที่ server แล้วตั้ง value ตอนโหลดโปรไฟล์ ตัวสลับจะแสดงและจำค่านั้นให้

HTMLReactReact + Tailwindconst switcher = document.querySelector('ui-theme-switcher'); switcher.addEventListener('ui-theme-change', (event) => { const { mode, theme } = event.detail; // เช่น 'dark', 'g100' saveProfile({ theme: mode }); // ฟังก์ชันของแอปคุณเอง }); // เมื่อได้โปรไฟล์มาแล้ว switcher.value = profile.theme; // profile มาจาก server ส่วน saveProfile เป็นฟังก์ชันของแอปคุณเอง <UiThemeSwitcher value={profile.theme} onUiThemeChange={(e) => saveProfile({ theme: e.detail.mode })} /> // เมื่อใส่ value ตัวสลับจะแสดงตามค่าที่ส่งเข้าไป saveProfile จึงต้องอัปเดต profile.theme ด้วย <ThemeSwitcher value={profile.theme} onChange={({ mode }) => saveProfile({ theme: mode })} />

วาดธีมที่จำไว้ตั้งแต่เฟรมแรก

ตัวสลับธีมทำงานหลังจาก script ของมันโหลดเสร็จ ตอนรีโหลดหน้าจึงจะเห็นธีมเริ่มต้นแวบหนึ่งก่อนสลับ themeScript() คืน script สั้น ๆ สำหรับ <head> ที่ตั้งธีมที่จำไว้ก่อนจะวาดอะไรบนจอ ให้ render ใน server หรือเขียนลง index.html ตอน build:

import { themeScript } from '@purpurabog/ui/core'; const head = `<script>${themeScript({ storageKey: 'ui-theme', lightTheme: 'white', darkTheme: 'g100' })}</script>`;

ใส่ storageKey, lightTheme และ darkTheme ให้ตรงกับตัวสลับธีม ไม่ว่าจะเป็นแบบไหนในสี่แบบ ถ้ายังไม่มีค่าที่จำไว้ script จะไม่ทำอะไร <html data-theme> ที่คุณตั้งไว้จึงยังเป็นค่าเริ่มต้นเหมือนเดิม บน server useThemeMode และตัวสลับของ React + Tailwind ที่ใช้ hook นี้ จะคืน defaultValue (หรือ light) จึงควรใส่ themeScript() ใน <head> ด้วยเช่นกัน

วางช่องกรอกบน tile: <ui-layer>

Carbon ระบายสีพื้นผิวเป็นชั้น ๆ ช่องกรอกที่วางบน tile สีเทาต้องไม่เป็นเทาเดียวกับ tile <ui-layer> คือ Layer ของ Carbon ข้างในมัน component จะใช้ชุดสีของชั้นถัดไปในธีม:

  • พื้นของช่องกรอก tile และเมนู รวมถึงแถวที่ถูกเลือก
  • เส้นขอบและเส้นแบ่ง
  • สีตอน hover และตอนกด
level ใช้
0 ชุดเดียวกับหน้า เหมือนอยู่นอก layer
1 ชุดที่สอง
2 ชุดที่สาม (ลึกสุด)

ถ้าไม่ใส่ level layer จะคำนวณเองแบบ cds-layer ของ Carbon: layer ที่ไม่ได้อยู่ใน layer อื่นเป็น level 0 ส่วนที่ซ้อนอยู่จะเป็น level ของตัวแม่ + 1 สูงสุด 2 ใส่ level เพื่อกำหนดเอง ส่วน with-background จะระบายพื้นของ layer ด้วย layer background ของ Carbon ซึ่งเป็นสีที่เนื้อหาข้างในวางอยู่

HTMLReactReact + Tailwind<ui-layer level="1" with-background> <ui-text-input label="ช่องบน tile"></ui-text-input> <ui-layer with-background> <ui-text-input label="ลึกลงไปอีกชั้น"></ui-text-input> </ui-layer> </ui-layer> import { UiLayer, UiTextInput } from '@purpurabog/ui/react'; <UiLayer level={1} withBackground> <UiTextInput label="ช่องบน tile" /> <UiLayer withBackground> <UiTextInput label="ลึกลงไปอีกชั้น" /> </UiLayer> </UiLayer> import { Layer } from '@/components/ui/react-tw/layer'; import { TextInput } from '@/components/ui/react-tw/text-input'; <Layer withBackground className="p-4"> <TextInput label="ช่องบน tile" /> <Layer withBackground className="p-4"> <TextInput label="ลึกลงไปอีกชั้น" /> </Layer> </Layer>

<Layer> ของ Carbon React เริ่มที่ level 1 ไม่ใช่ 0 Layer ของ React + Tailwind ทำแบบ Carbon React ตรงนี้จึงไม่ต้องใส่ level ส่วน wrapper ของ React render <ui-layer> จึงเริ่มที่ 0 เหมือน element ถ้าอยากได้ผลเดียวกันให้ใส่ level="1" (level={1})

ใช้ธีมใน shadow root (micro app)

หัวข้อนี้สำหรับ web component ในแอป Lit ถ้าเป็นแอป React + Tailwind ใน shadow root ดูที่ ใช้กับ framework ต่าง ๆ

token เป็น CSS custom property ซึ่งสืบทอดผ่าน shadow root ได้ ธีมที่ตั้งบน <html> จึงไปถึงทุก component ไม่ว่าจะอยู่ตรงไหน

แต่กฎ [data-theme] อยู่ใน tokens.css ระดับ document ถ้าแอปของคุณ render อยู่ใน shadow root ของตัวเอง แล้วใส่ data-theme ที่ element ข้างในนั้น ต้องโหลด tokens.css เข้า shadow root นั้นด้วย ไฟล์นี้ประกาศ :host ไว้ด้วย การใส่ data-theme ที่ host ของแอปจึงทำงานเหมือนใส่ที่ <html>:

import { LitElement, html, unsafeCSS } from 'lit'; import tokens from '@purpurabog/ui/tokens.css?inline'; // Vite: ได้ CSS เป็นข้อความ import '@purpurabog/ui/text-input'; class ContractsApp extends LitElement { static styles = unsafeCSS(tokens); render() { return html`<ui-text-input label="ชื่อสัญญา"></ui-text-input>`; } } customElements.define('contracts-app', ContractsApp); <contracts-app data-theme="g90"></contracts-app>

ตัวสลับธีมเปลี่ยนแค่ <html> ใน micro app ให้ตั้ง data-theme ที่ host ของตัวเองแทน ส่วน <ui-layer> ไม่ต้องทำอะไรเพิ่ม เพราะกฎของมันอยู่ในตัว element จึงใช้ได้ใน shadow root ทุกที่
