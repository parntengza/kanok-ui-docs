Headless Tabs

Tabs คือพฤติกรรมของ Tabs แบบมี style ในรูป React part ที่ไม่มี style: แถบแท็บมีจุดหยุดของ Tab จุดเดียว (roving tabindex) ปุ่มลูกศร Home และ End การเลือกแบบอัตโนมัติหรือ manual ปุ่ม Delete และปุ่มปิดของแท็บที่ปิดได้ และ role tablist / tab / tabpanel ที่ผูก id กันไว้แล้ว สถานะแสดงเป็น attribute data-* ไว้แต่ง style

markup และ style ทั้งหมดเป็นของคุณ ทั้งเส้นใต้หรือแบบ contained ขนาด ไอคอน ปุ่มเลื่อนของแถบที่ยาว และการจัดวางคอลัมน์แนวตั้ง

ติดตั้ง

ส่วน headless มากับแพ็กเกจเลย (ไม่มี item ของ shadcn; item ของ React + Tailwind สร้างบนมัน):

npm install @purpurabog/ui import { Tabs } from '@purpurabog/ui/headless';

วิธีใช้

import { Tabs } from '@purpurabog/ui/headless'; const tab = 'h-10 cursor-pointer border-0 border-b-2 border-solid border-hairline bg-transparent px-4 text-sm text-ink-muted hover:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-selected:border-border-interactive data-selected:font-semibold data-selected:text-ink data-disabled:cursor-not-allowed data-disabled:text-ink-disabled'; const panel = 'p-4 text-sm text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus'; export default function Example() { return ( <Tabs.Root> <Tabs.List aria-label="รายละเอียดสัญญา" className="flex gap-px"> <Tabs.Tab value="overview" className={tab}>ภาพรวม</Tabs.Tab> <Tabs.Tab value="parties" className={tab}>คู่สัญญา</Tabs.Tab> <Tabs.Tab value="history" className={tab}>ประวัติ</Tabs.Tab> <Tabs.Tab value="archive" disabled className={tab}>เก็บถาวร</Tabs.Tab> </Tabs.List> <Tabs.Panel value="overview" className={panel}>สรุปเงื่อนไขของสัญญา</Tabs.Panel> <Tabs.Panel value="parties" className={panel}>ผู้ลงนามและคู่สัญญา</Tabs.Panel> <Tabs.Panel value="history" className={panel}>ทุกการแก้ไข ล่าสุดอยู่บน</Tabs.Panel> <Tabs.Panel value="archive" className={panel}>สำเนาที่เก็บถาวร</Tabs.Panel> </Tabs.Root> ); }

โครงสร้าง

<Tabs.Root> <Tabs.List> <Tabs.Tab value="a" /> <Tabs.Close value="a" /> </Tabs.List> <Tabs.Panel value="a" /> </Tabs.Root>

Tab กับ Panel ของมันใช้ value เดียวกัน Close ใช้เฉพาะแท็บที่ปิดได้ ให้วางไว้ข้าง Tab ห้ามวางข้างใน (ปุ่มซ้อนปุ่มไม่ได้)

แท็บเริ่มต้นและการเปลี่ยนแท็บ

ถ้าไม่มี value หรือ defaultValue จะเลือก Tab แรกที่ใช้งานได้ Root หาแท็บนั้นจาก children ของมัน โดยมองเข้าไปใน List และ fragment เท่านั้น ถ้าแท็บอยู่ใน wrapper อื่น ให้ตั้ง defaultValue เอง ใช้ value คู่กับ onValueChange เมื่อต้องการควบคุมค่าเอง

import { useState } from 'react'; import { Tabs } from '@purpurabog/ui/headless'; const tab = 'h-10 cursor-pointer border-0 border-b-2 border-solid border-hairline bg-transparent px-4 text-sm text-ink-muted hover:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-selected:border-border-interactive data-selected:font-semibold data-selected:text-ink'; const panel = 'p-4 text-sm text-ink'; export default function Example() { const [step, setStep] = useState('review'); return ( <div className="grid gap-2"> <Tabs.Root value={step} onValueChange={setStep}> <Tabs.List aria-label="ขั้นตอนอนุมัติ" className="flex gap-px"> <Tabs.Tab value="draft" className={tab}>ร่าง</Tabs.Tab> <Tabs.Tab value="review" className={tab}>ฝ่ายกฎหมายตรวจ</Tabs.Tab> <Tabs.Tab value="sign" className={tab}>ลงนาม</Tabs.Tab> </Tabs.List> <Tabs.Panel value="draft" className={panel}>ผู้ขอกรอกแบบฟอร์มสัญญา</Tabs.Panel> <Tabs.Panel value="review" className={panel}>ฝ่ายกฎหมายตรวจเงื่อนไขและคู่สัญญา</Tabs.Panel> <Tabs.Panel value="sign" className={panel}>ทั้งสองฝ่ายลงนาม แล้วจัดเก็บสัญญา</Tabs.Panel> </Tabs.Root> <p className="text-xs text-ink-muted">แท็บที่เลือก: {step}</p> </div> ); }

เลือกด้วยตัวเอง (manual)

activation="manual": ปุ่มลูกศรย้ายแค่โฟกัส แล้วกด Enter หรือ Space เพื่อเลือก ใช้เมื่อ panel แสดงผลช้าหรือต้องโหลดข้อมูล

import { useState } from 'react'; import { Tabs } from '@purpurabog/ui/headless'; const tab = 'h-10 cursor-pointer border-0 border-b-2 border-solid border-hairline bg-transparent px-4 text-sm text-ink-muted hover:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-selected:border-border-interactive data-selected:font-semibold data-selected:text-ink'; export default function Example() { const [report, setReport] = useState('month'); return ( <div className="grid gap-2"> <Tabs.Root activation="manual" value={report} onValueChange={setReport}> <Tabs.List aria-label="รายงาน" className="flex gap-px"> <Tabs.Tab value="month" className={tab}>เดือนนี้</Tabs.Tab> <Tabs.Tab value="quarter" className={tab}>ไตรมาสนี้</Tabs.Tab> <Tabs.Tab value="year" className={tab}>ปีนี้</Tabs.Tab> </Tabs.List> <Tabs.Panel value="month" className="p-4 text-sm text-ink">โฟกัสที่แท็บ ใช้ปุ่มลูกศรย้าย แล้วกด Enter หรือ Space</Tabs.Panel> <Tabs.Panel value="quarter" className="p-4 text-sm text-ink">รายงานรายไตรมาส</Tabs.Panel> <Tabs.Panel value="year" className="p-4 text-sm text-ink">รายงานรายปี</Tabs.Panel> </Tabs.Root> <p className="text-xs text-ink-muted">โหลดแล้ว: {report}</p> </div> ); }

คงแท็บเดิมไว้

onValueChange บอกแท็บที่ผู้ใช้เลือก ถ้าควบคุมค่าเอง ให้คง value ไว้เหมือนเดิมเพื่ออยู่ที่แท็บเดิม เช่น ตอนที่ฟอร์มในแท็บยังมีการแก้ไขที่ไม่ได้บันทึก

import { useState } from 'react'; import { Tabs } from '@purpurabog/ui/headless'; const tab = 'h-10 cursor-pointer border-0 border-b-2 border-solid border-hairline bg-transparent px-4 text-sm text-ink-muted hover:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-selected:border-border-interactive data-selected:font-semibold data-selected:text-ink'; export default function Example() { const [tabValue, setTabValue] = useState('form'); const [dirty, setDirty] = useState(true); const [message, setMessage] = useState(''); return ( <div className="grid gap-2"> <label className="flex items-center gap-2 text-sm text-ink"> <input type="checkbox" checked={dirty} onChange={(e) => setDirty(e.target.checked)} /> ฟอร์มสัญญามีการแก้ไขที่ยังไม่บันทึก </label> <Tabs.Root value={tabValue} onValueChange={(next) => { setMessage(dirty ? `บันทึกฟอร์มก่อนเปิด "${next}"` : ''); if (!dirty) setTabValue(next); }} > <Tabs.List aria-label="สัญญา" className="flex gap-px"> <Tabs.Tab value="form" className={tab}>ฟอร์ม</Tabs.Tab> <Tabs.Tab value="preview" className={tab}>ตัวอย่าง</Tabs.Tab> </Tabs.List> <Tabs.Panel value="form" className="p-4 text-sm text-ink">แก้ไขสัญญาที่นี่</Tabs.Panel> <Tabs.Panel value="preview" className="p-4 text-sm text-ink">สัญญาในแบบที่คู่สัญญาจะเห็น</Tabs.Panel> </Tabs.Root> <p role="status" className="text-xs text-error-text">{message}</p> </div> ); }

แท็บแนวตั้ง

orientation="vertical" ทำให้ปุ่ม ↑ และ ↓ เป็นปุ่มที่ย้ายแท็บ ตั้ง aria-orientation="vertical" ที่ list และ data-orientation="vertical" ที่ Root และ List การจัดวางเป็นคอลัมน์เป็นหน้าที่ของคุณ

import { Tabs } from '@purpurabog/ui/headless'; const tab = 'box-border h-12 w-full cursor-pointer border-0 border-b border-s-[3px] border-solid border-b-hairline border-s-hairline bg-transparent px-4 text-start text-sm text-ink-muted hover:bg-layer-hover-1 hover:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-selected:border-s-border-interactive data-selected:bg-layer-1 data-selected:font-semibold data-selected:text-ink data-disabled:cursor-not-allowed data-disabled:text-ink-disabled'; const panel = 'p-4 text-sm text-ink'; export default function Example() { return ( <Tabs.Root orientation="vertical" className="flex min-h-48 max-w-xl border border-solid border-hairline"> <Tabs.List aria-label="การตั้งค่า" className="flex w-44 shrink-0 flex-col"> <Tabs.Tab value="profile" className={tab}>โปรไฟล์</Tabs.Tab> <Tabs.Tab value="notifications" className={tab}>การแจ้งเตือน</Tabs.Tab> <Tabs.Tab value="signatures" className={tab}>ลายเซ็น</Tabs.Tab> <Tabs.Tab value="audit" disabled className={tab}>บันทึกการตรวจสอบ</Tabs.Tab> </Tabs.List> <Tabs.Panel value="profile" className={panel}>ชื่อและแผนกของคุณ</Tabs.Panel> <Tabs.Panel value="notifications" className={panel}>การแจ้งเตือนทางอีเมลและในแอป</Tabs.Panel> <Tabs.Panel value="signatures" className={panel}>ลายเซ็นที่คุณบันทึกไว้</Tabs.Panel> <Tabs.Panel value="audit" className={panel}>ใครแก้ไขอะไร</Tabs.Panel> </Tabs.Root> ); }

แท็บที่ปิดได้

เมื่อตั้ง dismissable การกด Delete บนแท็บที่โฟกัสอยู่และการคลิก Close ของแท็บ จะเรียก onTabCloseRequest พร้อม value ของแท็บ ให้ลบแท็บนั้นออกจากรายการของคุณเพื่อปิด ถ้าปิดแท็บที่เลือกอยู่ การเลือกจะย้ายไปแท็บแรกที่ใช้งานได้ (onValueChange) และโฟกัสย้ายไปแท็บที่มาอยู่แทนที่ ถ้าไม่มีก็ไปแท็บก่อนหน้า

แท็บในตัวอย่างนี้อยู่ใน wrapper คู่กับ Close ของมัน Root จึงต้องมี defaultValue

import { useState } from 'react'; import { Tabs } from '@purpurabog/ui/headless'; const files = [ { value: 'contract', label: 'สัญญา.pdf' }, { value: 'memo', label: 'บันทึกข้อความ.docx' }, { value: 'notes', label: 'โน้ต' }, ]; const tab = 'h-10 cursor-pointer border-0 border-b-2 border-solid border-hairline bg-transparent ps-4 pe-10 text-sm text-ink-muted hover:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-selected:border-border-interactive data-selected:font-semibold data-selected:text-ink'; export default function Example() { const [open, setOpen] = useState(files); return ( <Tabs.Root dismissable defaultValue="contract" onTabCloseRequest={(value) => setOpen((list) => list.filter((file) => file.value !== value))}> <Tabs.List aria-label="เอกสารที่เปิดอยู่" className="flex gap-px"> {open.map((file) => ( <span key={file.value} className="relative flex"> <Tabs.Tab value={file.value} className={tab}>{file.label}</Tabs.Tab> <Tabs.Close value={file.value} title={`ปิด ${file.label}`} className="absolute inset-y-0 end-2 my-auto grid size-6 cursor-pointer place-items-center border-0 bg-transparent p-1 text-ink-muted hover:bg-ghost-hover hover:text-ink" > <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current"> <path d="m12 4.7-.7-.7L8 7.3 4.7 4l-.7.7L7.3 8 4 11.3l.7.7L8 8.7l3.3 3.3.7-.7L8.7 8z" /> </svg> </Tabs.Close> </span> ))} </Tabs.List> {open.map((file) => ( <Tabs.Panel key={file.value} value={file.value} className="p-4 text-sm text-ink"> {file.label}: ปุ่ม × หรือ Delete บนแท็บที่โฟกัสอยู่จะปิดแท็บนั้น </Tabs.Panel> ))} {open.length === 0 ? ( <button type="button" onClick={() => setOpen(files)} className="mt-4 h-8 cursor-pointer border-0 bg-interactive px-4 text-sm text-on-primary"> เปิดใหม่ทั้งหมด </button> ) : null} </Tabs.Root> ); }

แต่ง style

แบบ contained: แท็บอยู่บน accent layer แท็บที่เลือกอยู่บน layer พร้อมขอบบนสีน้ำเงิน เส้นคั่นและสีทั้งหมดมาจาก CSS ของคุณ

import { Tabs } from '@purpurabog/ui/headless'; const tab = 'h-12 cursor-pointer border-0 bg-layer-accent-1 px-4 text-sm text-ink-muted hover:bg-layer-accent-hover-1 hover:text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus data-selected:bg-layer-1 data-selected:font-semibold data-selected:text-ink data-selected:shadow-[inset_0_2px_0_0_var(--ui-border-interactive)] data-disabled:cursor-not-allowed data-disabled:bg-button-disabled data-disabled:text-on-color-disabled'; export default function Example() { return ( <Tabs.Root> <Tabs.List aria-label="รายละเอียดสัญญา" className="flex"> <Tabs.Tab value="overview" className={tab}>ภาพรวม</Tabs.Tab> <Tabs.Tab value="parties" className={tab}>คู่สัญญา</Tabs.Tab> <Tabs.Tab value="history" className={tab}>ประวัติ</Tabs.Tab> <Tabs.Tab value="archive" disabled className={tab}>เก็บถาวร</Tabs.Tab> </Tabs.List> <Tabs.Panel value="overview" className="bg-layer-1 p-4 text-sm text-ink">สรุปเงื่อนไขของสัญญา</Tabs.Panel> <Tabs.Panel value="parties" className="bg-layer-1 p-4 text-sm text-ink">ผู้ลงนามและคู่สัญญา</Tabs.Panel> <Tabs.Panel value="history" className="bg-layer-1 p-4 text-sm text-ink">ทุกการแก้ไข ล่าสุดอยู่บน</Tabs.Panel> <Tabs.Panel value="archive" className="bg-layer-1 p-4 text-sm text-ink">สำเนาที่เก็บถาวร</Tabs.Panel> </Tabs.Root> ); } [role='tab'] { border-bottom: 2px solid #e0e0e0; color: #525252; } [role='tab'][data-selected] { border-bottom-color: #0f62fe; color: #161616; font-weight: 600; } [role='tab'][data-disabled] { color: #a8a8a8; cursor: not-allowed; } [role='tablist'][data-orientation='vertical'] { flex-direction: column; } [role='tabpanel']:focus-visible { outline: 2px solid #0f62fe; outline-offset: -2px; }

Parts

Tabs.Root

render <div> ที่เก็บสถานะ รับ prop ของ <div> ได้ทุกตัว

Prop Type ค่าเริ่มต้น
value string — value ของแท็บที่เลือก (ควบคุมเอง)
defaultValue string Tab แรกที่ใช้งานได้ แท็บเริ่มต้น (ไม่ควบคุมเอง) หาจากใน List และ fragment เท่านั้น
onValueChange (value: string) => void — หลังผู้ใช้เลือกแท็บอื่น หรือเมื่อแท็บที่เลือกถูกปิดแล้วการเลือกย้ายไปแท็บอื่น
activation 'automatic' | 'manual' 'automatic' automatic เลือกไปพร้อมการย้ายโฟกัส manual เลือกเมื่อกด Enter หรือ Space
orientation 'horizontal' | 'vertical' 'horizontal' ใช้ ← / → หรือ ↑ / ↓ ย้าย
dismissable boolean false Delete และ Close ขอปิดแท็บ
onTabCloseRequest (value: string) => void — แท็บขอปิด ให้ลบแท็บนั้นออกจาก children เพื่อปิด
Attribute เมื่อ
data-orientation มีเสมอ: horizontal หรือ vertical

Tabs.List

render <div role="tablist"> (มี aria-orientation="vertical" เมื่อเป็นแนวตั้ง) จัดการปุ่มคีย์บอร์ดและการคลิกของแท็บข้างใน รับ prop ของ <div> ได้ทุกตัว ตั้งชื่อด้วย aria-label หรือ aria-labelledby

Attribute เมื่อ
data-orientation มีเสมอ: horizontal หรือ vertical

Tabs.Tab

render <button type="button" role="tab"> ที่มี aria-selected, aria-controls (panel ของมัน) และ id ที่ได้จาก Root เฉพาะแท็บที่เป็นจุดหยุดของ Tab จะมี tabIndex={0}

Prop Type ค่าเริ่มต้น
value string — ตรงกับ value ของ Panel (ต้องใส่)
disabled boolean false aria-disabled: ยังมองเห็นและอ่านออกเสียง แต่เลือกไม่ได้และปุ่มลูกศรข้ามไป
Attribute เมื่อ
data-selected เป็นแท็บที่เลือกอยู่
data-disabled ตั้ง disabled
data-value มีเสมอ: value ของแท็บ

ในแท็บที่ปิดได้ แท็บที่ใช้งานได้แต่ละตัวจะได้ aria-keyshortcuts="Delete" เว้นแต่คุณใส่ค่าของคุณเอง

Tabs.Close

render <button type="button"> ที่มี tabIndex={-1} และ aria-hidden="true" เพราะการกด Delete บนแท็บทำสิ่งเดียวกันสำหรับผู้ใช้คีย์บอร์ดและ screen reader ตั้งชื่อด้วย title สำหรับผู้ใช้เมาส์

Prop Type ค่าเริ่มต้น
value string — แท็บที่จะปิด (ต้องใส่)

Tabs.Panel

render <div role="tabpanel"> ที่ใช้แท็บของมันเป็นชื่อ และ hidden เมื่อแท็บไม่ได้ถูกเลือก จะเป็นจุดหยุดของ Tab (tabIndex={0}) เฉพาะเมื่อข้างในไม่มีอะไรรับโฟกัสได้

Prop Type ค่าเริ่มต้น
value string — ตรงกับ value ของ Tab (ต้องใส่)
Attribute เมื่อ
data-selected แท็บของมันถูกเลือก

Tabs.useTabsContext() ให้สถานะของ Root ที่ครอบอยู่ (value, orientation, activation, dismissable …) กับ part ของคุณเอง และ Tabs.tabIds(id, value) ให้ id ของแท็บและ panel

คีย์บอร์ดและ accessibility

ปุ่ม ทำอะไร
← / → แท็บก่อนหน้า / ถัดไปที่ใช้งานได้ วนรอบ (กลับด้านเมื่อเขียนจากขวาไปซ้าย) ถ้าเป็น automatic จะเลือกด้วย
↑ / ↓ เหมือนกันเมื่อ orientation="vertical"
Home / End แท็บแรก / สุดท้ายที่ใช้งานได้
Enter, Space เลือกแท็บที่โฟกัสอยู่
Delete ขอปิดแท็บที่โฟกัสอยู่ (dismissable)
Tab ออกจากแถบ จุดถัดไปคือ panel หรือสิ่งแรกที่รับโฟกัสได้ข้างใน

part ตั้ง role, aria-selected, aria-controls, aria-labelledby, aria-disabled, aria-orientation และ tabIndex แบบ roving ให้แล้ว

สิ่งที่คุณต้องใส่เอง:

  • ชื่อของแถบ: aria-label หรือ aria-labelledby ที่ List
  • aria-label บนแท็บที่แสดงแค่ไอคอน และ tooltip สำหรับผู้ที่มองเห็น
  • ปุ่มเลื่อนเมื่อแท็บล้นแถบ ให้อยู่นอกลำดับ Tab เหมือนที่ Tabs แบบมี style ทำ
