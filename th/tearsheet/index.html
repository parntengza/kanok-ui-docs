Tearsheet

Tearsheet คือ modal ขนาดใหญ่ที่เลื่อนขึ้นมาจากด้านล่างของจอ ทับหน้าเว็บที่ถูกหรี่ไว้ ใช้กับงานที่ต้องการพื้นที่แต่ให้ผู้ใช้อยู่ที่เดิม เช่น สร้างรายการใหม่ ฟอร์มหลายส่วน หรือการตรวจทานที่มีบานข้าง ตัวนี้คือ Tearsheet ของ Carbon for IBM Products ถ้าเป็นการตัดสินใจสั้น ๆ ให้ใช้ Modal ถ้าต้องการให้หน้าเว็บยังมองเห็นอยู่ ให้ใช้ Side panel

ตั้ง open เพื่อแสดง และตั้งกลับเป็น false เพื่อซ่อน มันคือ <dialog> แบบ modal ของ browser: หน้าเว็บข้างหลังเป็น inert และเลื่อนไม่ได้ และ Tab วนอยู่ใน sheet ตอนเปิด โฟกัสจะไปที่ selector-initial-focus (selector ของ element ใน sheet) ถ้าไม่ตั้งจะไปที่ × ถ้าไม่มี × จะไปที่ช่องแรก ตอนปิดโฟกัสจะกลับไปที่ตัวเดิม และส่ง ui-close เมื่อ sheet เลื่อนลงไปแล้ว

เนื้อหาไม่มี padding ของตัวเอง ให้ใส่เองรอบเนื้อหาอย่างในตัวอย่าง React + Tailwind เป็นแบบ controlled: onRequestClose(reason) บอกว่ามีการกด × กด Esc หรือคลิกข้างนอก แล้วคุณตั้ง open เป็น false

แบบแคบ

width="narrow" (ค่าเริ่มต้น) กว้างเท่า modal ขนาดเล็กของ Carbon คือ 60%, 42% หรือ 36% ของจอ ตั้งแต่จอขนาดกลาง ใหญ่ และใหญ่พิเศษขึ้นไป เริ่มที่ 130px จากด้านบน vertical-position="normal" เลื่อนขึ้นไปที่ 90px เหมือนแบบกว้าง หัวข้อเล็กลงหนึ่งขนาด และเนื้อหาอยู่บน layer แทนพื้นหลัง React + Tailwind มี TearsheetNarrow ให้ด้วย

ขอยืนยันก่อนปิด

× กด Esc และคลิกนอก sheet จะส่ง ui-request-close ซึ่งยกเลิกได้ และมี reason เป็น close-button, escape หรือ outside เรียก preventDefault() เพื่อให้เปิดค้างไว้ prevent-close-on-click-outside ปิดการคลิกข้างนอกไปเลย เหมาะกับฟอร์มที่ผู้ใช้พิมพ์ข้อมูล ลองพิมพ์อะไรด้านล่าง แล้วกด Esc

ui-request-close และ ui-close bubble ขึ้นมา notification ที่อยู่ข้างในจึงส่ง event เหล่านี้ถึง tearsheet ด้วย ต้องเช็กว่า event.target คือ tearsheet ส่วน UiTearsheet ของ React เช็กให้แล้ว onUiRequestClose และ onUiClose ได้รับเฉพาะ event ของ tearsheet เอง requestClose(reason) ใช้ถามจากปุ่มของคุณเอง ส่วนการตั้ง open เป็น false จะปิดโดยไม่ถาม

คีย์บอร์ด

ปุ่ม ทำอะไร
Tab / Shift+Tab เลื่อนไปมาระหว่างช่องและปุ่มใน sheet และวนอยู่ข้างใน
Esc ขอปิด (escape) แล้วโฟกัสกลับไปที่ตัวที่เปิด tearsheet

Accessibility

  • มันคือ <dialog> แบบ modal ของ browser ที่ใช้ heading เป็นชื่อ หน้าเว็บข้างหลังเป็น inert ทั้งกับเมาส์ คีย์บอร์ด และ screen reader
  • ใส่ heading ให้ทุก tearsheet ถ้าไม่มี dialog จะไม่มีชื่อ
  • × มีชื่อว่า "ปิด" ตามภาษาของหน้า เปลี่ยนได้ด้วย close-icon-description

ต้องการแค่พฤติกรรมโดยไม่มี style: Headless Tearsheet

<ui-tearsheet> · React UiTearsheet

Attribute

Attribute Property ชนิด ค่าเริ่มต้น คำอธิบาย
open open boolean false
width width 'narrow' | 'wide' 'narrow' narrow: Carbon's small modal; wide: the whole screen but 64px each side.
vertical-position verticalPosition 'normal' | 'lower' | undefined How far from the top the sheet starts: normal 90px, lower 130px (default lower for a narrow one).
heading heading string ''
label label string '' A small label above the heading.
description description string ''
influencer-placement influencerPlacement 'left' | 'right' 'right'
influencer-width influencerWidth 'narrow' | 'wide' 'narrow'
has-close-icon hasCloseIcon boolean false Show the × even with actions (it always shows without them).
close-icon-description closeIconDescription string '' The ×'s name (default "Close", translated).
prevent-close-on-click-outside preventCloseOnClickOutside boolean false
selector-initial-focus selectorInitialFocus string '' What takes focus on open (a selector in the content), else × or the first control.

Method

Method คำอธิบาย
placeInStack(position, depth) Called by the stack: this sheet's place among the open ones (position 1 = oldest) and how many show.
requestClose(reason) Asks to close (cancelable ui-request-close), then closes.

Event

Event React คำอธิบาย
ui-close onUiClose After it closed
ui-request-close onUiRequestClose Cancelable; detail: { reason: 'escape' | 'close-button' | 'outside' }

Slot

Slot คำอธิบาย
(ค่าเริ่มต้น) The content
label Rich label (instead of label)
description Rich description (instead of description), e.g. a <ui-truncated-text>
header-actions Small buttons in the header (wide)
header-navigation Tabs under the header text (wide)
influencer A side pane beside the content (wide)
actions Up to four action buttons

Part คำอธิบาย

Custom property ค่าเริ่มต้น คำอธิบาย
