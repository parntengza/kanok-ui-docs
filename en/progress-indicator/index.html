Progress indicator

A progress indicator shows where the user is in a task of several steps: which steps are done, which one is current and what comes next. Use it above a multi-step form or a wizard.

HTMLReactReact + Tailwind<ui-progress-indicator current-index="1"> <ui-progress-step label="Contract details"></ui-progress-step> <ui-progress-step label="Signers"></ui-progress-step> <ui-progress-step label="Review"></ui-progress-step> <ui-progress-step label="Send"></ui-progress-step> </ui-progress-indicator> <UiProgressIndicator currentIndex={1}> <UiProgressStep label="Contract details" /> <UiProgressStep label="Signers" /> <UiProgressStep label="Review" /> <UiProgressStep label="Send" /> </UiProgressIndicator> <ProgressIndicator currentIndex={1}> <ProgressStep label="Contract details" /> <ProgressStep label="Signers" /> <ProgressStep label="Review" /> <ProgressStep label="Send" /> </ProgressIndicator>

Step states

current-index (0-based) decides each step's state: the steps before it are complete (a check mark), the step at it is current (a half-filled circle), the steps after it are incomplete (an empty circle). Two flags on a step add to that:

  • invalid shows a warning icon in red: the step has an error to fix.
  • disabled greys the step out. It can't be clicked, even in an interactive indicator.
HTMLReactReact + Tailwind<ui-progress-indicator current-index="1"> <ui-progress-step label="Contract details"></ui-progress-step> <ui-progress-step label="Signers"></ui-progress-step> <ui-progress-step label="Review" invalid></ui-progress-step> <ui-progress-step label="Send" disabled></ui-progress-step> </ui-progress-indicator> <UiProgressIndicator currentIndex={1}> <UiProgressStep label="Contract details" /> <UiProgressStep label="Signers" /> <UiProgressStep label="Review" invalid /> <UiProgressStep label="Send" disabled /> </UiProgressIndicator> <ProgressIndicator currentIndex={1}> <ProgressStep label="Contract details" /> <ProgressStep label="Signers" /> <ProgressStep label="Review" invalid /> <ProgressStep label="Send" disabled /> </ProgressIndicator>

Secondary label

secondary-label adds a smaller line under the label: "Optional", a date, a count.

Complete out of order

complete on a step marks it done whatever current-index says. Use it when the user may fill the steps in any order: here the attachments are already in, while the user is still on the signers.

HTMLReactReact + Tailwind<ui-progress-indicator current-index="1"> <ui-progress-step label="Contract details"></ui-progress-step> <ui-progress-step label="Signers"></ui-progress-step> <ui-progress-step label="Attachments" complete></ui-progress-step> <ui-progress-step label="Send"></ui-progress-step> </ui-progress-indicator> <UiProgressIndicator currentIndex={1}> <UiProgressStep label="Contract details" /> <UiProgressStep label="Signers" /> <UiProgressStep label="Attachments" complete /> <UiProgressStep label="Send" /> </UiProgressIndicator> <ProgressIndicator currentIndex={1}> <ProgressStep label="Contract details" /> <ProgressStep label="Signers" /> <ProgressStep label="Attachments" complete /> <ProgressStep label="Send" /> </ProgressIndicator>

Let the user jump between steps

interactive makes the steps buttons: a click on a step (not the current one, not a disabled one) makes it current and fires ui-change with detail.index. In React + Tailwind, onChange gets the index. Use it when going back to an earlier step is safe, for example to correct the details before sending.

Current step: 2

HTMLReactReact + Tailwind<ui-progress-indicator id="progress-jump" current-index="2" interactive> <ui-progress-step label="Contract details"></ui-progress-step> <ui-progress-step label="Signers"></ui-progress-step> <ui-progress-step label="Review"></ui-progress-step> <ui-progress-step label="Send" disabled></ui-progress-step> </ui-progress-indicator> <p>Current step: <output id="progress-jump-out">2</output></p> <script type="module"> const steps = document.getElementById('progress-jump'); const out = document.getElementById('progress-jump-out'); steps.addEventListener('ui-change', (event) => (out.value = event.detail.index)); </script> const [step, setStep] = useState(2); <UiProgressIndicator currentIndex={step} interactive onUiChange={(e) => setStep(e.detail.index)}> <UiProgressStep label="Contract details" /> <UiProgressStep label="Signers" /> <UiProgressStep label="Review" /> <UiProgressStep label="Send" disabled /> </UiProgressIndicator> <p>Current step: <output>{step}</output></p> const [step, setStep] = useState(2); <ProgressIndicator currentIndex={step} interactive onChange={setStep}> <ProgressStep label="Contract details" /> <ProgressStep label="Signers" /> <ProgressStep label="Review" /> <ProgressStep label="Send" disabled /> </ProgressIndicator> <p>Current step: <output>{step}</output></p>

React + Tailwind also takes defaultCurrentIndex when you don't need to hold the step yourself.

Back and Next buttons

Most often the page moves through the steps itself: set current-index from your Back and Next buttons. The indicator only shows the position; it doesn't change it on its own unless it is interactive.

Vertical

vertical stacks the steps. Use it in a narrow column beside the form, or when the labels are long.

Space equally

By default each step is 128px wide, and a longer label wraps at 88px (Carbon cuts it with an ellipsis; here no step name is hidden). space-equally stretches the steps to share the full width instead. It has no effect with vertical.

HTMLReactReact + Tailwind<ui-progress-indicator current-index="2" space-equally> <ui-progress-step label="Details"></ui-progress-step> <ui-progress-step label="Signers"></ui-progress-step> <ui-progress-step label="Review"></ui-progress-step> <ui-progress-step label="Send"></ui-progress-step> </ui-progress-indicator> <UiProgressIndicator currentIndex={2} spaceEqually> <UiProgressStep label="Details" /> <UiProgressStep label="Signers" /> <UiProgressStep label="Review" /> <UiProgressStep label="Send" /> </UiProgressIndicator> <ProgressIndicator currentIndex={2} spaceEqually> <ProgressStep label="Details" /> <ProgressStep label="Signers" /> <ProgressStep label="Review" /> <ProgressStep label="Send" /> </ProgressIndicator>

Skeleton

While the steps load, show ui-progress-indicator-skeleton: steps empty steps (4 by default), in a row or stacked with vertical. It is hidden from screen readers, so say "loading" on the container (for example aria-busy).

HTMLReactReact + Tailwind<ui-progress-indicator-skeleton></ui-progress-indicator-skeleton> <ui-progress-indicator-skeleton steps="3" vertical></ui-progress-indicator-skeleton> import { UiProgressIndicatorSkeleton } from '@purpurabog/ui/react'; <UiProgressIndicatorSkeleton /> <UiProgressIndicatorSkeleton steps={3} vertical /> import { ProgressIndicatorSkeleton } from '@/components/ui/react-tw/progress-indicator'; <ProgressIndicatorSkeleton /> <ProgressIndicatorSkeleton steps={3} vertical />

On the web component, import it from @purpurabog/ui/progress-indicator-skeleton.

Keyboard

Key Does
Tab / Shift+Tab With interactive: moves between the steps (disabled steps are skipped). Without it the steps aren't Tab stops.
Enter, Space With interactive: makes the focused step current (nothing on the current step)

Accessibility

  • The indicator is a list and each step a list item, as Carbon's <ul> / <li>.
  • The current step has aria-current="step". After each label, screen readers hear the step's state: "Complete", "Current", "Incomplete" or "Invalid" (in Thai with lang="th").
  • A disabled step's button is disabled and aria-disabled.
  • The indicator shows progress; it doesn't name the task. Put a heading above it, and repeat the current step in text (as "Step 2 of 4" above) for people who don't see the icons.

Unstyled React parts with the same behaviour: Headless Progress indicator.
