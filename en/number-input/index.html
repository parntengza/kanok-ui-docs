Number input

A number input takes a number: a quantity, an amount, a percentage. Carbon's − and + buttons sit at the end of the field, and ↑ / ↓ step from the keyboard.

HTMLReactReact + Tailwind<ui-number-input label="Number of units" name="units" value="1" min="1" max="20"></ui-number-input> <UiNumberInput label="Number of units" name="units" value="1" min={1} max={20} /> <NumberInput label="Number of units" name="units" defaultValue={1} min={1} max={20} />

Use it

HTMLReactReact + Tailwind<script type="module">import '@purpurabog/ui/number-input';</script> <ui-number-input label="Number of units" name="units" min="1" max="20"></ui-number-input> import { UiNumberInput } from '@purpurabog/ui/react'; <UiNumberInput label="Number of units" name="units" min={1} max={20} onChange={(e) => setUnits((e.target as HTMLInputElement).value)} /> import { NumberInput } from '@/components/ui/react-tw/number-input'; <NumberInput label="Number of units" name="units" min={1} max={20} value={units} onChange={setUnits} />
  • The value is text, so the field can be empty: "12", "0.5", or "". The element's valueAsNumber gives the number (NaN while empty).
  • The element fires input on every keystroke or step, and change when the value is committed (leaving the field, Enter, a step). The React wrapper has onInput and onChange.
  • The React + Tailwind onChange gets the new value as text, not an event.

Step, minimum and maximum

step (1 by default) is how far − / + and ↑ / ↓ move. A step stays within min and max, and the button at the end of the range turns off. A value typed outside the range is an error.

From an empty field, the first step goes to step-start-value if you set one; otherwise to min when only a minimum is set, else to 1 or −1, as in Carbon.

HTMLReactReact + Tailwind<ui-number-input label="Rent increase" name="increase" value="3" min="0" max="10" step="0.5" suffix-text="%"></ui-number-input> <ui-number-input label="Floor" name="floor" min="1" step-start-value="10"></ui-number-input> <UiNumberInput label="Rent increase" name="increase" value="3" min={0} max={10} step={0.5} suffixText="%" /> <UiNumberInput label="Floor" name="floor" min={1} stepStartValue={10} /> <NumberInput label="Rent increase" name="increase" defaultValue={3} min={0} max={10} step={0.5} suffixText="%" /> <NumberInput label="Floor" name="floor" min={1} stepStartValue={10} />

Decimals

A step rounds to the decimals of the value or of step, whichever has more, so 0.1 + 0.2 shows 0.3, not 0.30000000000000004. With the default type="number", step is also the precision the browser accepts: with step="0.01", 12.345 is an error.

HTMLReactReact + Tailwind<ui-number-input label="Interest rate" name="rate" value="2.75" step="0.01" min="0" suffix-text="% a year"></ui-number-input> <UiNumberInput label="Interest rate" name="rate" value="2.75" step={0.01} min={0} suffixText="% a year" /> <NumberInput label="Interest rate" name="rate" defaultValue="2.75" step={0.01} min={0} suffixText="% a year" />

Currency, units and number formats

prefix-text and suffix-text put text inside the field, before or after the number: ฿, kg, baht a month. They stay in view while the user types and aren't part of the value. They have no Carbon counterpart.

For Carbon's formatted field, set type="text" with format-options, which takes any Intl.NumberFormat options: thousands separators, currency, percent, units. The text is free while the user types and is formatted when they leave. The value stays a plain number: ฿1,234.50 submits 1234.5, and a percent style gives the fraction (0.5 for 50%). The locale is the page language, or locale.

HTMLReactReact + Tailwind<ui-number-input label="Deposit" name="deposit" value="45000" min="0" prefix-text="฿"></ui-number-input> <ui-number-input label="Monthly rent" name="rent" type="text" value="18500" format-options='{"style":"currency","currency":"THB"}'></ui-number-input> <UiNumberInput label="Deposit" name="deposit" value="45000" min={0} prefixText="฿" /> <UiNumberInput label="Monthly rent" name="rent" type="text" value="18500" formatOptions={{ style: 'currency', currency: 'THB' }} /> <NumberInput label="Deposit" name="deposit" defaultValue={45000} min={0} prefixText="฿" /> <NumberInput label="Monthly rent" name="rent" type="text" defaultValue={18500} formatOptions={{ style: 'currency', currency: 'THB' }} />

Percent and units

With format-options, the percent sign or the unit is part of the formatted text, which is Carbon's way. A percent style stores the fraction: 7.5% is 0.075, so give step, min and max as fractions too. locale picks the number format when it must not follow the page.

HTMLReactReact + Tailwind<ui-number-input label="Discount" name="discount" type="text" value="0.075" step="0.005" min="0" max="1" format-options='{"style":"percent","maximumFractionDigits":1}' helper-text="7.5% submits 0.075"></ui-number-input> <ui-number-input label="Cargo weight" name="weight" type="text" value="1250.5" step="0.5" min="0" format-options='{"style":"unit","unit":"kilogram"}'></ui-number-input> <UiNumberInput label="Discount" name="discount" type="text" value="0.075" step={0.005} min={0} max={1} formatOptions={{ style: 'percent', maximumFractionDigits: 1 }} helperText="7.5% submits 0.075" /> <UiNumberInput label="Cargo weight" name="weight" type="text" value="1250.5" step={0.5} min={0} formatOptions={{ style: 'unit', unit: 'kilogram' }} /> <NumberInput label="Discount" name="discount" type="text" defaultValue={0.075} step={0.005} min={0} max={1} formatOptions={{ style: 'percent', maximumFractionDigits: 1 }} helperText="7.5% submits 0.075" /> <NumberInput label="Cargo weight" name="weight" type="text" defaultValue={1250.5} step={0.5} min={0} formatOptions={{ style: 'unit', unit: 'kilogram' }} />

Empty fields

As in Carbon, an empty number input counts as missing, even without required: the form won't submit until there is a number. Set allow-empty on a field that may stay empty.

HTMLReactReact + Tailwind<ui-number-input label="Parking spaces (optional)" name="parking" min="0" allow-empty></ui-number-input> <UiNumberInput label="Parking spaces (optional)" name="parking" min={0} allowEmpty /> <NumberInput label="Parking spaces (optional)" name="parking" min={0} allowEmpty />

Steppers and the mouse wheel

  • hide-steppers removes the − / + buttons; ↑ / ↓ still step.
  • disable-wheel stops the mouse wheel from changing a focused field, which is easy to do by accident while scrolling a long form.
  • decrement-label and increment-label rename the buttons for screen readers ("Decrement number" and "Increment number" by default, translated).
HTMLReactReact + Tailwind<ui-number-input label="Year built" name="year" value="2019" min="1900" max="2026" hide-steppers disable-wheel></ui-number-input> <UiNumberInput label="Year built" name="year" value="2019" min={1900} max={2026} hideSteppers disableWheel /> <NumberInput label="Year built" name="year" defaultValue={2019} min={1900} max={2026} hideSteppers disableWheel />

Sizes, messages, read-only and disabled

  • size: sm 32px, md 40px (the default), lg 48px.
  • helper-text, warn + warn-text and invalid + invalid-text work as on the text input. A value outside min / max gets the browser's or the built-in message unless you set invalid-text. More in Forms and validation.
  • readonly shows and submits the number, and the steppers turn off. disabled greys it out; it isn't submitted.
HTMLReactReact + Tailwind<ui-number-input label="Guests" name="guests" value="12" warn warn-text="The room seats 10"></ui-number-input> <ui-number-input label="Team size" name="team" value="42" min="1" max="30" invalid invalid-text="At most 30 people"></ui-number-input> <ui-number-input label="Contract length" name="months" value="24" suffix-text="months" readonly></ui-number-input> <ui-number-input label="Floors" name="floors" value="3" size="sm" disabled></ui-number-input> <UiNumberInput label="Guests" name="guests" value="12" warn warnText="The room seats 10" /> <UiNumberInput label="Team size" name="team" value="42" min={1} max={30} invalid invalidText="At most 30 people" /> <UiNumberInput label="Contract length" name="months" value="24" suffixText="months" readonly /> <UiNumberInput label="Floors" name="floors" value="3" size="sm" disabled /> <NumberInput label="Guests" name="guests" defaultValue={12} warn warnText="The room seats 10" /> <NumberInput label="Team size" name="team" defaultValue={42} min={1} max={30} invalid invalidText="At most 30 people" /> <NumberInput label="Contract length" name="months" defaultValue={24} suffixText="months" readOnly /> <NumberInput label="Floors" name="floors" defaultValue={3} size="sm" disabled />

Fluid

fluid (Carbon's FluidNumberInput), or a <ui-fluid-form> around the field, puts the label inside a 64px box; an error or a warning shows inside the box, and there is no helper text. See fluid forms.

HTMLReactReact + Tailwind<ui-number-input label="Monthly rent" name="rent" value="18500" min="0" step="500" prefix-text="฿" fluid></ui-number-input> <UiNumberInput label="Monthly rent" name="rent" value="18500" min={0} step={500} prefixText="฿" fluid /> <NumberInput label="Monthly rent" name="rent" defaultValue={18500} min={0} step={500} prefixText="฿" fluid />

Outlined (Kanok design)

In the Kanok design, fields are filled by default: a soft grey fill, no edge. Put data-field-variant="outlined" on an element around the field (a <form>, or <html> for the whole app) for a 1px edge on no fill; focus is still the soft blue halo. The attribute does nothing in the Carbon design, so the example below sits inside data-design="kanok". See Kanok design for the details.

HTMLReactReact + Tailwind<div data-design="kanok" data-theme="paper" data-field-variant="outlined"> <ui-number-input label="Number of units" name="units" value="1" min="1" max="20"></ui-number-input> </div> <div data-field-variant="outlined"> <UiNumberInput label="Number of units" name="units" value="1" min={1} max={20} /> </div> <div data-field-variant="outlined"> <NumberInput label="Number of units" name="units" defaultValue={1} min={1} max={20} /> </div>

Work out a total

Listen to input to update a total on every keystroke and every step. valueAsNumber gives the number, or NaN while the field is empty.

Total:

HTMLReactReact + Tailwind<ui-number-input id="number-input-qty" label="Units" name="qty" value="2" min="1" max="50"></ui-number-input> <ui-number-input id="number-input-price" label="Price per unit" name="price" value="1500" min="0" step="100" prefix-text="฿"></ui-number-input> <p>Total: <output id="number-input-total"></output></p> <script type="module"> const qty = document.getElementById('number-input-qty'); const price = document.getElementById('number-input-price'); const baht = new Intl.NumberFormat('en', { style: 'currency', currency: 'THB' }); const update = () => { const total = qty.valueAsNumber * price.valueAsNumber; document.getElementById('number-input-total').textContent = Number.isNaN(total) ? '–' : baht.format(total); }; qty.addEventListener('input', update); price.addEventListener('input', update); update(); </script> <UiNumberInput label="Units" name="qty" value={qty} min={1} max={50} onInput={(e) => setQty((e.target as HTMLInputElement).value)} /> <UiNumberInput label="Price per unit" name="price" value={price} min={0} step={100} prefixText="฿" onInput={(e) => setPrice((e.target as HTMLInputElement).value)} /> <p>Total: {baht.format(Number(qty) * Number(price))}</p> <NumberInput label="Units" name="qty" value={qty} min={1} max={50} onChange={setQty} /> <NumberInput label="Price per unit" name="price" value={price} min={0} step={100} prefixText="฿" onChange={setPrice} /> <p>Total: {baht.format(Number(qty) * Number(price))}</p>

In a form

With a name, the field submits a plain number: the formatted rent ฿18,500.00 below submits 18500. A value outside min / max, or an empty field without allow-empty, blocks the submit and shows its error. Try 72 months.

Skeleton

While the data of a form loads, <ui-number-input-skeleton> keeps the field's place: a label bar and a field bar at its size, or a fluid box with fluid. Screen readers skip it, so say "loading" on the form (for example aria-busy="true").

HTMLReactReact + Tailwind<ui-number-input-skeleton></ui-number-input-skeleton> <ui-number-input-skeleton fluid></ui-number-input-skeleton> import { UiNumberInputSkeleton } from '@purpurabog/ui/react'; <UiNumberInputSkeleton /> <UiNumberInputSkeleton fluid /> import { NumberInputSkeleton } from '@/components/ui/react-tw/number-input'; <NumberInputSkeleton /> <NumberInputSkeleton fluid />

Keyboard

Key What it does
↑ / ↓ One step up or down, within min / max
Enter Commits the value and submits the form the field sits in

The − / + buttons are out of the Tab order, as in Carbon: the arrow keys do the same from the field.

Accessibility

  • The label is a real <label> for the inner <input>; the prefix, the suffix and the message line are its description.
  • The − / + buttons have names ("Decrement number", "Increment number") and turn off at the end of the range.
  • inputmode="decimal" brings up a keyboard with a decimal point on phones.

Unstyled React parts with the same behaviour: Headless Number input.
