Skeleton

A skeleton is a grey placeholder in the shape of the content to come, shown while a page loads its data for the first time. <ui-skeleton> draws text lines, a heading, a field, a button or a block. Most components also have their own skeleton element; see the index at the end.

HTMLReactReact + Tailwind<div aria-busy="true" style="display: grid; gap: 16px; max-width: 480px"> <ui-skeleton shape="heading"></ui-skeleton> <ui-skeleton lines="3"></ui-skeleton> <ui-skeleton shape="field"></ui-skeleton> <ui-skeleton shape="button"></ui-skeleton> </div> <div aria-busy="true"> <UiSkeleton shape="heading" /> <UiSkeleton lines={3} /> <UiSkeleton shape="field" /> <UiSkeleton shape="button" /> </div> <div aria-busy="true"> <Skeleton shape="heading" /> <Skeleton lines={3} /> <Skeleton shape="field" /> <Skeleton shape="button" /> </div>

Use it

HTMLReactReact + Tailwind<script type="module">import '@purpurabog/ui/skeleton';</script> <ui-skeleton lines="2"></ui-skeleton> import { UiSkeleton } from '@purpurabog/ui/react'; <UiSkeleton lines={2} /> import { Skeleton } from '@/components/ui/react-tw/skeleton'; <Skeleton lines={2} />

Skeleton or loading?

Use a skeleton for the first load of a page, when you know the layout of what is coming: the page appears at once and the content fills in. Use Loading or Inline loading when the user waits for an action, such as saving, and a skeleton would hide what they were working on.

Text lines

shape="text" (the default) draws lines bars, 3 by default. The last of several lines is shorter, so it reads as a paragraph.

HTMLReactReact + Tailwind<div style="display: grid; gap: 24px; max-width: 480px"> <ui-skeleton lines="1"></ui-skeleton> <ui-skeleton lines="4"></ui-skeleton> </div> <UiSkeleton lines={1} /> <UiSkeleton lines={4} /> <Skeleton lines={1} /> <Skeleton lines={4} />

Heading

shape="heading" is one 24px bar, half the width by default.

HTMLReactReact + Tailwind<div style="display: grid; gap: 16px; max-width: 480px"> <ui-skeleton shape="heading"></ui-skeleton> <ui-skeleton lines="2"></ui-skeleton> </div> <UiSkeleton shape="heading" /> <UiSkeleton lines={2} /> <Skeleton shape="heading" /> <Skeleton lines={2} />

Field and button

shape="field" is a short label bar above a 48px field bar. shape="button" is a 48px bar, 120px wide, that sits inline. For a real field or button, prefer its own skeleton element (see the index below), which matches its size.

HTMLReactReact + Tailwind<div style="display: grid; gap: 16px; max-width: 480px"> <ui-skeleton shape="field"></ui-skeleton> <ui-skeleton shape="field"></ui-skeleton> <div style="display: flex; flex-wrap: wrap; gap: 16px; align-items: center"> <ui-skeleton shape="button"></ui-skeleton> <ui-skeleton shape="button"></ui-skeleton> </div> </div> <UiSkeleton shape="field" /> <UiSkeleton shape="field" /> <UiSkeleton shape="button" /> <UiSkeleton shape="button" /> <Skeleton shape="field" /> <Skeleton shape="field" /> <Skeleton shape="button" /> <Skeleton shape="button" />

Placeholder block

shape="block" is one bar, 160px high by default, for an image, a chart or a whole card (Carbon's SkeletonPlaceholder). Set the height with the --ui-skeleton-height CSS property (height in React + Tailwind).

HTMLReactReact + Tailwind<div style="display: grid; grid-template-columns: repeat(auto-fill, minmax(160px, 1fr)); gap: 16px; max-width: 520px"> <ui-skeleton shape="block"></ui-skeleton> <ui-skeleton shape="block" style="--ui-skeleton-height: 96px"></ui-skeleton> </div> <UiSkeleton shape="block" /> <UiSkeleton shape="block" style={{ '--ui-skeleton-height': '96px' } as CSSProperties} /> <Skeleton shape="block" /> <Skeleton shape="block" height="96px" />

Width

Every shape is full width by default (a heading half, a button 120px). Set the width with the --ui-skeleton-width CSS property (width in React + Tailwind), so the placeholder looks like the content to come. Give it with its unit ("200px", "70%"); width and height take strings, as Carbon's SkeletonText width.

HTMLReactReact + Tailwind<div style="display: grid; gap: 16px; max-width: 480px"> <ui-skeleton shape="heading" style="--ui-skeleton-width: 200px"></ui-skeleton> <ui-skeleton lines="1" style="--ui-skeleton-width: 70%"></ui-skeleton> <ui-skeleton shape="button" style="--ui-skeleton-width: 160px"></ui-skeleton> </div> <UiSkeleton shape="heading" style={{ '--ui-skeleton-width': '200px' } as CSSProperties} /> <UiSkeleton lines={1} style={{ '--ui-skeleton-width': '70%' } as CSSProperties} /> <UiSkeleton shape="button" style={{ '--ui-skeleton-width': '160px' } as CSSProperties} /> <Skeleton shape="heading" width="200px" /> <Skeleton lines={1} width="70%" /> <Skeleton shape="button" width="160px" />

In React + Tailwind, give width and height with their unit, as strings: they set CSS properties, and a bare number has no unit there.

Swap it for the content

Skeletons are hidden from screen readers. Tell them about the load on the container instead: aria-busy="true" while it loads, and a short status message. When the data arrives, put the content in place and drop both.

Component skeletons

Most components have a skeleton element in their own shape and size, as Carbon's TextInputSkeleton, DropdownSkeleton and so on. Each has its own import, @purpurabog/ui/<component>-skeleton. Each has a React wrapper named after it in @purpurabog/ui/react (UiTextInputSkeleton, UiDropdownSkeleton …). React + Tailwind has a …Skeleton component next to each component.

Fluid field skeletons

The field skeletons take fluid for the skeleton of a fluid field: a 64px box with two bars. Inside <ui-fluid-form> (FluidForm in React + Tailwind) they are fluid without the attribute. The time picker skeleton is always fluid, as Carbon has only that one.

Accessibility

  • Every skeleton is hidden from screen readers (aria-hidden) and never takes focus.
  • Say "loading" on the container: aria-busy="true" and a short status message, such as a role="status" "Loading contracts…". Drop both when the content arrives.
  • The bars have Carbon's 3-second shimmer; under prefers-reduced-motion it stops.
