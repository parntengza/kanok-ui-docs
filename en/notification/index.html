Notification

A notification tells the user about a change or a problem: a file that failed to upload, a draft that was restored, a policy that applies to the page. One element covers Carbon's inline, actionable, toast and callout notifications. For toasts that stack in the corner of the screen, see Toast.

HTMLReactReact + Tailwind<ui-notification kind="error" heading="Upload failed" subtitle="contract.pdf is larger than 25 MB."></ui-notification> <UiNotification kind="error" heading="Upload failed" subtitle="contract.pdf is larger than 25 MB." /> <Notification kind="error" title="Upload failed" subtitle="contract.pdf is larger than 25 MB." />

Use it

HTMLReactReact + Tailwind<script type="module">import '@purpurabog/ui/notification';</script> <ui-notification kind="success" heading="Contract sent" subtitle="3 signers were notified."></ui-notification> import { UiNotification } from '@purpurabog/ui/react'; <UiNotification kind="success" heading="Contract sent" subtitle="3 signers were notified." /> import { Notification } from '@/components/ui/react-tw/notification'; <Notification kind="success" title="Contract sent" subtitle="3 signers were notified." />

heading is the bold title (title in React + Tailwind) and subtitle the text after it. The default kind is error, so always set it. An inline notification is 288px to 832px wide, depending on the screen.

Kinds

kind sets the colour and the icon: error, success, info, info-square, warning and warning-alt.

Low contrast

A notification is dark (the inverse surface) by default. low-contrast gives it a light tint of its kind with a thin border instead, which sits more quietly in a form.

HTMLReactReact + Tailwind<ui-notification kind="info" low-contrast heading="Auto-save is on" subtitle="Changes are saved every minute."></ui-notification> <ui-notification kind="warning" low-contrast heading="Owner on leave" subtitle="Ananya P. is away until 20 October."></ui-notification> <UiNotification kind="info" lowContrast heading="Auto-save is on" subtitle="Changes are saved every minute." /> <UiNotification kind="warning" lowContrast heading="Owner on leave" subtitle="Ananya P. is away until 20 October." /> <Notification kind="info" lowContrast title="Auto-save is on" subtitle="Changes are saved every minute." /> <Notification kind="warning" lowContrast title="Owner on leave" subtitle="Ananya P. is away until 20 October." />

Links and other content

When the title or subtitle needs markup, put it in slot="title" or slot="subtitle". Anything without a slot goes after the subtitle: a link, a short list. React + Tailwind takes markup in title and subtitle, and extra content as children.

Not paid yet for CT-2026-0142. Pay now
HTMLReactReact + Tailwind<ui-notification kind="warning" low-contrast heading="Stamp duty"> <span slot="subtitle">Not paid yet for <strong>CT-2026-0142</strong>.</span> <a href="#notification-pay">Pay now</a> </ui-notification> <UiNotification kind="warning" lowContrast heading="Stamp duty"> <span slot="subtitle">Not paid yet for <strong>CT-2026-0142</strong>.</span> <a href="/stamp-duty">Pay now</a> </UiNotification> <Notification kind="warning" lowContrast title="Stamp duty" subtitle={<>Not paid yet for <strong>CT-2026-0142</strong>.</>}> <a href="/stamp-duty">Pay now</a> </Notification>

With an action

action-label adds a button for one quick action, such as Undo or Retry (Carbon's actionable notification). Pressing it fires ui-action; it doesn't close the notification. An actionable notification becomes an alertdialog: when it appears, focus moves to the action button, Tab goes round its own controls, and Esc closes it while focus is inside it (as Carbon: an Esc meant for something else, such as a modal, leaves it open). Add no-autofocus when it is on the page from the start, as here, so it doesn't take focus from the page.

Action:

close() closes it the way × does; it is described under Closing.

Callout

variant="callout" is a static box of guidance that belongs to the page, not a message about something that just happened. It has no role, no close button and never takes focus. Its action button is described by the title.

Toast look

variant="toast" is the 288px card with a shadow that Carbon uses for toasts: the text stacks, caption adds a small line (often the time), and the action becomes a tertiary button under the text. To show toasts in the corner of the screen and stack them, use the toaster: Toast.

Close after a time

timeout closes the notification by itself after that many milliseconds (reason timeout). The countdown pauses while the pointer is over it or focus is inside it, and a notification with an action never closes by itself, so nobody loses a message they are reading. Hover the toast below to hold it.

Show again
HTMLReactReact + Tailwind<ui-notification id="notification-timeout" variant="toast" kind="info" heading="Saved" subtitle="This closes after 5 seconds." timeout="5000"></ui-notification> <ui-button id="notification-timeout-again" kind="tertiary" size="sm">Show again</ui-button> <script type="module"> const note = document.getElementById('notification-timeout'); document.getElementById('notification-timeout-again').addEventListener('click', () => (note.open = true)); </script> <UiNotification variant="toast" kind="info" heading="Saved" subtitle="This closes after 5 seconds." timeout={5000} /> <Notification variant="toast" kind="info" title="Saved" subtitle="This closes after 5 seconds." timeout={5000} />

Setting open back to true shows it again and starts the countdown afresh.

Full width

full-width lets an inline notification or a callout fill its container instead of stopping at Carbon's widths: a banner across the top of a page or a card. A toast stays 288px.

HTMLReactReact + Tailwind<ui-notification kind="info" low-contrast full-width heading="Scheduled maintenance" subtitle="The contract system is read-only tonight from 22:00 to 23:00."></ui-notification> <UiNotification kind="info" lowContrast fullWidth heading="Scheduled maintenance" subtitle="The contract system is read-only tonight from 22:00 to 23:00." /> <Notification kind="info" lowContrast fullWidth title="Scheduled maintenance" subtitle="The contract system is read-only tonight from 22:00 to 23:00." />

Closing

×, Esc (on an actionable one) and the timeout fire ui-request-close, cancelable, with the reason: close-button, escape or timeout. Unless you call preventDefault(), the notification sets open to false (it stays in the page, hidden) and fires ui-close. If focus was inside it, focus goes back to where it was before. hide-close-button removes × when the message must stay until the problem is fixed.

Without open, the React + Tailwind notification hides itself when it closes.

Errors after a submit

A notification can sum up what blocks a form. It is a polite status by default; role="alert" makes screen readers announce it at once, for an error the user must deal with now. Press Check below.

Keyboard

Key Does
Tab Reaches the content's links, the action button and × in order; in an actionable notification it goes round them
Enter, Space Press the focused button
Esc Closes an actionable notification while focus is inside it (close-on-escape="false" turns it off)

Accessibility

  • The role is status by default (announced politely), none for a callout, and alertdialog with an action, named by the title and described by the subtitle. role sets another, such as alert.
  • Screen readers announce changes inside a live region; a notification added to the page together with its text may not be read. The toaster keeps one region in the page for its toasts, so every toast is announced.
  • The icon is named after the kind ("error icon"); icon-label changes it. × is named "Close notification" in the page language; close-label changes it.
  • Don't put a timeout on a message people need to act on.

Unstyled React parts with the same behaviour: Headless Notification.
