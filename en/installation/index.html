Installation

The package is public on npm. Pick the way that fits your app; you can mix them.

Choose a style

The components come in two styles. Both use the same JavaScript: a style is only a stylesheet.

Style Load On the page
Carbon (the default) tokens.css nothing to add
Kanok (our own design) tokens.css, then kanok.css data-design="kanok" on <html> or on your app's root element
Both, switchable the same two files set or remove data-design at run time
<html data-design="kanok"> <link rel="stylesheet" href="node_modules/@purpurabog/ui/dist/tokens.css" /> <link rel="stylesheet" href="node_modules/@purpurabog/ui/dist/kanok.css" />

Kanok uses the Bai Jamjuree font (Thai and Latin, SIL Open Font License). Install it with npm i @fontsource/bai-jamjuree, then import the weights 400, 500, 600 and 700 (import '@fontsource/bai-jamjuree/400.css'; and so on).

To see the whole site in Kanok, open Settings (the gear in the header) and choose Kanok under Style, or share a link ending in ?design=kanok. More in Kanok design.

Web components (any framework)

npm i @purpurabog/ui lit

Load the design tokens once per page, then the components you use:

<link rel="stylesheet" href="node_modules/@purpurabog/ui/dist/tokens.css" /> <script type="module"> import '@purpurabog/ui'; // every component // or only what you use: import '@purpurabog/ui/date-picker'; </script>

React

React wrappers with typed props and events come with the package. They need @lit/react too (an optional peer dependency, only for @purpurabog/ui/react):

npm i @purpurabog/ui lit @lit/react

Load the tokens once (import '@purpurabog/ui/tokens.css';), then import the wrappers you use from @purpurabog/ui/react.

React + Tailwind with shadcn

Copy a component into your app and edit its classes. Its behaviour (keyboard, focus, ARIA) comes from @purpurabog/ui/headless, which the CLI installs for you.

  1. Your app needs Tailwind v4 and a components.json. If you already use shadcn, add only the registries part:
{ "$schema": "https://ui.shadcn.com/schema.json", "style": "new-york", "rsc": false, "tsx": true, "tailwind": { "config": "", "css": "src/index.css", "baseColor": "neutral", "cssVariables": true, "prefix": "" }, "aliases": { "components": "@/components", "utils": "@/lib/utils", "ui": "@/components/ui", "lib": "@/lib", "hooks": "@/hooks" }, "registries": { "@kanok-ui": { "url": "https://cdn.jsdelivr.net/npm/@purpurabog/ui@latest/registry/{name}.json" } } }

Pin the version in the URL (@purpurabog/ui@0.82.0 instead of @latest) so every copy in your app comes from the same release.

  1. Add components:
npx shadcn@4 add @kanok-ui/tw-select @kanok-ui/tw-button
  1. Import the tokens and the theme after Tailwind in your main CSS:
@import 'tailwindcss'; @import './components/ui/primitives/tokens.css'; @import './components/ui/react-tw/theme.css';

The files land in components/ui/ (under src/ when your app has one).

Unstyled React (headless)

For your own design system: the behaviour without a single class.

npm i @purpurabog/ui react react-dom

State shows as data-* attributes (data-open, data-selected, data-highlighted …) to style on. The parts have their own section: start at Headless.

Use your first component

The same dropdown as a web component, with the React wrapper and with React + Tailwind. Every example on this site comes in these tabs: pick yours once and the other pages follow. The headless version is in Headless.

HTMLReactReact + Tailwind<html lang="th"> <ui-dropdown label="Contract type" name="type" placeholder="Choose a type"> <option value="sale">Sale</option> <option value="lease">Lease</option> </ui-dropdown> import { UiDropdown } from '@purpurabog/ui/react'; <UiDropdown label="Contract type" name="type" placeholder="Choose a type"> <option value="sale">Sale</option> <option value="lease">Lease</option> </UiDropdown> // npx shadcn@4 add @kanok-ui/tw-dropdown import { Dropdown } from '@/components/ui/react-tw/dropdown'; const types = [ { value: 'sale', label: 'Sale' }, { value: 'lease', label: 'Lease' }, ]; <Dropdown label="Contract type" name="type" placeholder="Choose a type" items={types} />

lang on the element or any ancestor sets the language of the built-in text of the web components and the React wrappers (Thai and English are included).
