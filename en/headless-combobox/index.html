Headless Combobox

The Combobox parts give you the behaviour of the styled Combobox with no styles: a text box with role="combobox", a listbox in the top layer that typing narrows or only highlights, the keyboard, the rule for what leaving the field keeps, a clear button and a chevron that are not Tab stops, and a hidden input that submits the value.

You own the markup, the <label>, any helper or error message, the "Searching…" and "No matching items" text, and every style. The parts show their state as data-* attributes for you to style on.

Installation

The headless parts come with the package (there is no shadcn item; the React + Tailwind items are built on them):

npm install @purpurabog/ui import { Combobox } from '@purpurabog/ui/headless';

Use it

import { Combobox } from '@purpurabog/ui/headless'; const provinces = [ { value: 'bkk', label: 'Bangkok' }, { value: 'cnx', label: 'Chiang Mai' }, { value: 'cei', label: 'Chiang Rai' }, { value: 'kkc', label: 'Khon Kaen' }, { value: 'hkt', label: 'Phuket' }, ]; export default function Example() { return ( <div className="grid max-w-xs gap-2"> <Combobox.Root items={provinces} name="province" filter="contains"> <label htmlFor="province" className="text-xs text-ink-muted">Province</label> <Combobox.Anchor className="flex h-10 items-center border-b border-border-strong-1 bg-field-1 hover:bg-field-hover-1 focus-within:outline-2 focus-within:-outline-offset-2 focus-within:outline-focus"> <Combobox.Input id="province" placeholder="Type a province" className="h-full min-w-0 flex-1 bg-transparent ps-4 text-sm text-ink outline-none placeholder:text-ink-placeholder" /> <Combobox.Toggle aria-label="Open" className="group grid h-full w-10 shrink-0 place-items-center text-ink"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current transition-transform group-data-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Combobox.Toggle> </Combobox.Anchor> <Combobox.Popup aria-label="Province" className="max-h-72 overflow-y-auto bg-layer-1 text-sm text-ink shadow-lg"> {(items) => items.map((p) => ('options' in p ? null : ( <Combobox.Option key={p.value} value={p.value} className="cursor-pointer px-4 py-3 text-ink-muted hover:bg-layer-hover-1 data-highlighted:bg-layer-hover-1 data-selected:bg-layer-selected-1 data-selected:text-ink"> {p.label} </Combobox.Option> )))} </Combobox.Popup> </Combobox.Root> </div> ); }

items on Root is every option. Popup calls its children function with the items the typed text keeps (groups kept), so you render only those.

How typing narrows the list

Typing opens the list and highlights the first enabled option whose label contains the text. filter decides whether the other options stay:

filter The list while typing
none (default) Every option stays; only the highlight moves
contains Only options whose label contains the text
starts-with Only options whose label starts with the text

While the text still equals the chosen option's label, the list shows every option.

import { useState } from 'react'; import { Combobox } from '@purpurabog/ui/headless'; type Filter = 'none' | 'contains' | 'starts-with'; const provinces = [ { value: 'cnx', label: 'Chiang Mai' }, { value: 'cei', label: 'Chiang Rai' }, { value: 'msn', label: 'Mae Hong Son' }, { value: 'lpn', label: 'Lamphun' }, { value: 'nan', label: 'Nan' }, ]; export default function Example() { const [filter, setFilter] = useState<Filter>('starts-with'); return ( <div className="grid max-w-xs gap-4"> <label className="grid gap-2 text-xs text-ink-muted"> filter <select value={filter} onChange={(e) => setFilter(e.target.value as Filter)} className="h-8 border-b border-border-strong-1 bg-field-1 px-2 text-sm text-ink focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-focus" > <option value="none">none</option> <option value="contains">contains</option> <option value="starts-with">starts-with</option> </select> </label> <div className="grid gap-2"> <Combobox.Root items={provinces} filter={filter}> <label htmlFor="province-filter" className="text-xs text-ink-muted">Province</label> <Combobox.Anchor className="flex h-10 items-center border-b border-border-strong-1 bg-field-1 hover:bg-field-hover-1 focus-within:outline-2 focus-within:-outline-offset-2 focus-within:outline-focus"> <Combobox.Input id="province-filter" placeholder="Try “ma” or “n”" className="h-full min-w-0 flex-1 bg-transparent ps-4 text-sm text-ink outline-none placeholder:text-ink-placeholder" /> <Combobox.Toggle aria-label="Open" className="group grid h-full w-10 shrink-0 place-items-center text-ink"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current transition-transform group-data-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Combobox.Toggle> </Combobox.Anchor> <Combobox.Popup aria-label="Province" className="max-h-72 overflow-y-auto bg-layer-1 text-sm text-ink shadow-lg"> {(items) => items.map((p) => ('options' in p ? Free text or a listed option

When the user leaves the field, text that exactly matches an enabled option's label picks that option. Other text snaps back to the option chosen before. With allowCustomValue, the typed text becomes the value instead.

import { useState } from 'react'; import { Combobox } from '@purpurabog/ui/headless'; const titles = [ { value: 'Lawyer', label: 'Lawyer' }, { value: 'Paralegal', label: 'Paralegal' }, ]; export default function Example() { const [title, setTitle] = useState(''); return ( <div className="grid max-w-xs gap-2"> <Combobox.Root items={titles} name="title" allowCustomValue onValueChange={setTitle}> <label htmlFor="job-title" className="text-xs text-ink-muted">Job title</label> <Combobox.Anchor className="flex h-10 items-center border-b border-border-strong-1 bg-field-1 hover:bg-field-hover-1 focus-within:outline-2 focus-within:-outline-offset-2 focus-within:outline-focus"> <Combobox.Input id="job-title" placeholder="Pick one or type your own" className="h-full min-w-0 flex-1 bg-transparent ps-4 text-sm text-ink outline-none placeholder:text-ink-placeholder" /> <Combobox.Toggle aria-label="Open" className="group grid h-full w-10 shrink-0 place-items-center text-ink"> <svg viewBox="0 0 16 16" aria-hidden="true" className="size-4 fill-current transition-transform group-data-open:rotate-180"> <path d="M8 11 3 6l.7-.7L8 9.6l4.3-4.3.7.7z" /> </svg> </Combobox.Toggle> </Combobox.Anchor> <Combobox.Popup aria-label="Job title" className="bg-layer-1 text-sm text-ink shadow-lg"> {(items) => items.map((t) => ('options' in t ? null : ( <Combobox.Option key={t.value} value={t.value} className="cursor-pointer px-4 py-3 text-ink-muted hover:bg-layer-hover-1 data-highlighted:bg-layer-hover-1 data-selected:bg-layer-selected-1 data-selected:text-ink"> {t.label} </Combobox.Option> )))} </Combobox.Popup> </Combobox.Root> <p className="text-xs text-ink-muted">Value: {title || '(none)'}</p> </div> ); }

Value

Hold the value yourself with value and onValueChange, or give a starting defaultValue. onValueChange fires when the value changes: a pick, a committed text, a clear. When value changes from outside, the text box shows the new choice's label.

Search on a server

onInputValueChange gets the text each time the user types. Fetch the matches, replace items, and set loading while the request runs: the popup then has aria-busy. Keep filter="none" (the default), as the server has already filtered.

The parts draw no "Searching…" or "No matching items" text. Combobox.useComboboxContext() gives you open, loading and listed (the options the text keeps) to render them:

import { useRef, useState } from 'react'; import { Combobox, type ListOption } from '@purpurabog/ui/headless'; const all = ['Bangkok', 'Chiang Mai', 'Chiang Rai', 'Khon Kaen', 'Nakhon Ratchasima', 'Phuket', 'Songkhla', 'Udon Thani']; // stands in for the server: the cities containing the text, after 600 ms const search = (text: string) => new Promise<ListOption[]>((resolve) => { const found = all.filter((city) => city.toLowerCase().includes(text.trim().toLowerCase())); setTimeout(() => resolve(found.map((city) => ({ value: city, label: city }))), 600); }); function statusText(loading: boolean, count: number) { if (loading) return 'Searching…'; return count === 0 ? 'No matching items' : ''; } function ListStatus() { const { open, loading, listed } = Combobox.useComboboxContext(); return <p role="status" className="min-h-4 text-xs text-ink-muted">{open ? statusText(loading, listed.length) : ''}</p>; } export default function Example() { const [cities, setCities] = useState<ListOption[]>([]); const [loading, setLoading] = useState(false); const latest = useRef(''); const onText = async (text: string) => { latest.current = text; setLoading(true); const found = await search(text); if (latest.current !== text) return; // a newer search is on its way setCities(found); setLoading(false); }; return ( <div className="grid max-w-xs gap-2"> <Combobox.Root items={cities} name="city" loading={loading} onInputValueChange={onText}> <label htmlFor="city" className="text-xs text-ink-muted">City</label> <Combobox.Anchor className="flex h-10 items-center border-b border-border-strong-1 bg-field-1 hover:bg-field-hover-1 focus-within:outline-2 focus-within:-outline-offset-2 focus-within:outline-focus"> <Combobox.Input id="city" placeholder="Type to search" className="h-full min-w-0 flex-1 bg-transparent px-4 text-sm text-ink outline-none placeholder:text-ink-placeholder" /> </Combobox.Anchor> <Combobox.Popup aria-label="City" className="max-h-72 overflow-y-auto bg-layer-1 text-sm text-ink shadow-lg"> {(items) => items.map((c) => ('options' in c ? null : ( <Combobox.Option key={c.value} value={c.value} className="cursor-pointer px-4 py-3 text-ink-muted hover:bg-layer-hover-1 data-highlighted:bg-layer-hover-1 data-selected:bg-layer-selected-1 data-selected:text-ink"> {c.label} </Combobox.Option> )))} </Combobox.Popup> <ListStatus /> </Combobox.Root> </div> ); }

Here search() stands in for the server and answers after a short wait; in your app it fetches the matches, as on Combobox.

Groups and descriptions

Groups are { label, options } in items, and options take description and disabled. Typing only searches the labels. isGroup tells a group from an option in the Popup function:

Esc on a closed list also clears.

Open above, read-only and disabled

  • side="top" on Popup prefers opening above; it flips when there is no room. The list lines up with Anchor and is as wide as it (the Input when there is no Anchor).
  • readOnly makes the input read-only: the keys and clicks don't open the list, and Toggle and Clear are disabled.
  • disabled disables the input, Toggle and Clear.
  • A disabled field renders no hidden input, so it isn't submitted (as a disabled native control). A form reset puts an uncontrolled value and its text back.

Parts

Combobox.Root

Renders no element of its own: its children, then the hidden input when name is set and disabled isn't.

Prop Type Default
items ListItem[] Options and groups { label, options }
value string The chosen value (controlled)
defaultValue string '' The starting value (uncontrolled)
onValueChange (value: string) => void After the value changes: a pick, a committed text, a clear
onInputValueChange (text: string) => void Each time the user types
filter 'none' | 'contains' | 'starts-with' 'none' How typed text narrows the list
allowCustomValue boolean false Keep text that matches no option as the value
loading boolean false The popup is aria-busy
onOpenChange (open: boolean) => void After the list opens or closes
disabled boolean false Disables the input, Toggle and Clear
readOnly boolean false The text and the value can't change
required boolean false aria-required on the input
invalid boolean false aria-invalid and data-invalid on the input
name string Submits the value with the form (a hidden input), unless disabled
id string generated The input's id, and the base of the other ids: <id>-list, <id>-opt-<n>. The popup's aria-labelledby points at <id>-label, an id only your own <label> can carry (see Combobox.Popup)

Combobox.useComboboxContext() returns the Root's state (text, value, open, listed, loading, interactive …) to any component inside it.

Combobox.Input

An <input type="text" role="combobox" autocomplete="off">. Its id is Root's id unless you pass one. It takes every input prop except type, role, value, defaultValue, disabled and readOnly, which come from Root.

Attribute When
data-open The list is open
data-disabled Disabled
data-readonly Read-only
data-invalid invalid is set

Combobox.Anchor

A <div> around the input and its buttons. The popup lines up with it and matches its width. No props, no data attributes.

Combobox.Clear

A <button type="button"> with tabIndex={-1} (pass your own to change it). A click empties the text and the value, closes the list and keeps focus in the input. It is disabled while Root is disabled or read-only. Give it an aria-label.

Combobox.Toggle

A <button type="button"> with tabIndex={-1}, aria-expanded and aria-controls. A click opens or closes the list; focus stays in the input. It is disabled while Root is disabled or read-only. Give it an aria-label.

Attribute When
data-open The list is open

Combobox.Popup

A <ul role="listbox" popover="manual"> in the top layer. Its rows render only while the list is open. Its aria-labelledby is <id>-label unless you pass your own; there is no label part, so give it an aria-label or give your <label> that id.

Prop Type Default
children ReactNode | ((items: ListItem[]) => ReactNode) The rows, or a function of the items the typed text keeps
side 'bottom' | 'top' 'bottom' Where the list opens; it flips when there is no room
Attribute When
data-open The list is open
data-side bottom or top: where the list went

Combobox.Option, Group, GroupLabel, GroupOptions

The same parts as in Headless Dropdown: Option is an <li role="option"> with a required value and data-highlighted, data-selected and data-disabled. A click on an enabled option picks it, puts its label in the text box and closes the list.

Keyboard and accessibility

Key Does
Typing Opens the list and highlights the first option containing the text
↓ / ↑ Opens the list on the chosen option (else the first / last); then moves the highlight (no wrap)
Alt+↓ Opens the list without a highlight
Alt+↑ Picks the highlighted option and closes
Enter Picks the highlighted option. With no highlight, picks the first option containing the text (or keeps the text with allowCustomValue)
Esc Closes the list; on a closed list, clears the text and the value
Tab Moves on without picking the highlight; the text is committed or snaps back

The parts set role="combobox", aria-autocomplete="list", aria-expanded, aria-controls, aria-activedescendant, aria-required and aria-invalid on the input, and the listbox and option roles on the list. Focus stays in the input.

You add:

  • A <label htmlFor> for the input, and a name for the popup (aria-label, or a <label> with the id <id>-label).
  • aria-label on Clear and Toggle.
  • Helper and error text, linked with aria-describedby on the input.
  • A role="status" text for "Searching…" and "No matching items", as in the example above.
