Slider

A slider picks a number, or a range between two numbers, from a scale. A number box beside the track lets users type the exact value.

HTMLReactReact + Tailwind<ui-slider label="Volume" name="volume" value="40"></ui-slider> <UiSlider label="Volume" name="volume" value={40} /> <Slider label="Volume" name="volume" defaultValue={40} />

Use it

HTMLReactReact + Tailwind<script type="module">import '@purpurabog/ui/slider';</script> <ui-slider label="Volume" name="volume" value="40"></ui-slider> import { UiSlider } from '@purpurabog/ui/react'; import type { UiSlider as SliderElement } from '@purpurabog/ui'; <UiSlider label="Volume" name="volume" value={volume} onChange={(e) => setVolume((e.target as SliderElement).value)} /> import { Slider } from '@/components/ui/react-tw/slider'; <Slider label="Volume" name="volume" value={volume} onChange={setVolume} />

The web component fires input while the value moves (dragging, keys, typing) and change when it is committed: the pointer released, a key handled, the number box left. In React those are onInput / onChange on UiSlider. The Tailwind Slider calls onChange(value) on every change and onRelease(value) on commits.

Scale and step

min and max set the ends (0 and 100 by default) and step the increment (1). Arrow keys move one step; with Shift they move step-multiplier steps (4 by default). min-label and max-label add a unit after the end numbers.

HTMLReactReact + Tailwind<ui-slider label="Discount" min="0" max="50" step="5" value="10" min-label="%" max-label="%"></ui-slider> <UiSlider label="Discount" min={0} max={50} step={5} value={10} minLabel="%" maxLabel="%" /> <Slider label="Discount" min={0} max={50} step={5} defaultValue={10} minLabel="%" maxLabel="%" />

Format the labels

For more control, the formatLabel property (a function (value, label) => string) formats the end labels and the value screen readers hear. It is a property on the web component and a prop in both React versions. With hide-text-input, the tooltip on the thumb uses it too, so money reads as money.

HTMLReactReact + Tailwind<ui-slider id="slider-budget" label="Training budget" min="0" max="10000" step="100" value="2500" hide-text-input></ui-slider> <ui-slider id="slider-rent" label="Rent per month" min="0" max="50000" step="500" value="8000" value-upper="20000" hide-text-input></ui-slider> <script type="module"> const baht = (value) => `฿${value.toLocaleString('th-TH')}`; document.getElementById('slider-budget').formatLabel = baht; document.getElementById('slider-rent').formatLabel = baht; </script> const baht = (value: number) => `฿${value.toLocaleString('th-TH')}`; <UiSlider label="Training budget" min={0} max={10000} step={100} value={2500} hideTextInput formatLabel={baht} /> <UiSlider label="Rent per month" min={0} max={50000} step={500} value={8000} valueUpper={20000} hideTextInput formatLabel={baht} /> const baht = (value: number) => `฿${value.toLocaleString('th-TH')}`; <Slider label="Training budget" min={0} max={10000} step={100} defaultValue={2500} hideTextInput formatLabel={baht} /> <Slider label="Rent per month" min={0} max={50000} step={500} defaultValue={8000} defaultValueUpper={20000} hideTextInput formatLabel={baht} />

Two handles: a range

Set value-upper and the slider picks a range from value to value-upper. The two thumbs never pass each other, a press on the track moves the nearer one, and each has its own number box: the lower one before the track, the upper one after.

Search from 200 to 600

HTMLReactReact + Tailwind<ui-slider id="slider-price" label="Price" min="0" max="1000" step="10" value="200" value-upper="600" name="min-price" name-upper="max-price"></ui-slider> <p>Search from <output id="slider-price-out">200 to 600</output></p> <script type="module"> const price = document.getElementById('slider-price'); price.addEventListener('change', () => { document.getElementById('slider-price-out').textContent = `${price.value} to ${price.valueUpper}`; }); </script> <UiSlider label="Price" min={0} max={1000} step={10} value={200} valueUpper={600} name="min-price" nameUpper="max-price" onChange={(e) => { const slider = e.target as SliderElement; search(slider.value, slider.valueUpper); }} /> <Slider label="Price" min={0} max={1000} step={10} defaultValue={200} defaultValueUpper={600} name="min-price" nameUpper="max-price" onRelease={(low, high) => search(low, high)} />

The form gets both values: under name-upper for the upper one, or both under name when you leave name-upper out. The thumbs are named "Lower bound" and "Upper bound" after the slider's label; input-label and upper-input-label rename the number boxes.

The number box

The box mirrors the value, and typing changes it:

  • A number in range applies at once, snapped to the nearest step.
  • On blur or Enter, a number outside min / max is clamped to the nearest end. Screen readers hear that it was corrected (corrected-text changes the words; {value} is the typed number).
  • A box that holds no number (cleared, say) shows the error "Enter a number" and blocks submit until it is fixed.

hide-text-input removes the box and shows the value in a tooltip on the thumb instead:

HTMLReactReact + Tailwind<ui-slider label="Brightness" value="70" hide-text-input></ui-slider> <UiSlider label="Brightness" value={70} hideTextInput /> <Slider label="Brightness" defaultValue={70} hideTextInput />

Errors and warnings

invalid with invalid-text shows an error from your own validation and blocks submit; warn with warn-text shows a warning that doesn't. The slider has no helper line.

HTMLReactReact + Tailwind<ui-slider label="Team size" min="1" max="20" value="18" warn warn-text="Rooms hold 15 people."></ui-slider> <ui-slider label="Retention period" min="0" max="120" value="6" max-label=" months" invalid invalid-text="Keep records for at least 12 months."></ui-slider> <UiSlider label="Team size" min={1} max={20} value={18} warn warnText="Rooms hold 15 people." /> <UiSlider label="Retention period" min={0} max={120} value={6} maxLabel=" months" invalid invalidText="Keep records for at least 12 months." /> <Slider label="Team size" min={1} max={20} defaultValue={18} warn warnText="Rooms hold 15 people." /> <Slider label="Retention period" min={0} max={120} defaultValue={6} maxLabel=" months" invalid invalidText="Keep records for at least 12 months." />

How errors show across fields: Forms and validation.

Read-only and disabled

readonly keeps the value and submits it; the thumb can't be moved and the number box can't be edited. A read-only thumb leaves the Tab order unless the box is hidden, so users still reach the value. disabled greys everything out and nothing is submitted.

HTMLReactReact + Tailwind<ui-slider label="Limit" value="30" readonly></ui-slider> <ui-slider label="Limit" value="30" disabled></ui-slider> <UiSlider label="Limit" value={30} readonly /> <UiSlider label="Limit" value={30} disabled /> <Slider label="Limit" defaultValue={30} readOnly /> <Slider label="Limit" defaultValue={30} disabled />

The web component and its React wrapper spell it readonly; React + Tailwind uses readOnly.

Show the value as it moves

Use input to update what depends on the value while the thumb moves, and change to save once it settles. In React + Tailwind those are onChange and onRelease.

In a form

With a name, the slider submits its value with the form; a range also submits name-upper. Form reset puts the thumbs back where they started.

Skeleton

While the page loads its data, show <ui-slider-skeleton> in the slider's place, as Carbon's SliderSkeleton. two-handles (twoHandles in React + Tailwind) draws a range and hide-label leaves out the label bar. It has its own import, @purpurabog/ui/slider-skeleton, and is hidden from screen readers.

HTMLReactReact + Tailwind<ui-slider-skeleton></ui-slider-skeleton> <ui-slider-skeleton two-handles></ui-slider-skeleton> import { UiSliderSkeleton } from '@purpurabog/ui/react'; <UiSliderSkeleton /> <UiSliderSkeleton twoHandles /> import { SliderSkeleton } from '@/components/ui/react-tw/slider'; <SliderSkeleton /> <SliderSkeleton twoHandles />

Keyboard

On a thumb:

Key Does
← / ↓ One step down
→ / ↑ One step up
Shift + arrow step-multiplier steps (4 by default)
Home / End To min / max (in a range, as far as the other thumb allows)

In the number box, Enter commits the typed number.

Accessibility

  • Each thumb is a role="slider" with aria-valuemin, aria-valuemax, aria-valuenow and aria-valuetext, named by the label. In a range each thumb's bounds stop at the other thumb.
  • A click on the label focuses the thumb, as a label focuses a native range input.
  • The number box is a native number input with its own name ("Slider number input", or "Lower bound" / "Upper bound"; input-label and upper-input-label change them).
  • An error sets aria-invalid and is linked with aria-describedby. A clamped number is announced in a polite live region.

Unstyled React parts with the same behaviour: Headless Slider.
