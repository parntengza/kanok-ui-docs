Icons

The components don't ship icons; they take yours in a slot or an icon prop and size and color them. Use Carbon's icons, the set this design system is drawn with: browse them in the IBM UI icon library and install the package for your stack.

Install

Carbon publishes the icons as two packages, both under the Apache-2.0 license. Install the one for your stack; @purpurabog/ui doesn't depend on either.

ReactHTML, Lit and other frameworksnpm install @carbon/icons-react npm install @carbon/icons @carbon/icon-helpers

Find an icon's name

The library shows each icon's name in lowercase with hyphens, such as trash-can. Each package spells it its own way:

In the library React (@carbon/icons-react) Others (@carbon/icons)
add Add @carbon/icons/es/add/16.js
trash-can TrashCan @carbon/icons/es/trash-can/16.js
overflow-menu--horizontal OverflowMenuHorizontal @carbon/icons/es/overflow-menu--horizontal/16.js
chevron--right ChevronRight @carbon/icons/es/chevron--right/16.js

@carbon/icons has a file for each size: 16.js, 20.js, 24.js and 32.js. Some icons are drawn differently at 16px, so pick the size the component shows (see Size and color).

Put an icon in a component

In React, an icon is a component that renders an <svg> and passes other props, such as slot, to it. Without a bundler or in another framework, turn the icon's data into an <svg> with toString from @carbon/icon-helpers. For a static HTML page, use Download SVG in the library and paste the <svg>, as the HTML examples on this site do.

LitJavaScriptReactReact + Tailwindimport { html } from 'lit'; import { unsafeHTML } from 'lit/directives/unsafe-html.js'; import { toString } from '@carbon/icon-helpers'; import Add16 from '@carbon/icons/es/add/16.js'; import TrashCan16 from '@carbon/icons/es/trash-can/16.js'; /** A Carbon icon as markup, with extra attributes such as `slot`. */ const icon = (descriptor, attrs = {}) => unsafeHTML(toString({ ...descriptor, attrs: { ...descriptor.attrs, ...attrs } })); html` <ui-button kind="primary">Add ${icon(Add16, { slot: 'suffix' })}</ui-button> <ui-icon-button label="Delete">${icon(TrashCan16)}</ui-icon-button> `; import { toString } from '@carbon/icon-helpers'; import Add16 from '@carbon/icons/es/add/16.js'; const button = document.querySelector('ui-button'); button.insertAdjacentHTML('beforeend', toString({ ...Add16, attrs: { ...Add16.attrs, slot: 'suffix' } })); import { UiMenuItem, UiOverflowMenu } from '@purpurabog/ui/react'; import { Copy, Edit } from '@carbon/icons-react'; <UiOverflowMenu label="Document options"> <UiMenuItem label="Edit"><Edit slot="icon" /></UiMenuItem> <UiMenuItem label="Duplicate"><Copy slot="icon" /></UiMenuItem> </UiOverflowMenu> import { MenuItem, OverflowMenu } from '@/components/ui/react-tw/menu'; import { Copy, Edit } from '@carbon/icons-react'; <OverflowMenu label="Document options"> <MenuItem label="Edit" icon={<Edit />} /> <MenuItem label="Duplicate" icon={<Copy />} /> </OverflowMenu>

Size and color

The component sets the icon's size: 16px in buttons, menus, tags and the side nav, 20px in the header and in large icon-only tabs, 32px before a page header's title. The width and height an icon comes with don't matter there. Use the icon's own size (size={20} in React, 20.js in @carbon/icons) when the component shows it at 20px or more, so you get the drawing made for that size.

Carbon's icons fill with currentColor, so they take the component's text color, also on hover, when disabled and in every theme. Don't set a fill of your own.

Accessibility

An icon inside a control is decoration: both packages add aria-hidden="true" to an icon without an aria-label. The control carries the name, such as the label of an icon button, which is also its tooltip. Don't give the icon a label as well, or screen readers read the name twice.

An icon that stands alone and means something (a status, for example) needs its own name: pass aria-label (React) or add it to attrs; the icon then gets role="img". For status, the status indicator already has the right icons and names.

Names that clash

Some icon names are also component names, such as Search, Notification or Copy. Rename the icon when you import it. The examples on this site use an Icon suffix:

import { Search as SearchIcon, Notification as NotificationIcon } from '@carbon/icons-react';
